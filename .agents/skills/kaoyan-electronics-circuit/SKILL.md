# 822电路题分析

## 角色定位

本模块只处理“看图、识图、建模、分析”。目标不是泛泛解释电路，而是把电路题转化为 822 可作答的结构。

---

## 输入类型

| 输入 | 处理方式 |
| --- | --- |
| 模电电路图 | 识别器件与偏置，先静态后动态 |
| 数电逻辑图 | 写表达式、真值表或状态关系 |
| 时序电路图 | 写驱动方程、状态方程、状态表 |
| 文字描述电路 | 先重构拓扑，再选择SOP |

---

## 模电分析模板

1. 电路类型识别。
2. 工作区判断。
3. 直流通路与静态工作点：$I_{BQ}$、$I_{CQ}$、$U_{CEQ}$。
4. 交流微变等效。
5. 动态指标：$A_u$、$R_i$、$R_o$。
6. 易错点：负载、电容开短路、反馈、符号方向。

---

## 数电分析模板

1. 电路类型识别。
2. 逻辑表达式或驱动方程。
3. 真值表、状态表或状态图。
4. 功能描述。
5. 自启动/竞争冒险/无效状态检查。
6. 对应SOP和错题标签。

---

## 输出要求

- 先给“电路识别结论”，再展开计算。
- 看不清的元件参数必须显式标注不确定，不硬猜。
- 上传图片时，优先提取题干文字和元件数值。
- 需要做完整题解时，转入 `kaoyan-electronics-sop` 的对应流程。

---

## 常见错因标签

| 标签 | 场景 |
| --- | --- |
| circuit | 拓扑、信号流、反馈路径看错 |
| formula | 增益、状态方程、功率公式写错 |
| state | 状态转换或自启动漏检 |
| condition | 虚短虚断、工作区、饱和/截止条件误用 |
| calculation | 代数和数值计算错误 |
