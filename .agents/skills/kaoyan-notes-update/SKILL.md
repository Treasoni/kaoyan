# 必背/速查笔记补充更新技能（kaoyan-notes-update）

## 技能概述

本技能用于向**必背/速查类聚合笔记**（线代必背知识、高数必背公式、英语速查等）补充、改写或重构内容。

**核心原则（用户明确要求）**：必背笔记是“复习知识点、会做题”用的，**不是背结论**。任何方法/操作类内容都必须是“能理解 + 能启动做题”的，而不是只丢一个公式。

> 📁 六要素骨架模板见 [templates/skeleton-template.md](templates/skeleton-template.md)

---

## 触发条件

### 触发本技能当：
- 用户往必背/速查笔记提供新内容：“看看这部分如何补充进 11.”、“把这个补进必背知识”、“更新速查页”
- 用户提供公式/推导/知识点，要求写进速查聚合页
- 用户指出速查页某节“只有结论/看不懂/就给我一个结论”，要求重写
- 用户要求把笔记“整合/融会贯通”、补横向关联、检查孤立章节

### 不触发本技能当：
- 生成独立知识点笔记（非速查聚合页）→ `kaoyan-math-notes` / 对应科目 notes 模块
- 章节总结 → `chapter-summary`
- 错题记录/重构 → `mistake-*`
- 验证理解、推导 → `understanding`
- 纯计划/进度 → `kaoyan-plan`

## 执行流程

### Step 1 先读，再写

先读取：
1. 用户本次提供的内容（推导/公式/截图）；
2. 必背笔记中目标章节的现状；
3. 该章节的**源笔记**（来源链接）或用户指定的参考笔记。

原则：按“源笔记原句/公式/步骤 → 精简压缩 → 必要补充”的顺序处理，不凭空另写一套表达。

### Step 2 判断内容类型

| 类型 | 判定 | 必背页该放什么 |
|:---|:---|:---|
| 纯公式型 | 本身就是公式卡（如幂零求逆） | 公式 + 口诀 + 一句话理解机制本质；长推导折叠 |
| 结构识别型 | 靠结构模板辨认（三角/爪形/范德蒙德） | 识别模板 + 结构特征 + 识别口诀 |
| 方法操作型 | 是一套解题步骤/方法（消爪法/加边法/求秩） | **必须**：核心思想 + 带中间状态的操作模板 + 易错点 |

### Step 3 组织六要素骨架

按需裁剪，不强行全塞：

**识别特征 → 核心思想 → 操作模板 → 公式 → 口诀 → 易错点**

- 方法操作型：核心思想（为什么这么做）+ 操作模板（分步 + 中间状态：中间矩阵/公式），缺一不可；
- 新内容尽量与既有章节形成对照（如“这是第 11 节 ab 型的升级版”）；
- 长推导放 `> [!note]-` 折叠块，完整例题只留链接回源笔记。

### Step 4 建立横向关联（融会贯通）

- 补 `> [!tip] 关联`，指向相关章节；
- 凡涉及主等价链 / 初等变换贯穿 / 秩贯穿 / 特征值连接，显式写出并对照顶部知识地图；
- 主等价链：$\lvert A\rvert\neq 0 \iff A$ 可逆 $\iff r(A)=n \iff$ 齐次只有零解 $\iff$ 非齐次唯一解。

### Step 5 数学验算

公式、推导、中间步骤、边界情况（分母为 0、$a_i-a=0$ 等）先独立核验再写入，不能“写完再看”。

### Step 6 格式合规

见下方“关键约束”清单。

### Step 7 回读验证

写入后回读目标段落，检查反斜杠、表格管道符、折叠块渲染；确认行内数学使用 `$...$`、块数学使用独立的 `$$...$$`。

## 关键约束

1. **证明/推导类内容**统一使用 `> [!note]-` 单一折叠块（默认折叠，可含 `$$`）；`$$` 前留空行，不要紧跟 `[!type]`。
2. **表格内 LaTeX 绝对值**用 `\lvert A\rvert`，不用 `|A|`、`\Vert`、`\left|`。
3. **长推导和完整例题留在源笔记**，必背页只放压缩后的机制本质；完整例题给 wikilink。
4. **写入含大量 LaTeX/反引号的内容**：用 quoted heredoc（`<<'EOF'`）、外部脚本或占位符；写后立即扫描控制字符（只允许 `\n`、`\r`、`\t`）并回读。
5. **保护已有内容**：不覆盖原结论行、易错提醒、`## 个人笔记` 等个人区块；区块替换用标题边界，不用裸 `---`。
6. **Mermaid**：中文节点/含括号/比较符标签用双引号包裹；避免裸 `<` `<=`。
7. **wikilink** 生成前先用 Glob 确认目标存在。
8. **不把新规则提升到 CLAUDE.md / AGENTS.md**；经验只写入 `.learnings/RULES.md`。
9. **Obsidian 数学分隔符**：行内数学统一使用 `$...$`，块数学使用独立的 `$$...$$`；不要使用 `\(...\)`。
10. **命令层转义**：命令中含 LaTeX 反斜杠时，使用 `String.raw` 配合 quoted heredoc 或外部脚本；禁止把 Markdown/LaTeX 直接放进 JavaScript 普通字符串，并在写入后扫描控制字符。

## 验证清单

- [ ] 数学内容独立验算（含边界）
- [ ] 方法型有「核心思想（为什么）」+「带中间状态的操作模板」
- [ ] 有横向关联（`> [!tip] 关联` 或对照既有章节）
- [ ] 长推导已折叠、完整例题已回源笔记
- [ ] 折叠块/表格/LaTeX 合规
- [ ] 行内数学使用 `$...$`、块数学使用独立的 `$$...$$`，无 `\(...\)`
- [ ] 回读无转义污染、无控制字符
- [ ] 已有结论行与易错提醒未被覆盖

---

## 禁止事项

- 禁止只给公式/结论就收尾（会被用户否回，Pattern-Key: `notes.conclusion_only_reject`）
- 禁止在未读源笔记时凭空另写一套表达
- 禁止覆盖用户已有结论行与易错提醒
- 禁止把完整推导/完整例题整体搬进速查页
- 禁止未经确认修改 `.learnings/RULES.md`
