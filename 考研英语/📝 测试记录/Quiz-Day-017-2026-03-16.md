## 📊 答案速查

| 题号 | 答案 | 解析 |
|------|------|------|
| Q1 | D | critic=批评家，critical=adj. |
| Q2 | B | superior to 是固定搭配，无 than |
| Q3 | B | suffice = 足够（vi.） |
| Q4 | B | resort to 诉诸，求助于 |
| Q5 | C | dubious = 无把握的，可疑的 |
| Q6 | B | be critical of 对...挑剔/批评 |
| Q7 | B | as a last resort 作为最后手段 |
| Q8 | C | be vulnerable to 易受...伤害 |
| Q9 | A | in response to 作为对...回应 |
| Q10 | B | prompt sb to do sth 催促某人做某事 |
| Q11 | B | dramatic 描述变化时 = 巨大的，急剧的 |
| Q12 | B | intelligence agency = 情报机构 |
| Q13 | C | customs duty = 关税 |
| Q14 | C | -proof = 防...的（waterproof 防水） |
| Q15 | C | culture = 培养物（生物/医学术语） |

## 🎯 重点错题类型分析

### 高危易错点
1. **superior to**（不能用 than）⭐⭐⭐
2. **as a last resort**（非 resource）⭐⭐⭐
3. **dramatic** 的僻义"巨大的、急剧的"⭐⭐⭐
4. **intelligence** 的僻义"情报"⭐⭐⭐
