## 三、✍️ 写作词汇库

### 议论文必备（⭐⭐⭐⭐⭐）

**表达"重要性/意义"：**
- significant / significance
- imply / impart
- deserve

**表达"因果关系"：**
- outcome
- incur
- derive from

**表达"趋势/变化"：**
- increase / increasingly / growth
- flourish

### 图表描述词汇（⭐⭐⭐⭐）

- **increase**: increase to/by, significant increase
- **growth**: growth in sth
- **signal**: signal that... (标志)

### 逻辑连接词

- **otherwise**: 否则；除此以外
- **significantly**: 显著地
- **increasingly**: 越来越多地

### 写作升级替换

| 原级表达 | 升级表达 |
|----------|----------|
| important | **significant / of great significance** |
| show | **signify / signal** |
| get/obtain | **derive from** |
| cause | **incur** |
| grow | **flourish** |
| result | **outcome** |
| connect | **link / incorporate** |
| very/extremely | **incredible / literally** |
| proper/suitable | **desirable / become** |
| harm/damage | **impair** |
