## 🔤 前缀/词根专题分析

### 核心发现：约80%单词使用 in-/im-/ir- 否定或向内前缀

本次100个单词中，约80个以 in- 或其变体（il-/im-/ir-）开头，是本日单词表最显著的特征。这批单词分为两大语义类别：

#### 1️⃣ 否定前缀 in-（表示"不/无/非"）

派生模式：in- + 形容词/名词 → 反义派生词

| 前缀变体 | 出现条件 | 示例单词 |
|---------|---------|---------|
| **in-** | 通用（b/p/m/l/r除外） | inaccurate, inadequate, inappropriate, incapable, incomplete, inconclusive, incorrect, indefinite, indefensible, independent, indifferent, ineffective, inefficient, inescapable, inevitable, inexorable, inexpressible, infallible, informal, inhuman, injurious, innate, innumerable, insensitive, insignificant, insufficient, intake, intangible, invalid, involuntary, inarticulate, inborn, inclement, inedible, inexorable, inexpressible, infirm, inglorious, injurious, innermost, insane, insatiable, insensible, insidious, insignificant, insufficient, insurmountable, intact, integral, intellectual, intelligent, intense, intentional, inter-, invisible, inward |
| **ir-** | 后接 r 开头词根 | irregular, irrepressible, irresistible, irresponsible, irrational |
| **im-** | 后接 b/p/m 开头 | (本日未出现，但作为补充：impossible, imperfect, immature) |
| **il-** | 后接 l 开头 | (本日未出现，补充：illegal, illogical, illiterate) |

> 实际在本日单词表中出现的 in- 变体频率：
> - **in-** (通用): ~75词
> - **ir-** (r前): 2词 (irregular, irrepressible)
> - **il- / im-**: 0词

#### 2️⃣ 向内/进入前缀 in-（表示"入/内"）

与否定前缀不同，这类 in- 带有"进入、向内"的空间含义：

| 单词 | 词根 | 字面义 → 实际义 |
|------|------|---------------|
| intake | take(拿) | 拿进来 → 摄入量 |
| infuse | fuse(注入) | 注入 → 灌输 |
| inflate | flat(吹) | 吹进去 → 使膨胀/充气 |
| incite | cite(唤起) | 唤起→煽动 |
| induct | duct(引导) | 引导进入→使就职 |
| inspection | spect(看) | 进去看→检查 |
| insight(ful) | sight(看) | 向内看→洞察(力) |
| innate | nat(出生) | 与生俱来 → 先天的 |
| inborn | born(出生) | 出生时就有 → 天生的 |
| instinct | stinct(刺激) | 内在刺激 → 本能 |
| intrinsic | (来自内在) | 内在的，固有的 |
| intrusion | trus(推) | 推进来 → 闯入 |
| instinct | stinct(刺) | 内在刺痛 → 本能 |
| intuition | tuit(看) | 向内看 → 直觉 |
| inherent | her(粘) | 粘在里面 → 固有的 |
| indigenous | gen(生) | 在当地产生 → 本土的 |
| inter- | (之间) | interpersonal, interactive, etc. |

#### 3️⃣ inter- 前缀族（10词集中出现）

本日单词表有10个 inter- 前缀词，构成第二大词汇群：

**inter- = "between/among"（在...之间，相互）**

| 单词 | 构成方式 | 释义 |
|------|---------|------|
| interpersonal | inter- + personal | 人际的 |
| interactive | inter- + active | 互动的 |
| interdependence | inter- + dependence | 互相依赖 |
| interplay | inter- + play | 相互作用 |
| intermarriage | inter- + marriage | 通婚 |
| interprovincial | inter- + provincial | 省际的 |
| interviewer | inter- + viewer | 面试官 |
| interviewee | inter- + viewee | 被面试者 |
| intrusion | in- (进入) + trus | 闯入 (非inter-) |
| introductory | intro- (向内) + duct | 入门的 (非inter-) |

> **注意**：intrusion 和 introductory 虽以 int- 开头但不属于 inter- 族，前者是 in-(进入) + trus(推)，后者是 intro-(向内) + duct(引导)。仅拼写相似。
