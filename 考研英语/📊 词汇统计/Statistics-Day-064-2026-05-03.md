## 🔤 前缀/词根专题分析

### 核心主题：over- 过度前缀 -- 本日最大词族（14词）

**over-** = "too much, above, beyond"（过度/超越/在上）

本日99词中，over- 前缀族以 **14词** 成为最突出的词族，加上 out- (5词) 和 ob-/op- (8词)，三大O开头前缀共占27词。

---

#### 1️⃣ over- 过度前缀（14词）

over- 是英语中最高产的前缀之一，可附着于动词、名词、形容词。本日词汇覆盖三类用法：

**类型A：over- + 动词 = "过度做..."**

| 单词 | 构成 | 释义 | 反义词 |
|------|------|------|--------|
| overstate | over- + state(陈述) | 夸大 | understate |
| overestimate | over- + estimate(估计) | 高估 | underestimate |
| overpay | over- + pay(支付) | 多付 | underpay |
| overwork | over- + work(工作) | 过度工作 | -- |
| overvalue | over- + value(估价) | 高估 | undervalue |
| overstep | over- + step(跨步) | 逾越 | -- |
| overrule | over- + rule(统治) | 否决 | -- |
| overshadow | over- + shadow(阴影) | 使黯然失色 | -- |

**类型B：over- + 形容词/副词 = "过于..."**

| 单词 | 构成 | 释义 |
|------|------|------|
| overly | over- + -ly | 过于地 |
| overdue | over- + due(到期的) | 过期的/早该发生的 |
| oversize | over- + size(尺寸) | 特大号的 |
| overblown | over- + blown(吹) | 夸张的 |

**类型C：over- + 动词 = "压倒性地"**

| 单词 | 构成 | 释义 |
|------|------|------|
| overwhelmingly | over- + whelm(淹没) + -ingly | 压倒性地 |
| outweigh | over- + weigh(称重) | 重于, 超过 |

> **词源小知识**：`outweigh` 中的 `out-` 实际上是 `over-` 因发音同化变为 `out-` 的变体。outweigh 在词源上属于 `over-` 族而非 `out-` 族（outweigh = "weigh over"）。同理，outnumber, outrun, outgrow 等也属于此族。

---

#### 2️⃣ out- 超越前缀（5词）

**out-** = "beyond, surpass"（超越/超过）

| 单词 | 构成 | 释义 |
|------|------|------|
| outsource | out- + source(来源) | 外包 |
| outcry | out- + cry(喊叫) | 强烈抗议 |
| outlive | out- + live(生活) | 比...活得长 |
| outsize | out- + size(尺寸) | 特大 |
| out-of-town | out- + of + town(城镇) | 外地的 |

> **辨析**：`over-` 强调"过度/超过某一标准"（如 `overestimate` "估计得过高"），而 `out-` 强调"超越/胜过"（如 `outlive` "活得比...长"）。`overstate` vs. `outstrip`：overstate 是"说得过火"，outstrip 是"在程度上超过"，含义相近但构词逻辑不同。

---

#### 3️⃣ ob-/op- 朝向/反对前缀（8词）

**ob-** = "toward, against"（朝向/反对）

| 单词 | 构成 | 释义 |
|------|------|------|
| observer | ob- + serv(保持) + -er | 观察者 |
| opposition | op- + posit(放置) + -ion | 反对 |
| objectionable | ob- + ject(投掷) + -ionable | 令人反感的 |
| observable | ob- + serv(注意) + -able | 可观察的 |
| oppression | op- + press(压) + -ion | 压迫 |
| obtainable | ob- + tain(拿) + -able | 可得到的 |
| obscene | ob- + scene(场景) | 淫秽的 |
| obsess | ob- + sedere(坐) | 使痴迷（"坐在对面" → 占据心神） |

> 注意：`ob-` 的变体 `op-` 出现在 `opposition` 和 `oppression` 中（`ob-` 后接 `p` 开头的词根时同化为 `op-`）。同理还有 `oc-`（occur）、`of-`（offer）、`o-`（omit）等同化变体。

---

#### 4️⃣ per- 贯穿词根（8词）

**per-** = "through, thoroughly"（贯穿/彻底）

| 单词 | 构成 | 释义 |
|------|------|------|
| persistent | per- + sist(站立) | 执着的；持续的（"一直站着"） |
| persistence | per- + sist(站立) + -ence | 毅力 |
| perpetuate | per- + pet(追求) + -uate | 使持续（"一直追求下去"） |
| perceptive | per- + cept(拿) + -ive | 有洞察力的（"完全抓住"） |
| perceptual | per- + cept(拿) + -ual | 知觉的 |
| permissive | per- + miss(发送) + -ive | 放任的（"完全放行"） |
| pernicious | per- + nec(死亡) + -ious | 有害的（"导致彻底毁灭"） |
| performative | per- + form(形成) + -ative | 表述行为的（"彻底完成"） |

> **记忆技巧**：per- 的核心义是"through"（贯穿）。想象一根针穿过布料：一直穿过 → `persistent`（坚持到底），完全穿过 → `perceptive`（看穿本质），让某物穿过 → `permissive`（允许通过）。

---

#### 5️⃣ non- 否定前缀（4词）

**non-** = "not"（否定）

| 单词 | 构成 | 释义 |
|------|------|------|
| nonverbal | non- + verbal(言语的) | 非言语的 |
| non-standard | non- + standard(标准) | 不标准的 |
| non-materialistic | non- + materialistic(物质主义的) | 非物质的 |
| nonconformist | non- + conformist(遵守成规者) | 不墨守成规的人 |

> **辨析**：`non-` vs. `un-` vs. `in-`：`non-` 是最中性的否定前缀（仅仅是"不是"），`un-` 带有"相反"含义，`in-` 则常带"缺乏"义。如 `nonverbal` = "不是言语的"，`unspoken` = "未说出口的（但可以意会）"，`ineffable` = "无法言说的（超出语言范围）"。

## ⚠️ 僻义预警汇总

| 单词 | 常见义 | 考研僻义 | 级别 | 考频 |
|------|--------|---------|------|------|
| persistent | adj. 执着的(褒义) | adj. 持续的(中性/贬义) | 🟡 Warning | 高频 |
| overshadow | vt. 遮暗 | vt. 使相形见绌(抽象义) | 🟡 Warning | 中频 |
| pathway | n. 小路 | n. 途径/路径(抽象义) | 🟡 Warning | 中频 |
| nudge | v./n. 轻推(物理) | v./n. 微调/助推(行为经济学) | 🟡 Warning | 中频 |
| obscene | adj. 淫秽的 | adj. 骇人听闻的/大量的(引申) | 🟢 Notice | 低频 |

> **重点提示**：
> - `persistent` 的"持续的"义在科技/医学语篇中尤为重要：persistent infection（持续性感染）、persistent poverty（长期贫困）
> - `overshadow` 的抽象义远重要于字面义：The achievement overshadowed all previous records.（该成就使之前的纪录黯然失色）
> - `nudge` 在行为经济学中（如《Nudge》一书）已成为专业术语，表示"助推/微调政策"
> - `obscene` 的引申义在考研阅读中偶有出现：obscene profits（暴利）、obscene amounts（巨量）
> - `pathway` 在生物学中常指信号通路：signaling pathway（信号传导通路）
