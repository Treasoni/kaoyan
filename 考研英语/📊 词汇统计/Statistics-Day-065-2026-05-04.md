## 🔤 前缀/词根专题分析

### 核心主题：re- 再次前缀 -- 本日最大词族（22词）

**re-** = "again, back"（再次/返回）

本日100词中，re-前缀族以 **22词** 成为最突出的词族，加上 pro-（17词）和 pre-（10词），三大前缀共占49词。

---

#### 1️⃣ re- 再次前缀（22词）

re- 是英语最高产的前缀之一。本日覆盖三类用法：

**类型A：re- + 动词 = "再/重新做..."**

| 单词 | 构成 | 释义 |
|------|------|------|
| reconsider | re- + consider（考虑） | 重新考虑 |
| regain | re- + gain（获得） | 重新获得 |
| redefine | re- + define（定义） | 重新定义 |
| reconstruct | re- + construct（建造） | 重建 |
| reaffirm | re- + affirm（确认） | 重申 |
| rebuild | re- + build（建造） | 重建 |
| re-evaluate | re- + evaluate（评估） | 重新评估 |
| redirect | re- + direct（指引） | 改变方向 |
| remarry | re- + marry（结婚） | 再婚 |
| renege | re- + neg（否认） | 食言（否认回去） |

**类型B：re- + 名词/形容词 = "再/返回"（抽象化）**

| 单词 | 构成 | 释义 |
|------|------|------|
| relatively | re- + lat（带）+ -ive + -ly | 相对地 |
| renowned | re- + nown（名字） | 著名的 |
| relic | re- + lic（留下） | 遗迹 |
| redundancy | re- + dund（涌动） | 冗余/裁员 |

**类型C：re- 变体或特殊用法**

| 单词 | 构成 | 释义 |
|------|------|------|
| recorder | re- + cord（心）+ -er | 录音机（记在心里） |
| recruitment | re- + cruit（成长） | 招聘（使再成长） |
| reactor | re- + act（反应）+ -or | 反应堆 |
| refutation | re- + fut（打） | 反驳（打回去） |

> **对比**：re- vs. pro- vs. pre-
> - `re-` = "again/back"：时间上的重复或返回（redefine, rebuild）
> - `pro-` = "forward/for"：空间上的向前或赞成（promotion, proficient）
> - `pre-` = "before"：时间上的预先（predictably, prerequisite）

## ✅ 今日学习建议

1. **重点突破 re- 家族**（15分钟）：22个 re- 前缀词是今日最核心的词族。掌握 re- = "again/back" 的构词规律后，可自行推导 recall, repay, rephrase, retell 等同族词。

2. **三大前缀对比速记**（10分钟）：re-（再次）vs. pro-（向前）vs. pre-（之前），注意区分：
   - `re-` = 时间上的重复或返回（regain, rebuild）
   - `pro-` = 空间上的向前或赞成（promote, proficient）
   - `pre-` = 时间上的预先（predict, prerequisite）

3. **pro- 同化变体**（5分钟）：注意 pro- 可变为 pur- 出现在 purport 中。pro- + port → purport（带到前面→声称）。

4. **psych- 词根词**（5分钟）：今日 psychology 词族出现4词（psychological, psychologist, psychoactive, psychedelic），与考研阅读中心理学/脑科学文章密切相关。

   - 行为/态度：prudery（假正经）、quick-witted（机智的）、proclivity（癖性）
