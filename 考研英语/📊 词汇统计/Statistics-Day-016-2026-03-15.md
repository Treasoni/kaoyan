## 📊 词族关联记忆法

### 示例1：pro- 词根族（向前）

```
pro- (向前)
    │
    ├─→ promote (向前移动 → 促进)
    │       └─→ promising (给人承诺的 → 有希望的)
    │       └─→ prominent (向前突出的 → 杰出的)
    │
    ├─→ propose (向前提出 → 提议)
    │       └─→ proposal (提议)
    │       └─→ proposition (主张)
    │
    ├─→ prohibit (挡在前面 → 禁止)
    │
    ├─→ prolong (向前拉长 → 延长)
    │
    └─→ propel (向前推 → 推进)
```

### 示例2：inter- 词根族（之间）

```
inter- (之间)
    │
    ├─→ interpret (在中间传递 → 口译/解释)
    │
    ├─→ international (国家之间的 → 国际的)
    │
    ├─→ internal (在内的 → 内部的)
    │       └─→ interior (内部的)
    │
    ├─→ interest (在中间 → 使关注)
    │       └─→ 僻义：利息
    │
    ├─→ intense (向内极度伸展 → 强烈的)
    │       └─→ intensive (密集的)
    │       └─→ intensity (强度)
    │
    └─→ intend (向内心伸展 → 打算)
            └─→ intention (意图)
```
