## 📋 重点词汇速记

### 高频词组搭配
- **foster creativity** = 培养创造力
- **be hostile to** = 对...敌对
- **exempt from** = 免除...
- **first and foremost** = 首要地
- **at any cost** = 不惜任何代价
- **count on** = 指望；依靠
- **look forward to** = 期待，期望
- **a host of** = 大量的
- **in fragments** = 不完整地
- **by fair means or foul** = 千方百计地

### 易混淆词辨析
| 词对 | 区别 |
|------|------|
| **cosy** vs **cozy** | cosy = 英式拼写；cozy = 美式拼写 |
| **fragrant** vs **fragment** | fragrant = 芳香的；fragment = 碎片 |
| **host** vs **hostage** | host = 主人；hostage = 人质 |
| **intimate** vs **intimidate** | intimate = 亲密的；intimidate = 恐吓 |
| **forth** vs **forward** | forth = 向前(副词)；forward = 向前(可作多种词性) |
