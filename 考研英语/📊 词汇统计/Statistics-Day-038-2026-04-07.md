## 📋 重点词汇速记

### 高频词组搭配
- **cope with** = 处理，应对
- **exceed expectations** = 超出预期
- **in excess of** = 超过
- **at regular intervals** = 每隔一定时间
- **be bound to** = 必然会
- **gut feeling** = 直觉
- **take pride in** = 以...自豪
- **pay tribute to** = 向...致敬
- **coordinate system** = 坐标系
- **monetary policy** = 货币政策

### 易混淆词辨析
| 词对 | 区别 |
|------|------|
| **except** vs **except for** | except 接同类排除；except for 接异类补充 |
| **correspond with** vs **correspond to** | with = 通信/一致；to = 相对应 |
| **bound** vs **boundary** | bound = 界限/跳跃；boundary = 边界线 |
