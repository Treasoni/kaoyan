## 📚 词根词缀分析

### 词根：re-（回/再）
- **recall** = re(回) + call(叫) → 叫回来 → 回忆
- **reconcile** = re(再) + concile(召集) → 再次召集 → 和解
- **rectify** = rect(直) + ify(使) → 使变直 → 纠正
- **redundant** = red(反复) + und(波浪) + ant → 波浪反复涌动 → 过剩

### 词根：via-（道路/通过）
- **via** → 通过
- **viable** = via(道路) + ble(可) → 有路可走的 → 可行的

### 词根：ject-（扔）
- **inject** = in(内) + ject(扔) → 扔进去 → 注射
- 同根词：reject, project, object

### 词根：cogn-（知道）
- **cognitive** = cogn(知道) + itive → 认知的
- 同根词：cognition, recognize
