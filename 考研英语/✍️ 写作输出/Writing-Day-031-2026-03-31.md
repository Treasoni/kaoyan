## 📝 写作词汇替换练习
```

### Task 1: 基础替换
```
将下列句子中的普通词汇替换为今日学习的高级词汇：
```
| 原句 | 替换后 |
|------|--------|
| We need to **fix** this problem. | we need to **rectify** this problem. |
| The two views are **different**. | The two views are **conflicting**. We need to **reconcile** them. |
| This plan is **possible**. | This plan is **viable**. |
| He **broke** the law. | He **violated** the law. |
| The company **fired** many workers. | Many workers were **made redundant**. |
| We need **strong** evidence. | We need **tangible** evidence. |
| Music is a **way** to express feelings. | Music is **a vehicle for** expressing feelings. |
| Too much confidence **causes** disaster. | Overconfidence is **a recipe for disaster**. |
| The industry **contracted** significantly. | The industry **shrank** significantly. |
| He **hid** his disappointment. | He **masked** his disappointment. |
| We should **inject** more funds into the project. | We should **inject** more funds into the project. |

### Task 2: 句子改写
```
使用指定词汇改写下列句子：
```

#### 2.1 使用 "viable" 的僻义
```
**原句**： This business plan can succeed.
```
**改写**： This business plan is **viable**.
```
---

#### 2.2 使用 "reconcile" 的僻义
```
**原句**： We need to make these two theories consistent.
```
**改写**： We need to **reconcile** these two theories.
```
---

#### 2.3 使用 "mask" 的僻义
```
**原句**： She tried to hide her anxiety.
```
**改写**： She tried to **mask** her anxiety.
```
---

#### 2.4 使用 "plant" 的僻义
```
**原句**： They work in a large factory.
```
**改写**： They work in a large manufacturing **plant**.
```
---

#### 2.5 使用 "pitch" 的僻义
```
**原句**： He gave a great sales presentation.
```
**改写**： He made a great sales **pitch**.
```

### Task 3: 汉译英练习
```
将下列中文翻译成英文，使用今日学习的词汇：
```

#### 3.1 基础翻译
```
1. 政府需要**整顿**市场秩序。
   The government needs to **rectify** the market order.
```
2. 我们必须**调和**这两方的利益。
   We must **reconcile** the interests of both parties.
```
3. 这是一个**可行的**解决方案。
   This is a **viable** solution.
```
4. 他的行为**违反**了公司规定。
   His behavior **violuated** company regulations.
```
5. 我们需要**有力证据**来证明这一点。
   We need **tangible** evidence to prove this point.
```
---

#### 3.2 进阶翻译（使用僻义）
```
6. 互联网已成为**传播**知识的重要**工具**。
   The Internet has become an important **vehicle for** spreading knowledge.
```
7. 忽视这些警告是**导致灾难的因素**。
   Ignoring these warnings is **a recipe for disaster**.
```
8. 他试图**掩饰**自己的不安。
   He tried to **mask** his nervousness.
```
9. 这家公司需要向经济**注入**更多资金。
   The company needs to **inject** more funds into the economy.
```
10. 许多工人在这轮裁员中**失业了**。
   Many workers were **made redundant** in this round of layoffs.
```

### Task 4: 写作段落练习
```
使用至少 **5个** 今日学习的词汇，词汇需加粗
```
**练习：关于创新与保护的写作**
```
---

**Innovation vs. Plagiarism**
```
In today's **affluent** society, companies must find **viable** solutions to stay competitive. The **layout** of modern business demands constant innovation. **Pioneers** in every field face a critical challenge: how to protect their innovations while sharing knowledge.
```
When companies **violate** intellectual property rights, the **injury** to innovation is severe. **Pirates** of technology don't just steal products—they steal the incentive to innovate. A **coalition** of industry leaders has formed to **tackle** this problem, arguing that **quota** systems for copyright enforcement need strengthening.
```
**Via** careful **rectification** of IP laws, nations are attempting to **reconcile** the interests of creators and users. The **pitch** from industry is clear: protect innovation, or watch investment **shrink** as creators move elsewhere. **Cognitive** scientists suggest that some **recreation** of ideas is natural—standing on the shoulders of giants is how progress works.
```
---

**词汇使用检查**：
- [x] **affluent** - 富裕的
- [x] **viable** - 可行的
- [x] **layout** - 布局
- [x] **pioneers** - 先驱
- [x] **violate** - 违反
- [x] **injury** - 伤害
- [x] **pirates** - 海盗/盗版者
- [x] **coalition** - 联盟
- [x] **tackle** - 处理
- [x] **quota** - 配额
- [x] **via** - 通过
- [x] **rectification** - 纠正
- [x] **reconcile** - 调和
- [x] **pitch** - 推销
- [x] **shrink** - 收缩
- [x] **cognitive** - 认知的
- [x] **recreation** - 再创造
