## 一、高级词汇替换练习

考研写作中，使用高级词汇替换基础词汇是提分关键。以下从今日词汇中提取可用于写作替换的词汇。

### 1.1 基础词 → 高级替换

| 基础表达 | 高级替换 | 例句 |
|---------|---------|------|
| change | **transform**（改变） | Technology has **transformed** modern society. |
| important | **critical**（关键的） | This is a **critical** issue for all of us. |
| solve | **address**（处理） | We must **address** this problem immediately. |
| use | **utilize**（利用） | We should **utilize** available resources. |
| quick | **agile**（敏捷的） | An **agile** response is essential. |
| big | **substantial**（大量的） | **Substantial** progress has been made. |
| many | **numerous**（众多的） | **Numerous** challenges remain. |
| get better | **enhance**（提升） | We must **enhance** our capabilities. |
| show | **demonstrate**（展示） | The data **demonstrates** this trend. |
| end | **conclude**（结束） | Let me **conclude** with this point. |

## 三、词义辨析练习

### 3.1 animate vs animal vs animation

**题目1**：The documentary about marine ______ is fascinating. (animals / animations)
> **答案**：animals（关于海洋动物的纪录片）

**题目2**：Her ______ spirit made everyone feel welcome. (animated / animal)
> **答案**：animated（她活泼的精神使每个人都感到受欢迎）

**题目3**：The computer ______ brought the characters to life. (animals / animation)
> **答案**：animation（电脑动画使角色栩栩如生）

### 3.2 ancestor vs ancient vs anarchy

**题目4**��The family ______ can be traced back centuries. (ancestors / ancient)
> **答案**：ancestors（家族祖先可以追溯到几个世纪前）

**题目5**：Without rules, there would be ______. (ancient / anarchy)
> **答案**：anarchy（没有规则，就会产生无政府状态）

### 3.3 arbiter vs arbitrary vs arbitration

**题目6**：The judge acted as an ______ in the dispute. (arbiter / arbitrary)
> **答案**：arbiter（法官在争端中充当仲裁人）

**题目7**：His decision seemed completely ______. (arbiter / arbitrary)
> **答案**：arbitrary（他的决定似乎完全武断）

### 3.4 aquatic vs aqua

**题目8**：The ______ plants require special care. (aquatic / aqua)
> **答案**：aquatic（水生植物需要特别照顾）
