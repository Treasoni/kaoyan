## 六、易混淆词组

| 词组 | 辨析要点 |
|------|---------|
| **quiet** vs **quite** | quiet = 安静的(adj.)；quite = 相当(adv.)。拼写差一个字母 |
| **a number of** vs **the number of** | a number of = 许多（谓语复数）；the number of = ...的数量（谓语单数） |
| **no more** vs **no longer** | no more = 不再（强调数量/程度）；no longer = 不再（强调时间） |
| **put on** vs **put up** | put on = 穿上/上演/假装；put up = 建造/举起/提供 |
| **pass away** vs **pass out** | pass away = 去世；pass out = 失去知觉 |
