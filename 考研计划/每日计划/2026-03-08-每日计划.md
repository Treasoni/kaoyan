#### 2. 极限计算（核心）⭐⭐⭐⭐⭐

- [ ] 泰勒公式展开（必须背诵！）
- [ ] 等价无穷小替换规则
- [ ] 洛必达法则的使用条件
- [ ] 夹逼准则的应用

#### 3. 连续与间断（常考）
- [ ] 连续点的定义（三要素）
- [ ] 间断点的分类（第一类/第二类）
- [ ] 闭区间性质（零点定理、介值定理）

### 易错点提醒 ⚠️

1. **泰勒展开阶数不够** → 导致结果错误
2. **等价无穷小加减法误用** → 只能用于乘除！
3. **间断点分类忘记计算左右极限** → 导致分类错误
4. **$1^\infty$ 型极限忘记简化公式** → 计算繁琐
