#### 今日核心收获

**1. 反函数的本质理解** ✅
- 理解了 $f$ 与 $f^{-1}$ 是互为相反的**运算法则**
- 掌握了变量交换的数学惯例（$y$ 作因变量，$x$ 作自变量）
- 明确了定义域限制的重要性：只有一一对应的函数才有反函数

**2. 题型1：求函数表达式 — 整体替换法** ✅
- **核心思路**：将 $f(\square)$ 中的 $\square$ 视为整体
- **配凑技巧**：
  - 含 $x$ 和 $x^3$ → 除以 $x^2$，凑成 $x + \frac{1}{x}$
  - 含 $x$ 和常数 → 凑 $(x + a)^2$ 展开
  - 分式复杂 → 分子分母同除以最高次幂
- **完成练习**：3道专项练习题

**3. 题型2：方程组法求函数** ✅
- **识别技巧**：含有 $f(x)$ 和 $f(\frac{1}{x})$ 或 $f(-x)$ 的关系式
- **常见形式**：
  - $f(x)$ 与 $f(\frac{1}{x})$ → $x \to \frac{1}{x}$ 变换
  - $f(x)$ 与 $f(-x)$ → $x \to -x$ 变换
  - $f(x)$ 与 $f(x-a)$ → $x \to x+a$ 变换
- **完成练习**：3道专项练习题
