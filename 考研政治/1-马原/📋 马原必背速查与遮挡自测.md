## 二、全书「唯一 / 根本 / 标志 / 枢纽 / 核心」高频帽子词总表（单选秒杀库）

| 必考帽子提问 | 标准唯一答案 | 易混对比与避坑 |
| :--- | :--- | :--- |
| 物质的**唯一特性** | **客观实在性**（不以人的意志为转移） | 物质的**根本属性 / 存在方式**是**运动**！ |
| 时间和空间的含义与特性 | **时间**：物质运动的持续性、顺序性，特点是**一维性**；<br>**空间**：物质运动的广延性、伸张性，特点是**三维性**。 | **物质运动总伴随着时空，但时空不是物质的唯一特性**；具体物质形态的时空是有限的，整个物质世界的时空是无限的。 |
| 人类社会存在和发展的**基础** & 自然界与人类社会分化的**历史前提** | **物质生产实践（劳动）** | 意识是**自然界长期发展**的产物，更是**社会历史（劳动）**的产物（社会历史性是决定性因素，语言是意识的物质外壳）。 |
| 客观规律性与主观能动性关系的**黄金两句话** | ① **尊重客观规律**是正确发挥主观能动性的**前提**；<br>② **只有充分发挥主观能动性**，才能正确认识和利用客观规律。 | 正确发挥主观能动性的**根本途径（基本途径）**是**实践**；还要依赖于一定的物质条件和物质手段。 |
| 唯物辩证法的**总特征（总观点）** vs **根本认识方法** | **总特征**：**普遍联系**和**永恒发展**；<br>**根本认识方法**：**矛盾分析法**。 | 唯物辩证法的**实质和核心**是**对立统一规律（矛盾规律）**！ |
| 发展的**实质** | **新事物的产生和旧事物的灭亡** | 区分新旧事物的**根本标志**：**是否符合历史前进方向、是否具有远大前途**（❌ 不是看出现时间先后或一时力量强弱）。 |
| 决定事物性质的是哪两个？ | ① **矛盾的特殊性**（“特立独行”决定事物的不同性质）；<br>② **主要矛盾的主要方面**（“主次分明”决定事物的性质）。 | **主要矛盾**在矛盾体系中居支配地位，对事物发展过程起决定作用；但事物的**性质**主要由**主要矛盾的主要方面**决定！ |
| 矛盾问题的**精髓** vs 马克思主义**活的灵魂** | **矛盾问题的精髓**：**矛盾的普遍性和特殊性（共性与个性、绝对与相对）的辩证关系**；<br>**活的灵魂**：**具体问题具体分析**（以及实事求是）。 | 事物之间**相互作用、相互影响、相互制约**是矛盾的**普遍性**；**构成事物的诸多要素以及事物之间的相互联系**是**系统**概念。 |
| 实践区别于认识的**根本特征** | **直接现实性（客观实在性）** | 实践的**主体**处于**中心**地位；主体能力结构中**知识性因素是首要的能力**。 |
| 检验真理的**唯一标准**为什么是实践？ | 由**真理的本性**（主观与客观相符合）和**实践的特点**（**直接现实性**）共同决定。 | **真理尺度是价值尺度的前提**（❌ 绝不能说价值/主体意义是真理的前提！）。 |
| 社会历史发展的**决定力量** vs 衡量社会进步的**最高标准** | **社会存在中的决定力量**：**物质生产方式**；<br>**最终决定力量 & 衡量社会进步的最高标准**：**生产力**。 | **价值评价的最高标准**：符合社会历史发展客观规律、符合**最广大人民群众的根本利益**。 |
| 生产关系中最基本的、**决定社会性质**的是？ | **生产资料所有制关系** | 上层建筑中居于**主导地位**的是**政治上层建筑**；上层建筑的**核心**是**国家政权**。 |
| 理解政治经济学的**枢纽** | **劳动二重性学说**（具体劳动与抽象劳动） | 马克思主义政经的**基石**是**剩余价值学说**。 |
| 简单商品经济的**基本矛盾** vs 资本主义的**基本矛盾** | **简单商品经济**：**私人劳动和社会劳动的矛盾**；<br>**资本主义**：**生产资料资本主义私人占有和生产社会化的矛盾**。 | 资本主义经济危机的**本质特征**是**生产相对过剩**；爆发的**根本原因**是**资本主义基本矛盾**。 |
| 货币转化为资本的**前提** | **劳动力成为商品** | 劳动力商品价值的**最低界限**是**维持劳动者本人生存所必需的生活资料价值**。 |

## 三、政经计算与判断 8 大黄金公式速查卡（考场单选多选拿满 6 分！）

1. **劳动生产率三行分数公式**：
   $$\text{社会劳动生产率} = \frac{\text{数量}}{\text{总社时}} = \frac{1}{\text{单社时}}$$
   - **使用价值量 $=\text{数量}$**（社会$\uparrow \implies \uparrow$；个人$\uparrow \implies \uparrow$）；
   - **单产品价值 $=\frac{1}{\text{社劳率}}$**（社会$\uparrow \implies \downarrow$；个人$\uparrow \implies \text{不变}$）；
   - **总产品价值 $=\frac{\text{数量}}{\text{社劳率}}$**（社会$\uparrow \implies \text{不变}$；个人$\uparrow \implies \uparrow$）。
2. **商品总价值与新创造价值**：
   $$W = C + V + m, \qquad \text{生产成本 } K = C + V, \qquad \text{工人新创造的价值} = V + m\text{（❌绝不含转移的 }C\text{！）}$$
3. **资本双重划分交叉图**：
   - 按**价值增殖作用**分：**不变资本 $C$**（厂房机器设备 $+$ 原材料种子化肥） vs **可变资本 $V$**（工人工资，剩余价值的唯一源泉）；
   - 按**价值周转方式**分：**固定资本**（仅厂房机器设备） vs **流动资本**（原材料种子化肥 $+$ 可变资本 $V$）。
4. **剩余价值率（剥削率 $m'$） vs 利润率（$p'$）**：
   $$m' = \frac{m}{V} = \frac{\text{剩余劳动时间}}{\text{必要劳动时间}}, \qquad p' = \frac{m}{C + V}\text{（分母为全部预付总资本，恒有 } p' < m'\text{）}$$
5. **年剩余价值量（$M$）与年剩余价值率（$M'$）**：
   $$M = m \cdot n = V \cdot m' \cdot n, \qquad M' = \frac{M}{V} = m' \cdot n\text{（}n\text{ 为一年内可变资本周转次数）}$$
6. **资本有机构成**：
   $$\text{资本有机构成} = C : V\text{（必须是由【技术构成】即机器与工人的物理比例变化所引起的 }C:V\text{ 变化才算数！）}$$
7. **生产价格与垄断价格**：
   $$\text{生产价格} = \text{生产成本 } K(C+V) + \text{平均利润 } \bar{P}$$
   $$\text{垄断价格} = \text{生产成本 } K(C+V) + \text{平均利润 } \bar{P} + \text{垄断利润 } X$$

> 12. 必然寓于偶然之中，科学研究必须**通过大量的偶然现象去揭示背后的必然规律**（❌ 不能说通过必然把握偶然）。因果是前后相继且彼此制约；现象分**真象**（正面表现本质）和**假象**（反面歪曲表现本质，**假象也是客观的**；错觉是主观的）；内容决定形式；现实与可能看有无根据和条件。

> 21. **“具使抽价”**：**具体劳动**创造**使用价值**（**不是唯一源泉**，还需自然界；是交换价值的前提和**物质承担者**）；**抽象劳动**创造**价值**（**是价值的唯一源泉和实体**；是交换价值的**基础**，交换价值是价值的**表现形式**）。
> 22. **社会劳动生产率$\uparrow$**：使用价值（数量）$\uparrow$，单品价值$\downarrow$，总价值**不变**；**个人劳动生产率$\uparrow$**：使用价值（数量）$\uparrow$，单品价值**不变**，总价值$\uparrow$。
> 23. 简单商品经济基本矛盾：**私人劳动与社会劳动的矛盾**（解决唯一途径是**交换**），在资本主义下发展为**生产资料资本主义私人占有与生产社会化的矛盾**。复杂劳动转化为简单劳动是在交换中**✅ 自发实现的**（❌ 非人为计算）。
> 24. 两大基本职能：**价值尺度**（观念货币）和**流通手段**（现实货币）；还债、房租、工资、税款是**支付手段**。价值规律是**商品经济**的规律（❌ 非资本主义特有）。三对积极 vs 消极：调节资源分配 $\leftrightarrow$ **社会资源浪费**；刺激生产力 $\leftrightarrow$ **阻碍技术进步**（保守技术秘密）；调节收入 $\leftrightarrow$ **收入两极分化**。
> 25. **生产关系产生两途径**：小商品经济分化 + **商人和高利贷者**转化；**资本原始积累两途径**：用暴力抢夺农民**土地** + 用暴力抢夺**货币财富**。劳动力价值最低界限：**维持劳动者本人生活所需的生活资料价值**。
> 26. 工人新创造价值 $= V + m$（**❌ 不含转移的 $C$**）。**固定资本** $=$ 厂房机器（属 $C$）；**流动资本** $=$ 原材料（属 $C$）$+$ 可变资本工资 $V$。
> 27. $m' = \frac{m}{V} = \frac{\text{剩时}}{\text{必时}}$；$p' = \frac{m}{C+V}$（分母为总预付资本）；生产价格 $= K(C+V) + \text{平均利润}$；垄断价格 $= K(C+V) + \text{平均利润} + \text{垄断利润}$。**相对剩余价值**以**全社会劳动生产率提高**为条件，是各个资本家竞相追逐**超额剩余价值**（个别企业效率提高）的必然结果。
> 28. 购买阶段（货币资本）对应**实物补偿**；售卖阶段（商品资本）对应**价值补偿**。**资本有机构成（$C:V$）**是由**资本技术构成决定并反映技术构成变化**的资本价值构成。集中两大杠杆：**竞争和信用**。**所有制决定所有权**。
> 29. 国家垄断资本主义形成三大原因（生产力发展、经济危机深化、缓和社会矛盾）**❌ 不包含“社会主义显示优越性”**（那是当代资本主义新变化的原因）。金融资本形成三途径**“资金人”**（资本参与、金融联系、人事参与）。金融寡头统治：经济**“参与制”**、政治**“个人联合”**、社会**政策咨询机构**。
