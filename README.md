### 2. kaoyan-math (数学学习系统)

**版本**: v3.1.0

**核心功能**：
- 📐 LaTeX格式强制：所有公式自动转换为LaTeX
- 🔗 知识点主动关联：AI主动提示跨章节关联
- 💾 MemOS持久化：错题记录永久保存
- 🔢 跨学科关联：数学↔电子技术知识图谱
- 📊 统一错误模型：支持跨技能错题聚合

**数学二覆盖范围**：
- 高等数学
- 线性代数

**笔记格式标准**：
```markdown
# [知识点名称]

## 原始定义
$$ \lim_{x \to x_0} \frac{f(x)}{g(x)} = \lim_{x \to x_0} \frac{f'(x)}{g'(x)} $$

## 定理条件 ⚠️
1. $\lim f(x) = \lim g(x) = 0$ 或 $\infty$
2. $f(x)$ 和 $g(x)$ 在某去心邻域内可导

## 我的错误类型 📌
- 条件遗漏
- 推导跳步
- 计算失误
```

**跨学科关联示例**：
| 数学知识点 | 电子技术应用 | 关联强度 |
|-----------|-------------|---------|
| 复数运算 | 频率响应分析、交流电路 | ⚠️ 必需 |
| 微分方程 | 暂态响应、RC/RL电路 | ⚠️ 必需 |
| 拉普拉斯变换 | s域分析、传递函数 | 高 |

**高频考点清单**：

**模电必考**：
1. 反馈放大器 - 反馈类型判断 + 深度负反馈计算

1. 时序逻辑电路 - 分析与设计

| 夹断电压 | $U_{GS(off)}$ | FET参数 |

## MemOS 记忆系统

所有技能集成 MemOS，实现：

| 功能 | 说明 |
|------|------|
| 💾 用户画像持久化 | 考试日期、目标、作息类型等 |
| 📈 学习进度追踪 | 每日计划执行情况、完成率 |
| 🔗 跨设备同步 | 多设备间学习进度同步 |
| 🛡️ 优雅降级 | MemOS不可用时自动降级为无状态模式 |

**数据存储策略**：

| 数据类型 | 保留策略 |
|----------|----------|
| 用户画像 | 永久保存 |
| 每日计划 | 每日1条current + 多条history |
| 错题记录 | 永久保存 |
| 心理状态 | 最近30天 |

## 关键规则

### 数学笔记生成规范
**生成数学笔记时，必须严格按照高数资料目录（`/Users/zhqznc/Documents/高数资料`）中的章节结构和笔记内容来生成知识点，不得偏离教材体系。**

### 数学和专业课输出规范

**所有公式必须使用LaTeX格式**：

```markdown
# 内联公式
使用 $...$ 格式，如 $f(x) = x^2$

# 独立公式行
使用 $$...$$ 格式
$$
\lim_{x \to x_0} \frac{f(x)}{g(x)} = \lim_{x \to x_0} \frac{f'(x)}{g'(x)}
$$
```

### 技能优先原则

```
kaoyan-plan (中央调度器)
    ↓
kaoyan-math → 数学学习与笔记生成
kaoyan-english → 英语词汇与真题管理
kaoyan-electronics → 电子技术基础学习
```

### 跨学科关联

系统自动识别并关联不同学科的知识点：

- 数学 → 专业课：复数运算 ↔ 频率响应分析
- 数学 → 专业课：微分方程 ↔ 暂态响应
- 数学 → 专业课：积分 ↔ RC充放电
