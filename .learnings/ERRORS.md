## [ERR-20260926-001] notes.index_renumber_scope

**Logged**: 2026-09-26T20:26:57+08:00
**Priority**: medium
**Status**: resolved
**Area**: notes/考研数学/0-基础知识/每天一背.md

### Summary
向《每天一背》按模块位置插入新条目并顺延索引编号时，重排脚本的「行号行」正则匹配到了索引表以外的其它两列表格，被断言拦下。

### Error
脚本用 `^\| (\d+) \| (.+) \|$` 识别索引表行，把正文中同样是「首列为数字、共两列」的表格行也当成索引行参与了 +1 重编号（实际收集到 51 个索引编号后又多出 7 个），断言 `seen == list(range(1, 51))` 立即失败；脚本在落盘前退出，文件未被破坏。

### Context
在 每天一背.md 插入 Tier 2 §2.11「定积分物理应用（微元法总纲）」并同步「📋 条目索引」（插入 #26、原 #26–#50 顺延为 #27–#51）。第一版脚本对整个文件做行号匹配，没有先限定索引表区间。

### Resolution
2026-09-26：改为先定位 `| # | 条目 | 位置 | 复习 |` 表头，再向后找到 `---` 作为表尾，只在 `lines[start:end]` 区间内重编号；写入后回读索引表，确认 #1–#51 连续无重复。教训：批量重排表格行号时，匹配范围必须先限定到该表格区间，并在落盘前用断言校验编号序列完整性。

## [ERR-20261023-003] notes.state_diagram_wrong_bullet

**Logged**: 2026-10-23
**Priority**: medium
**Status**: resolved
**Area**: 考研专业课/数字电子技术/5-锁存器和触发器/06-JK触发器.md

### Summary
JK 状态图读图要点里，把 $J=K=1$ 解释成"属于 J=1 必到 1、K=1 必到 0"两条规则同时成立，读起来像矛盾，实际状态图只画了四条弧，没有"翻转"这条弧。

### Error
初稿写"$J=1$ 必到 1、$K=1$ 必到 0"，没有说明这两句分别以"当前处于 0 态"和"当前处于 1 态"为前提，读者会以为两个条件在同一条弧上冲突。

### Context
状态图的弧是"从某个状态出发"的局部规则，弧上的条件只在其起点状态下有效。

### Resolution
2026-10-23：改写为"从 0 出发只看 J，从 1 出发只看 K；J=K=1 时处在 0 态走 J=1 那条弧到 1，处在 1 态走 K=1 那条弧回 0，两条弧合起来就是翻转"。教训：写状态图文字前先说清"从哪个状态出发"，避免把两条局部规则并列成全局规则。
