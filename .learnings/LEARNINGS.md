## [LRN-20261028-001] notes.power_exponential_no_binomial

**Logged**: 2026-10-28
**Area**: 考研数学/0-基础知识

### 观察
用户在 $(1+x)^{\frac{2}{x}}$ 上重犯同一错 3 次：把**变指数**幂指函数当成**常指数**幂函数 $(1+x)^{\alpha}$，套二项式泰勒展开后令 $\alpha=\frac{2}{x}$，算出 $5-x$ 与真值 $e^2$ 冲突。根因不是计算失误，而是把"公式前提（$\alpha$ 为常数）"当成了可忽略的注解。

### 提炼
- 泰勒展开的每个公式都带**前提条件**，前提不是脚注。写作时把前提写进公式行的同一格里（如"二项式（$\alpha$ 为常数）"），而不是留给读者自己回忆。
- 用户重犯型错误的笔记组织方式：**错法还原 → 为什么绝对不成立（分层次判据）→ 正确路径 → 秒检习惯 → 一眼识别**。只写"正确做法"不足以阻断复发。
- 幂指函数的两侧同源：求导侧 $(x^x)'\neq x\cdot x^{x-1}$（§7.14），展开侧 $(1+x)^{2/x}\neq$ 二项式（§9.3）。两处互相回指，比单点提醒有效。
- 秒检模板：任何展开式令 $x\to0$，**常数项必须等于原函数的极限值**。这一步能在考场上自证对错。

### 已落地
- `每天一背` §4.6 新增「易错专讲」折叠块，索引第 41 行条目名同步；§4.9 二项式行补前提与回指。
- `高数必背公式` §9.3 补推导 + `[!warning]` 陷阱块；§7.14 与 §9.3 双向回指；§10.3 表格补前提。
- `📋 高数必背速查` §三 补 `[!danger]` 陷阱块（秒查层）。

## [LRN-20261102-001] notes.counter_state_naming

**Logged**: 2026-11-02
**Priority**: medium
**Status**: pending
**Area**: 考研专业课/数字电子技术/6-时序逻辑电路/06-计数器.md

### 观察
整理 74161/74160 的 N 进制接法时，初稿写"第 $N$ 个状态 $S_N$"，与本目录既有写法（初态记 $S_0$）冲突：$S_N$ 究竟指"第 $N$ 个状态"还是"第 $N$ 个脉冲之后的状态"会差一拍，直接决定异步清零译码的是 $S_N$ 还是 $S_{N-1}$。

### 提炼
- 计数器状态只按**脉冲计数**命名："第 $k$ 个脉冲之后的状态记 $S_k$"，初态 $S_0$ 是第 0 个脉冲之前/之后都成立的同一个状态。不写"第 N 个状态"。
- 两种 N 进制接法的落点随之固定：异步清零译码 $S_N$（瞬态，只闪现）、主循环 $S_0\sim S_{N-1}$；同步置数译码 $S_{N-1}$（稳态），循环 $M\sim S_{N-1}$。
- 模值公式必须连同两个量的身份一起写：$N=X-M+1$，$X$ 是译码状态、$M$ 是 $D$ 端初值；只写公式会让读者默认 $M=0$。
- 术语要与同章 [[07-常见错误与考点总结]] 一致，跨笔记口径统一才算可读。

**Logged**: 2026-11-02
**Priority**: medium
**Status**: pending
**Area**: 考研专业课/数字电子技术/6-时序逻辑电路/06-计数器.md

### 观察
160/161 对照表初稿把"清零方式"和"置数方式"混在一列里：写 161/160 异步清零、163/162 同步清零时，读者会顺带以为置数方式也跟着变。实际四片芯片**置数全部同步**，清零方式与置数方式是两条独立维度。

### 提炼
- 芯片对照表先定列 = 一个维度（计数进制 / 有效状态 / 进位条件 / 清零方式 / 置数方式），一格只填该维度的值，不同维度不挤进同一格。
- 自检两句话必须能同时验证："161 能异步清零"为真；"161 能异步置数"为假——置数一律等上升沿。
- 新增对照表前先问：这一列回答哪个维度？同一行是否偷偷换了变量？列语义错了，整张表再怎么排版都错。
- 相关：图与表的份工要保持——对照序列用重绘 PNG，原始课件截图只在折叠块里溯源一次，不在正文重复嵌入。
