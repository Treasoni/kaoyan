# 4.5.2 向量组等价常用判据

## 判据 1：相互线性表示

若向量组（I）与向量组（II）可相互线性表示，即（I）与（II）等价，则

$$
r ( \mathrm { I } ) = r ( \mathrm { I I } )
$$

> [!note] 注意
> 秩相等是等价的**必要条件**，但不是充分条件。

## 判据 2：秩相等 + 单侧表出

若向量组（I）可由向量组（II）线性表示，且 $r \big ( \mathrm { I } \big ) = r \big ( \mathrm { I I } \big )$，则向量组（I）与向量组（II）等价。

## 判据 3：三秩相同

若 $r \big ( \mathrm { I } \big ) = r \big ( \mathrm { I I } \big ) = r \big ( \mathrm { I } , \mathrm { I I } \big )$（三秩相同），则向量组（I）与向量组（II）等价。

> [!summary] 核心思想
> - 等价 $\Leftrightarrow$ 相互线性表示
> - "能表出 + 秩相等" → 等价
> - "三秩相同" → 等价
