# 4.5.3 向量组等价常用性质

> [!tip] 快速记忆
> **极大无关组**是向量组的"代表"，等价向量组的"代表"也等价。

---

## 四条核心性质

### 1. 向量组与其任一极大无关组等价

$$\text{向量组} \cong \text{它的任一极大无关组}$$

**为什么？** 因为极大无关组可以线性表出原向量组的每个向量（由定义），而原向量组显然可以线性表出它的子组（极大无关组）。

### 2. 向量组的任意两个极大无关组等价

$$\text{极大无关组}_1 \cong \text{向量组} \cong \text{极大无关组}_2$$

**证明思路**：利用性质 1 + [[4.5.1-向量组等价定义#等价的三个性质|传递性]]

### 3. 等价向量组的极大无关组等价

$$\text{向量组}_A \cong \text{向量组}_B \implies \text{极大无关组}_A \cong \text{极大无关组}_B$$

**证明思路**：
- 由性质 1：$\text{极大无关组}_A \cong \text{向量组}_A$
- 由条件：$\text{向量组}_A \cong \text{向量组}_B$
- 由性质 1：$\text{向量组}_B \cong \text{极大无关组}_B$
- 由传递性得证。

### 4. 等价向量组的秩相等

$$\text{向量组}_A \cong \text{向量组}_B \implies r(A) = r(B)$$

**为什么？** 由性质 3，等价向量组的极大无关组等价，而极大无关组的向量个数就是秩，所以秩相等。

---

## 重要易错点

> [!warning] 易错 1：向量个数不一定相等
> 两个向量组等价，**向量的个数不一定相同**。
>
> **例子**：$\alpha_1 = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$ 与 $\beta_1 = \begin{pmatrix} 1 \\ 0 \end{pmatrix}, \beta_2 = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$
>
> 虽然向量个数不同（1 vs 2），但它们等价（都能互相线性表出）。

---

## 向量组等价 vs 矩阵等价

| 对比项 | 向量组等价 | 矩阵等价 |
|:---:|:---:|:---:|
| **定义** | 互相线性表出 | 存在可逆矩阵 $P, Q$ 使 $B = PAQ$ |
| **核心要求** | 线性表示能力相同 | 行列变换可互化 |
| **秩的关系** | 秩相等 | 秩相等 |
| **充要条件** | $r(A) = r(B) = r(A \mid B)$ | $r(A) = r(B)$ |
| **向量个数** | 可以不同 | 必须相同（同型矩阵） |

> [!important] 记忆口诀
> **向量组等价条件更严**：不仅要秩相等，还要能互相表出（$r(A) = r(B) = r(A \mid B)$）
>
> **矩阵等价条件更松**：只要秩相等就行（$r(A) = r(B)$）

---

## 矩阵乘法 $AB = C$ 的空间本质

> [!tip] 核心视角
> 矩阵乘法不是"数字的堆砌运算"，而是**列向量的线性组合**（左视角）与**行向量的线性组合**（右视角）的统一。

### 视角一：按列分块（看左侧矩阵 $A$）

**结论**：$C$ 的每一列，是 $A$ 的列向量的线性组合（系数取自 $B$ 的对应列）。

设 $A = (\alpha_1, \alpha_2, \cdots, \alpha_n)$，$B$ 和 $C$ 按列分块为 $B = (\beta_1, \beta_2, \cdots, \beta_s)$，$C = (c_1, c_2, \cdots, c_s)$。

$AB = C$ 等价于 $A\beta_i = c_i$（$i = 1, 2, \cdots, s$），展开第一列：

$$c_1 = (\alpha_1, \alpha_2, \cdots, \alpha_n) \begin{pmatrix} b_{11} \\ b_{21} \\ \vdots \\ b_{n1} \end{pmatrix} = b_{11}\alpha_1 + b_{21}\alpha_2 + \cdots + b_{n1}\alpha_n$$

**大白话**：结果矩阵 $C$ 的第 $i$ 列，就是把 $A$ 的所有列拿过来，用 $B$ 的第 $i$ 列的数字做系数，做一次线性组合。

### 视角二：按行分块（看右侧矩阵 $B$）

**结论**：$C$ 的每一行，是 $B$ 的行向量的线性组合（系数取自 $A$ 的对应行）。

设 $B$ 的行向量为 $\beta_1^T, \beta_2^T, \cdots, \beta_n^T$，$C$ 的行向量为 $\gamma_1^T, \gamma_2^T, \cdots, \gamma_m^T$。

单独看 $C$ 的第一行：

$$\gamma_1^T = a_{11}\beta_1^T + a_{12}\beta_2^T + \cdots + a_{1n}\beta_n^T$$

**大白话**：结果矩阵 $C$ 的第 $j$ 行，就是把 $B$ 的所有行拿过来，用 $A$ 的第 $j$ 行的数字做系数，做一次线性组合。

### 黄金口诀：左列右行

> [!important] 四字口诀
> **左列**：$C$ 的**列**，由**左**侧（前）矩阵 $A$ 的列线性组合（系数在 $B$ 中）
>
> **右行**：$C$ 的**行**，由**右**侧（后）矩阵 $B$ 的行线性组合（系数在 $A$ 中）

### 实战推论：秩的不等式

既然 $C$ 的列由 $A$ 的列组合而来，$C$ 的列空间维度不可能超过 $A$ 的列空间维度：

$$r(AB) \leq r(A) \quad \text{且} \quad r(AB) \leq r(B)$$

> [!warning] 注意
> 这就是为什么"向量组等价"的条件比"矩阵等价"更严格——向量组等价要求**互相**线性表出（双向），而矩阵乘法只提供了**单向**的表出关系。

## 常用证明模板

### 证明向量组等价的标准步骤

```
要证：向量组 A ≅ 向量组 B

步骤 1：证明 A 中每个向量可由 B 线性表出
步骤 2：证明 B 中每个向量可由 A 线性表出
步骤 3：由定义，A ≅ B
```

### 证明秩相等的标准步骤

```
要证：r(A) = r(B)

方法 1（直接法）：找出极大无关组，数个数
方法 2（等价法）：证明 A ≅ B → 由性质 4 → r(A) = r(B)
```

## 自测题

> [!question] 检验你的理解
> 1. 向量组 $\alpha_1, \alpha_2, \alpha_3$ 的一个极大无关组是 $\alpha_1, \alpha_2$，问 $r(\alpha_1, \alpha_2, \alpha_3) = ?$
> 2. 若向量组 A 与 B 等价，且 A 有 3 个向量，B 有 5 个向量，能否确定 B 的秩？
> 3. 向量组等价与矩阵等价，在什么条件下是等价的？

> [!success]- 答案
> 1. $r = 2$（极大无关组的向量个数）
> 2. 不能。只知道 $r(B) = r(A)$，但不知道 $r(A)$ 具体是多少
> 3. 当两个矩阵同型且列数相同时，向量组等价 $\iff$ 矩阵等价
