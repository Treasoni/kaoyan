# 4.5.1 向量组等价定义

## 向量组之间的线性表出

如果向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 中每个向量都可由 $\beta _ { 1 } , \beta _ { 2 } , \cdots , \beta _ { t }$ 线性表出，就称向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 可由 $\beta _ { 1 } , \beta _ { 2 } , \cdots , \beta _ { t }$ **线性表出**。

## 向量组等价

如果两个向量组**互相可以线性表出**，就称它们**等价**。

## 等价的三个性质

向量等价具有：
- **反身性**：每组与自身等价
- **对称性**：若 A 与 B 等价，则 B 与 A 等价
- **传递性**：若 A 与 B 等价，B 与 C 等价，则 A 与 C 等价

> [!important] 注意
> 传递性需要引起特别重视，在证明题中经常会用到。
