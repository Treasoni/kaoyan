# 4.4.2 判断极大线性无关组

## 判断标准（三点检查）

判断一个部分组是否为极大无关组，需验证以下三点：
1. **是否是部分组**：选自原向量组
2. **是否线性无关**：该部分组本身线性无关
3. **个数是否满足要求**：所含向量个数等于向量组的秩

## 示例

设 $\left[ \alpha _ { 1 } , \alpha _ { 2 } , \alpha _ { 3 } \right] = \left[ \begin{array} { l l l } { 1 } & { 0 } & { 2 } \\ { 1 } & { 2 } & { 4 } \\ { 1 } & { 5 } & { 7 } \end{array} \right]$，经过初等行变换：

$$
\left[ \alpha _ { 1 } , \alpha _ { 2 } , \alpha _ { 3 } \right] = \left[ \begin{array} { l l l } { 1 } & { 0 } & { 2 } \\ { 1 } & { 2 } & { 4 } \\ { 1 } & { 5 } & { 7 } \end{array} \right] \xrightarrow { ( r ) } \left[ \begin{array} { l l l } { 1 } & { 0 } & { 2 } \\ { 0 } & { 2 } & { 2 } \\ { 0 } & { 0 } & { 0 } \end{array} \right]
$$

故知 $r \big ( \pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } \big ) = 2$，而 $r \big ( { \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , { \pmb { \alpha } } _ { 3 } \big ) = 2$，因此 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 }$ 是向量组的一个极大无关组。

> [!important] 注
> 极大线性无关组**一般不唯一**。上述例子中， $r \left( \alpha _ { 1 } , \alpha _ { 3 } \right) = 2$ 及 $r \big ( \pmb { \alpha } _ { 2 } , \pmb { \alpha } _ { 3 } \big ) = 2$，可知 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 3 }$ 和 ${ \pmb { \alpha } } _ { 2 } , { \pmb { \alpha } } _ { 3 }$ 也都是极大无关组。
