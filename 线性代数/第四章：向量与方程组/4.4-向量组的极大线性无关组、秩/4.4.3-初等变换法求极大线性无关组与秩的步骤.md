# 4.4.3 初等变换法求极大线性无关组、秩的步骤

## 原理

> 初等行变换**不改变**列向量组的线性相关性。

## 步骤

**步骤 1**：对列向量组构成的矩阵 $\pmb { A } = \left( \pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } , \cdots , \pmb { \alpha } _ { s } \right)$ 作初等行变换，化成行阶梯形 $\pmb { { \cal B } } = \left( \pmb { \alpha } _ { 1 } ^ { \prime } , \pmb { \alpha } _ { 2 } ^ { \prime } , \cdots , \pmb { \alpha } _ { s } ^ { \prime } \right)$，行阶梯形 $\pmb { B }$ 的秩就是原矩阵 $\pmb { A }$ 的秩，即向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 的秩；

**步骤 2**：在行阶梯形 $\pmb { { \cal B } } = \left( \pmb { \alpha } _ { 1 } ^ { \prime } , \pmb { \alpha } _ { 2 } ^ { \prime } , \cdots , \pmb { \alpha } _ { s } ^ { \prime } \right)$ 中的每个阶梯抽取一列，记录所在列的序号；

**步骤 3**：在矩阵 $\pmb { A }$ 采取同样的抽取方式，所得到的部分组即为 $\pmb { A } = \left( \pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } , \cdots , \pmb { \alpha } _ { s } \right)$ 的极大无关组。

> [!summary] 一句话总结
> 化行阶梯 → 取主元列 → 在原矩阵中取对应列 → 得极大无关组
