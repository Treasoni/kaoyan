# 4.4.1 极大线性无关组定义

## 定义

设有向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$，如果在其中能选出 $r$ 个向量 ${ \pmb { \alpha } } _ { i 1 } , { \pmb { \alpha } } _ { i 2 } , \cdots , { \pmb { \alpha } } _ { i r }$ 满足：

1. 向量组 ${ \pmb { \alpha } } _ { i 1 } , { \pmb { \alpha } } _ { i 2 } , \cdots , { \pmb { \alpha } } _ { i r }$ 线性无关；
2. 向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 中每个向量均能被 ${ \pmb { \alpha } } _ { i 1 } , { \pmb { \alpha } } _ { i 2 } , \cdots , { \pmb { \alpha } } _ { i r }$ 线性表示，

则称向量组 ${ \pmb { \alpha } } _ { i 1 } , { \pmb { \alpha } } _ { i 2 } , \cdots , { \pmb { \alpha } } _ { i r }$ 是向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 的一个**极大线性无关组**，简称为**极大无关组**。

## 向量组的秩

极大线性无关组所含向量个数 $r$ 称为向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 的**秩**。

> [!note] 注 1
> 只含有零向量的向量组没有极大线性无关组，规定它的秩为 0。

> [!note] 注 2
> 定义中条件（2）也可以替换成：向量组中任意 $r + 1$ 个向量（如果存在的话）都线性相关。
