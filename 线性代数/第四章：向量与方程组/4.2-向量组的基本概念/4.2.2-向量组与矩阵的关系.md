# 4.2.2 向量组与矩阵的关系

每个矩阵都可看成是由一些行向量或列向量所构成的。

## 列向量组

设矩阵 $A = \left( a _ { i j } \right) _ { n \times s }$， $\pmb { A }$ 的每一列都可以视为一个 $n$ 维列向量。如果用 $\pmb { \alpha } _ { j }$ 表示其第 $j$ 个列向量，则 $\pmb { A }$ 就可以用这些列向量表示：

$$
\pmb { A } = \left( \pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } , \cdots , \pmb { \alpha } _ { s } \right)
$$

## 行向量组

同理， $\pmb { A }$ 的每一行都可以视为一个 $s$ 维行向量。如果用 $\beta _ { i }$ 表示其第 $i$ 个行向量，则：

$$
A = \begin{pmatrix} \beta_1 \\ \beta_2 \\ \vdots \\ \beta_n \end{pmatrix}
$$

## 向量组与矩阵的关系

> [!summary] 一一对应关系
> - 给定列向量组 → 以它们为列构成矩阵
> - 给定行向量组 → 以它们为行构成矩阵
> - 含有限个向量的有序向量组总可以与矩阵**一一对应**

## 向量组的秩

$n$ 维向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 所对应的矩阵的秩就是这个向量组的秩，记为 $r \big ( \pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } , \cdots , \pmb { \alpha } _ { s } \big )$ .

> [!important] 行列秩相等
> 任意矩阵的行向量组的秩与其列向量组的秩相等，均等于矩阵的秩。即
> $$
> r (A) = A \text {的 行 秩} = A \text {的 列 秩}.
> $$

向量组的秩在某种意义下刻画了向量组中向量间相互独立的程度。
