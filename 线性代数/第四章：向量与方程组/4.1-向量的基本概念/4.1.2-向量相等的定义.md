# 4.1.2 向量相等的定义

设 $k$ 和 $l$ 为两个任意的常数， $\alpha , \beta$ 和 $\gamma$ 为三个任意的 $n$ 维向量，其中 $\pmb { \alpha } = \left( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } \right) , \ \pmb { \beta } = \left( b _ { 1 } , b _ { 2 } , \cdots , b _ { n } \right)$ .

如果 $\pmb { \alpha }$ 和 $\beta$ 对应的分量都相等，即 $a _ { i } = b _ { i } \left( i = 1 , 2 , \cdots , n \right)$ ，就称这两个向量相等，记为 $\pmb { \alpha } = \pmb { \beta }$ .

> [!summary] 核心
> 两向量相等当且仅当它们对应的每个分量都相等。
