# 4.1.3 向量的线性运算

向量作为一种特殊的矩阵， $n$ 维向量加（减）法及数乘运算规律与矩阵相同。

## 向量加法

对于列向量 $\pmb{ \alpha } = \left( \begin{array} { c } { a _ { 1 } } \\ { a _ { 2 } } \\ { \vdots } \\ { a _ { n } } \end{array} \right) , \pmb { \beta } = \left( \begin{array} { c } { b _ { 1 } } \\ { b _ { 2 } } \\ { \vdots } \\ { b _ { n } } \end{array} \right)$，称向量 $\left( \begin{array}{c} a_1 \pm b_1 \\ a_2 \pm b_2 \\ \vdots \\ a_n \pm b_n \end{array} \right)$ 为 $\alpha, \beta$ 的和（差），记为 $\alpha \pm \beta$ .

## 数乘运算

如果 $k$ 是数，则称向量 $\left( \begin{array}{c} k a_1 \\ k a_2 \\ \vdots \\ k a_n \end{array} \right)$ 为数 $k$ 与向量 $\pmb { \alpha }$ 的数乘，记为 $k \pmb { \alpha }$ .

> [!summary] 线性运算
> 以上加法运算和数乘运算统称为 $n$ 维向量的**线性运算**。
