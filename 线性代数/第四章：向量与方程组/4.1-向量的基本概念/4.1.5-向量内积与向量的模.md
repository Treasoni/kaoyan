# 4.1.5 向量内积与向量的模

## （1）向量内积定义

设 $\pmb { \alpha } = \left( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } \right) ^ { \operatorname { T } } , \pmb { \beta } = \left( b _ { 1 } , b _ { 2 } , \cdots , b _ { n } \right) ^ { \operatorname { T } }$，则 $\pmb { \alpha }$ 与 $\beta$ 的内积为

$$
\left(\boldsymbol {\alpha}, \boldsymbol {\beta}\right) = \boldsymbol {\alpha} ^ {\mathrm {T}} \boldsymbol {\beta} = \left(a _ {1}, a _ {2}, \dots , a _ {n}\right) \left( \begin{array}{c} b _ {1} \\ b _ {2} \\ \vdots \\ b _ {n} \end{array} \right) = a _ {1} b _ {1} + a _ {2} b _ {2} + \dots + a _ {n} b _ {n}.
$$

## （2）向量内积的性质

1. $\left( \alpha , \beta \right) = \left( \beta , \alpha \right)$
2. $\left( k \alpha , \beta \right) = k \left( \alpha , \beta \right)$
3. $\left( \alpha + \beta , \gamma \right) = \left( \alpha , \gamma \right) + \left( \beta , \gamma \right)$
4. $\left( \pmb { \alpha } , \pmb { \alpha } \right) = \pmb { \alpha } ^ { \mathrm { T } } \pmb { \alpha } \geq 0$，且 $\left( \alpha , \alpha \right) = \alpha ^ { \mathrm { { T } } } \alpha = 0 \Leftrightarrow \alpha = \mathbf { 0 }$

其中， $k$ 是数， $\alpha , \beta , \gamma$ 均为 $n$ 维向量。

> [!note] Cauchy 不等式（内积形式）
> $$
> \left| (\alpha , \beta) \right| \leq \sqrt {(\alpha , \alpha)} \sqrt {(\beta , \beta)}.
> $$

## （3）向量的模、单位向量

向量的模：
$$
\| { \pmb { \alpha } } \| = { \sqrt { \left( { \pmb { \alpha } } , { \pmb { \alpha } } \right) } } = { \sqrt { a _ { 1 } ^ { 2 } + a _ { 2 } ^ { 2 } + \cdots + a _ { n } ^ { 2 } } } .
$$

特殊地，若 $\| { \pmb { \alpha } } \| = 1$，此时称 $\pmb { \alpha }$ 为**单位向量**。

### 模的性质

1. **非负性**： $\| { \pmb { \alpha } } \| { \geq } 0$， $\| { \pmb { \alpha } } \| { = } 0 \Leftrightarrow { \pmb { \alpha } } { = } { \mathbf { 0 } }$
2. **齐次性**： $\| k \alpha \| = \left| k \right| \| \alpha \|$
3. **三角不等式**： $\left\| \alpha + \beta \right\| \leq \left\| \alpha \right\| + \left\| \beta \right\|$

> [!tip] 单位化
> 如果 $\pmb { \alpha }$ 是非零向量，则 ${ \frac { 1 } { \| { \pmb { \alpha } } \| } } { \pmb { \alpha } }$ 一定是单位向量，这个过程叫将向量 $\pmb { \alpha }$ **单位化**。

## （4）向量的夹角、正交向量

若 $\alpha , \beta$ 均不为 0，则它们的夹角定义为：
$$
\theta = \arccos \frac { ( \alpha , \beta ) } { \sqrt { ( \alpha , \alpha ) } { \sqrt { ( \beta , \beta ) } } } .
$$

若 $\left( { \pmb { \alpha } } , { \pmb { \beta } } \right) = 0$，则称 $\pmb { \alpha }$ 与 $\beta$ **正交**，记为 $\alpha \perp \beta$ .
