# 4.7.1 向量空间的定义

> [!note] 本节内容仅适用于数一

设 $\mathbf{R}$ 为实数的集合，用 $\mathbf { R } ^ { n }$ 表示 $n$ 维实列向量全体所构成的集合。

设 $V$ 是 $\mathbf { R } ^ { n }$ 的非空子集。若对任意 $\pmb { \alpha } , \pmb { \beta } \in V$ 及实数 $k$，有

$$
{ \pmb { \alpha } } + { \pmb { \beta } } \in V , \quad k { \pmb { a } } \in V
$$

则称 $V$ 是 $\pmb { R } ^ { n }$ 的**子空间**，或简称为**向量空间**。

> [!summary] 一句话理解
> 向量空间就是 $\pmb { R } ^ { n }$ 的在向量的线性运算下**封闭**的非空子集。

## 封闭性的两层含义

1. **加法封闭**：任意两向量的和仍在 $V$ 中
2. **数乘封闭**：任意向量的数乘仍在 $V$ 中
