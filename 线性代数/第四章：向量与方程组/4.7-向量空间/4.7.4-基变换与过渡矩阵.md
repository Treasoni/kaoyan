# 4.7.4 基变换与过渡矩阵

## 基变换公式

设 ${ \pmb { a } } _ { 1 }, { \pmb { a } } _ { 2 }, \cdots , { \pmb { a } } _ { s }$ 及 $\pmb { \beta } _ { 1 }, \pmb { \beta } _ { 2 }, \cdots , \pmb { \beta } _ { s }$ 都是 $s$ 维线性空间 $V$ 的基，若有

$$
\left\{ \begin{array}{l} \boldsymbol {\beta} _ {1} = c _ {1 1} \boldsymbol {\alpha} _ {1} + c _ {2 1} \boldsymbol {\alpha} _ {2} + \dots + c _ {s 1} \boldsymbol {\alpha} _ {s} \\ \boldsymbol {\beta} _ {2} = c _ {1 2} \boldsymbol {\alpha} _ {1} + c _ {2 2} \boldsymbol {\alpha} _ {2} + \dots + c _ {s 2} \boldsymbol {\alpha} _ {s} \\ \dots \dots \\ \boldsymbol {\beta} _ {s} = c _ {1 s} \boldsymbol {\alpha} _ {1} + c _ {2 s} \boldsymbol {\alpha} _ {2} + \dots + c _ {s s} \boldsymbol {\alpha} _ {s} \end{array} \right.
$$

则可写成矩阵形式：

$$
\left(\boldsymbol {\beta} _ {1}, \boldsymbol {\beta} _ {2}, \dots , \boldsymbol {\beta} _ {s}\right) = \left(\boldsymbol {\alpha} _ {1}, \boldsymbol {\alpha} _ {2}, \dots , \boldsymbol {\alpha} _ {s}\right) \boldsymbol {C}
$$

其中 $n$ 阶矩阵 $\pmb { C } = \left( c _ { i j } \right) _ { s \times s }$，即

$$
\boldsymbol {C} = \left( \begin{array}{c c c c} c _ {1 1} & c _ {1 2} & \dots & c _ {1 s} \\ c _ {2 1} & c _ {2 2} & \dots & c _ {2 s} \\ \vdots & \vdots & & \vdots \\ c _ {s 1} & c _ {s 2} & \dots & c _ {s s} \end{array} \right)
$$

## 过渡矩阵

将此式称为**基变换公式**，矩阵 $\pmb { C }$ 称为由基 ${ \pmb { a } } _ { 1 }, { \pmb { a } } _ { 2 }, \cdots , { \pmb { a } } _ { s }$ 到基 $\pmb { \beta } _ { 1 }, \pmb { \beta } _ { 2 }, \cdots , \pmb { \beta } _ { s }$ 的**过渡矩阵**。

> [!important] 注意
> 过渡矩阵中的系数排列： $\beta_j$ 的各分量是旧基 $\alpha_i$ 的组合系数中**第 $j$ 列**排列！
