# 4.7.2 向量空间的基和维数

## 基的定义

在向量空间 $V$ 中，如果存在 $s$ 个向量 ${ \pmb { a } } _ { 1 }, \pmb { a } _ { 2 }, \cdots , \pmb { a } _ { s }$，满足以下两点：

1. ${ \pmb { a } } _ { 1 }, { \pmb { a } } _ { 2 }, \cdots , { \pmb { a } } _ { s }$ **线性无关**；
2. $V$ 中**任一**向量 $\pmb { \alpha }$ 总可由 ${ \pmb { a } } _ { 1 }, { \pmb { a } } _ { 2 }, \cdots , { \pmb { a } } _ { s }$ **线性表示**。

那么， ${ \pmb { a } } _ { 1 }, { \pmb { a } } _ { 2 }, \cdots , { \pmb { a } } _ { s }$ 就称为向量空间 $V$ 的一个**基**。

## 维数

$s$ 称为向量空间 $V$ 的**维数**，记为 $s = \dim V$。

> [!note] 注 1（类比）
> - 向量空间的基 $\leftrightarrow$ 向量组的极大无关组
> - 向量空间的维数 $\leftrightarrow$ 向量组的秩

> [!note] 注 2
> 向量空间 $V$ 的任意两组基是**等价**的。

## $\mathbf{R}^n$ 的标准正交基

设 $n$ 维向量 $\boldsymbol { e } _ { 1 }, \boldsymbol { e } _ { 2 }, \cdots , \boldsymbol { e } _ { n }$ 是向量空间 $\mathbf { R } ^ { n }$ 的一个基，若它们两两正交且均为单位向量，则称为**标准正交基**。

例如， $\mathbf{R}^3$ 的标准正交基：

$$
e_1 = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}, \quad
e_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}, \quad
e_3 = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}
$$
