# 4.7.5 坐标变换

## 坐标变换公式

设向量空间 $V$ 的从基 ${ \pmb { a } } _ { 1 }, { \pmb { a } } _ { 2 }, \cdots , { \pmb { a } } _ { s }$ 到基 $\pmb { \beta } _ { 1 }, \pmb { \beta } _ { 2 }, \cdots , \pmb { \beta } _ { s }$ 的过渡矩阵为 $P$，向量 $\pmb { \eta } \in V$ 在两组基下的坐标分别是 $\boldsymbol { x }$ 和 $\boldsymbol { y }$，则必定有：

$$
\boldsymbol { x } = P \boldsymbol { y } \quad \text{或} \quad \boldsymbol { y } = P ^ { - 1 } \boldsymbol { x }
$$

此公式称为**坐标变换公式**。

## 推导

按坐标的定义，有：

$$
\boldsymbol {\eta} = \left(\boldsymbol {\alpha} _ {1}, \boldsymbol {\alpha} _ {2}, \dots , \boldsymbol {\alpha} _ {s}\right) \boldsymbol {x} = \left(\boldsymbol {\beta} _ {1}, \boldsymbol {\beta} _ {2}, \dots , \boldsymbol {\beta} _ {s}\right) \boldsymbol {y}
$$

由于 $\left( \pmb { \beta } _ { 1 } , \pmb { \beta } _ { 2 } , \cdots , \pmb { \beta } _ { s } \right) = \left( \pmb { a } _ { 1 } , \pmb { a } _ { 2 } , \cdots , \pmb { a } _ { s } \right) \pmb { P }$，故有

$$
\left(\boldsymbol {a} _ {1}, \boldsymbol {a} _ {2}, \dots , \boldsymbol {a} _ {s}\right) \boldsymbol {x} = \left(\boldsymbol {a} _ {1}, \boldsymbol {a} _ {2}, \dots , \boldsymbol {a} _ {s}\right) \boldsymbol {P y}
$$

因为 ${ \pmb { a } } _ { 1 }, { \pmb { a } } _ { 2 }, \cdots , { \pmb { a } } _ { s }$ 线性无关，所以必有矩阵等式 $\boldsymbol { x } = P \boldsymbol { y }$ 或 $\boldsymbol { y } = P ^ { - 1 } \boldsymbol { x }$。

> [!summary] 记忆技巧
> - 新坐标 → 旧坐标： $\boldsymbol{x} = P \boldsymbol{y}$（旧 = 过渡矩阵 × 新）
> - 旧坐标 → 新坐标： $\boldsymbol{y} = P^{-1} \boldsymbol{x}$
