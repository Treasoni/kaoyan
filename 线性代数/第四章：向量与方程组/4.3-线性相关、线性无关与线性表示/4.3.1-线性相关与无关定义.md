# 4.3.1 线性相关/无关定义

## 线性相关

如果有不全为零的数 $k _ { 1 } , k _ { 2 } , \cdots , k _ { s }$，使

$$
k _ {1} \boldsymbol {\alpha} _ {1} + k _ {2} \boldsymbol {\alpha} _ {2} + \dots + k _ {s} \boldsymbol {\alpha} _ {s} = \mathbf {0},
$$

称向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ **线性相关**。

## 线性无关

如果只有在

$$
k _ {1} = k _ {2} = \dots = k _ {s} = 0
$$

时上式才成立，就称向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ **线性无关**。

> [!important] 注
> 向量组，要么线性相关，要么线性无关，两者必取其一。
