# 4.3.5 从方程组和秩的角度理解线性表示（出）

## 单个向量的线性表示

$\beta$ 可以由 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 线性表示

$$
\begin{aligned}
&\Leftrightarrow \text{非齐次线性方程组 } ( \alpha _ { 1 } , \alpha _ { 2 } , \cdots , \alpha _ { s } ) { \left( \begin{array} { l } { k _ { 1 } } \\ { k _ { 2 } } \\ { \vdots } \\ { k _ { s } } \end{array} \right) } = \beta \text{ 有解} \\
&\Leftrightarrow r \left(\alpha_ {1}, \alpha_ {2}, \dots , \alpha_ {s}\right) = r \left(\alpha_ {1}, \alpha_ {2}, \dots , \alpha_ {s}, \beta\right).
\end{aligned}
$$

$\beta$ **不能**由 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 线性表示

$$
\begin{aligned}
&\Leftrightarrow r \left(\alpha_ {1}, \alpha_ {2}, \dots , \alpha_ {s}\right) < r \left(\alpha_ {1}, \alpha_ {2}, \dots , \alpha_ {s}, \beta\right) \\
&\Leftrightarrow r (\alpha_ {1}, \alpha_ {2}, \dots , \alpha_ {s}, \beta) = r (\alpha_ {1}, \alpha_ {2}, \dots , \alpha_ {s}) + 1.
\end{aligned}
$$

## 向量组之间的线性表示

向量组 $\pmb { { \cal B } } : \pmb { \beta } _ { 1 } , \pmb { \beta } _ { 2 } , \cdots , \pmb { \beta } _ { t }$ 可由向量组 $\pmb { A } : \pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } , \cdots , \pmb { \alpha } _ { s }$ 线性表示

$$
\begin{aligned}
&\Leftrightarrow \text{方程 } \pmb { A } \pmb { X } = \pmb { B } \text{ 有解} \\
&\Leftrightarrow r (\alpha_ {1}, \alpha_ {2}, \dots , \alpha_ {s}) = r (\alpha_ {1}, \alpha_ {2}, \dots , \alpha_ {s}, \beta_ {1}, \beta_ {2}, \dots , \beta_ {t}).
\end{aligned}
$$

## 秩不等式

如果向量组 $\beta _ { 1 } , \beta _ { 2 } , \cdots , \beta _ { t }$ 可由向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 线性表示，则

$$
r \left(\boldsymbol {\beta} _ {1}, \boldsymbol {\beta} _ {2}, \dots , \boldsymbol {\beta} _ {t}\right) \leqslant r \left(\boldsymbol {\alpha} _ {1}, \boldsymbol {\alpha} _ {2}, \dots , \boldsymbol {\alpha} _ {s}\right).
$$

## 典型例题

> **【例 1】** 证明：单个非零向量线性无关，两个不成比例的向量线性无关。

> **【例 2】** 现有四个向量组，其中线性相关的向量组有（ ）.

> **【例 3】** 已知向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , { \pmb { \alpha } } _ { 3 }$ 线性无关，判断变换后的向量组是否线性无关。

> **【例 4】** 向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s } \left( s \geq 2 \right)$ 线性无关，证明：向量组 ${ \pmb { \alpha } } _ { 1 }, { \pmb { \alpha } } _ { 1 } + { \pmb { \alpha } } _ { 2 }, \cdots , { \pmb { \alpha } } _ { 1 } + { \pmb { \alpha } } _ { 2 } + \cdots + { \pmb { \alpha } } _ { s }$ 也线性无关。

> **【例 5】** $A$ 为 3 阶矩阵，证明给定条件下向量组线性无关。

> **【例 6】** 利用 $A^k x = 0$ 的条件证明向量组线性无关。

> **【例 7】** 判断 $\beta_1$ 与 $\beta_2$ 能否由向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 }$ 线性表示。

> **【例 8】** 证明向量组（II）可由（I）线性表示。
