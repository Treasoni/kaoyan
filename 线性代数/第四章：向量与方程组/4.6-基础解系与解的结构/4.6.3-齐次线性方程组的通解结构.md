# 4.6.3 齐次线性方程组 $\pmb {A x} = \pmb {0}$ 的通解结构

## 通解公式

如果 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { n - r }$ 为齐次线性方程组 $\pmb { A x } = \pmb { 0 }$ 的基础解系，则称

$$
\pmb { x } = k _ { 1 } \pmb { \alpha } _ { 1 } + k _ { 2 } \pmb { \alpha } _ { 2 } + \cdots + k _ { n - r } \pmb { \alpha } _ { n - r }
$$

为 $\pmb { A x } = \pmb { 0 }$ 的**通解**， $k _ { 1 } , k _ { 2 } , \cdots , k _ { n - r }$ 是**任意常数**。

> [!summary] 解的结构
> 通解 = 基础解系的任意线性组合
