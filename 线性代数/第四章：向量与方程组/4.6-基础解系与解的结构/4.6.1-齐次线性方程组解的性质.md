# 4.6.1 齐次线性方程组 $\pmb {A x} = \pmb {0}$ 解的性质

## 解的可加性

设 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 都是 $\pmb { A x } = \pmb { 0 }$ 的解，则解的线性组合

$$
k _ { 1 } { \pmb { \alpha } } _ { 1 } + k _ { 2 } { \pmb { \alpha } } _ { 2 } + \cdots + k _ { s } { \pmb { \alpha } } _ { s }
$$

也是 $\pmb { A x } = \pmb { 0 }$ 的解， $k _ { 1 } , k _ { 2 } , \cdots , k _ { s }$ 是任意常数。

### 证明

**第一步：翻译已知条件**

既然 $\alpha_1, \cdots, \alpha_s$ 是解，代入方程必然成立：

$$
\begin{cases}
A\alpha_1 = 0 \\
A\alpha_2 = 0 \\
\vdots \\
A\alpha_s = 0
\end{cases}
$$

**第二步：验证结论（利用矩阵乘法的分配律与提取常数性质）**

把线性组合当成一个新向量 $X$，验证 $AX$ 是否等于 $0$：

$$
\begin{aligned}
& A(k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s) \\
= \ & A(k_1\alpha_1) + A(k_2\alpha_2) + \cdots + A(k_s\alpha_s) \quad \text{（矩阵乘法对加法的分配律）} \\
= \ & k_1(A\alpha_1) + k_2(A\alpha_2) + \cdots + k_s(A\alpha_s) \quad \text{（常数可以提出来）}
\end{aligned}
$$

由于第一步已知括号里的 $A\alpha_i$ 全都是 $0$ 向量，代入得：

$$
= k_1 \cdot 0 + k_2 \cdot 0 + \cdots + k_s \cdot 0 = 0
$$

证明完毕。

> [!summary] 核心
> 齐次方程组的解的任意线性组合仍是解 → 解集合构成向量空间（零空间）。
