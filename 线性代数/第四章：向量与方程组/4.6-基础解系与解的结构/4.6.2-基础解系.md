# 4.6.2 基础解系

## 定义

若 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { n - r }$ 满足下列三条：

1. **是解**： ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { n - r }$ 均是齐次线性方程组 $\pmb { A } \pmb { x } = \pmb { 0 }$ 的解向量；
2. **无关**： ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { n - r }$ 线性无关；
3. **个数满足要求**： ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { n - r }$ 向量个数为 $n - r ( A )$，

则称 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { n - r }$ 为齐次线性方程组 $\pmb { A } \pmb { x } = \pmb { 0 }$ 的**基础解系**。

> [!tip] 为什么个数是 n - r(A)
> **n - r(A) = 自由变量的个数**
> - n 个未知量，被 r(A) 个独立方程约束后，还剩 n - r(A) 个自由变量
> - 每个自由变量可以任意取值，对应一个线性无关的特解
> - 所以基础解系需要 n - r(A) 个向量
>
> 例：3个未知量，独立方程只有1个 → 自由变量 2 个 → 基础解系有 2 个向量

> [!tip] 本质理解
> 基础解系可看成**解向量组的一个极大无关组**。

## 定理

齐次线性方程组若有非零解，则它一定有基础解系，且基础解系所含解向量的个数等于 $n - r ( A )$。

> [!summary] 关键公式
> **基础解系中向量个数 = 未知量个数 - 系数矩阵的秩 = $n - r(A)$**
