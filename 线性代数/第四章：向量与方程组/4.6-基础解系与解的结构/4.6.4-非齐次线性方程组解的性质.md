# 4.6.4 非齐次线性方程组 $\pmb {A} \pmb {x} = \pmb {b}$ 解的性质

以下 $\pmb {A} \pmb {x} = \pmb {0}$ 称为非齐次方程组的**导出组**。

## 性质 1：解的差

设 $\pmb { \eta } _ { 1 } , \pmb { \eta } _ { 2 }$ 都是 $\pmb { A } \pmb { x } = \pmb { b }$ 的解，则

$$
\pmb { \eta } _ { 1 } - \pmb { \eta } _ { 2 } \text{ 是导出组 } \pmb { A } \pmb { x } = \pmb { 0 } \text{ 的解}
$$

这里可以用高数的[二阶常系数非齐次线性微分方程](../../../考研数学/微分方程/3-高阶线性微分方程的求解/二阶常系数非齐次线性微分方程.md#^104a22)

## 性质 2：特解 + 齐次解

设 $\pmb { \eta }$ 是 $\pmb { A } \pmb { x } = \pmb { b }$ 的一个解， $\pmb { \alpha }$ 是导出组 $\pmb { A } \pmb { x } = \pmb { 0 }$ 的解，则

$$
{ \pmb { \alpha } } + { \pmb { \eta } } \text{ 是 } \pmb { A } \pmb { x } = \pmb { b } \text{ 的解}
$$

## 性质 3：线性组合与系数和

设 $\pmb { \eta } _ { 1 } , \pmb { \eta } _ { 2 } , \cdots , \pmb { \eta } _ { s }$ 都是 $\pmb { A } \pmb { x } = \pmb { b }$ 的解，则：

- 当 $k _ { 1 } + k _ { 2 } + \dots + k _ { s } = 1$ 时，$k _ { 1 } \pmb { \eta } _ { 1 } + k _ { 2 } \pmb { \eta } _ { 2 } + \cdots + k _ { s } \pmb { \eta } _ { s }$ 是 $\pmb { A } \pmb { x } = \pmb { b }$ 的解；
- 当 $k _ { 1 } + k _ { 2 } + \cdots + k _ { s } = 0$ 时，$k _ { 1 } \pmb { \eta } _ { 1 } + k _ { 2 } \pmb { \eta } _ { 2 } + \cdots + k _ { s } \pmb { \eta } _ { s }$ 是 $\pmb { A } \pmb { x } = \pmb { 0 }$ 的解。

> [!summary] 记忆技巧
> - 系数和 $=1$ → 仍是非齐次解
> - 系数和 $=0$ → 导出组（齐次）解

### 证明

直接代入原方程检验：

$$
A(k_1\eta_1 + k_2\eta_2 + \cdots + k_s\eta_s)
$$

由矩阵乘法的线性性质展开：

$$
= k_1(A\eta_1) + k_2(A\eta_2) + \cdots + k_s(A\eta_s)
$$

因为每个 $\eta_i$ 都是 $Ax = b$ 的解，即 $A\eta_i = b$，代入得：

$$
= k_1 b + k_2 b + \cdots + k_s b = (k_1 + k_2 + \cdots + k_s)b
$$

**情况一：** 系数和 $= 1$，即 $k_1 + k_2 + \cdots + k_s = 1$

$$
(k_1 + k_2 + \cdots + k_s)b = 1 \cdot b = b
$$

$\Rightarrow k_1\eta_1 + k_2\eta_2 + \cdots + k_s\eta_s$ 是原非齐次方程组 $Ax = b$ 的解。

**情况二：** 系数和 $= 0$，即 $k_1 + k_2 + \cdots + k_s = 0$

$$
(k_1 + k_2 + \cdots + k_s)b = 0 \cdot b = \pmb{0}
$$

$\Rightarrow k_1\eta_1 + k_2\eta_2 + \cdots + k_s\eta_s$ 是对应的齐次方程组 $Ax = \pmb{0}$ 的解。$\blacksquare$

> [!tip] 考研常考特例
> 1. **两个解的差**：取 $s=2,\; k_1=1,\; k_2=-1$，系数和 $=0$，故 $\eta_1 - \eta_2$ 是齐次解（即性质 1）
> 2. **两个解的平均**：取 $s=2,\; k_1=k_2=\frac{1}{2}$，系数和 $=1$，故 $\dfrac{\eta_1+\eta_2}{2}$ 仍是非齐次解
>
> [!warning] 注意边界
> 性质 3 仅适用于**多个非齐次解**的线性组合。若要将非齐次特解 $\eta^*$ 与齐次解 $\alpha$ 相加，需用**性质 2** 单独证明，不能直接套用性质 3。
