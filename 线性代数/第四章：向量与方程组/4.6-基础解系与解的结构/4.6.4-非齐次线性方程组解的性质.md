# 4.6.4 非齐次线性方程组 $\pmb {A} \pmb {x} = \pmb {b}$ 解的性质

以下 $\pmb {A} \pmb {x} = \pmb {0}$ 称为非齐次方程组的**导出组**。

## 性质 1：解的差

设 $\pmb { \eta } _ { 1 } , \pmb { \eta } _ { 2 }$ 都是 $\pmb { A } \pmb { x } = \pmb { b }$ 的解，则

$$
\pmb { \eta } _ { 1 } - \pmb { \eta } _ { 2 } \text{ 是导出组 } \pmb { A } \pmb { x } = \pmb { 0 } \text{ 的解}
$$

## 性质 2：特解 + 齐次解

设 $\pmb { \eta }$ 是 $\pmb { A } \pmb { x } = \pmb { b }$ 的一个解， $\pmb { \alpha }$ 是导出组 $\pmb { A } \pmb { x } = \pmb { 0 }$ 的解，则

$$
{ \pmb { \alpha } } + { \pmb { \eta } } \text{ 是 } \pmb { A } \pmb { x } = \pmb { b } \text{ 的解}
$$

## 性质 3：线性组合与系数和

设 $\pmb { \eta } _ { 1 } , \pmb { \eta } _ { 2 } , \cdots , \pmb { \eta } _ { s }$ 都是 $\pmb { A } \pmb { x } = \pmb { b }$ 的解，则：

- 当 $k _ { 1 } + k _ { 2 } + \dots + k _ { s } = 1$ 时，$k _ { 1 } \pmb { \eta } _ { 1 } + k _ { 2 } \pmb { \eta } _ { 2 } + \cdots + k _ { s } \pmb { \eta } _ { s }$ 是 $\pmb { A } \pmb { x } = \pmb { b }$ 的解；
- 当 $k _ { 1 } + k _ { 2 } + \cdots + k _ { s } = 0$ 时，$k _ { 1 } \pmb { \eta } _ { 1 } + k _ { 2 } \pmb { \eta } _ { 2 } + \cdots + k _ { s } \pmb { \eta } _ { s }$ 是 $\pmb { A } \pmb { x } = \pmb { 0 }$ 的解。

> [!summary] 记忆技巧
> - 系数和 $=1$ → 仍是非齐次解
> - 系数和 $=0$ → 导出组（齐次）解
