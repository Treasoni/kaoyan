# 4.6.5 非齐次线性方程组 $\pmb {A} \pmb {x} = \pmb {b}$ 解的结构

## 通解公式

如果线性方程组 $\pmb { A } \pmb { x } = \pmb { b }$ 有解 $\pmb { \eta }$ 满足 $A \pmb { \eta } = \pmb { b }$，其导出组 $\pmb { A } \pmb { x } = \pmb { 0 }$ 的通解为 $\pmb { x } = k _ { 1 } \pmb { \alpha } _ { 1 } + k _ { 2 } \pmb { \alpha } _ { 2 } + \cdots + k _ { n - r } \pmb { \alpha } _ { n - r }$，则 $\pmb { A } \pmb { x } = \pmb { b }$ 的任意解都可写成

$$
\pmb { x } = k _ { 1 } \pmb { \alpha } _ { 1 } + k _ { 2 } \pmb { \alpha } _ { 2 } + \cdots + k _ { n - r } \pmb { \alpha } _ { n - r } + \pmb { \eta }
$$

其中 $k _ { 1 } , k _ { 2 } , \cdots , k _ { n - r }$ 是任意常数。

> [!summary] 解的结构
> **非齐次通解 = 导出组通解 + 一个特解**

## 解题思路

当非齐次线性方程组 $\pmb { A } \pmb { x } = \pmb { b }$ 有无穷多解时：

1. 求一个特解 $\pmb { \eta }$
2. 求导出组 $\pmb { A } \pmb { x } = \pmb { 0 }$ 的通解（即基础解系的线性组合）
3. 两者相加即得全部解
