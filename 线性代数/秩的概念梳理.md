# 秩的概念梳理

> [!abstract] 说明
> 秩是贯穿第二章（矩阵）、第三章（线性方程组）、第四章（向量与方程组）、第五章（特征值与特征向量）、第六章（二次型）的核心概念。本文将五个章节中秩的定义、性质和应用统一梳理。

---

## 零、核心映射："方程组"与"向量组"的思维转换器

> [!tip] 全局心智模型
> 解决向量组问题时，将 $x_1\alpha_1 + x_2\alpha_2 + \cdots + x_s\alpha_s = \beta$ 视为矩阵方程 $Ax = \beta$，启用以下翻译：

| 向量语言 | $\iff$ | 方程组语言 |
|---------|--------|-----------|
| 向量的个数 $s$ | $\iff$ | 未知数的个数（需要分配的系数个数） |
| 矩阵的秩 $r(A)$ | $\iff$ | 有效方程数（系统真正独立的约束条件数） |
| 向量的维数 $n$ | $\iff$ | 方程的总行数（空间的最大理论维度） |

> [!summary] 一句话本质
> **秩 = 有效约束数。** 秩小于未知数 → 约束不足 → 有自由变量 → 有非零解/能表示；秩等于未知数 → 约束充足 → 只有零解/唯一系数。

## 一、秩的定义（第二章 矩阵）

### 1.1 子式定义

> [!important] 定义
> $m \times n$ 矩阵 $A$ 中，不为零的子式的最高阶数 $r$ 称为 $A$ 的秩，记作 $r(A) = r$。

$$
r(A) = r \iff \begin{cases} \text{存在 } r \text{ 阶子式} \neq 0 \\ \text{所有 } r+1 \text{ 阶子式} = 0 \end{cases}
$$

### 1.2 等价描述

| 描述方式 | 内容 |
|---------|------|
| 子式视角 | 不为零子式的最高阶数 |
| 行阶梯形 | 非零行的行数 |
| 向量组视角 | 列向量组极大无关组的大小 |
| 方程组视角 | $Ax = 0$ 解空间的余维数（$n - \text{dim}(\text{解空间})$） |

### 1.3 基本性质

| # | 性质 | 表述 |
|:-:|------|------|
| 1 | 范围 | $0 \leqslant r(A) \leqslant \min\{m, n\}$ |
| 2 | 满秩等价（方阵） | $r(A) = n \iff \|A\| \neq 0 \iff A$ 可逆 |
| 3 | 转置 | $r(A) = r(A^{\mathrm{T}})$ |
| 4 | 数乘（$k \neq 0$） | $r(kA) = r(A)$ |
| 5 | 初等变换 | 不改变秩 |

## 二、秩的运算性质（第二章 结论）

### 2.1 乘积的秩

$$
r(AB) \leqslant \min\{r(A), r(B)\}
$$

> 秩越乘越小。等号条件：$A$ 列满秩时 $r(AB)=r(B)$；$B$ 行满秩时 $r(AB)=r(A)$。

### 2.2 $AB = O$ 的推论

$$
A_{m \times n} B_{n \times s} = O \implies r(A) + r(B) \leqslant n
$$

### 2.3 和差的秩

$$
r(A \pm B) \leqslant r(A, B) \leqslant r(A) + r(B)
$$

### 2.4 拼接矩阵

$$
\max\{r(A), r(B)\} \leqslant r(A, B) \leqslant r(A) + r(B)
$$

### 2.5 伴随矩阵的秩

$$
r(A^*) = \begin{cases} n, & r(A) = n \\ 1, & r(A) = n-1 \\ 0, & r(A) < n-1 \end{cases}
$$

> 口诀：$n \to n,\; n{-}1 \to 1,\; {<}n{-}1 \to 0$

### 2.6 分块矩阵

- 对角/副对角分块：$r\begin{pmatrix} A & O \\ O & B \end{pmatrix} = r(A) + r(B)$
- 三角分块：$r\begin{pmatrix} A & C \\ O & B \end{pmatrix} \geqslant r(A) + r(B)$

## 三、线性方程组中的秩（第三章）

### 3.1 齐次方程组 $Ax = 0$

| 条件 | 结论 | 自由变量数 |
|:---:|:---:|:---:|
| $r(A) = n$ | 唯一零解 | $0$ |
| $r(A) < n$ | 无穷多解 | $n - r(A)$ |

- 齐次**必有解**（至少零解）
- $m < n$（方程数 < 未知数）→ 必有非零解

### 3.2 非齐次方程组 $Ax = b$

| $r(A, b)$ vs $r(A)$ | $r(A)$ vs $n$ | 结论 |
|:---:|:---:|:---:|
| $\neq$ | — | **无解** |
| $=$ | $= n$ | **唯一解** |
| $=$ | $< n$ | **无穷多解** |

> 口诀：**齐次看秩比 $n$，非齐次先看等不等，再看秩比 $n$**

### 3.3 含参方程组

```
1. 化增广矩阵为行阶梯形
2. 找出使主元位置出现零的行（含参数的行）
3. 按参数取值分类讨论
```

## 四、向量组中的秩（第四章）

### 4.1 线性相关性的秩判据（对应齐次方程 $Ax = 0$）

> [!question] 核心问题
> $\alpha_1, \dots, \alpha_s$ 是否存在非零组合使未知数归零？

构造矩阵 $A = [\alpha_1, \alpha_2, \dots, \alpha_s]$，则：

| 相关性 | 秩的条件 |
|:------:|:--------:|
| **线性相关** | $r(A) < s$ |
| **线性无关** | $r(A) = s$ |

> [!abstract] 直觉理解
> **线性相关** $\iff r(A) < s$：有效方程数（约束）< 未知数个数。约束不足，必定存在可以自由取值的变量（自由未知量）。因此除了全填 $0$，一定能找到非零系数使其成立。
> **本质**：向量组中存在"废话向量"，可以被其他向量加减组合出来。
>
> **线性无关** $\iff r(A) = s$：有效方程数 = 未知数个数。信息量刚好完全锁死所有未知数，只能有唯一零解（系数全为 $0$）。
> **本质**：核心班底，全员独立，谁也无法替代谁。

推论：
- 方阵（$n = s$）：$|A| = 0 \iff$ 线性相关
- $s > n$（个数 > 维数）→ 必线性相关（"多必相关"）

> [!note] 多必相关的逻辑
> 有效方程数 $r(A)$ 受限于维数 $n$（即 $r(A) \leqslant n$）。当向量个数 $s > n$ 时，必然有 $r(A) \leqslant n < s$。有效方程数永远追不上未知数个数，约束必定不足，故必线性相关。

> [!warning] 易错
> 比较的核心是 **$r(A)$ 与向量个数 $s$**，而非维数 $n$。

### 4.2 线性表示的秩判据（对应非齐次方程 $Ax = \beta$）

> [!question] 核心问题
> 目标向量 $\beta$ 能否由原向量组拼装出来？

$\beta$ 能否由 $\alpha_1, \dots, \alpha_s$ 线性表示：

$$
\text{能表示} \iff r(\alpha_1, \dots, \alpha_s) = r(\alpha_1, \dots, \alpha_s, \beta)
$$

$$
\text{不能表示} \iff r(\alpha_1, \dots, \alpha_s) < r(\alpha_1, \dots, \alpha_s, \beta)
$$

> [!abstract] 直觉理解
> **能表示**：加入 $\beta$ 后，总有效方程数没有增加。说明 $\beta$ 的信息已经包含在原有的约束系统内，融入系统后没有引发逻辑矛盾（方程有解）。
>
> **不能表示**：加入 $\beta$ 后，有效方程数凭空增加了 $1$。说明 $\beta$ 带来了原系统无法支撑的新维度信息，方程组产生了逻辑矛盾（出现 $0 =$ 非零，方程无解）。

> [!tip] 口诀
> **系数矩阵秩 = 增广矩阵秩 ⟺ 逻辑无矛盾 ⟺ 方程有解 ⟺ 能线性表示**

### 4.3 向量组之间的线性表示

向量组 $\mathcal{B}$ 可由向量组 $\mathcal{A}$ 线性表示：

$$
r(\mathcal{B}) \leqslant r(\mathcal{A})
$$

> [!abstract] 信息量法则
> $\mathcal{A}$ 是"原材料"，$\mathcal{B}$ 是用 $\mathcal{A}$ 拼装出来的"产物"。
> 产物所包含的独立有效信息量（秩），绝不可能超越原材料的总有效信息量（秩）。
> 例如：用二维平面的向量无论怎么拼，也拼不出三维空间的信息量。

> [!warning] 反过来不一定成立
> $r(\mathcal{B}) \leqslant r(\mathcal{A})$ 不能推出 $\mathcal{B}$ 可由 $\mathcal{A}$ 线性表示。特殊情况：若 $t = s$ 且 $r(\mathcal{B}) = r(\mathcal{A})$，则可以相互表示（等价向量组）。

### 4.4 极大线性无关组与秩

> [!abstract] 定义翻译
> 在一个含有"废话向量"的大向量组中，剔除所有冗余信息后，留下的最精简、最核心的独立干货班底。

核心等式：**向量组的秩 = 极大线性无关组中向量的个数 = $r(A)$**

> [!important] 考研标准求法
> 1. 将向量作为**列向量**拼成矩阵 $A$
> 2. 仅做**初等行变换**化为行阶梯形（保证列与列之间的线性组合关系不动）
> 3. 寻找**主元所在的列**，这几列在**原矩阵**中对应的向量，即为极大线性无关组

### 4.5 基础解系与秩

齐次方程组 $Ax = 0$ 的基础解系含 $n - r(A)$ 个向量。

> [!abstract] 直觉理解
> $n$ 是总未知数个数，$r(A)$ 是有效方程数（核心约束数）。
> $n - r(A)$ 即为**自由变量的个数**，代表该系统在解空间里可以"自由演变"的独立方向。
>
> **本质**：基础解系就是整个解空间的"极大线性无关组"。自由变量有几个，就需要派发几个独立的基准向量去描述它，因此解向量的个数精准等于 $n - r(A)$。

## 五、特征值与特征向量中的秩（第五章）

### 5.1 相似变换与秩

> [!important] 核心结论
> 若 $A \sim B$（即 $P^{-1}AP = B$，$P$ 可逆），则 $r(A) = r(B)$。**相似变换保秩。**

证明：$P$ 可逆 $\implies$ $P^{-1}$ 也可逆，可逆矩阵乘法不改变秩，故 $r(P^{-1}AP) = r(AP) = r(A)$。

> [!warning] 逆命题不成立
> $r(A) = r(B) \not\Rightarrow A \sim B$。秩相等只是相似的必要条件，远非充分。

### 5.2 对角化的秩条件

> [!question] 核心问题
> $A$ 能否相似于一个对角矩阵 $\Lambda$？

对于 $n$ 阶矩阵 $A$ 的每个特征值 $\lambda_i$（代数重数为 $n_i$）：

$$
\text{几何重数} = \dim\!\big( \ker(\lambda_i I - A) \big) = n - r(\lambda_i I - A)
$$

> [!important] 可对角化充要条件（秩版）
> $A$ 可对角化 $\iff$ 对每个特征值 $\lambda_i$，有 $n_i = n - r(\lambda_i I - A)$
>
> 即：**每个特征值的代数重数 = 几何重数。**

> [!abstract] 直觉理解
> $r(\lambda_i I - A)$ 表示方程组 $(\lambda_i I - A)x = 0$ 的有效约束数。剩下 $n - r(\lambda_i I - A)$ 个自由变量，恰好对应该特征值能贡献的独立特征向量个数。这个数（几何重数）必须和特征值的代数重数（特征多项式中的次数）相等，才能拼出完整的对角化基。

### 5.3 秩与特征值的关系

| 条件 | 结论 |
|:---:|:---:|
| $r(A) = n$ | $A$ 满秩 $\iff$ 所有特征值 $\neq 0$ |
| $r(A) < n$ | $A$ 降秩 $\iff$ $\lambda = 0$ 是 $A$ 的特征值 |

> [!abstract] 直觉理解
> $\lvert A \rvert = \lambda_1 \lambda_2 \cdots \lambda_n$。若任一特征值为零，行列式为零，矩阵降秩。
>
> 零特征值的**几何重数** $= n - r(A)$，即 $A$ 的零空间维数。
> 零特征值的**代数重数** $\geqslant n - r(A)$（代数重数 $\geqslant$ 几何重数，由代数基本性质保证）。

> [!tip] 对角化后秩的意义
> 若 $A$ 可对角化为 $A = P\Lambda P^{-1}$，则 $r(A) = r(\Lambda) = \Lambda$ 对角线上非零元的个数。

### 5.4 特征向量的线性无关性

> [!important] 关键定理
> 属于不同特征值的特征向量**线性无关**。

秩视角：若 $\lambda_1 \neq \lambda_2 \neq \cdots \neq \lambda_k$，则对应特征向量 $\xi_1, \dots, \xi_k$ 拼成的矩阵的秩 $= k$（满列秩）。

推论：若 $n$ 阶矩阵有 $n$ 个不同的特征值，则必定可对角化（因为有 $n$ 个线性无关特征向量，特征向量矩阵满秩 $= n$）。

## 六、二次型中的秩（第六章）

### 6.1 二次型的秩

> [!important] 定义
> 对于二次型 $f(x_1, \dots, x_n) = x^{\mathrm{T}} A x$（$A$ 为实对称矩阵），称 $r(A)$ 为**二次型的秩**。

### 6.2 合同变换与秩

> [!important] 核心结论
> 若 $A$ 与 $B$ 合同（即 $C^{\mathrm{T}} A C = B$，$C$ 可逆），则 $r(A) = r(B)$。**合同变换也保秩。**

> [!abstract] 等价、相似、合同的秩关系
> - 等价：$PAQ = B$ → $r(A) = r(B)$
> - 相似：$P^{-1}AP = B$ → $r(A) = r(B)$
> - 合同：$C^{\mathrm{T}}AC = B$ → $r(A) = r(B)$
>
> 三者都保秩。秩是等价/相似/合同三种关系下的**不变量**。

### 6.3 标准形与规范形中的秩

二次型通过可逆线性变换化为标准形：

$$f = d_1 y_1^2 + d_2 y_2^2 + \cdots + d_r y_r^2 \quad (d_i \neq 0)$$

其中平方项个数 $r = r(A)$。

继续化为规范形：

$$f = z_1^2 + \cdots + z_p^2 - z_{p+1}^2 - \cdots - z_{p+q}^2$$

> [!important] 关键关系
> $$
> p + q = r(A), \quad n - r(A) = \text{规范形中 } 0 \text{ 的个数}
> $$
>
> - $p$：正惯性指数
> - $q$：负惯性指数
> - **惯性指数之和 = 秩**（惯性定理保证 $p, q$ 是合同不变量）

### 6.4 正定性与秩

> [!important] 正定 $\iff r(A) = n$ 且特征值全正

| 类型 | 秩条件 | 惯性指数 | 特征值 |
|:---:|:---:|:---:|:---:|
| 正定 | $r(A) = n$ | $p = n, q = 0$ | 全 $\gt 0$ |
| 半正定 | $r(A) \lt n$ | $p \lt n, q = 0$ | 全 $\geqslant 0$ |
| 负定 | $r(A) = n$ | $p = 0, q = n$ | 全 $\lt 0$ |
| 半负定 | $r(A) \lt n$ | $p = 0, q \lt n$ | 全 $\leqslant 0$ |
| 不定 | — | $p \gt 0, q \gt 0$ | 有正有负 |

> [!abstract] 直觉理解
> 正定矩阵必满秩：若 $r(A) < n$，则存在非零 $x$ 使 $Ax = 0$，从而 $x^{\mathrm{T}}Ax = 0$，与正定义 $x^{\mathrm{T}}Ax > 0$（对任意 $x \neq 0$）矛盾。
>
> 但满秩不一定正定：例如有负特征值的满秩矩阵，其二次型可取负值。

## 七、统一视角：秩的三重身份

```
              矩阵 A (m×n)
                │
    ┌───────────┼───────────┐
    │           │           │
  子式视角    向量组视角    方程组视角
    │           │           │
 最高阶非零   列向量组的   Ax=0 解空间
   子式阶数   极大无关组   的维数
    │          大小 r       n - r(A)
    └───────────┼───────────┘
                │
           统一为 r(A)
                │
    ┌───────────┼───────────┐
    │           │           │
 方程组判定   相关性判定   表示性判定
  有解/无解   相关/无关    能/不能表示
  唯一/无穷   r(A) vs s    r(A,β) vs r(A)
```

## 八、考场速查卡

| 场景 | 用秩怎么做 |
|------|-----------|
| 判断线性相关 | 拼矩阵求秩，与向量个数 $s$ 比 |
| 判断线性表示 | 比 $r(A)$ 和 $r(A, \beta)$ |
| 方程组解的判定 | 齐次比 $r(A)$ 与 $n$；非齐次先比 $r(A,b)$ 与 $r(A)$ |
| 求基础解系个数 | $n - r(A)$ |
| $AB = O$ | $r(A) + r(B) \leqslant n$ |
| 伴随矩阵秩 | 三段式 $n \to n,\; n{-}1 \to 1,\; {<}n{-}1 \to 0$ |
| $A^{\mathrm{T}}A$ 的秩 | $r(A^{\mathrm{T}}A) = r(A)$ |
| 秩为1矩阵 | $A = \alpha\beta^{\mathrm{T}}$，$A^n = l^{n-1}A$，特征值为 $\text{tr}(A)$ 和 $n{-}1$ 个 $0$ |
| 对角化判定 | 对每个 $\lambda_i$，$n - r(\lambda_i I - A)$ = 代数重数 |
| 零特征值 | $r(A) < n \iff \lambda = 0$ 是特征值 |
| 相似矩阵秩 | $A \sim B \implies r(A) = r(B)$ |
| 二次型秩 | $p + q = r(A)$，惯性指数之和即为秩 |
| 正定性 | 正定 $\implies r(A) = n$；满秩不一定正定 |
