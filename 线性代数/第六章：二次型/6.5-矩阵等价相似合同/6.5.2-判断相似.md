# 6.5.2 判断相似

## 相似的定义

$\pmb{A}$ 与 $\pmb{B}$ **相似** $\iff$ 存在可逆矩阵 $\pmb{P}$，使 $\pmb{P}^{-1} \pmb{A} \pmb{P} = \pmb{B}$，记为 $\pmb{A} \sim \pmb{B}$。

## 判定步骤

### 第一步：必要条件（快速排除）

若以下任一条件不满足，则 $\pmb{A}, \pmb{B}$ **必定不相似**：

| 必要条件 | 说明 |
|:---|:---|
| $\vert \pmb{A} \vert = \vert \pmb{B} \vert$ | 行列式相等 |
| $\operatorname{tr}(\pmb{A}) = \operatorname{tr}(\pmb{B})$ | 迹相等 |
| $r(\pmb{A}) = r(\pmb{B})$ | 秩相等 |
| $\lambda_A = \lambda_B$ | 特征值相等（含重数） |

### 第二步：充分判定

必要条件都满足后，再借助以下方法：

1. **定义法**：寻找可逆矩阵 $\pmb{P}$，使 $\pmb{P}^{-1} \pmb{A} \pmb{P} = \pmb{B}$
2. **传递性**：$\pmb{A} \sim \pmb{B}$，$\pmb{B} \sim \pmb{C} \Rightarrow \pmb{A} \sim \pmb{C}$
3. **对角化判定**：若两者都可对角化且有相同的特征值（含重数），则相似

>[!important] 重点
>特征值相等（含代数重数）是判定相似的**核心必要条件**。
