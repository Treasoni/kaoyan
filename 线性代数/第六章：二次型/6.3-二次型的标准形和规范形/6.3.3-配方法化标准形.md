# 6.3.3 配方法化标准形

## 方法二：配方法

对二次型

$$
f(x_1, x_2, \dots, x_n) = \pmb{x}^{\mathrm{T}} \pmb{A} \pmb{x} = \sum_{i=1}^{n} \sum_{j=1}^{n} a_{ij} x_i x_j
$$

## 有平方项时

1. 找出一个系数不为零的平方项 $x_k^2$
2. 把所有包含 $x_k$ 的项集中到一起，配成完全平方
3. 寻找下一个系数不为零的平方项 $x_l^2$，重复上述步骤
4. 直到每一项都成为完全平方的形式

## 无平方项时（只有交叉项）

若二次型不含平方项，但 $a_{ij} \neq 0 \; (i \neq j)$，则先作可逆线性变换：

$$
\begin{cases}
x_i = y_i + y_j \\
x_j = y_i - y_j \\
x_k = y_k \quad (k \neq i, j)
\end{cases}
$$

化为含平方项的二次型后，再按配方法进行。

>[!tip] 原理
>$x_i x_j = (y_i + y_j)(y_i - y_j) = y_i^2 - y_j^2$，产生了平方项。

## 典型例题

### 例 2：含平方项的配方

$f(x_1, x_2, x_3) = 2x_1^2 + 3x_2^2 + x_3^2 + 4x_1x_2 - 4x_1x_3 - 8x_2x_3$

**解**：
1. 关于 $x_1$ 配方：
   $$f = 2[x_1^2 + 2x_1(x_2 - x_3)] + 3x_2^2 + x_3^2 - 8x_2x_3$$
   $$= 2[x_1 + (x_2 - x_3)]^2 - 2(x_2 - x_3)^2 + 3x_2^2 + x_3^2 - 8x_2x_3$$
   $$= 2(x_1 + x_2 - x_3)^2 + x_2^2 - x_3^2 - 4x_2x_3$$
2. 关于 $x_2$ 继续配方：
   $$= 2(x_1 + x_2 - x_3)^2 + (x_2 - 2x_3)^2 - 5x_3^2$$

令 $\begin{cases} y_1 = x_1 + x_2 - x_3 \\ y_2 = x_2 - 2x_3 \\ y_3 = x_3 \end{cases}$，得标准形：$2y_1^2 + y_2^2 - 5y_3^2$

### 例 3：无平方项时的处理

$f(x_1, x_2, x_3) = 2x_1x_2 + 4x_1x_3$

**解**：先作变换产生平方项：
令 $\begin{cases} x_1 = y_1 + y_2 \\ x_2 = y_1 - y_2 \\ x_3 = y_3 \end{cases}$

得 $f = 2(y_1^2 - y_2^2) + 4(y_1 + y_2)y_3 = 2y_1^2 - 2y_2^2 + 4y_1y_3 + 4y_2y_3$

再按配方法继续处理。
