# 4.3.2 利用定义法判断线性相关/无关

## 方法

设 $k _ { 1 } \pmb { \alpha } _ { 1 } + k _ { 2 } \pmb { \alpha } _ { 2 } + \dots + k _ { s } \pmb { \alpha } _ { s } = \mathbf { 0 }$，

- 若证明出 $k _ { 1 } = k _ { 2 } = \cdots = k _ { s } = 0$，则说明 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ **线性无关**。
- 若存在不全为零的 $k_1, k_2, \cdots, k_s$ 使等式成立，则**线性相关**。

> [!tip] 关键思路
> 定义法就是从线性相关/无关的原始定义出发，导出系数 $k_i$ 必须满足的条件。
