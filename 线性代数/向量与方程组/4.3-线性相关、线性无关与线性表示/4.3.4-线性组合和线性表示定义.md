# 4.3.4 线性组合和线性表示（出）定义

## 线性组合

设 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 都是 $n$ 维向量， $k _ { 1 } , k _ { 2 } , \cdots , k _ { s }$ 是数，则称向量

$$
k _ {1} \boldsymbol {\alpha} _ {1} + k _ {2} \boldsymbol {\alpha} _ {2} + \dots + k _ {s} \boldsymbol {\alpha} _ {s}
$$

是向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 的**线性组合**， $k _ { 1 } , k _ { 2 } , \cdots , k _ { s }$ 是这个线性组合的**组合系数**。

## 线性表示（出）

如果 $n$ 维向量 $\beta$ 可以写成 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 的线性组合，即

$$
\beta = k_1 \alpha_1 + k_2 \alpha_2 + \cdots + k_s \alpha_s
$$

则称 $\beta$ 可以由 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ **线性表示（出）**。

> [!note] 注
> - 零向量能被任意向量组线性表示
> - 任意向量能被包含自身的向量组线性表示
