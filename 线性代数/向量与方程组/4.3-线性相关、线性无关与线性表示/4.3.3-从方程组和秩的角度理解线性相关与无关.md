# 4.3.3 从方程组和秩的角度理解线性相关/无关

## 核心思想

$n$ 维向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 构成矩阵 $\pmb { A } = \left[ \pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } , \cdots , \pmb { \alpha } _ { s } \right]$，向量组 $\pmb { A }$ 线性相关，就是齐次线性方程组

$$
x _ {1} \boldsymbol {\alpha} _ {1} + x _ {2} \boldsymbol {\alpha} _ {2} + \dots + x _ {s} \boldsymbol {\alpha} _ {s} = \mathbf {0} \quad (\boldsymbol {A} \boldsymbol {x} = \mathbf {0})
$$

有非零解，其中 $\pmb { x } = \left( x _ { 1 } , x _ { 2 } , \cdots , x _ { s } \right) ^ { \mathrm { T } }$ .

## 定理（秩判据）

$n$ 维向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$：

- **线性相关** $\Leftrightarrow$ 它所构成的矩阵 $\pmb { A } = \left[ \pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } , \cdots , \pmb { \alpha } _ { s } \right]$ 的秩小于向量个数 $s$，即 $r \left( A \right) < s$
- **线性无关** $\Leftrightarrow$ $r \left( A \right) = s$

## 推论

> **推论 1（方阵情况）**
> $$
> \begin{aligned}
> \text{线性相关} &\Leftrightarrow \left| A \right| = 0 \\
> \text{线性无关} &\Leftrightarrow \left| A \right| \neq 0
> \end{aligned}
> $$

> **推论 2（个数大于维数）**
> 当 $s > n$ 时，$s$ 个 $n$ 维向量**必线性相关**。
