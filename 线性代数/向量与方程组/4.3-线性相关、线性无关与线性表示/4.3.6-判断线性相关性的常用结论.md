# 4.3.6 判断线性相关性的常用结论

## 结论（1）自身表出

向量组 $\pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } , \cdots , \pmb { \alpha } _ { s } \left( s \geq 2 \right)$：
- **线性相关** $\Leftrightarrow$ 其中至少有一个向量能由其他向量线性表出
- **线性无关** $\Leftrightarrow$ 其中任一个向量都不能由其余 $s - 1$ 个向量线性表示

## 结论（2）零向量与成比例

- 包含零向量的向量组**线性相关**
- 单个非零向量**线性无关**
- 两个成比例的向量**线性相关**
- 两个不成比例的向量**线性无关**

## 结论（3）行列式判据

$n$ 维向量组 $\pmb { A } : \pmb { \alpha } _ { 1 } , \pmb { \alpha } _ { 2 } , \cdots , \pmb { \alpha } _ { n }$：
- 线性相关 $\Leftrightarrow \left| A \right| = 0$
- 线性无关 $\Leftrightarrow \left| A \right| \neq 0$
- 向量个数大于向量维数时，向量组**必线性相关**

## 结论（4）部分与整体

> **"部分相关 $\Rightarrow$ 整体相关；整体无关 $\Rightarrow$ 部分无关"**

- 如果向量组的某个部分向量组线性相关，则整个向量组线性相关
- 如果向量组线性无关，则其任一部分向量组都线性无关

## 结论（5）延长与缩短

> **"原相关 $\Rightarrow$ 缩短相关，原无关 $\Rightarrow$ 延长无关"**

在 $n$ 维向量组各向量添上 $m$ 个分量变成 $n + m$ 维向量组：

- 如果延长组线性相关，那么原向量组也线性相关
- 如果原向量组线性无关，那么延长组也线性无关

## 结论（6）重排分量

设 ${ \pmb { \alpha } } _ { 1 } ^ { \prime } , { \pmb { \alpha } } _ { 2 } ^ { \prime } , \cdots , { \pmb { \alpha } } _ { s } ^ { \prime }$ 是对 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 各分量顺序进行重排后得到的向量组，则这两个向量组有**相同的线性相关性**。

> [!tip] 拓展
> - 初等行变换不改变列向量组的线性相关性
> - 初等列变换不改变行向量组的线性相关性

## 结论（7）唯一表示

设向量组 $\beta _ { 1 } , \beta _ { 2 } , \cdots , \beta _ { s }$ 线性无关，而向量组 $\pmb { \beta } _ { 1 } , \pmb { \beta } _ { 2 } , \cdots , \pmb { \beta } _ { s } , \pmb { \alpha }$ 线性相关，则 $\pmb { \alpha }$ 能由向量组 $\beta _ { 1 } , \beta _ { 2 } , \cdots , \beta _ { s }$ 线性表示，且表示式是**唯一**的。

## 结论（8）以少表多

> **"以少表多，多必相关"**

设向量组 $\beta _ { 1 } , \beta _ { 2 } , \cdots , \beta _ { t }$ 可由向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 线性表示且 $t > s$，那么 $\beta _ { 1 } , \beta _ { 2 } , \cdots , \beta _ { t }$ **线性相关**。

**等价命题**：如果向量组 $\beta _ { 1 } , \beta _ { 2 } , \cdots , \beta _ { t }$ 可由向量组 ${ \pmb { \alpha } } _ { 1 } , { \pmb { \alpha } } _ { 2 } , \cdots , { \pmb { \alpha } } _ { s }$ 线性表示，且 $\beta _ { 1 } , \beta _ { 2 } , \cdots , \beta _ { t }$ 线性无关，那么 $t { \leqslant } s$。
