# 4.1.4 n维向量的线性运算的性质

以下 $\alpha , \beta , \gamma$ 是 $n$ 维向量， $k , l$ 是常数。

1. $0 \cdot \alpha = \mathbf{0}$
2. $( k + l ) \alpha = k \alpha + l \alpha$
3. $k ( l \pmb { \alpha } ) = \left( k l \right) \pmb { \alpha }$
4. $k ( \alpha + \beta ) = k \alpha + k \beta$
5. $\pmb { \alpha } + \pmb { \beta } = \pmb { \beta } + \pmb { \alpha }$
6. $\left( \alpha + \beta \right) + \gamma = \alpha + \left( \beta + \gamma \right)$

> [!summary] 总结
> 这六条性质分别是：零乘律、分配律、结合律、交换律。与矩阵的线性运算性质完全一致。
