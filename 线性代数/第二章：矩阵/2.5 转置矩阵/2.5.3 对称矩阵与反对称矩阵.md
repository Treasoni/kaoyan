# 2.5.3 对称矩阵与反对称矩阵

## 定义

设 $\boldsymbol{A} = (a_{ij})_{n \times n}$：

- **对称矩阵**：$a_{ij} = a_{ji}$（即 $\boldsymbol{A} = \boldsymbol{A}^{\mathrm{T}}$）
- **反对称矩阵**：$a_{ij} = -a_{ji}$（即 $\boldsymbol{A} = -\boldsymbol{A}^{\mathrm{T}}$）

## 重要结论

### 结论 1
设 $\boldsymbol{B}$ 是 $m \times n$ 矩阵，则 $\boldsymbol{B}^{\mathrm{T}} \boldsymbol{B}$ 和 $\boldsymbol{B} \boldsymbol{B}^{\mathrm{T}}$ 都是对称矩阵。

> 证明：$(\boldsymbol{B}^{\mathrm{T}} \boldsymbol{B})^{\mathrm{T}} = \boldsymbol{B}^{\mathrm{T}} (\boldsymbol{B}^{\mathrm{T}})^{\mathrm{T}} = \boldsymbol{B}^{\mathrm{T}} \boldsymbol{B}$

### 结论 2
反对称阵必有主对角元全零：$a_{ii} = 0\ (i = 1, 2, \cdots, n)$。

### 结论 3
奇数阶反对称阵的行列式必为 $0$：$\vert A \vert = 0$。

### 结论 4（分解定理）
任意一个 $n$ 阶方阵都可以表示成一个对称矩阵与一个反对称矩阵的和：

$$
A = \frac{A + A^{\mathrm{T}}}{2} + \frac{A - A^{\mathrm{T}}}{2}
$$

- $\frac{A + A^{\mathrm{T}}}{2}$ 为对称矩阵
- $\frac{A - A^{\mathrm{T}}}{2}$ 为反对称矩阵
