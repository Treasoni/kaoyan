# 2.7.3 逆矩阵相关结论

## 逆矩阵的运算性质

| 序号 | 结论 | 说明 |
|------|------|------|
| (1) | $(A^{-1})^{-1} = A$ | 反身性 |
| (2) | $(kA)^{-1} = \frac{1}{k}A^{-1}$ | $k \neq 0$ 时成立 |
| (3) | $(AB)^{-1} = B^{-1}A^{-1}$ | 乘积的逆 = 逆的逆序乘积 |
| (4) | $(A_1 \cdots A_m)^{-1} = A_m^{-1} \cdots A_1^{-1}$ | 推广到多个矩阵 |
| (5) | $(A^n)^{-1} = (A^{-1})^n$ | 幂的逆 = 逆的幂 |

## 伴随矩阵与逆矩阵的关系

| 结论 | 公式 |
|------|------|
| 逆矩阵公式 | $A^{-1} = \frac{1}{\vert A \vert} A^{*}$ |
| 伴随的逆 | $(A^{*})^{-1} = (A^{-1})^{*}$ |
| 数乘伴随 | $(kA)^{*} = k^{n-1}A^{*} \quad (k \neq 0)$ |
| 转置伴随 | $(A^{*})^{\mathrm{T}} = (A^{\mathrm{T}})^{*}$ |
| 伴随的双重 | $(A^{*})^{*} = \vert A \vert^{n-2} A$ |

## 矩阵方程的等价变形

> [!abstract] 核心原则
> 在矩阵方程中，**同时左乘**或**同时右乘**一个可逆矩阵，不改变方程的解。

### 推导过程

| 方程类型 | 变形操作 | 结果 |
| -------- | -------- | ---- |
| $AX = B$ 且 $A$ 可逆 | 两边同时左乘 $A^{-1}$ | $X = A^{-1}B$ |
| $XA = B$ 且 $A$ 可逆 | 两边同时右乘 $A^{-1}$ | $X = BA^{-1}$ |

### 为何必须强调"可逆"？

| 乘以的矩阵 | 效果 | 原因 |
| --------- | ---- | ---- |
| **可逆矩阵** | ✅ 解不变（等价变形） | 操作可逆转，信息不丢失 |
| **不可逆矩阵（如 $O$）** | ❌ 改变解（可能产生增根） | 如同等式两边同乘 $0$，$=$ 变成 $=$，无中生有引入"解" |

> [!example] 类比理解
> 将"同乘可逆矩阵"类比为初等数学中"等式两边同乘一个**不为 0 的常数**"。
>
> - 乘以非零常数：操作可逆，解不变
> - 乘以 $0$：$1 = 2$ 变成 $0 = 0$，改变了原方程的解

> [!danger] 易错提醒
> 当 $A$ **不可逆** 时，$AX = B$ **不能**直接通过"两边除以 $A$"来求解，必须使用其他方法（如待定系数法、分块矩阵等）。
