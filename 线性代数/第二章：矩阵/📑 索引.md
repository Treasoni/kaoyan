## 核心公式速查

| 公式 | 说明 |
|------|------|
| $\vert AB \vert = \vert A \vert \cdot \vert B \vert$ | 矩阵乘法的行列式公式（方阵） |
| $\vert kA \vert = k^n \vert A \vert$ | 数乘的行列式公式 |
| $AA^* = A^*A = \vert A \vert E$ | 伴随矩阵核心公式 |
| $\vert A^* \vert = \vert A \vert^{n-1}$ | 伴随矩阵行列式 |
| $A^{-1} = \frac{1}{\vert A \vert} A^*$ | 逆矩阵公式（$\vert A \vert \neq 0$） |
| $(AB)^{-1} = B^{-1}A^{-1}$ | 乘积的逆矩阵 |
| $(AB)^T = B^TA^T$ | 乘积的转置 |
| $\vert A^{-1} \vert = \frac{1}{\vert A \vert}$ | 逆矩阵行列式 |

## 重要结论

1. 矩阵乘法**不满足**交换律和消去律
2. $AB = O$ 不能推出 $A = O$ 或 $B = O$
3. $r(A) = r$ 说明存在 $r$ 阶子式不为零，所有 $r+1$ 阶子式全为零
4. 可逆矩阵 $\iff$ 满秩矩阵 $\iff$ 行列式不为零
5. 初等变换不改变矩阵的秩
