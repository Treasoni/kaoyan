## 二、3.1 线性方程组的定义及基本概念

### 2.1 线性方程判断标准

> [!important] 核心规则
> 每一项要么是常数，要么是**未知量的一次幂**。
> - ❌ 禁止：平方 $x_i^2$、乘积 $x_i x_j$、三角函数 $\sin x_i$、指数 $e^{x_i}$ 等

### 2.2 一般形式

$$
\left\{ \begin{array}{l}
a_{11} x_{1} + a_{12} x_{2} + \dots + a_{1n} x_{n} = b_{1} \\
a_{21} x_{1} + a_{22} x_{2} + \dots + a_{2n} x_{n} = b_{2} \\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \vdots \\
a_{m1} x_{1} + a_{m2} x_{2} + \dots + a_{mn} x_{n} = b_{m}
\end{array} \right.
$$

| 符号 | 含义 |
|:---:|:---|
| $a_{\lvert i j \rvert}$ | 第 $i$ 个方程、第 $j$ 个未知量的系数 |
| $b_i$ | 第 $i$ 个方程右侧的常数项 |
| $m$ | 方程个数（行数） |
| $n$ | 未知数个数（列数） |

### 2.3 两大分类：齐次 vs 非齐次

| 类型 | 条件 | 矩阵形式 | 特点 |
|:---|:---:|:---:|:---|
| **齐次** | 所有 $b_i = 0$ | $A\mathbf{x} = \mathbf{0}$ | 必有零解 |
| **非齐次** | $b_i$ 不全为零 | $A\mathbf{x} = \mathbf{b}$ | 可能无解 |

> [!important] 导出组定义
> 非齐次方程组 $A\mathbf{x} = \mathbf{b}$ 的**导出组**是 $A\mathbf{x} = \mathbf{0}$（将常数项全部换为零）

### 2.4 三个核心矩阵

$$
\boxed{\boldsymbol{A} = \begin{bmatrix}
a_{11} & \cdots & a_{1n} \\
\vdots & \ddots & \vdots \\
a_{m1} & \cdots & a_{mn}
\end{bmatrix}},\quad
\boxed{\boldsymbol{x} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix}},\quad
\boxed{\boldsymbol{b} = \begin{bmatrix} b_1 \\ b_2 \\ \vdots \\ b_m \end{bmatrix}}
$$

矩阵方程形式：$\boxed{A\mathbf{x} = \mathbf{b}}$

| 矩阵 | 组成 | 作用 |
|:---|:---|:---|
| **系数矩阵** $A$ | 仅系数，$m \times n$ | 描述未知量之间的线性关系 |
| **增广矩阵** $(A \mid \mathbf{b})$ | 系数 + 常数项，$m \times (n+1)$ | **唯一确定**整个方程组 |

## 三、3.2 解方程原理及高斯消元法

### 3.1 两种基本问题

```
① 是否有解？ ──→ ② 若有解，如何求解？
   (判定问题)         (求解问题)
```

### 3.2 初等行变换（三大工具）

| 编号 | 方程操作 | 矩阵行操作 | 可逆性 |
|:----:|---------|-----------|:------:|
| ① | 互换两个方程的位置 | **交换两行** $r_i \leftrightarrow r_j$ | ✅ |
| ② | 用非零常数 $k$ 乘某一方程 | **某行乘以 $k$** $r_i \times k$（$k \neq 0$） | ✅ |
| ③ | 把某一方程的 $k$ 倍加到另一个方程 | **某行的 $k$ 倍加到另一行** $r_i + k r_j$ | ✅ |

> [!warning] 常见误区
> - ❌ 把某行乘以 0 → **不可逆**，会丢失信息
> - ❌ 行变换与列变换混淆 → 解方程组**只允许行变换**
> - ✅ 三种变换都是**可逆**的，意味着变换前后的方程组等价

### 3.3 高斯消元法标准步骤

```
Step 1：写出增广矩阵 (A | b)
Step 2：初等行变换 → 行阶梯形
Step 3：判断是否有解
Step 4：回代求解
```

### 3.4 核心概念

| 概念 | 定义 | 直观理解 |
|------|------|---------|
| **主元位置** | 非零行的**首个非零元素**所在的位置 | 每行"台阶"的起点 |
| **主元列** | 含有主元位置的列 | 有"台阶"的列 |
| **基本变量** | 主元列对应的变量 | 被"锁定"的变量 |
| **自由变量** | 非主元列对应的变量 | 可以自由赋值的变量 |

```
行阶梯形矩阵示意（□ 为主元，* 为任意数）：
┌                  ┐
│ □  *  *  *  *   │  ← 第1行主元在第1列
│ 0  □  *  *  *   │  ← 第2行主元在第2列
│ 0  0  0  □  *   │  ← 第3行主元在第4列
│ 0  0  0  0  0   │  ← 全零行
└                  ┘
主元列：第1、2、4列  →  基本变量：x₁, x₂, x₄
非主元列：第3、5列   →  自由变量：x₃, x₅
```

### 3.5 解的判定决策树

```
行阶梯形 (A₁ | b₁)
        │
        ├── 存在一行 (0,...,0 | d), d ≠ 0 ?
        │       │
        │       ├── 是 → ⛔ 无解（立即判定，无需继续）
        │       │
        │       └── 否 → 有解，继续判断：
        │               │
        │               ├── r = n（非零行数 = 未知数个数）
        │               │   → ✅ 唯一解
        │               │
        │               └── r < n（非零行数 < 未知数个数）
        │                   → 🔄 无穷多解（有 n-r 个自由变量）
        │
        └── 齐次方程组（b = 0）？
                ├── 跳过"无解"判断（齐次不会无解）
                └── 直接比较 r 与 n
```

## 四、3.3 方程组解的判定

### 4.1 齐次线性方程组 $A_{m \times n}\mathbf{x} = \mathbf{0}$

| 条件 | 结论 | 自由变量数 |
|:---:|:---:|:---:|
| $r(A) = n$ | **只有零解（唯一解）** | $0$ |
| $r(A) < n$ | **无穷多组非零解** | $n - r(A)$ |

> [!important] 齐次的两条铁律
> - **必有解**：至少零解（永远不出现"无解"）
> - **方程数 $m < n$**（未知数多于方程数）$\Rightarrow$ 必有 $r(A) \leq m < n$ $\Rightarrow$ **必有非零解**
> - **$A$ 为方阵时**：$|A| = 0 \iff r(A) < n \iff$ 有非零解

### 4.2 非齐次线性方程组 $A_{m \times n}\mathbf{x} = \mathbf{b}\; (\mathbf{b} \neq \mathbf{0})$

| $r(A,\mathbf{b})$ 与 $r(A)$ | $r(A)$ 与 $n$ | 结论 | 自由变量数 |
|:---:|:---:|:---:|:---:|
| $\neq$ | — | **无解** | — |
| $=$ | $= n$ | **唯一解** | $0$ |
| $=$ | $< n$ | **无穷多解** | $n - r(A)$ |

> [!important] 非齐次判定三步法
> 1. **先判有无解**：$r(A, \mathbf{b}) \stackrel{?}{=} r(A)$——不等则直接无解
> 2. **再判多少解**：相等时，$r(A) \stackrel{?}{=} n$——等于则唯一，小于则无穷多
> 3. **最后数自由变量**：$n - r(A)$ 个

### 4.3 齐次 vs 非齐次判定逻辑对比

| 对比维度 | 齐次 $A\mathbf{x} = \mathbf{0}$ | 非齐次 $A\mathbf{x} = \mathbf{b}$ |
|:---:|:---|:---|
| 是否一定有解 | **是**（至少零解） | **不一定**（无解是常见情况） |
| 第一步判断 | $r(A)$ 与 $n$ 比较 | $r(A,\mathbf{b})$ 与 $r(A)$ 比较 |
| 唯一解条件 | $r(A) = n$ | $r(A,\mathbf{b}) = r(A) = n$ |
| 无穷多解条件 | $r(A) < n$ | $r(A,\mathbf{b}) = r(A) < n$ |

### 4.4 解的判定速查表

| 场景 | 判定条件 | 解的情况 |
|:---|:---|:---:|
| 齐次 | $r(A) = n$ | **唯一解**（零解） |
| 齐次 | $r(A) < n$ | **无穷多解** |
| 非齐次 | $r(A,\mathbf{b}) \neq r(A)$ | **无解** |
| 非齐次 | $r(A,\mathbf{b}) = r(A) = n$ | **唯一解** |
| 非齐次 | $r(A,\mathbf{b}) = r(A) < n$ | **无穷多解** |

> [!tip] 记忆口诀
> **齐次看秩比 n，非齐次先看等不等，再看秩比 n**

## 五、标准解题流程

### 5.1 通用五步法

> [!abstract] 行化简算法
> 1. 写出方程组的**增广矩阵**（齐次则只需系数矩阵）
> 2. 利用初等行变换化为**行阶梯形**，判断是否有解。无解则停止
> 3. 继续化为**行最简形**
> 4. 写出最简形矩阵对应的方程组
> 5. 将每个非零方程改写为用自由变量表示基本变量的形式

### 5.2 含参方程组的分类讨论模板

```
Step 1: 化增广矩阵为行阶梯形
Step 2: 找出使主元位置出现零的行（即含参数的行）
Step 3: 按参数取值分类讨论：
  - 情况1：参数使主元非零 → 秩确定 → 直接判断
  - 情况2：参数使主元 = 0 → 需进一步化简，再判断
```

## 六、易错点与考场速记

### 6.1 考场高频易错点

| # | 易错点 | 正确做法 |
|:-:|-------|---------|
| 1 | 把列变换混入消元过程 | 解方程组**只能用行变换**，列变换改变变量对应关系 |
| 2 | 某行乘以 0 | 乘以 0 会丢失信息且不可逆（不属于初等行变换） |
| 3 | 漏掉系数为 0 的列 | 增广矩阵中每个变量对应一列，系数 0 也要写 0 |
| 4 | 看到 $r < n$ 就认为无解 | $r < n$ 且无矛盾行时是**无穷多解**，不是无解 |
| 5 | 齐次方程也检查"无解" | 齐次方程 $b=0$，**永远不会无解** |
| 6 | 自由变量赋值后忘记回代求基本变量 | 自由变量取任意值后，须依次回代求出所有基本变量 |
| 7 | 非齐次唯一解的条件是双条件 | $r(A, \mathbf{b}) = r(A) = n$，缺一不可 |
| 8 | $r(A) = n$ 只保证齐次唯一解 | 不保证非齐次有解 |
| 9 | 含参题先代入再化简 | 要先化简再分类，代入具体值会丢失信息 |
| 10 | 自由变量个数算错 | 自由变量个数 = $n - r$，不是 $m - r$ |

### 6.2 考场速记卡片

| 条件 | 结论 |
|:---|:---|
| $r(A) = n$（齐次） | 唯一解（零解） |
| $r(A) < n$（齐次） | 无穷多解 |
| $r(A, \mathbf{b}) \neq r(A)$ | 无解 |
| $r(A, \mathbf{b}) = r(A) = n$ | 唯一解 |
| $r(A, \mathbf{b}) = r(A) < n$ | 无穷多解 |

> [!tip] 重要结论
> - **行满秩**（$r(A) = m$）保证非齐次有解
> - **列满秩**（$r(A) = n$）保证齐次唯一解
> - **自由变量个数** = $n - r$（$r$ 为非零行数 = 主元个数）
