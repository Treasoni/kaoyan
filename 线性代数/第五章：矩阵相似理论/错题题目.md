## 错题25

已知 $\alpha, \beta$ 是 2 维单位列向量。若满足 $\|\alpha + \beta\| = \|\alpha - \beta\|$，则矩阵 $A = (\alpha, \beta)$ 必是（　）。

(A) 实对称矩阵　　(B) 单位矩阵　　(C) 正交矩阵　　(D) 正定矩阵

**答案：(C) 正交矩阵**

### 一、核心考点解析

本题考查向量范数、内积、标量转置不变性以及正交矩阵的判定，融合代数推导与几何直觉。

1. **向量范数与内积的转化**：模长的平方等于向量与自身的内积，即 $\|\alpha\|^2 = \alpha^T\alpha$。
2. **实数标量转置不变性**：两个同维列向量的内积结果是实数，故 $(\alpha^T\beta)^T = \beta^T\alpha = \alpha^T\beta$。
3. **正交矩阵的判定**：$A$ 为正交矩阵的充要条件是 $A^T A = E$（列向量构成规范正交基）。

### 二、解题思路与证明

#### 方法一：严谨代数推导

**第一步：利用范数条件推导向量正交**

由 $\|\alpha + \beta\| = \|\alpha - \beta\|$ 两边平方：

$$(\alpha + \beta)^T(\alpha + \beta) = (\alpha - \beta)^T(\alpha - \beta)$$

展开：

$$\alpha^T\alpha + \alpha^T\beta + \beta^T\alpha + \beta^T\beta = \alpha^T\alpha - \alpha^T\beta - \beta^T\alpha + \beta^T\beta$$

消去相同项：

$$\alpha^T\beta + \beta^T\alpha = -\alpha^T\beta - \beta^T\alpha$$

> **易错关键点**：$\alpha^T\beta$ 是标量，标量的转置等于其自身，即 $\beta^T\alpha = (\alpha^T\beta)^T = \alpha^T\beta$。

代入得：

$$2\alpha^T\beta = -2\alpha^T\beta \implies \alpha^T\beta = 0$$

结论：$\alpha$ 与 $\beta$ 正交。

**第二步：计算 $A^T A$ 验证正交性**

$$A^T A = \begin{pmatrix} \alpha^T \\ \beta^T \end{pmatrix} (\alpha, \beta) = \begin{pmatrix} \alpha^T\alpha & \alpha^T\beta \\ \beta^T\alpha & \beta^T\beta \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} = E$$

故 $A$ 必定是正交矩阵。

#### 方法二：几何直觉"秒杀法"

把 $\alpha, \beta$ 看作二维平面上平行四边形的两个邻边：
- $\alpha + \beta$、$\alpha - \beta$ 分别是两条对角线
- $\|\alpha + \beta\| = \|\alpha - \beta\|$ 意味着两对角线等长

由几何常识可知：对角线相等的平行四边形必是矩形，即邻边 $\alpha \perp \beta$。结合单位向量条件，$A = (\alpha, \beta)$ 由规范正交基构成，故为正交矩阵。

### 三、延伸警示与避坑指南

**关于"正交矩阵特征值为 $\pm 1$"的伪证陷阱**

很多同学在证明"正交矩阵特征值为 $\pm 1$"时会写出如下推导：

> ❌ **错误做法**：设 $Q\alpha = \lambda\alpha$，取转置得 $\alpha^T Q^T = \lambda\alpha^T$。两式相乘：$\alpha^T Q^T Q \alpha = \lambda^2 \alpha^T\alpha$，约去 $\alpha^T\alpha$ 得 $\lambda^2 = 1$。🚨 此处错了！

**避坑原因**：上述推导默认 $\alpha$ 为实向量。若 $\alpha$ 为复向量，则 $\alpha^T\alpha$ 完全可能为 0！

例如 $\alpha = (1, i)^T$，则 $\alpha^T\alpha = 1^2 + i^2 = 1 - 1 = 0$，无法在等式两边约去。

✅ **正确姿势**：证明正交矩阵特征值的模为 1，必须引入**共轭转置**（记为 $H$ 或 $\overline{(\cdot)}^T$），使用 $\alpha^H \alpha$ 代替 $\alpha^T\alpha$。复向量与其共轭转置相乘（复内积）严格大于 0，方可安全约分，得 $|\lambda|^2 = 1 \implies |\lambda| = 1$。

> **补充说明**：对于**实**正交矩阵，特征值的模为 1。若特征值为实数则必为 $\pm 1$，但一般情形下特征值可能在复平面单位圆上（如旋转矩阵 $R_\theta$ 的特征值为 $e^{\pm i\theta}$），并非仅取 $\pm 1$。

## 错题27

设 $A$ 是 3 阶实对称矩阵，已知 $A$ 的三个特征值为 $-1, 1, 2$，且 $\lambda_1 = -1$ 对应的特征向量为 $\alpha_1 = (1, 2, 1)^T$，$\lambda_2 = 1$ 对应的特征向量为 $\alpha_2 = (-1, 0, 1)^T$。求 $\lambda_3 = 2$ 对应的特征向量 $\alpha_3$。

**证明**：

**第一步：求特征值的可能取值**

由 $A^3 + A^2 + A - 3E = O$ 知，$A$ 的特征值 $\lambda$ 必满足标量方程：

$$\lambda^3 + \lambda^2 + \lambda - 3 = 0$$

观察可知 $\lambda = 1$ 是根（$1 + 1 + 1 - 3 = 0$），因式分解：

$$(\lambda - 1)(\lambda^2 + 2\lambda + 3) = 0$$

对 $\lambda^2 + 2\lambda + 3 = 0$，判别式 $\Delta = 4 - 12 = -8 < 0$，仅有两个共轭复数根。

**第二步：利用实对称矩阵的特征值必为实数**

实对称矩阵的核心性质：所有特征值必为实数。因此复数根被淘汰，$A$ 的所有特征值只能是 $1$。

**第三步：利用实对称矩阵可相似对角化**

实对称矩阵必可正交相似对角化，存在正交矩阵 $Q$ 使得 $Q^{-1}AQ = \Lambda$，其中 $\Lambda$ 是特征值构成的对角阵。

由于所有特征值均为 $1$，故 $\Lambda = E$，从而：

$$Q^{-1}AQ = E \implies A = QEQ^{-1} = QQ^{-1} = E \qquad \blacksquare$$

**两个关键卡点**：

1. **复数根取舍**：算出方程后必须借助"A 为实对称 ⇒ 特征值为实数"淘汰复数根，否则无法得出特征值全是 $1$ 的结论。
2. **不可省略对角化步骤**：特征值全为 $1$ 不能直接推出 $A = E$。反例：$B = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$ 特征值全为 $1$ 但 $B \neq E$。必须先证明 $A$ 可相似对角化，由 $A = P\Lambda P^{-1} = PEP^{-1} = E$ 得证。
