# 5.1.2 特征多项式与特征方程

## 特征多项式

由定义 $\pmb{A}\pmb{x} = \lambda \pmb{x}$ 移项得

$$
(\lambda \pmb{E} - \pmb{A})\pmb{x} = \pmb{0}
$$

这是一个含 $n$ 个方程 $n$ 个未知数的齐次线性方程组，其系数矩阵为 $\lambda \pmb{E} - \pmb{A}$。

## 特征方程

齐次方程组 $(\lambda \pmb{E} - \pmb{A})\pmb{x} = \pmb{0}$ 有非零解 $\iff \det(\lambda \pmb{E} - \pmb{A}) = 0$

- **特征多项式**：$f(\lambda) = |\lambda \pmb{E} - \pmb{A}|$
- **特征方程**：$f(\lambda) = |\lambda \pmb{E} - \pmb{A}| = 0$

## 逻辑链条

```mermaid
flowchart LR
    A[定义式 Ax = λx] --> B[移项得 (λE-A)x = 0]
    B --> C[齐次线性方程组有非零解]
    C --> D[|λE-A| = 0]
    D --> E[求解特征方程得 λ]
    E --> F[代入 (λE-A)x = 0 求特征向量]
```

## 关键理解

- 特征向量是 $(\lambda \pmb{E} - \pmb{A})\pmb{x} = \pmb{0}$ 的**非零解**
- 特征值 $\lambda$ 使 $(\lambda \pmb{E} - \pmb{A})$ 成为**奇异矩阵**（行列式为 0）
- 求特征向量的本质：求解齐次线性方程组的非零解问题
