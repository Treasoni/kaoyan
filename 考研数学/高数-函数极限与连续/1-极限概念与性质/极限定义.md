# 极限定义

## 原始定义

设函数 $f(x)$ 在点 $x_0$ 的某一去心邻域内有定义。若存在常数 $A$，对于任意给定的 $\varepsilon > 0$（不论它多么小），总存在正数 $\delta$，使得当 $0 < |x - x_0| < \delta$ 时，对应的函数值 $f(x)$ 都满足不等式 $|f(x) - A| < \varepsilon$，则 $A$ 叫作函数 $f(x)$ 当 $x \to x_0$ 时的极限，记为

$$
\lim_{x \to x_0} f(x) = A \quad \text{或} \quad f(x) \to A \ (x \to x_0)
$$

## 直观理解 💡

### 生活类比1：追人游戏

想象你在追一个朋友：
- 你不断靠近他，但**永远不一定要真正追上**
- 只要你能**无限接近**他，这就是"极限"

**关键**：极限不是"到达"，而是"无限靠近"。

### 生活类比2：GPS导航定位

GPS告诉你目的地在"前方500米"：
- 这个500米是个**近似值**
- 但只要GPS精度够高，误差可以**任意小**
- 极限就是：==误差要多小有多小==

### ε-δ语言的含义

**打靶比喻**：
- $A$ 是靶心（目标值）
- $\varepsilon$ 是你允许的误差范围（靶的半径）
- $\delta$ 是你瞄准的精确度（控制自变量的范围）

**核心思想**：==只要你给我任意小的误差要求 $\varepsilon$，我总能找到一个 $\delta$ 邻域，使得在这个邻域内，函数值与目标值的距离小于 $\varepsilon$==。

### 为什么强调"去心邻域"？

**关键理解**：==极限研究的是**趋势**，与该点函数值无关。==

**生活类比**：
- 你观察某人"走路的方向"（趋势）
- 不需要知道他"站在哪里"（函数值）
- 他可能站在原地不动，但**方向**（极限）可以是任何方向

**数学意义**：
- $x \to x_0$ 表示 $x$ 无限接近 $x_0$，但**永远不等于** $x_0$
- 函数在 $x_0$ 处可以有定义，也可以没有定义
- 即使有定义，$f(x_0)$ 也可能与极限值不同

> [!personal] 深度理解：为什么"必须"用去心邻域？
>
> **1. 逻辑上的"必须"：处理无定义的点**
> - 极限让我们研究那些原本没法算的地方
> - 例子：$f(x) = \frac{\sin x}{x}$ 在 $x=0$ 是 $\frac{0}{0}$，无定义
> - 如果不把中心点"挖掉"，就无法讨论 $x \to 0$ 时的趋势
> - 正是因为只看去心邻域，才能得出 $\lim_{x \to 0} \frac{\sin x}{x} = 1$
>
> **2. 定义中的"必须"：ε-δ 语言**
> - 定义中的 $0 < |x - x_0| < \delta$ 在法律上规定：$x$ 永远不能等于 $x_0$
> - 如果去掉 $0 < \cdots$，则当 $x = x_0$ 时必须 $|f(x_0) - L| < \varepsilon$
> - 这会导致极限值 $L$ 必须等于函数值 $f(x_0)$
> - 极限和"连续性"混为一谈，失去独立工具的意义
>
> **3. 直觉上的"必须"：趋势 vs 结果**
> - **去心邻域**：通往终点的那段路程
> - **中心点**：终点站本身
> - 极限只关心"往哪儿走"（趋势），不关心"最后坐哪儿"（结果）
>
> **总结**：
> - **有极限**：邻居们（去心邻域）都说你往这儿走
> - **连续**：邻居们说你往这儿走，且你真的坐在了那儿
>
> **延伸：代入法的数学依据**
> - 代入法是"先斩后奏"：只有在连续时才能直接代入
> - 严谨逻辑：$f$ 在 $x_0$ 连续 $\Rightarrow \lim_{x \to x_0} f(x) = f(x_0)$
> - 做题逻辑：初等函数在定义域内连续，所以可用 $f(x_0)$ 代表极限值
>
> **代入法何时翻车？**
> - **分段函数陷阱**：$f(x) = \begin{cases} x+1 & x \neq 0 \\ 100 & x = 0 \end{cases}$
>   - 代入得 100（函数值），但极限是 1（邻居们的趋势）
> - **未定式化简**：$\lim_{x \to 1} \frac{x^2 - 1}{x - 1}$
>   - 直接代入得 $\frac{0}{0}$（报错）
>   - 但 $x \neq 1$，可约分：$\frac{(x-1)(x+1)}{x-1} = x + 1$
>   - 约掉后"填坑"成功，代入得 2

### 左右极限与极限存在

**门框比喻**：
- 想象你要通过一扇门
- 从左边走，门框高度是 $h_1$
- 从右边走，门框高度是 $h_2$
- 只有 $h_1 = h_2$ 时，门才能"平滑通过"（极限存在）

**数学表述**：
$$\lim_{x \to x_0} f(x) \text{ 存在} \Leftrightarrow \lim_{x \to x_0^+} f(x) = \lim_{x \to x_0^-} f(x)$$


## 定理条件 ⚠️

### ε-δ语言的标准表述

$$
\lim_{x \to x_0} f(x) = A \Leftrightarrow \forall \varepsilon > 0, \exists \delta > 0, \text{当 } 0 < |x - x_0| < \delta \text{ 时，有 } |f(x) - A| < \varepsilon
$$

**关键符号说明**：
- $\forall$（Arbitrary的首字母倒写）：任意给定
- $\exists$（Exist的首字母倒写）：存在

### 24种极限定义一览

函数极限共有 **24 种定义**，由 **6 种自变量趋近方式** 与 **4 种函数趋近方式** 组合而成（$6 \times 4 = 24$）。

> [!info] 定义结构
> - **自变量趋近**：$x \to x_0$、$x \to x_0^+$、$x \to x_0^-$、$x \to \infty$、$x \to +\infty$、$x \to -\infty$
> - **函数趋近**：$f(x) \to A$（有限极限）、$f(x) \to \infty$、$f(x) \to +\infty$、$f(x) \to -\infty$

---

#### 一、自变量 $x \to x_0$ 类（有限点极限）

##### 1.1 $\displaystyle \lim_{x \to x_0} f(x) = A$

$$\forall \varepsilon > 0, \exists \delta > 0, \text{ 当 } 0 < |x - x_0| < \delta \text{ 时，有 } |f(x) - A| < \varepsilon$$

##### 1.2 $\displaystyle \lim_{x \to x_0} f(x) = \infty$

$$\forall M > 0, \exists \delta > 0, \text{ 当 } 0 < |x - x_0| < \delta \text{ 时，有 } |f(x)| > M$$

##### 1.3 $\displaystyle \lim_{x \to x_0} f(x) = +\infty$

$$\forall M > 0, \exists \delta > 0, \text{ 当 } 0 < |x - x_0| < \delta \text{ 时，有 } f(x) > M$$

##### 1.4 $\displaystyle \lim_{x \to x_0} f(x) = -\infty$

$$\forall M > 0, \exists \delta > 0, \text{ 当 } 0 < |x - x_0| < \delta \text{ 时，有 } f(x) < -M$$

---

#### 二、自变量 $x \to x_0^+$ 类（右极限）

##### 2.1 $\displaystyle \lim_{x \to x_0^+} f(x) = A$

$$\forall \varepsilon > 0, \exists \delta > 0, \text{ 当 } 0 < x - x_0 < \delta \text{ 时，有 } |f(x) - A| < \varepsilon$$

##### 2.2 $\displaystyle \lim_{x \to x_0^+} f(x) = \infty$

$$\forall M > 0, \exists \delta > 0, \text{ 当 } 0 < x - x_0 < \delta \text{ 时，有 } |f(x)| > M$$

##### 2.3 $\displaystyle \lim_{x \to x_0^+} f(x) = +\infty$

$$\forall M > 0, \exists \delta > 0, \text{ 当 } 0 < x - x_0 < \delta \text{ 时，有 } f(x) > M$$

##### 2.4 $\displaystyle \lim_{x \to x_0^+} f(x) = -\infty$

$$\forall M > 0, \exists \delta > 0, \text{ 当 } 0 < x - x_0 < \delta \text{ 时，有 } f(x) < -M$$

---

#### 三、自变量 $x \to x_0^-$ 类（左极限）

##### 3.1 $\displaystyle \lim_{x \to x_0^-} f(x) = A$

$$\forall \varepsilon > 0, \exists \delta > 0, \text{ 当 } 0 < x_0 - x < \delta \text{ 时，有 } |f(x) - A| < \varepsilon$$

##### 3.2 $\displaystyle \lim_{x \to x_0^-} f(x) = \infty$

$$\forall M > 0, \exists \delta > 0, \text{ 当 } 0 < x_0 - x < \delta \text{ 时，有 } |f(x)| > M$$

##### 3.3 $\displaystyle \lim_{x \to x_0^-} f(x) = +\infty$

$$\forall M > 0, \exists \delta > 0, \text{ 当 } 0 < x_0 - x < \delta \text{ 时，有 } f(x) > M$$

##### 3.4 $\displaystyle \lim_{x \to x_0^-} f(x) = -\infty$

$$\forall M > 0, \exists \delta > 0, \text{ 当 } 0 < x_0 - x < \delta \text{ 时，有 } f(x) < -M$$

---

#### 四、自变量 $x \to \infty$ 类（无穷远极限）

##### 4.1 $\displaystyle \lim_{x \to \infty} f(x) = A$

$$\forall \varepsilon > 0, \exists X > 0, \text{ 当 } |x| > X \text{ 时，有 } |f(x) - A| < \varepsilon$$

##### 4.2 $\displaystyle \lim_{x \to \infty} f(x) = \infty$

$$\forall M > 0, \exists X > 0, \text{ 当 } |x| > X \text{ 时，有 } |f(x)| > M$$

##### 4.3 $\displaystyle \lim_{x \to \infty} f(x) = +\infty$

$$\forall M > 0, \exists X > 0, \text{ 当 } |x| > X \text{ 时，有 } f(x) > M$$

##### 4.4 $\displaystyle \lim_{x \to \infty} f(x) = -\infty$

$$\forall M > 0, \exists X > 0, \text{ 当 } |x| > X \text{ 时，有 } f(x) < -M$$

---

#### 五、自变量 $x \to +\infty$ 类（正无穷极限）

##### 5.1 $\displaystyle \lim_{x \to +\infty} f(x) = A$

$$\forall \varepsilon > 0, \exists X > 0, \text{ 当 } x > X \text{ 时，有 } |f(x) - A| < \varepsilon$$

##### 5.2 $\displaystyle \lim_{x \to +\infty} f(x) = \infty$

$$\forall M > 0, \exists X > 0, \text{ 当 } x > X \text{ 时，有 } |f(x)| > M$$

##### 5.3 $\displaystyle \lim_{x \to +\infty} f(x) = +\infty$

$$\forall M > 0, \exists X > 0, \text{ 当 } x > X \text{ 时，有 } f(x) > M$$

##### 5.4 $\displaystyle \lim_{x \to +\infty} f(x) = -\infty$

$$\forall M > 0, \exists X > 0, \text{ 当 } x > X \text{ 时，有 } f(x) < -M$$

---

#### 六、自变量 $x \to -\infty$ 类（负无穷极限）

##### 6.1 $\displaystyle \lim_{x \to -\infty} f(x) = A$

$$\forall \varepsilon > 0, \exists X > 0, \text{ 当 } x < -X \text{ 时，有 } |f(x) - A| < \varepsilon$$

##### 6.2 $\displaystyle \lim_{x \to -\infty} f(x) = \infty$

$$\forall M > 0, \exists X > 0, \text{ 当 } x < -X \text{ 时，有 } |f(x)| > M$$

##### 6.3 $\displaystyle \lim_{x \to -\infty} f(x) = +\infty$

$$\forall M > 0, \exists X > 0, \text{ 当 } x < -X \text{ 时，有 } f(x) > M$$

##### 6.4 $\displaystyle \lim_{x \to -\infty} f(x) = -\infty$

$$\forall M > 0, \exists X > 0, \text{ 当 } x < -X \text{ 时，有 } f(x) < -M$$

---

> [!tip] 记忆规律
> 1. **有限点用 $\delta$，无穷远用 $X$**：$x \to x_0$ 型用 $\delta$ 控制邻域，$x \to \infty$ 型用 $X$ 控制范围
> 2. **双向与单向**：$x \to x_0$ 需双向（$|x - x_0|$），左右极限只看单侧（$x - x_0$ 或 $x_0 - x$）
> 3. **有限极限用 $\varepsilon$，无穷极限用 $M$**：趋近有限值 $A$ 用 $|f(x) - A| < \varepsilon$，趋近无穷用 $|f(x)| > M$
> 4. **正负无穷的区别**：$+\infty$ 要求 $f(x) > M$，$-\infty$ 要求 $f(x) < -M$

## 典型题型

### 题型1：判断极限是否存在

**关键**：对于 $x \to x_0$，需检验 $\lim_{x \to x_0^+} f(x) = \lim_{x \to x_0^-} f(x)$

**常见陷阱函数**：
- $e^{\frac{1}{x-1}}$（在 $x \to 1$ 时左右极限不同）
- $\frac{\sin x}{|x|}$（在 $x \to 0$ 时左右极限不同）
- $\arctan x$（在 $x \to \infty$ 时正负无穷不同）

### 题型2：利用极限存在性求参数

**核心方法**：若 $\lim_{x \to 0} \frac{f(x)}{g(x)} = A \neq 0$，且 $\lim_{x \to 0} f(x) = 0$，则 $\lim_{x \to 0} g(x) = 0$

## 解题方法

### 方法1：定义法证明极限

**步骤**：
1. 任给 $\varepsilon > 0$
2. 分析 $|f(x) - A|$，找到与 $|x - x_0|$ 的关系
3. 令 $|f(x) - A| < \varepsilon$，解出 $\delta$ 的范围
4. 验证当 $0 < |x - x_0| < \delta$ 时，结论成立

### 方法2：左右极限法

**适用场景**：分段函数、含绝对值、指数函数

**步骤**：
1. 求左极限 $\lim_{x \to x_0^-} f(x)$
2. 求右极限 $\lim_{x \to x_0^+} f(x)$
3. 若左右极限相等，则极限存在且等于该值；否则极限不存在

## 易错点 ⚠️

⚠️ **易错点1**：忽略去心邻域
- 错误：认为 $x = x_0$ 时 $f(x_0)$ 必须等于 $A$
- 正确：极限只关心 $x \to x_0$ 时的趋势，与 $f(x_0)$ 无关

⚠️ **易错点2**：混淆左、右极限
- 错误：直接求 $\lim_{x \to 0} \frac{\sin x}{|x|}$
- 正确：需分别求 $\lim_{x \to 0^+}$ 和 $\lim_{x \to 0^-}$

⚠️ **易错点3**：$e^{\frac{1}{x-1}}$ 型函数
- 错误：认为 $\lim_{x \to 1} e^{\frac{1}{x-1}}$ 存在
- 正确：
  - $x \to 1^+$ 时，$\frac{1}{x-1} \to +\infty$，$e^{\frac{1}{x-1}} \to +\infty$
  - $x \to 1^-$ 时，$\frac{1}{x-1} \to -\infty$，$e^{\frac{1}{x-1}} \to 0$
  - 左右不等，极限不存在

⚠️ **易错点4**：$x \to \infty$ 的双向性
- $x \to \infty$ 意味着 $x \to +\infty$ 且 $x \to -\infty$ 两个方向
- 如 $\lim_{x \to \infty} e^x$ 不存在（正负方向结果不同）

### 过程 vs 结果 💡

> [!personal] 理解记录（2026-03-04）
>
> **极限的过程 vs 结果**
> - 在 $\lim_{x \to x_0} f(x) = A$ 中，$x \to x_0$ 表示 $x$ 无限靠近 $x_0$，但严格规定 $x \neq x_0$
> - 极限 $A$ 是当 $x$ 在这个运动过程中，$f(x)$ 表现出来的"目标值"
>
> **$f(x)$ 与极限 $A$ 的三种关系**
> - **完全不相等**（最典型）：如 $f(x) = \frac{x^2-1}{x-1}$，$x \to 1$ 时极限为 2，但 $f(1)$ 无定义
> - **始终相等**（常数函数）：如 $f(x) = 5$，极限就是 5，$f(x)$ 始终等于极限值
> - **穿梭相等**（振荡趋近）：如 $x \sin(1/x)$，在趋近过程中反复穿过极限值
>
> **核心结论**
> - 极限关注的是**趋势**，而非**某一点的函数值**
> - 函数在某点是否有定义，与该点的极限是否存在无关
>
> **相关联的概念**：
> - **左极限与右极限**：判断极限存在性的关键工具
> - **$\varepsilon$-$\delta$ 定义**：理解极限本质的进阶视角

## 例题

> [!example] 例1：判断极限是否存在
> **题目**：当 $x \to 1$ 时，函数 $\frac{e^{\frac{1}{x-1}} \ln|1+x|}{(e^x - 1)(x - 2)}$ 的极限（ ）
>
> (A) 等于1  (B) 等于0  (C) 为 $\infty$  (D) 不存在且不为 $\infty$
>
> **分析**：$x \to 1$，关键看 $e^{\frac{1}{x-1}}$
>
> **解答**：
> - $x \to 1^+$ 时，$x - 1 \to 0^+$，$\frac{1}{x-1} \to +\infty$，$e^{\frac{1}{x-1}} \to +\infty$
> - $x \to 1^-$ 时，$x - 1 \to 0^-$，$\frac{1}{x-1} \to -\infty$，$e^{\frac{1}{x-1}} \to 0$
>
> 左右极限不相等，故极限不存在且不为 $\infty$，选 (D)
>
> **评注**：遇到 $e^{\frac{1}{x - x_0}}$ 型函数，必须分左右讨论

> [!example] 例2：利用极限存在性求参数
> **题目**：设 $\lim_{x \to 0} \frac{\sin x}{e^x - a}(\cos x - b) = 5$，则 $b = ?$
>
> **分析**：利用"若 $\lim \frac{f}{g} = A \neq 0$ 且 $\lim f = 0$，则 $\lim g = 0$"
>
> **解答**：
> - 由条件，$\lim_{x \to 0} \frac{\sin x}{e^x - a}(\cos x - b) = 5 \neq 0$
> - 且 $\lim_{x \to 0} \sin x = 0$（分子趋于0）
> - 故 $\lim_{x \to 0} (e^x - a) = 0$，即 $a = 1$
> - 原极限变为 $\lim_{x \to 0} \frac{\sin x}{e^x - 1}(\cos x - b) = \lim_{x \to 0} (\cos x - b) = 1 - b = 5$
> - 故 $b = -4$
>
> **评注**：记住这个结论，在定参数题目中可直接使用

- 在**定积分**中，黎曼和的极限 $\lim_{\lambda \to 0} \sum f(\xi_i)\Delta x_i$ 也用到极限定义
- 在**级数收敛**中，部分和数列的极限判断级数收敛性

### 极限的本质（三种视角）

**视角1：逼近视角**
- 极限是"无限靠近"的严格化描述
- 不要求"到达"，只要求"要多近有多近"

**视角2：稳定视角**
- 当 $x$ 足够接近 $x_0$ 时，$f(x)$ 就稳定在 $A$ 附近
- 这种稳定性不依赖于 $x_0$ 点本身

**视角3：控制视角（ε-δ语言）**
- $\varepsilon$ 是对输出的控制精度
- $\delta$ 是对输入的控制范围
- 极限存在 = 无论输出精度要求多高，总能找到对应的输入控制范围
