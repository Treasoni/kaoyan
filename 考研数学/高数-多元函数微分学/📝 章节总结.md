# 📝 多元函数微分学 — 章节总结

> 本章是考研数学二的高频考点，核心主线：**基本概念 → 微分法则 → 极值与最值**。

---

## 一、基本概念

### 1.1 邻域

**δ 邻域**：$U(P_0, \delta) = \left\{ (x, y) \mid \sqrt{(x - x_0)^2 + (y - y_0)^2} < \delta \right\}$，几何上是开圆盘。

**去心 δ 邻域**：$\dot{U}(P_0, \delta) = \left\{ P \mid 0 < |PP_0| < \delta \right\}$，讨论极限时使用。

> 📄 详见：[[邻域]]

---

### 1.2 极限（二重极限）

$$\lim_{(x,y) \to (x_0,y_0)} f(x,y) = A \;\Leftrightarrow\; \forall\varepsilon>0,\;\exists\delta>0,\;0<|PP_0|<\delta \Rightarrow |f(x,y)-A|<\varepsilon$$

其中 $|PP_0| = \sqrt{(x-x_0)^2 + (y-y_0)^2}$。

**核心区别**：一元极限只有左右两条路，二元极限有无穷多条路径。

#### 证明极限不存在的方法

| 路径 | 表达式 | 适用场景 |
|------|--------|----------|
| 沿 $x$ 轴 | $y = 0$ | 分母含 $y$ |
| 沿 $y$ 轴 | $x = 0$ | 分母含 $x$ |
| 沿直线 | $y = kx$ | 含 $y/x$ 项 |
| 沿对角线 | $y = x$ | 含对称结构 |
| 沿抛物线 | $y = x^2$ | 含高次项 |

#### 可用方法 vs 不能用

- $\checkmark$ **可用**：等价无穷小替换、夹逼准则、四则运算、代入法、脱帽法
- $\times$ **不能用**：洛必达法则、单调有界准则

> 📄 详见：[[极限]]

---

### 1.3 连续

$$\lim_{(x,y) \to (x_0,y_0)} f(x,y) = f(x_0,y_0)$$

**核心结论**：二元初等函数在定义区域上连续。考纲不要求讨论间断点类型。

> 📄 详见：[[连续]]

---

### 1.4 偏导数

#### 定义

$$f_x'(x_0,y_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x,\, y_0) - f(x_0,\, y_0)}{\Delta x}$$

$$f_y'(x_0,y_0) = \lim_{\Delta y \to 0} \frac{f(x_0,\, y_0 + \Delta y) - f(x_0,\, y_0)}{\Delta y}$$

#### 几何意义

- $f_x'(x_0,y_0)$：平面 $y=y_0$ 与曲面交线在 $x$ 方向的斜率
- $f_y'(x_0,y_0)$：平面 $x=x_0$ 与曲面交线在 $y$ 方向的斜率

#### 高阶偏导数

若 $f_{xy}''$ 和 $f_{yx}''$ 都连续，则 $f_{xy}'' = f_{yx}''$（与求导次序无关）。初等函数默认相等。

#### 三大考点

1. **求偏导时另一个变量是否为常数？** — 取决于变量是否相互独立
2. **"先代入，后求导"的降维魔法** — 仅限于求具体点的偏导数；求偏导函数表达式时**禁止**提前代入
3. **何时必须用定义？** — 遇到绝对值零点、分段函数分界点、套公式分母为零 → 立即用极限定义

> ⚠️ 偏导数存在 $\not\Rightarrow$ 函数连续（与一元函数的重大区别）

> 📄 详见：[[偏导数]]

---

### 1.5 可微 ⭐重难点

#### 核心定义

$$\boxed{\Delta z = A\Delta x + B\Delta y + o(\rho)}$$

其中 $\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}$，$A = \frac{\partial z}{\partial x}$，$B = \frac{\partial z}{\partial y}$。

全微分：$\boxed{\mathrm{d}z = \frac{\partial z}{\partial x}\mathrm{d}x + \frac{\partial z}{\partial y}\mathrm{d}y}$

#### 条件体系

| 条件 | 结论 |
|------|------|
| 偏导数存在且连续 | $\Rightarrow$ **可微**（充分不必要） |
| 函数可微 | $\Rightarrow$ 偏导数存在（必要不充分） |
| 偏导数不连续 | $\not\Rightarrow$ 不可微（定理失效） |

#### 一元 vs 二元对比

| 函数类型 | 可微 $\Rightarrow$ 可导/偏导存在 | 可导/偏导存在 $\Rightarrow$ 可微 |
|:------:|:---:|:---:|
| 一元 $y=f(x)$ | $\checkmark$ | $\checkmark$ |
| 二元 $z=f(x,y)$ | $\checkmark$ | $\times$ |

#### 三步判别法（定义法 — 充要条件）

$$\boxed{\lim_{\substack{\Delta x \to 0 \\ \Delta y \to 0}} \frac{\Delta z - (A\Delta x + B\Delta y)}{\sqrt{(\Delta x)^2 + (\Delta y)^2}} = 0 \;?}$$

- 极限 $= 0$ → **可微**
- 极限 $\neq 0$ → **不可微**

#### 决策树

```
正常初等函数（无绝对值，无分母→0）
  → 方法一：求偏导看连续性（偏导连续 ⇒ 可微）

带绝对值 / 分段函数 / 要求证明不可微
  → 方法二：定义法（必须用）
```

**易错**：
- 偏导数不连续 $\neq$ 不可微
- 定义法中 $\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}$，不是 $|\Delta x| + |\Delta y|$

> 📄 详见：[[可微]]

---

### 📊 基本概念关系总图

```
偏导数连续
    ↓ （充分）
   可微
    ↓ （必要）      偏导数存在
   连续          ←     ✗
```

> 可微 $\Rightarrow$ 连续 $\Rightarrow$ 极限存在；偏导数存在 $\not\Rightarrow$ 连续，偏导数存在 $\not\Rightarrow$ 可微。

## 二、微分法则

### 2.1 链式求导规则

#### 基本公式

$z = f(u,v)$，$u = u(x,y)$，$v = v(x,y)$：

$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\cdot\frac{\partial u}{\partial x} + \frac{\partial z}{\partial v}\cdot\frac{\partial v}{\partial x}$$

#### 全导数

$z = f(u,v)$，$u = \varphi(t)$，$v = \psi(t)$：

$$\frac{\mathrm{d}z}{\mathrm{d}t} = \frac{\partial z}{\partial u}\cdot\frac{\mathrm{d}u}{\mathrm{d}t} + \frac{\partial z}{\partial v}\cdot\frac{\mathrm{d}v}{\mathrm{d}t}$$

#### 两大铁律

- **铁律一（只认位置，不看内容）**：$f_1'$ = 对第 1 个位置求导，把第 2 个位置视作常数
- **铁律二（分层处理，绝不跨级）**：外层求导完再处理内层

> ⚠️ **最容易出错**：求完一阶导后，$f_1'$、$f_2'$ 仍具有与原函数完全相同的复合结构！再求导时还要用链式法则。

#### 记号约定

$f_1'$ = 对第 1 个位置求导，$f_{11}''$ = 对第 1 个位置求二阶导，$f_{12}''$ = 先对第 1 再对第 2。

> 📄 详见：[[链式求导规则]]

---

### 2.2 全微分形式不变性

**核心**：不管 $u, v$ 是自变量还是中间变量，全微分形式始终成立：

$$\boxed{\mathrm{d}z = \frac{\partial z}{\partial u}\mathrm{d}u + \frac{\partial z}{\partial v}\mathrm{d}v}$$

**应用**：用全微分法求隐函数偏导，可一步同时求出 $\frac{\partial z}{\partial x}$ 和 $\frac{\partial z}{\partial y}$。

> 📄 详见：[[全微分形式不变性]]

---

### 2.3 隐函数存在定理（公式法）

| 定理 | 公式 |
|------|------|
| $F(x,y)=0 \Rightarrow y=y(x)$ | $\displaystyle \frac{\mathrm{d}y}{\mathrm{d}x} = -\frac{F_x'}{F_y'}$ |
| $F(x,y,z)=0 \Rightarrow z=z(x,y)$ | $\displaystyle \frac{\partial z}{\partial x} = -\frac{F_x'}{F_z'},\;\frac{\partial z}{\partial y} = -\frac{F_y'}{F_z'}$ |

**三种求导方法**:
1. **公式法** — 直接套公式，最规范
2. **复合函数求导法** — 方程两边对 $x$ 求偏导，注意 $z$ 是 $x,y$ 的函数
3. **全微分法** — 同时求两个偏导，最高效

> 📄 详见：[[隐函数存在定理]]

---

### 2.4 二元函数的拉格朗日定理

若在区域 $D$ 上 $\frac{\partial f}{\partial x} = \frac{\partial f}{\partial y} = 0$，则 $f(x,y) \equiv C$（常数）。

> 这是一元函数"$f'(x)=0 \Rightarrow f(x)=C$"的自然推广，要求 $D$ 为连通开集。

> 📄 详见：[[二元函数的拉格朗日定理]]

## 三、极值与最值

### 3.1 概念辨析

| | 极值（局部） | 最值（整体） |
|---|---|---|
| 范围 | 某邻域内最大/小 | 整个定义域上最大/小 |

**常考结论**：
- 极值点处偏导（若存在）必为零
- "面有极值" 必推 "线有极值"，反之不成立

> 📄 详见：[[概念]]

---

### 3.2 无条件极值 ⭐重难点

#### 第一步：必要条件（找可疑点）

令 $f_x'(x,y)=0$，$f_y'(x,y)=0$ → 驻点 + 偏导数不存在的点 = **可疑点**

#### 第二步：充分条件（$\Delta = AC - B^2$ 判别法）

$A = f_{xx}''$，$B = f_{xy}''$，$C = f_{yy}''$，$\Delta = AC - B^2$

| $\Delta$ | $A$ | 结论 |
|:--------:|:---:|------|
| $> 0$ | $> 0$ | **极小值** |
| $> 0$ | $< 0$ | **极大值** |
| $< 0$ | 任意 | **非极值** |
| $= 0$ | 任意 | **方法失效** |

> ⚠️ 此判别法仅适用于二元函数，不能推广到三元及以上。

> 📄 详见：[[无条件极值]]

---

### 3.3 条件最值与拉格朗日乘数法 ⭐重难点

#### 标准步骤

1. 构造 $F = f + \lambda\varphi$（$+\mu\psi+\cdots$）
2. 令所有偏导为零，加上约束方程
3. 解方程组得备选点
4. 代入原函数比大小

#### 备选点完整策略

$$\text{备选点} = \{\text{拉格朗日驻点}\} \cup \{\text{约束边界端点}\}$$

> ⚠️ 不封闭约束（如圆弧一段）必须补充端点。

#### 简化技巧

> **能代入就代入！** 若约束容易解出一个变量，直接代入化为一元函数极值 → 优先策略。

**决策路径**：
```
约束是否容易解出一个变量？
├── 是 → 代入 → 无条件极值
└── 否 → 拉格朗日乘数法
```

**解方程要点**：检查取值范围、分类讨论 $\lambda=0$ 和 $\lambda\neq0$、利用对称性简化。

> 📄 详见：[[条件最值与拉格朗日乘数法]]

---

### 3.4 最远最近点的垂线原理

曲线上离某点最远/最近的点处，连线一定与切线**垂直**。可直接用垂线条件 $n \cdot \tau = 0$，省去构造拉格朗日函数。

> 📄 详见：[[最远最近点的垂线原理]]

---

### 3.5 有界闭区域上连续函数的最值

**三步法**：

1. **内部可疑点** — 令偏导 $=0$ 找驻点
2. **边界可疑点** — 代入法或拉格朗日乘数法
3. **比较** — 所有可疑点函数值取最大/最小

> ⚠️ 边界必须单独处理，不能只看内部驻点。

> 📄 详见：[[有界闭区域上连续函数的最值问题]]

## 四、解题流程总图

```
多元函数微分学
│
├── 求偏导/全微分
│   ├── 初等函数 → 直接求（或用"先代入后求导"求具体点）
│   ├── 分段/绝对值 → 用定义
│   └── 复合函数 → 链式法则（画树状图）
│
├── 判断可微性
│   ├── 初等正常函数 → 偏导连续 ⇒ 可微
│   └── 特殊函数 → 定义法（三步判别）
│
├── 隐函数求导
│   ├── 容易解出 → 直接求
│   ├── 公式法 → 套 $-\frac{F_x'}{F_y'}$
│   ├── 复合函数求导法
│   └── 全微分法（一步求两偏导）
│
└── 极值与最值
    ├── 无条件极值 → 找驻点 → $\Delta = AC-B^2$
    ├── 条件极值 → 拉格朗日乘数法（或代入化一元）
    └── 闭区域最值 → 内部驻点 + 边界 + 比较
```

## 五、易错点汇总

| 序号 | 易错点 | 正确理解 |
|:----:|--------|----------|
| 1 | 偏导存在 ⇒ 可微 | ✗ 偏导存在仅是可微的**必要**不充分条件 |
| 2 | 偏导不连续 ⇒ 不可微 | ✗ 偏导不连续 ≠ 不可微 |
| 3 | 证明极限存在用路径法 | ✗ 路径法只能证明**不存在**，不能证明存在 |
| 4 | 求偏导函数时提前代入值 | ✗ "先代入后求导"仅限于求**具体点** |
| 5 | 二阶偏导时漏链 | ✗ $f_1'$ 仍具有原复合结构，再求导必须用链式法则 |
| 6 | 闭区域只算内部驻点 | ✗ 边界点不能漏，必须单独处理 |
| 7 | 拉格朗日乘数法忽略端点 | ✗ 不封闭约束必须补端点 |
| 8 | $\rho = \vert\Delta x\vert + \vert\Delta y\vert$ | ✗ $\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}$ |
