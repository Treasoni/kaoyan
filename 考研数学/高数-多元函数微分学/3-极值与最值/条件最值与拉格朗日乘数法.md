# 条件最值与拉格朗日乘数法

## 基本方法

求目标函数 $u = f(x,y,z)$ 在约束条件 $\begin{cases} \varphi(x,y,z) = 0 \\ \psi(x,y,z) = 0 \end{cases}$ 下的最值。

### 步骤

1. **构造拉格朗日函数**：

$$F(x,y,z,\lambda,\mu) = f(x,y,z) + \lambda\varphi(x,y,z) + \mu\psi(x,y,z)$$

> 自变量个数 = 目标函数自变量个数 + 约束个数

2. **令各偏导数为零**：

$$\begin{cases} F_x' = f_x' + \lambda\varphi_x' + \mu\psi_x' = 0 \\ F_y' = f_y' + \lambda\varphi_y' + \mu\psi_y' = 0 \\ F_z' = f_z' + \lambda\varphi_z' + \mu\psi_z' = 0 \\ F_\lambda' = \varphi(x,y,z) = 0 \\ F_\mu' = \psi(x,y,z) = 0 \end{cases}$$

3. **解方程组**得备选点 $P_i$，求 $f(P_i)$，取最大/最小值。
4. **根据实际问题**，必存在最值，所得即为所求。

## 特殊情况

若约束条件 $\varphi(x,y,z) = 0$ 易解出 $z = z(x,y)$，可**代入目标函数**转化为无条件最值问题。

## 注意事项

- 对不封闭曲线用拉格朗日乘数法时，要注意比较**端点处**的函数值
- 拉格朗日乘数法求出的是**驻点**，需比较所有备选点的函数值
