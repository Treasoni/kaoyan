# 最远（近）点的垂线原理

> ⭐ 考纲不要求但可直接使用的结论，掌握后可大幅提高解题效率

## 定理

### 点到曲线的最远/最近点

如果 $\Gamma$ 是光滑闭曲线，点 $Q$ 是 $\Gamma$ 外的一个点，点 $P_1, P_2$ 分别是 $\Gamma$ 上与点 $Q$ 的最远点、最近点，则：

$$P_1Q \perp \Gamma \text{ 在 } P_1 \text{ 处的切线}, \quad P_2Q \perp \Gamma \text{ 在 } P_2 \text{ 处的切线}$$

即 $P_1Q$, $P_2Q$ 分别与点 $P_1$, $P_2$ 处的切线垂直。

### 两条曲线间的最远/最近点

若光滑闭曲线 $\Gamma_1$, $\Gamma_2$ 不相交，点 $P_1, P_2$ 分别是它们之间的最远（近）点，则：

$$P_1P_2 \text{ 是 } \Gamma_1, \Gamma_2 \text{ 的公垂线}$$

即 $P_1P_2$ 同时垂直于 $\Gamma_1$, $\Gamma_2$ 在这两个点处的切线。

## 应用方法

利用 $n \cdot \tau = 0$（法向量与切向量垂直），可以避免构造拉格朗日函数，直接得到关系式。
