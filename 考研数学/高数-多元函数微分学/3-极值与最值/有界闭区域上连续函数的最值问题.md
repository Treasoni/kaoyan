# 有界闭区域上连续函数的最值问题

## 理论依据

**最大值与最小值定理**：有界闭区域 $D$ 上的多元连续函数，在 $D$ 上一定有最大值和最小值。

## 求法（类比一元函数）

1. **内部可疑点**：由 $f_x'(x,y) = 0$, $f_y'(x,y) = 0$ 或偏导数不存在，求出区域 $D$ 内部的所有可疑点
2. **边界可疑点**：用拉格朗日乘数法或代入法，求出区域 $D$ 边界上的所有可疑点（类比一元函数的区间端点）
3. **比较**：比较以上所有可疑点的函数值，取其最大者为最大值，最小者为最小值

## 与一元函数的对比

| 一元函数 | 二元函数 |
|---------|---------|
| 内部驻点 + 端点值 | 内部驻点 + 边界最值 |
| $f'(x) = 0$ 的点 + 端点 | $f_x' = f_y' = 0$ 的点 + 边界上的可疑点 |
