# 概念

## 极值（局部概念）

若存在点 $(x_0,y_0)$ 的某个邻域，使得在该邻域内任意一点 $(x,y)$ 处，均有

$$f(x,y) \leqslant f(x_0,y_0) \quad (\text{或 } f(x,y) \geqslant f(x_0,y_0))$$

则��� $(x_0,y_0)$ 为 $f(x,y)$ 的**极大值点**（或**极小值点**），$f(x_0,y_0)$ 为极大值（或极小值）。

## 最值（整体概念）

若对于定义域内任意一点 $(x,y)$，均有

$$f(x,y) \leqslant f(x_0,y_0) \quad (\text{或 } f(x,y) \geqslant f(x_0,y_0))$$

则称 $f(x_0,y_0)$ 为**最大值**（或**最小值**）。

## 二元极值与一元极值的关系

> ⭐ 常考结论

二元函数 $f(x,y)$ 在 $(x_0,y_0)$ 处取极值 $\Rightarrow$ 一元函数 $f(x,y_0)$ 在 $x_0$ 处取极值，且 $f(x_0,y)$ 在 $y_0$ 处取极值。这是**充分条件**，非必要。

反例：$f(x,y) = x^4 + y^4 - (x+y)^2$ 在 $(0,0)$ 处不取极值，但 $f(x,0)$ 和 $f(0,y)$ 分别在 $x=0$ 和 $y=0$ 处取极大值。
