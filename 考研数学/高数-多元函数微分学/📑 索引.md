| 知识点 | 核心一句话 | 考频 |
|--------|-----------|:----:|

### 三、极值与最值

| 知识点 | 核心一句话 | 考频 |
|--------|-----------|:----:|

## 知识脉络

```
邻域 ──→ 极限 ──→ 连续
              │
         偏导数 ──→ 可微 ──→ 全微分
              │                  │
         链式求导 ←──── 全微分形式不变性
              │
         隐函数存在定理
              │
    ┌─────────┴──────────┐
 无条件极值          条件最值
 (Δ=AC-B²)     (拉格朗日乘数法)
    │                  │
    └──── 闭区域最值 ────┘
       (内部驻点 + 边界)
```

## 考试目标

1. 会求全微分，了解全微分存在的必要条件和充分条件
2. 了解全微分形式不变性
3. 了解隐函数存在定理，会求多元隐函数的偏导数
4. 了解二元函数的二阶泰勒公式（仅数学一）
5. 掌握多元函数极值存在的必要条件
6. 了解二元函数极值存在的充分条件，会求二元函数的极值
7. 会用拉格朗日乘数法求条件极值
8. 会求简单多元函数的最大值和最小值
