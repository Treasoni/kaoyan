# 邻域

## δ 邻域

设 $P_0(x_0, y_0)$ 是 $xOy$ 平面上的一个点，$\delta$ 是某一正数。与点 $P_0$ 的距离小于 $\delta$ ��点 $P(x,y)$ 的全体，称为点 $P_0$ 的 $\delta$ 邻域，记为 $U(P_0, \delta)$：

$$U(P_0, \delta) = \left\{ (x, y) \mid \sqrt{(x - x_0)^2 + (y - y_0)^2} < \delta \right\}$$

> 几何意义：$U(P_0, \delta)$ 表示以 $P_0$ 为中心、$\delta$ 为半径的**圆内部**（不算边界）。

## 去心 δ 邻域

$$\dot{U}(P_0, \delta) = \left\{ P \mid 0 < |PP_0| < \delta \right\}$$

## 与一元函数的对比

| 一元函数 | 二元函数 |
|---------|---------|
| $U(x_0, \delta) = \{x \mid \|x - x_0\| < \delta\}$（区间） | $U(P_0, \delta) = \{(x,y) \mid \sqrt{(x-x_0)^2 + (y-y_0)^2} < \delta\}$（圆盘） |
