# 📝 多元函数微分学 · 1-基本概念 章节总结

> [!abstract] 本章核心
> 从一元函数极限、连续、导数、微分的基本概念，推广到二元/多元函数。核心难点在于**无穷多路径**带来的复杂性，以及**可微性判别**。

---

## 一、核心概念速查表

| 概念 | 核心公式 | 关键要点 |
|------|---------|---------|
| **δ 邻域** | $U(P_0, \delta) = \{(x,y) \mid \sqrt{(x-x_0)^2+(y-y_0)^2} < \delta\}$ | 开圆盘（不含边界） |
| **去心邻域** | $\dot{U}(P_0, \delta) = \{P \mid 0 < \vert PP_0 \vert < \delta\}$ | 讨论极限时使用 |
| **二重极限** | $\displaystyle\lim_{(x,y)\to(x_0,y_0)} f(x,y) = A$ | 以**任意方式**趋近都趋于 $A$ |
| **连续性** | $\displaystyle\lim_{(x,y)\to(x_0,y_0)} f(x,y) = f(x_0,y_0)$ | 二元初等函数在定义区域连续 |
| **偏导数** | $f_x'(x_0,y_0) = \displaystyle\lim_{\Delta x\to 0}\frac{f(x_0+\Delta x, y_0)-f(x_0,y_0)}{\Delta x}$ | 固定其他变量，一元化求导 |
| **全微分** | $\mathrm{d}z = \dfrac{\partial z}{\partial x}\mathrm{d}x + \dfrac{\partial z}{\partial y}\mathrm{d}y$ | 线性主部 + 高阶无穷小 |

---

## 二、重要定义与定理

### 1. 极限的定义（ε-δ 语言）

$$\lim_{(x,y) \to (x_0,y_0)} f(x,y) = A \Leftrightarrow \forall\,\varepsilon>0,\;\exists\,\delta>0,\;0<|PP_0|<\delta \Rightarrow |f(x,y)-A|<\varepsilon$$

其中 $|PP_0| = \sqrt{(x-x_0)^2 + (y-y_0)^2}$

> [!warning] 核心区别
> 一元：$x \to x_0$ 只有**左右两条路** → 二元：$(x,y) \to (x_0,y_0)$ 有**无穷多条路**。

### 2. 偏导数的定义

**对 $x$ 的偏导数**：
$$f_x'(x_0,y_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x,\, y_0) - f(x_0,\, y_0)}{\Delta x}$$

**等价写法**（函数差值式）：
$$f_x'(x_0,y_0) = \lim_{x\to x_0}\frac{f(x,\, y_0) - f(x_0,\, y_0)}{x - x_0}$$

### 3. 可微的定义

全增量可表示为：
$$\boxed{\Delta z = A\Delta x + B\Delta y + o(\rho)}$$

其中 $\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}$，$A = \dfrac{\partial z}{\partial x}$，$B = \dfrac{\partial z}{\partial y}$

---

## 三、核心公式汇总

### 3.1 极限计算方法

| 可用 | 不可用 |
|------|-------|
| 等价无穷小替换 | **洛必达法则** |
| 夹逼准则 | **单调有界准则** |
| 四则运算、代入法 | |
| 脱帽法：$f(x,y) = A + \alpha$ | |

**常用等价无穷小**（$(x,y) \to (0,0)$）：
- $e^{x^2+y^2}-1 \sim x^2+y^2$
- $\sin u \sim u$，$\ln(1+u) \sim u$（$u$ 为 $x,y$ 的多项式）

### 3.2 高阶偏导数

$$\frac{\partial^2 z}{\partial x^2} = f_{xx}'', \quad \frac{\partial^2 z}{\partial y^2} = f_{yy}'', \quad \frac{\partial^2 z}{\partial x \partial y} = f_{xy}'', \quad \frac{\partial^2 z}{\partial y \partial x} = f_{yx}''$$

> [!important] 混合偏导数相等
> 若 $f_{xy}''$ 和 $f_{yx}''$ 都**连续**，则 $f_{xy}'' = f_{yx}''$（与求导次序无关）。

### 3.3 可微的判别步骤（三步法）

$$
\boxed{
\lim_{\substack{\Delta x \to 0 \\ \Delta y \to 0}}
\frac{\Delta z - (A\Delta x + B\Delta y)}{\sqrt{(\Delta x)^2 + (\Delta y)^2}} = 0 \;?
}
$$

| 结果 | 结论 |
|------|------|
| 极限 $= 0$ | **可微** — 线性近似完美贴合曲面 |
| 极限 $\neq 0$ | **不可微** — 曲面在此点有尖点或裂缝 |

---

## 四、证明方法

### 4.1 证明极限不存在

> [!important] 核心方法
> 找**两条不同路径**使极限值不等 $\Rightarrow$ 极限不存在。

**常用路径选择**：

| 路径 | 表达式 | 适用场景 |
|------|--------|----------|
| 沿 $x$ 轴 | $y = 0$ | 分母含 $y$ |
| 沿 $y$ 轴 | $x = 0$ | 分母含 $x$ |
| 沿直线 | $y = kx$ | 含 $y/x$ 项 |
| 沿对角线 | $y = x$ | 含对称结构 |
| 沿抛物线 | $y = x^2$ | 含高次项 |

### 4.2 判别偏导数是否连续

1. 用**定义法**求 $f'_x(x_0, y_0)$，$f'_y(x_0, y_0)$
2. 用**公式法**求 $f'_x(x, y)$，$f'_y(x, y)$
3. 计算极限 $\displaystyle\lim_{\substack{x \to x_0 \\ y \to y_0}} f'_x(x, y)$ 和 $\displaystyle\lim_{\substack{x \to x_0 \\ y \to y_0}} f'_y(x, y)$
4. 判断是否等于该点偏导数值

---

## 五、易错点与注意事项

| 易错点 | 正确理解 |
|--------|---------|
| **偏导数存在 $\not\Rightarrow$ 连续** | 偏导只反映沿坐标轴方向行为，不能保证沿其他方向连续 |
| **可微 $\Rightarrow$ 偏导存在**（仅必要） | 偏导存在且连续 $\Rightarrow$ 可微（充分不必要） |
| 洛必达法���不能用于二重极限 | 用夹逼准则、等价无穷小、定义法 |
| 微分符号 $\mathrm{d}$ vs 偏微分 $\partial$ | $\mathrm{d}x$（正体），$\dfrac{\partial z}{\partial x}$（偏导） |
| 二元初等函数间断点类型 | 考纲**未要求**讨论 |

## 六、考研实战决策树

```
判断可微性
    │
    ├─ 正常初等函数（无绝对值，无分母趋于0）
    │       └── 方法一：求偏导 → 看连续性
    │
    ├─ 带绝对值（如 |xy|）/ 分段函数 / 奇点
    │       └── 方法二：三步极限法（定义法）
    │
    └─ 要求证明"不可微"
            └── 只能用方法二：证极限 ≠ 0
```

## 七、关系总结图

### 一元函数
$$\text{可导} \;\Longleftrightarrow\; \text{可微} \;\Longrightarrow\; \text{连续} \;\Longrightarrow\; \text{极限存在}$$

### 二元函数

$$\text{偏导连续} \;\Longrightarrow\; \text{可微} \;\Longrightarrow\; \begin{cases} \text{偏导存在} \\ \text{连续} \end{cases} \;\Longrightarrow\; \text{极限存在}$$

> [!warning] 注意
> 二元函数中：**偏导存在** $\not\Rightarrow$ **连续** $\not\Rightarrow$ **可微**
