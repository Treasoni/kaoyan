# 可微

## 定义

设 $z = f(x,y)$ 在点 $(x,y)$ 的某邻域内有定义，若全增量

$$\Delta z = f(x + \Delta x, y + \Delta y) - f(x, y)$$

可表示为

$$\Delta z = A\Delta x + B\Delta y + o(\rho)$$

其中 $A, B$ 仅与 $(x,y)$ 有关，$\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}$，则称 $f(x,y)$ 在点 $(x,y)$ 处**可微**，并称 $A\Delta x + B\Delta y$ 为**全微分**：

$$\mathrm{d}z = \frac{\partial z}{\partial x}\mathrm{d}x + \frac{\partial z}{\partial y}\mathrm{d}y$$

## 可微的必要条件

可微 $\Rightarrow$ 偏导数存在，且 $A = \frac{\partial z}{\partial x}$，$B = \frac{\partial z}{\partial y}$。

> 注意：二元函数可微与偏导数存在**不等价**（区别于一元函数的可微 $\Leftrightarrow$ 可导）。

## 可微的充分条件

若偏导数 $f_x'(x,y)$ 和 $f_y'(x,y)$ 存在且**连续**，则 $f(x,y)$ 在该点可微。

## 可微的判别步骤

1. 写出全增量 $\Delta z = f(x_0 + \Delta x, y_0 + \Delta y) - f(x_0, y_0)$
2. 写出线性增量 $A\Delta x + B\Delta y$，其中 $A = f_x'(x_0, y_0)$，$B = f_y'(x_0, y_0)$
3. 求极限 $\lim_{(\Delta x, \Delta y) \to (0,0)} \frac{\Delta z - (A\Delta x + B\Delta y)}{\sqrt{(\Delta x)^2 + (\Delta y)^2}}$，若等于 0 则可微

## 连续、偏导数、可微的关系

> ⭐ 核心考点：多元函数与一元函数在可导、可微、连续关系上的差异

| 关系 | 一元函数 | 二元函数 |
|------|---------|---------|
| 可微 $\Rightarrow$ 可导 | $\checkmark$ | $\checkmark$（偏导数存在） |
| 可导 $\Rightarrow$ 可微 | $\checkmark$（等价） | $\times$（不一定） |
| 可微 $\Rightarrow$ 连续 | $\checkmark$ | $\checkmark$ |
| 偏导数连续 $\Rightarrow$ 可微 | — | $\checkmark$（充分条件） |
