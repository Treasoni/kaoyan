# 极坐标系与直角坐标系的互相转化

## 转化公式

$$x = r\cos\theta, \quad y = r\sin\theta$$

## 转化要点

1. 用好 $x = r\cos\theta$，$y = r\sin\theta$ 这个公式
2. 画出区域 $D$ 的边界图形，做好上限、下限的转化

## 何时需要转化

> [!tip] 当题目是累次积分时，通常考虑换积分顺序或者换坐标系

### 直角坐标 → 极坐标

当满足以下条件时优先考虑极坐标：
- 被积函数含 $x^2 + y^2$ 形式
- 积分区域是圆或圆的一部分

### 极坐标 → 直角坐标

当极坐标下计算困难时，可转回直角坐标。

## 关键：边界曲线的转换

| 直角坐标 | 极坐标 |
|----------|--------|
| $x^2 + y^2 = R^2$ | $r = R$ |
| $x^2 + y^2 = 2ax$ | $r = 2a\cos\theta$ |
| $x^2 + y^2 = 2ay$ | $r = 2a\sin\theta$ |
| $y = kx$ | $\theta = \arctan k$ |
| $x = a$ | $r\cos\theta = a$ |
| $y = b$ | $r\sin\theta = b$ |
