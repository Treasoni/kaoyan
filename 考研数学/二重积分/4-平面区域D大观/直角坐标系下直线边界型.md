# 直角坐标系下直线边界型

> 要想正确计算二重积分，准确画出平面区域 $D$ 是必不可少的基本功。

## 常见区域

### (1) 正方形

$D = \{(x,y) \mid 0 \leqslant x \leqslant 1, 0 \leqslant y \leqslant 1\}$

### (2) 三角形

$D = \{(x, y) \mid x + y \leqslant 1, x \geqslant 0, y \geqslant 0\}$

### (3) 下三角

$D = \{(x, y) \mid 0 \leqslant x \leqslant 1, 0 \leqslant y \leqslant x\}$

### (4) 扇形区间

$D = \{(x, y) \mid 0 \leqslant x \leqslant 2, x \leqslant y \leqslant \sqrt{3}x\}$

### (5) 矩形

$D = \{(x, y) \mid 0 \leqslant x \leqslant \pi, 0 \leqslant y \leqslant 1\}$

### (6) 带状区域

$D = \{(x, y) \mid 1 \leqslant x + y \leqslant 2, x \geqslant 0, y \geqslant 0\}$

### (7) 大扇形

$D = \{(x, y) \mid 0 \leqslant x \leqslant 3, 0 \leqslant y \leqslant 3, \frac{\sqrt{3}}{3}x \leqslant y \leqslant \sqrt{3}x\}$

### (8) 斜条

$D = \{(x, y) \mid 1 \leqslant x + y \leqslant 2, 0 \leqslant y \leqslant x\}$

### (9) L型

$D = \{(x, y) \mid 0 \leqslant x + y \leqslant 1, 0 \leqslant y \leqslant 1\}$

### (10) 上三角

$D = \{(x, y) \mid 0 \leqslant x \leqslant 1, x \leqslant y \leqslant 1\}$

### (15) 菱形

$D = \{(x, y) \mid |x| + |y| \leqslant 1\}$

### (17) 大正方形

$D = \{(x, y) \mid |x| \leqslant 1, |y| \leqslant 1\}$

> [!tip] 练习建议
> 这些图不是背的，而是训练画区域能力的素材。多画、多练！
