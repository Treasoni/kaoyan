# 极坐标方程型

> 考生应能熟练画出平面区域 $D$。有些 $D$ 是用直角坐标系下的表达式描述的，但实际上用极坐标方程更方便。

## 常见区域

### (1) 极坐标三角域

$D = \{(r, \theta) \mid 0 \leqslant r \leqslant \frac{1}{\sin \theta}, \frac{\pi}{4} \leqslant \theta \leqslant \frac{\pi}{2}\}$

### (2) 极坐标三角域

$D = \{(r, \theta) \mid 0 \leqslant r \leqslant \sec \theta, 0 \leqslant \theta \leqslant \frac{\pi}{4}\}$

### (3) 螺旋区域

$D = \{(r, \theta) \mid 0 \leqslant \theta \leqslant 2\pi, \frac{\theta}{2} \leqslant r \leqslant \pi\}$

### (4) 扇形

$D = \{(r, \theta) \mid 0 \leqslant r \leqslant 1, 0 \leqslant \theta \leqslant \frac{\pi}{4}\}$

### (6) 心形线区域

$D = \{(r, \theta) \mid 2 \leqslant r \leqslant 2(1 + \cos \theta), -\frac{\pi}{2} \leqslant \theta \leqslant \frac{\pi}{2}\}$

### (7) 双纽线

$D = \{(r, \theta) \mid 0 \leqslant r \leqslant \sqrt{\sin 2\theta}, 0 \leqslant \theta \leqslant \frac{\pi}{2}\}$

### (9) 圆域（先 $r$ 后 $\theta$）

$D = \{(r, \theta) \mid 0 \leqslant r \leqslant 2, -\arccos \frac{r}{2} \leqslant \theta \leqslant \arccos \frac{r}{2}\}$

### (10) 复合区域

$D = \{(r, \theta) \mid 0 \leqslant r \leqslant 2(\sin \theta + \cos \theta), \frac{\pi}{4} \leqslant \theta \leqslant \frac{3}{4}\pi\}$

### (13) 四分之一圆

$D = \{(r, \theta) \mid 0 \leqslant r \leqslant 2, 0 \leqslant \theta \leqslant \frac{\pi}{2}\}$

### (15) 矩形参数域

$D = \{(r, \theta) \mid 1 \leqslant r \leqslant u, 0 \leqslant \theta \leqslant v\}$

> [!tip] 注意
> 有些区域虽然用直角坐标描述，但更适合用极坐标处理。如2019年考研真题数学二(18)：
> $D = \{(x, y) \mid |x| \leqslant y, (x^2 + y^2)^3 \leqslant y^4\}$
