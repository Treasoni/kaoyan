# 📝 章节总结：最值或取值范围

## 一、章节概览

本节主要研究函数在给定区间上的**最值（最大值与最小值）** 问题，区分为**闭区间**与**开区间**两种情形，二者在存在性和求法上有本质区别。

---

## 二、核心定义

### 2.1 最值的定义

> [!def] 最值
> 设 $x_0$ 为 $f(x)$ 定义域内一点，若对于 $f(x)$ 的定义域内任意一点 $x$，均有
> $$f(x) \leqslant f(x_0) \quad (\text{或 } f(x) \geqslant f(x_0))$$
> 成立，则称 $f(x_0)$ 为 $f(x)$ 的**最大值**（或**最小值**）。

最值是**整体概念**，与极值（局部概念）有本质区别。

### 2.2 极值与最值的对比

| | 极值 | 最值 |
|---|------|------|
| 范围 | 局部（邻域内） | 整体（定义域内） |
| 个数 | 可以有多个 | 最多各一个 |
| 端点 | 不讨论 | 可以是 |
| 间断点 | 可以是 | 可以是 |

### 2.3 极值与最值的关系

1. **极值点不一定是最值点**：如 $f(x) = 3x - x^3$，$f(1) = 2$ 是极大值，但不是最大值
2. **最值点不一定是极值点**：如 $f(x) = e^x$ 在 $[0, +\infty)$ 上，$f(0) = 1$ 是最小值，但 $x = 0$ 是端点，不是极值点
3. **最值点若是内部点，必是极值点**：若 $f(x)$ 在区间 $I$ 上有最值点 $x_0$，且 $x_0$ 是 $I$ 的内部点（非端点），则 $x_0$ 必是 $f(x)$ 的一个极值点

## 三、核心定理与求法

### 3.1 闭区间上连续函数的最值

**最值定理**：闭区间 $[a, b]$ 上的连续函数**一定有**最大值和最小值。

> [!method] 求法步骤
> 1. 求出 $f(x)$ 在 $(a, b)$ 内的**可疑点**（驻点与不可导点），计算这些点的函数值
> 2. 求出**端点函数值** $f(a)$ 和 $f(b)$
> 3. **比较**所有函数值，最大者为最大值 $M$，最小者为最小值 $m$

### 3.2 开区间内连续函数的最值

**关键区别**：开区间 $(a, b)$ 上的连续函数**不一定有**最大值和最小值。

> [!method] 求法步骤
> 1. 求出 $f(x)$ 在 $(a, b)$ 内的**可疑点**（驻点与不可导点），计算这些点的函数值
> 2. 求 $(a, b)$ 两端的**单侧极限**：
>    - 有限端点：$\displaystyle\lim_{x \to a^+} f(x)$ 与 $\displaystyle\lim_{x \to b^-} f(x)$
>    - 无穷端点：$\displaystyle\lim_{x \to -\infty} f(x)$ 或 $\displaystyle\lim_{x \to +\infty} f(x)$
> 3. **比较**可疑点函数值与端点极限值，确定最值或取值范围

### 3.3 闭区间 vs 开区间对比

| | 闭区间 $[a, b]$ | 开区间 $(a, b)$ |
|---|----------------|-----------------|
| 最值存在性 | **一定有** | **不一定有** |
| 需要比较 | 端点函数值 | 端点极限值 |
| 结果形式 | 确定的最大/最小值 | 可能是取值范围 |

### 3.4 实际问题中的唯一极值点定理

> [!thm] 唯一极值点定理
> 如果实际问题**存在**最小值或最大值，且目标函数 $f(x)$ 有**唯一的极值点** $x_0$，则：
> $$f(x_0) = \text{所求的最小值或最大值}$$

**适用前提**：
- 实际问题确实存在最值（由物理/几何意义保证）
- 极值点**唯一**
- 仅适用于**实际问题**，纯数学问题不适用

### 3.5 实际问题最值求解步骤

> [!method]
> 1. **建立目标函数**：确定欲求最值的函数 $f(x)$
> 2. **确定定义区间**：根据实际问题限制确定 $x$ 的取值范围
> 3. **转化为函数最值问题**：按区间类型选择相应求法求解

## 四、开区间上的四种情形

| 情形 | 说明 | 示例 |
|------|------|------|
| 有最大值和最小值 | 函数在区间内部取得 | $f(x) = -x^2 + 2x$ 在 $(0, 2)$ |
| 只有最大值或只有最小值 | 一端趋近于极限值 | $f(x) = -x^2 + 2x$ 最大值 $1$，无最小值 |
| 既无最大值也无最小值 | 单调函数 | $f(x) = x$ 在 $(0, 1)$ |
| 结果是取值范围 | 值域为开区间 | $f(x) = x^2$ 在 $(0, 1)$，值域 $(0, 1)$ |

### 半开半闭区间

对于 $(a, b]$ 或 $[a, b)$：
- 在开区间求法的基础上
- 加上闭端点的函数值进行比较

## 五、典型例题

### 例1：闭区间最值
> 求 $f(x) = x + 2\cos x$ 在 $\left[0, \frac{\pi}{2}\right]$ 上的最大值。

**解**：
$f'(x) = 1 - 2\sin x$，令 $f'(x) = 0$，得 $x = \frac{\pi}{6}$
比较：
- $f(0) = 2$
- $f\left(\frac{\pi}{6}\right) = \frac{\pi}{6} + \sqrt{3} \approx 2.25$
- $f\left(\frac{\pi}{2}\right) = \frac{\pi}{2} \approx 1.57$

**最大值**：$\displaystyle\frac{\pi}{6} + \sqrt{3}$

### 例2：数列最大项问题
> 求数列 $\{\sqrt[n]{n}\}$ 的最大项。

**解**：设 $f(x) = x^{1/x}\;(x > 0)$，$f'(x) = x^{1/x} \cdot \frac{1 - \ln x}{x^2}$
令 $f'(x) = 0$ 得 $x = e$，比较 $f(2) = \sqrt{2}$ 与 $f(3) = \sqrt[3]{3}$：
$(\sqrt{2})^6 = 8$，$(\sqrt[3]{3})^6 = 9$

**最大项**：$\sqrt[3]{3}$

### 例3：开区间最值
> $f(x) = -x^2 + 2x$ 在 $(0, 2)$ 上。

**解**：
$f'(x) = -2x + 2$，驻点 $x = 1$，$f(1) = 1$（极大值点，也是最大值点）
$\displaystyle\lim_{x \to 0^+} f(x) = 0$，$\displaystyle\lim_{x \to 2^-} f(x) = 0$

**结果**：最大值 $f(1) = 1$，无最小值，取值范围 $(0, 1]$

## 六、易错点与注意事项

1. **端点不可遗漏**：闭区间最值必须比较端点函数值
2. **不可导点不可遗漏**：可疑点包括驻点和不可导点两类
3. **开区间考虑极限而非函数值**：开区间端点处考虑单侧极限，而非函数值
4. **实际问题唯一极值点定理的适用条件**：必须先确认最值存在，再验证唯一性，且只适用于实际问题
5. **极值与最值的混淆**：极值是局部概念，最值是整体概念，二者无包含关系
