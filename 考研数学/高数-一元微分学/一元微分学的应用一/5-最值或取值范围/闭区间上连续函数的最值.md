# 闭区间上连续函数的最值

> [!info] 概述
> 闭区间 $[a, b]$ 上的连续函数**一定有**最大值和最小值（最值定理）。

## 求法

> [!thm] 求闭区间上连续函数最值的步骤
> 1. 求出 $f(x)$ 在 $(a, b)$ 内的**可疑点**（驻点与不可导点），并求出这些可疑点处的函数值
> 2. 求出**端点的函数值** $f(a)$ 和 $f(b)$
> 3. **比较**以上所求得的所有函数值：
>    - 最大者 $\Rightarrow$ 最大值 $M$
>    - 最小者 $\Rightarrow$ 最小值 $m$

## 示意图

```
函数值比较：
┌─────────────────────────────────────────┐
│  f(a)  │  f(x₁)  │  f(x₂)  │  ...  │ f(b)  │
│ (端点) │ (驻点)  │ (不可导) │       │(端点) │
└─────────────────────────────────────────┘
         ↓
    最大 → M（最大值）
    最小 → m（最小值）
```

## 典型例子

> [!example] 例题
> **题目**：求 $f(x) = x + 2\cos x$ 在 $\left[0, \frac{\pi}{2}\right]$ 上的最大值。
>
> **解答**：
>
> $f'(x) = 1 - 2\sin x$，令 $f'(x) = 0$，得 $x = \frac{\pi}{6}$
>
> $f''(x) = -2\cos x$，$f''\left(\frac{\pi}{6}\right) = -\sqrt{3} < 0$
>
> 故 $x = \frac{\pi}{6}$ 是极大值点
>
> 比较各点函数值：
> - $f(0) = 0 + 2 \times 1 = 2$
> - $f\left(\frac{\pi}{6}\right) = \frac{\pi}{6} + 2 \times \frac{\sqrt{3}}{2} = \frac{\pi}{6} + \sqrt{3}$
> - $f\left(\frac{\pi}{2}\right) = \frac{\pi}{2} + 2 \times 0 = \frac{\pi}{2}$
>
> $\frac{\pi}{6} + \sqrt{3} \approx 0.52 + 1.73 = 2.25$ 最大
>
> 故最大值为 $\frac{\pi}{6} + \sqrt{3}$

## 注意事项

1. **一定要比较端点值**：最值可能在端点
2. **驻点和不可导点都要考虑**：不要遗漏
3. **可以转化为求值域**：$[m, M]$

## 典型题型

> [!example] 应用题
> 求数列 $\{\sqrt[n]{n}\}$ 的最大项。
>
> **解答**：
>
> 设 $f(x) = x^{1/x}$（$x > 0$）
>
> $f'(x) = x^{1/x} \cdot \frac{1 - \ln x}{x^2}$
>
> 令 $f'(x) = 0$，得 $x = e$
>
> 当 $x \in (0, e)$ 时 $f'(x) > 0$，当 $x \in (e, +\infty)$ 时 $f'(x) < 0$
>
> 故 $f(x)$ 在 $x = e$ 处取得最大值 $e^{1/e}$
>
> 由于 $e \approx 2.718$，介于 2 与 3 之间
>
> 比较 $f(2) = \sqrt{2}$ 和 $f(3) = \sqrt[3]{3}$
>
> $(\sqrt{2})^6 = 8$，$(\sqrt[3]{3})^6 = 9$
>
> 故 $\sqrt[3]{3}$ 是最大项
