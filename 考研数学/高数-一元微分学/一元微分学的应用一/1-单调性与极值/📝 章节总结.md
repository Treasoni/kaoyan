# 📝 章节总结：单调性与极值

## 一、本章概述

本章是微分学几何应用的起点，核心围绕**函数单调性的判别**和**极值的判定**展开。单调性通过一阶导数的符号判定，极值的判定则从必要条件（费马定理）出发，逐步引出三个充分条件，形成完整理论体系。

---

## 二、核心定义

### 2.1 极值的定义

> 对于函数 $f(x)$，若存在点 $x_0$ 的某个邻域，使得在该邻域内任意一点 $x$，均有
> $$f(x) \leqslant f(x_0) \quad (\text{或 } f(x) \geqslant f(x_0))$$
> 则称 $x_0$ 为 $f(x)$ 的**极大值点**（或**极小值点**），$f(x_0)$ 为**极大值**（或**极小值**）。

**关键特性**：
- 局部概念（邻域内比较）
- 端点不讨论极值
- 间断点**可以**是极值点
- 常数函数处处是极值

### 2.2 极值与最值的区别

| 对比项 | 极值 | 最值 |
|--------|------|------|
| 范围 | 局部（邻域内） | 整体（定义域内） |
| 数量 | 可以有多个 | 最多各一个 |
| 端点 | 不讨论 | 可以是 |
| 间断点 | 可以是极值点 | 不影响 |

## 三、核心定理

### 3.1 单调性判别定理

> 设 $y = f(x)$ 在 $[a,b]$ 上连续，在 $(a,b)$ 内可导。
> - 若 $f'(x) \geqslant 0$，且等号仅在有限个点成立 → $f(x)$ 在 $[a,b]$ 上**严格单调增加**
> - 若 $f'(x) \leqslant 0$，且等号仅在有限个点成立 → $f(x)$ 在 $[a,b]$ 上**严格单调减少**

> [!warning] 注意
> 导数大于 0 $\Rightarrow$ 严格单调增加，但逆命题不成立。如 $y = x^3$ 在 $x = 0$ 处导数为 0，但整体严格单调增加。

### 3.2 费马定理（极值点的必要条件）

> 设 $f(x)$ 在 $x_0$ 处可导，且在 $x_0$ 处取得极值 $\Rightarrow$ $f'(x_0) = 0$

**极值点的两种可能**：
1. **驻点**：$f'(x_0) = 0$（如 $y = x^2$ 在 $x = 0$）
2. **不可导点**：$f'(x_0)$ 不存在（如 $y = |x|$ 在 $x = 0$）

### 3.3 判别极值的第一充分条件

> 设 $f(x)$ 在 $x_0$ 处**连续**，在去心邻域 $\mathring{U}(x_0, \delta)$ 内可导。

| 左邻域 $f'(x)$ | 右邻域 $f'(x)$ | 结论 |
|:---:|:---:|:---:|
| $-$ | $+$ | **极小值**（左负右正，V字形） |
| $+$ | $-$ | **极大值**（左正右负，倒V字形） |
| 不变号 | 不变号 | **不是极值点** |

**判别步骤**：
1. 找可疑点：驻点 + 不可导点
2. 确保可疑点处连续
3. 考察左右邻域导数符号
4. 判定极值

### 3.4 判别极值的第二充分条件

> 设 $f(x)$ 在 $x_0$ 处**二阶可导**，且 $f'(x_0) = 0$，$f''(x_0) \neq 0$。
> - $f''(x_0) < 0$ → **极大值**
> - $f''(x_0) > 0$ → **极小值**

> [!warning] 注意
> $f''(x_0) = 0$ 时无法判断，需用第一或第三充分条件。

### 3.5 判别极值的第三充分条件

> 设 $f(x)$ 在 $x_0$ 处 $n$ 阶可导（$n \geqslant 2$），且
> $$f^{(m)}(x_0) = 0 \ (m = 1, 2, \ldots, n-1), \quad f^{(n)}(x_0) \neq 0$$
> - $n$ 为**偶数**且 $f^{(n)}(x_0) < 0$ → **极大值**
> - $n$ 为**偶数**且 $f^{(n)}(x_0) > 0$ → **极小值**
> - $n$ 为**奇数** → **不是极值点**

---

## 四、三种充分条件对比

| 对比项 | 第一充分条件 | 第二充分条件 | 第三充分条件 |
|--------|:----------:|:----------:|:----------:|
| 所需信息 | 左右邻域导数符号 | 一点处二阶导数值 | 一点处 $n$ 阶导数值 |
| 可导要求 | 去心邻域可导 | 二阶可导 | $n$ 阶可导 |
| 适用范围 | 驻点 + 不可导点 | 仅驻点（$f'(x_0) = 0$） | 仅驻点 |
| 导数为0时 | 可判断 | 失效 | 可判断 |
| 计算量 | 较大 | 较小 | 取决于 $n$ |
| 推荐场景 | 通用首选 | 二阶导易求时 | 高阶导易求时 |

## 五、典型例题

### 5.1 利用单调性判别极值

**题目**：求 $f(x) = x^3 - 3x$ 的极值。

**解答**：
- $f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$
- 驻点 $x = -1, x = 1$
- 列表分析：

| 区间 | $(-\infty, -1)$ | $(-1, 1)$ | $(1, +\infty)$ |
|:-:|:-:|:-:|:-:|
| $f'(x)$ | $+$ | $-$ | $+$ |
| $f(x)$ | ↗ | ↘ | ↗ |

- $x = -1$：左正右负 → **极大值** $f(-1) = 2$
- $x = 1$：左负右正 → **极小值** $f(1) = -2$

### 5.2 隐函数求极值

**题目**：设 $y = y(x)$ 由 $y^3 + xy^2 + x^2y + 6 = 0$ 确定，求 $y(x)$ 的极值。

**思路**：隐函数求导 → 令 $y' = 0$ 得驻点 → 代回原方程解出坐标 → 二阶导判极值。

### 5.3 高阶导数的极值问题

**题目**：设 $f(x) = xe^x$，求 $f^{(n)}(x)$ 的极值点和极值。

**核心**：$f^{(n)}(x) = (n + x)e^x$，利用第三充分条件（$n$ 为 2）判定。

### 5.4 端点极值问题

**题目**：设 $f(x)$ 在 $[a,b]$ 上可导，在 $x = a$ 处取最小值，$x = b$ 处取最大值，则 $f'_+(a) \geqslant 0$，$f'_-(b) \geqslant 0$。

## 六、易错点汇总

| # | 易错点 | 正确理解 |
|---|--------|----------|
| 1 | 极值点一定是驻点 | 极值点 $\in$ {驻点, 不可导点} |
| 2 | 驻点一定是极值点 | $f'(x_0) = 0$ 是必要条件非充分条件 |
| 3 | 间断点不能是极值点 | 间断点可以是极值点（四类间断点均可） |
| 4 | $f''(x_0) < 0$ 是极大值的必要条件 | 是充分不必要条件（反例：$f(x) = -x^4$） |
| 5 | 第二充分条件 $f''(x_0) = 0$ 时无极值 | 无法判断，需用第一/第三充分条件 |
| 6 | 第三充分条件 $n$ 从 0 开始 | $n$ 从 1 开始（$f'(x_0) = 0$ 是前提） |
| 7 | 导数大于 0 等价于严格单调增加 | 导数大于 0 $\Rightarrow$ 严格增，逆推不成立 |
| 8 | 端点可以讨论极值 | **极值是局部概念**，须在邻域内定义，端点处不存在完整邻域，因此不讨论极值 |

## 七、知识结构图

```
单调性与极值
├── 单调性判别
│   └── f'(x) 的符号判定（等号有限个点）
├── 极值的定义（局部概念 vs 最值）
├── 费马定理（必要条件）
│   ├── 驻点 (f'(x_0) = 0)
│   └── 不可导点
└── 三个充分条件（从弱到强）
    ├── 第一充分条件：左右邻域导数符号（通用）
    ├── 第二充分条件：一点处二阶导数值（速判）
    └── 第三充分条件：一点处 n 阶导数值（推广）
```

## 八、解题方法总结

### 求极值的标准流程

```
Step 1: 求 f'(x)，找出所有驻点和不可导点
Step 2: 检查各可疑点处的连续性
Step 3: 选择充分条件判定：
   ├── 二阶导易求且 f''(x_0) ≠ 0 → 第二充分条件
   ├── 高阶导易求且低阶导全为0 → 第三充分条件
   └── 其他情况 → 第一充分条件（左右邻域取点）
Step 4: 回代求极值
```

### 隐函数求极值流程

```
Step 1: 方程两边对 x 求导（含 y'）
Step 2: 令 y' = 0，得 y 与 x 的关系
Step 3: 代入原方程解出具体坐标
Step 4: 再次求导得 y'' 判别极值
```
