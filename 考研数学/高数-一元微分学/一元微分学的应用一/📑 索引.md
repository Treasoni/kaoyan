# 📑 一元微分学的应用一（几何应用）

> [!info] 模块概述
> 本模块是微分学的核心应用部分，主要研究如何利用导数分析函数的几何性质，包括单调性、极值、凹凸性、拐点、渐近线、最值以及函数图像的绘制。这是考研数学的**高频考点**，常以选择题、填空题、解答题形式出现。

| 最值问题 | 选择、填空、解答 | ⭐⭐⭐⭐ |
| 渐近线 | 选择、填空 | ⭐⭐⭐⭐ |

## 🗺️ 学习路线

```mermaid
graph LR
    A[单调性与极值] --> B[凹凸性与拐点]
    B --> C[极值点与拐点的重要结论]
    C --> D[渐近线]
    D --> E[最值或取值范围]
    E --> F[作函数图像]
    F --> G[曲率及曲率半径]
```

**建议学习顺序**：
1. 先掌握**单调性与极值**的判别方法（基础）
2. 对比学习**凹凸性与拐点**（方法类似）
3. 记忆**重要结论**（选择题技巧）
4. 学习**渐近线**和**最值**（常考题型）
5. 综合运用绘制**函数图像**
6. 数一/数二补充学习**曲率**

## ⚠️ 重难点提示

1. **极值点的判别**：三种充分条件的适用场景
2. **拐点的判别**：与极值点判别方法对比记忆
3. **间断点可以是极值点**：如 $f(x) = |x|$ 在 $x=0$ 处
4. **渐近线求解顺序**：铅直 → 水平 → 斜
5. **曲率公式**：需背诵，数一数二专属
