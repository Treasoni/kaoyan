# 📝 渐近线 章节总结

> 渐近线描述曲线在无穷远处的趋向行为，是函数形态分析的重要组成部分。渐近线分为三种：铅直（垂直）、水平、斜渐近线。

---

## 一、知识结构总览

```
渐近线
 ├── 铅直渐近线（垂直渐近线）
 │   └── 找无定义点 / 区间端点 / 分段点
 ├── 水平渐近线
 │   └── 看 x→±∞ 时的极限
 └── 斜渐近线
     └── 看 x→∞ 时 f(x)/x 的极限
```

### 寻找顺序

> [!tip] 渐近线寻找顺序
> **铅直 → 水平 → 斜**

1. 先找**无定义点、定义区间端点、分段点** → 铅直渐近线
2. 判别 $\lim_{x \to \pm\infty} f(x)$ 是否为常数 → 水平渐近线
3. 判别 $\lim_{x \to \pm\infty} \frac{f(x)}{x}$ 是否为非零常数 → 斜渐近线

---

## 二、核心定义与公式

### 1. 铅直渐近线

> [!def] 铅直渐近线
> 若 $\lim_{x \to x_0^+} f(x) = \infty$ 或 $\lim_{x \to x_0^-} f(x) = \infty$，则直线 $x = x_0$ 为曲线 $y = f(x)$ 的一条**铅直渐近线**。

**寻找方法：** $x_0$ 可能为以下三种点：
1. 函数的**无定义点**
2. 函数定义区间的**端点**
3. **分段函数的分段点**

> [!note] 注意
> - 只需**单侧**趋于无穷即可
> - 可能有**多条**铅直渐近线（如 $y = \tan x$ 有无穷多条）
> - 应先找铅直渐近线

### 2. 水平渐近线

> [!def] 水平渐近线
> - 若 $\lim_{x \to +\infty} f(x) = y_1$，则 $y = y_1$ 为一条水平渐近线
> - 若 $\lim_{x \to -\infty} f(x) = y_2$，则 $y = y_2$ 为一条水平渐近线

**$x \to +\infty$ 与 $x \to -\infty$ 的情况：**
- 可能**相同**（如 $y = e^{-|x|}$）
- 可能**不同**（如 $y = \arctan x$）
- 可能**一侧有一侧无**（如 $y = e^x$）

### 3. 斜渐近线

> [!def] 斜渐近线
> 若以下两个极限同时存在：
> $$a = \lim_{x \to \infty} \frac{f(x)}{x} \quad (a \neq 0)$$
> $$b = \lim_{x \to \infty}[f(x) - ax]$$
>
> 则 $y = ax + b$ 是一条**斜渐近线**。

> [!note] 推导思路
> 渐近线 $y = ax + b$ 满足 $\lim_{x \to \infty}[f(x) - (ax + b)] = 0$，由此可导出上述公式。

**重要说明：**
1. **$a$ 与 $b$ 都要求出来**——仅 $a$ 存在不能确定有斜渐近线
2. **左右可能不同**——$x \to +\infty$ 与 $x \to -\infty$ 时可能不同
3. **与水平渐近线互斥**——同一方向存在水平渐近线则无斜渐近线
4. **曲线可与渐近线相交**——渐近线只描述无穷远处的行为

---

## 三、重要关系

### 水平与斜渐近线的互斥关系

> [!warning] 核心要点
> 若存在水平渐近线，则**不存在斜渐近线**（同一方向）
>
> 因为：$\lim_{x \to \infty} f(x) = A \Rightarrow \lim_{x \to \infty} \frac{f(x)}{x} = 0$

### 三种渐近线对比

| 类型 | 方程形式 | 判定条件 | 极限方向 |
|------|----------|----------|----------|
| 铅直渐近线 | $x = x_0$ | $\lim_{x \to x_0} f(x) = \infty$ | 单侧即可 |
| 水平渐近线 | $y = y_0$ | $\lim_{x \to \pm\infty} f(x) = y_0$ | $+\infty$ 与 $-\infty$ 分别考虑 |
| 斜渐近线 | $y = ax + b$ | $\lim_{x \to \infty} \frac{f(x)}{x} = a \neq 0$ | $+\infty$ 与 $-\infty$ 分别考虑 |

## 四、典型例子

### 例1：$y = \arctan x$（含两条不同水平渐近线）

$$\lim_{x \to +\infty} \arctan x = \frac{\pi}{2},\quad \lim_{x \to -\infty} \arctan x = -\frac{\pi}{2}$$

故有两条水平渐近线：$y = \frac{\pi}{2}$ 和 $y = -\frac{\pi}{2}$

### 例2：$y = \tan x$（含无穷多条铅直渐近线）

在 $x = \frac{\pi}{2} + k\pi$（$k \in \mathbb{Z}$）处，$\tan x \to \infty$

### 例3：$y = x + \sin x$（反例——$a$ 存在但无斜渐近线）

$$a = \lim_{x \to \infty}\frac{y}{x} = 1,\quad 但\ b = \lim_{x \to \infty}(y - x) = \lim_{x \to \infty}\sin x\ \text{不存在}$$

故 $y = x + \sin x$ **无斜渐近线**。

### 例4：曲线穿越渐近线

$y = \frac{\sin x}{x}$ 的水平渐近线为 $y = 0$，但曲线在 $x = n\pi$（$n \neq 0$）处**穿过**渐近线。

> 渐近线描述的是 $x \to \infty$ 时的**极限行为**，而非全局约束。

## 五、综合例题

> [!example] 求 $y = \frac{1}{x} + \ln(1 + e^x)$ 的全部渐近线

**解答：**

1. **铅直渐近线**：
   $$\lim_{x \to 0} \left[\frac{1}{x} + \ln(1 + e^x)\right] = \infty$$
   故 $x = 0$ 是铅直渐近线。

2. **水平渐近线**：
   $$\lim_{x \to -\infty} \left[\frac{1}{x} + \ln(1 + e^x)\right] = 0 + \ln(1 + 0) = 0$$
   $$\lim_{x \to +\infty} \left[\frac{1}{x} + \ln(1 + e^x)\right] = +\infty$$
   故只有一条水平渐近线：$y = 0$（$x \to -\infty$ 方向）。

3. **斜渐近线**：
   $$a = \lim_{x \to +\infty}\frac{\frac{1}{x} + \ln(1 + e^x)}{x} = \lim_{x \to +\infty}\left[\frac{1}{x^2} + \frac{\ln(1 + e^x)}{x}\right] = 1$$
   $$b = \lim_{x \to +\infty}\left[\frac{1}{x} + \ln(1 + e^x) - x\right] = \lim_{x \to +\infty}\left[\frac{1}{x} + \ln(1 + e^{-x})\right] = 0$$
   故斜渐近线为 $y = x$（$x \to +\infty$ 方向）。

**结论**：共有 3 条渐近线：$x = 0$，$y = 0$，$y = x$

---

## 六、易错点

1. **漏找铅直渐近线**：只找无定义点，忘记考虑定义区间端点和分段点
2. **水平与斜渐近线混用**：同一方向二者互斥，不可同时存在
3. **斜渐近线只求 $a$ 不求 $b$**：$a$ 存在不代表 $b$ 也存在（反例：$y = x + \sin x$）
4. **忘记分左右**：$x \to +\infty$ 与 $x \to -\infty$ 要分别考虑
5. **误认为曲线不能穿越渐近线**：渐近线只约束无穷远处的行为
