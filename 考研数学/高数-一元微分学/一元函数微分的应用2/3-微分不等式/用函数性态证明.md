# 用函数性态证明不等式

> [!important] 首选方法
> 证明微分不等式时，**首先考虑**研究辅助函数 $F(x)$ 的凹凸性、最值、正负。

## 核心依据

### 1. 单调性

> [!theorem] 单调性与不等式
> 若有 $f'(x) \geqslant 0$，$a < x < b$，则有
> $$f(a) \leqslant f(x) \leqslant f(b)$$

### 2. 凹凸性

> [!theorem] 凹凸性与导数
> 若有 $f''(x) \geqslant 0$，$a < x < b$，则有 $f'(a) \leqslant f'(x) \leqslant f'(b)$。
>
> - 当 $f'(a) > 0$ 时，$f'(x) > 0$，则 $f(x)$ 单调增加
> - 当 $f'(b) < 0$ 时，$f'(x) < 0$，则 $f(x)$ 单调减少

### 3. 最值

> [!theorem] 极值与最值
> 设 $f(x)$ 在 $I$ 内连续，且有**唯一的极值点** $x_0$，则：
> - 当 $x_0$ 为**极大值点**时，即为 $I$ 内的**最大值点**，有 $f(x) \leqslant f(x_0)$
> - 当 $x_0$ 为**极小值点**时，即为 $I$ 内的**最小值点**，有 $f(x) \geqslant f(x_0)$

### 4. 凹凸性与端点值

> [!theorem] 重要结论
> 若有 $f''(x) > 0$，$a < x < b$，$f(a) = f(b) = 0$，则有
> $$f(x) < 0$$

---

## 证明步骤

1. **构造辅助函数**：将不等式转化为 $F(x) > 0$ 或 $F(x) < 0$
2. **研究函数性态**：
   - 求导判断单调性
   - 求二阶导判断凹凸性
   - 求极值、最值
3. **得出结论**

## 例题

> [!example] 例6.19
> 证明当 $0 < x < \frac{\pi}{2}$ 时，有 $\sin x > \frac{2x}{\pi}$。

**方法一：单调性**

欲证 $\sin x > \frac{2x}{\pi}$，即证 $\frac{\sin x}{x} > \frac{2}{\pi}$。

令 $f(x) = \frac{\sin x}{x}$，$x \in (0, \frac{\pi}{2})$。

$$f'(x) = \frac{x\cos x - \sin x}{x^2}$$

令 $g(x) = x\cos x - \sin x$，则 $g'(x) = -x\sin x < 0$，$g(x)$ 单调递减。

$g(x) < g(0) = 0$，所以 $f'(x) < 0$，$f(x)$ 单调递减。

故 $f(x) > f(\frac{\pi}{2}) = \frac{2}{\pi}$，即 $\sin x > \frac{2x}{\pi}$。

**方法二：凹凸性**

令 $f(x) = \sin x - \frac{2x}{\pi}$，$x \in (0, \frac{\pi}{2})$。

$$f'(x) = \cos x - \frac{2}{\pi}, \quad f''(x) = -\sin x < 0$$

曲线 $f(x)$ 在 $(0, \frac{\pi}{2})$ 内是**凸的**，又 $f(0) = f(\frac{\pi}{2}) = 0$，所以 $f(x) > 0$，即 $\sin x > \frac{2x}{\pi}$。
