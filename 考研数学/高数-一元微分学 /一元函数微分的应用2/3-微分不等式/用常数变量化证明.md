# 用常数变量化证明不等式

## 核心思想

如果欲证的不等式中**都是常数**，则可以将其中一个或几个常数**变量化**，再利用导数工具去证明。

---

## 方法步骤

1. **选择变量化的常数**：将不等式中的某个常数 $a$ 或 $b$ 替换为变量 $x$
2. **构造辅助函数**：$F(x) = \text{不等式左边} - \text{不等式右边}$
3. **研究函数性态**：求导、判断单调性、极值等
4. **还原结论**：取特定值得到原不等式

---

## 适用场景

- 不等式涉及多个常数，如 $a < b$、$0 < x < 1$ 等
- 直接证明困难，需要借助函数性态

---

## 例题

> [!example] 例6.21
> 设 $0 < a < b$，证明不等式
> $$\frac{2a}{a^2 + b^2} < \frac{\ln b - \ln a}{b - a} < \frac{1}{\sqrt{ab}}$$

**证明右边**：构造辅助函数 $\varphi(x) = \ln x - \ln a - \frac{x - a}{\sqrt{ax}}$（$x > a > 0$）

$$\varphi'(x) = \frac{1}{x} - \frac{1}{\sqrt{a}}\left(\frac{1}{2\sqrt{x}} + \frac{a}{2x\sqrt{x}}\right) = -\frac{(\sqrt{x} - \sqrt{a})^2}{2x\sqrt{ax}} < 0$$

故当 $x > a$ 时，$\varphi(x)$ 单调减少，又 $\varphi(a) = 0$，所以 $\varphi(x) < \varphi(a) = 0$。

即 $\ln x - \ln a < \frac{x - a}{\sqrt{ax}}$，特别地当 $x = b > a$ 时，$\ln b - \ln a < \frac{b - a}{\sqrt{ab}}$，即 $\frac{\ln b - \ln a}{b - a} < \frac{1}{\sqrt{ab}}$。

---

## 常见技巧

| 原不等式 | 变量化后 |
|----------|----------|
| $f(a) < f(b)$ | 研究 $F(x) = f(x)$ 的单调性 |
| $f(a,b) < g(a,b)$ | 固定 $a$，令 $F(x) = f(a,x) - g(a,x)$ |
| $\frac{f(b) - f(a)}{b - a} < h(a,b)$ | 研究 $F(x) = f(x) - f(a) - (x-a)h(a,x)$ |
