# 定理9：泰勒公式

> [!important] 重中之重
> 泰勒公式是**微积分的巅峰**，极限计算和证明题的**终极武器**！

## 定理内容

### 带拉格朗日余项的泰勒公式

> [!theorem] 拉格朗日余项形式
> 设 $f(x)$ 在点 $x_0$ 的某个邻域内 $n+1$ 阶导数存在，则对该邻域内的任意点 $x$，有
> $$f(x) = f(x_0) + f'(x_0)(x-x_0) + \cdots + \frac{1}{n!}f^{(n)}(x_0)(x-x_0)^n + \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$$
> 其中 $\xi$ 介于 $x, x_0$ 之间。
>
> **适用场景**：区间 $[a,b]$ 上的证明题，如证不等式、中值等式等。

### 带佩亚诺余项的泰勒公式

> [!theorem] 佩亚诺余项形式
> 设 $f(x)$ 在点 $x_0$ 处 $n$ 阶可导，则存在 $x_0$ 的一个邻域，对于该邻域内的任意点 $x$，有
> $$f(x) = f(x_0) + f'(x_0)(x-x_0) + \cdots + \frac{1}{n!}f^{(n)}(x_0)(x-x_0)^n + o((x-x_0)^n)$$
>
> **适用场景**：点 $x = x_0$ 及其邻域，如求极限、判定无穷小的阶数、判定极值等。

## 麦克劳林公式

当 $x_0 = 0$ 时的泰勒公式称为**麦克劳林公式**。

### 常用麦克劳林展开式

| 函数 | 展开式 |
|------|--------|
| $e^x$ | $1 + x + \frac{x^2}{2!} + \cdots + \frac{x^n}{n!} + o(x^n)$ |
| $\sin x$ | $x - \frac{x^3}{3!} + \cdots + (-1)^n\frac{x^{2n+1}}{(2n+1)!} + o(x^{2n+1})$ |
| $\cos x$ | $1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots + (-1)^n\frac{x^{2n}}{(2n)!} + o(x^{2n})$ |
| $\frac{1}{1-x}$ | $1 + x + x^2 + \cdots + x^n + o(x^n)$ |
| $\frac{1}{1+x}$ | $1 - x + x^2 - \cdots + (-1)^n x^n + o(x^n)$ |
| $\ln(1+x)$ | $x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots + (-1)^{n-1}\frac{x^n}{n} + o(x^n)$ |
| $(1+x)^\alpha$ | $1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \cdots + o(x^n)$ |

## 使用技巧

> [!tip] 如何选择展开点 $x_0$ 和被展开点 $x$？
> - **展开点 $x_0$**：取已知导数值的点或待证导数值的点
> - **被展开点 $x$**：取已知函数值的点或特殊点（端点、中间点等）
> - 关键是**消去未知的函数项或导数项**，向结论靠拢

> [!tip] 何时使用泰勒公式？
> - 遇到 $f$ 与 $f^{(n)}(n \geqslant 2)$ 的关系
> - 若证 $f^{(n)}(\xi) = 0$，用**罗尔定理**可能性大
> - 若证 $f^{(n)}(\xi) \neq 0$（不等式），用**泰勒公式**可能性大

## 例题

> [!example] 例6.13
> 设函数 $f(x)$ 在区间 $[-1,1]$ 上具有三阶连续导数，且 $f(-1) = 0$，$f(1) = 1$，$f'(0) = 0$。证明：在区间 $(-1,1)$ 内至少存在一点 $\xi$，使 $f'''(\xi) = 3$。

**证明**：
将 $f(x)$ 在 $x = 0$ 处展开成带拉格朗日余项的二阶泰勒公式：
$$f(x) = f(0) + f'(0)x + \frac{1}{2}f''(0)x^2 + \frac{1}{6}f'''(\eta)x^3$$

其中 $\eta$ 介于 $0$ 与 $x$ 之间，$x \in [-1,1]$。

分别令 $x = -1$ 和 $x = 1$：
$$0 = f(-1) = f(0) + \frac{1}{2}f''(0) - \frac{1}{6}f'''(\eta_1), \quad -1 < \eta_1 < 0$$
$$1 = f(1) = f(0) + \frac{1}{2}f''(0) + \frac{1}{6}f'''(\eta_2), \quad 0 < \eta_2 < 1$$

两式相减，得 $f'''(\eta_1) + f'''(\eta_2) = 6$。

由介值定理，存在 $\xi \in [\eta_1, \eta_2] \subset (-1, 1)$，使得
$$f'''(\xi) = \frac{f'''(\eta_1) + f'''(\eta_2)}{2} = 3$$
