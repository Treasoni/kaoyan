# 例2.17：充分不必要条件判断

## 题目

> [!example] 例2.17
> "存在正整数 $N$，当 $n \geqslant N$ 时，恒有 $|x_n - a| \leqslant \frac{1}{n}$" 是数列 $\{x_n\}$ 收敛于 $a$ 的（  ）。
>
> (A) 充分不必要条件
>
> (B) 必要不充分条件
>
> (C) 充分必要条件
>
> (D) 既不充分也不必要条件

## 题目分析

> [!info] 类型识别
> **充分必要条件判断** + **收敛速度问题**
>
> **关键**：$\frac{1}{n}$ 与 $n$ **有关**，对收敛速度提出了要求！

## 解答

**答案**：(A)

### 证明充分性

> [!check] 证明：条件 ⇒ 极限存在

如果存在正整数 $N$，当 $n \geqslant N$ 时，恒有 $|x_n - a| \leqslant \frac{1}{n}$。

**对于任意** $\varepsilon > 0$，取 $n_0 = \max\left\{N, \left[\frac{1}{\varepsilon}\right] + 1\right\}$

则 $|x_{n_0} - a| \leqslant \frac{1}{n_0} < \varepsilon$

由极限定义，$\lim_{n \to \infty} x_n = a$ ✓

### 证明非必要性

> [!fail] 证明：极限存在 ⇏ 条件成立

**反例**：取 $x_n = a + \frac{1}{\sqrt{n}}$

**验证**：
1. $\lim_{n \to \infty} x_n = \lim_{n \to \infty} \left(a + \frac{1}{\sqrt{n}}\right) = a$ ✓（极限存在）

2. 但 $|x_n - a| = \frac{1}{\sqrt{n}} > \frac{1}{n}$（当 $n > 1$ 时）

**原因分析**：
- $x_n = a + \frac{1}{\sqrt{n}}$ 收敛于 $a$ 的速度**慢于** $y_n = a + \frac{1}{n}$
- 因此 $|x_n - a| = \frac{1}{\sqrt{n}} > \frac{1}{n}$

### 结论

> [!success] 最终答案
> 条件是 $\{x_n\}$ 收敛于 $a$ 的**充分不必要条件**。
>
> **答案：(A)**

## 核心理解

> [!important] 关键区别
> **数列极限定义**：$\forall \varepsilon > 0$，$\varepsilon$ 可以是任意小的正数，但**不能与 $n$ 有关**！
>
> **本题条件**：$|x_n - a| \leqslant \frac{1}{n}$，其中 $\frac{1}{n}$ **与 $n$ 有关**。
>
> **含义**：这相当于对收敛速度提出了**特定要求**。

## 对比总结

| 题型 | $\varepsilon$ 形式 | 与 $n$ 的关系 | 条件类型 |
|------|------------------|-------------|---------|
| 例2.16 | $\frac{1}{2^k}$ | **无关** | 充分必要条件 |
| 例2.17 | $\frac{1}{n}$ | **有关** | 充分不必要条件 |

> [!tip] 判断口诀
> **$\varepsilon$ 若与 $n$ 有关，充分不必要；无关则可能充要。**

## 图解理解

```
收敛速度比较：
                    yₙ = a + 1/n
                          │
          ┌───────────────┼───────────────┐
          │               │               │
          │   xₙ = a + 1/√n              │
          │       (更慢)  │               │
          │               │               │
          │               │               │
          └───────────────┼───────────────┘
                          │
                          ▼
                          a

当 n 充分大时：
  |xₙ - a| = 1/√n > 1/n = |yₙ - a|
```

## 反例构造技巧

> [!tip] 如何构造反例
> 1. 找一个收敛速度**慢于** $\frac{1}{n}$ 的数列
> 2. 常见选择：$\frac{1}{\sqrt{n}}$，$\frac{1}{\ln n}$
> 3. 验证：极限存在，但不满足 $|x_n - a| \leqslant \frac{1}{n}$

## 易错点 ⚠️

- [ ] 忘记验证非必要性（反例）
- [ ] 误认为所有收敛条件都是充分必要条件
- [ ] 不理解 $\varepsilon$ 与 $n$ 的关系对条件类型的影响
