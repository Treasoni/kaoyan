# 7-收敛速度问题

> [!info] 模块概述
> 数列极限的定义只体现收敛目标，不体现收敛速度。这是命制选择题的重要理论依据。

## 🎯 核心结论

> [!important] 核心理论
> **数列极限的定义只体现收敛目标，不体现收敛速度**
>
> $$\lim_{n \to \infty} x_n = a \Leftrightarrow \forall \varepsilon > 0, \exists N > 0, \text{当 } n > N \text{ 时，恒有 } |x_n - a| < \varepsilon$$
>
> **关键**：$\varepsilon$ 可以是任意小的正数，但**不能与 $n$ 有关**！

> [!warning] 命题陷阱
> 若命题中的 $\varepsilon$ 与 $n$ 有关（如 $\varepsilon = \frac{1}{n}$），相当于对收敛速度提出了要求。
>
> 这类条件是极限存在的**充分条件**，但**不是必要条件**。

## 💡 收敛速度比较

设数列 $\{x_n\}$，$\{y_n\}$ 都收敛于 $a$，记 $u_n = |x_n - a|$，$\nu_n = |y_n - a|$，
$$
I = \lim_{n \to \infty} \frac{u_n}{\nu_n}
$$

| $I$ 的值 | 含义 | 结论 |
|---------|------|------|
| $I = 0$ | $u_n$ 是 $\nu_n$ 的高阶无穷小 | $x_n$ **收敛更快** |
| $I = b$（$b > 0$ 常数） | $u_n$ 与 $\nu_n$ 同阶 | 收敛速度**相近** |
| $I = \infty$ | $u_n$ 是 $\nu_n$ 的低阶无穷小 | $x_n$ **收敛更慢** |

> [!example] 例：比较收敛速度
> $x_n = \frac{1}{n}$，$y_n = \frac{1}{\sqrt{n}}$，都收敛于 $0$
>
> $$I = \lim_{n \to \infty} \frac{\left|\frac{1}{n} - 0\right|}{\left|\frac{1}{\sqrt{n}} - 0\right|} = \lim_{n \to \infty} \frac{1}{\sqrt{n}} = 0$$
>
> 故 $x_n$ 比 $y_n$ **收敛于 $0$ 的速度更快**。

## 📊 选择题判断技巧

> [!tip] 核心技巧
> 1. **检查 $\varepsilon$ 是否与 $n$ 有关**
>    - 无关 → 可能是充分必要条件
>    - 有关 → 充分不必要条件（对速度有要求）
>
> 2. **判断是否涉及收敛速度**
>    - 涉及速度比较（如 $|x_n - a| \leqslant \frac{1}{n}$）→ 充分不必要
>    - 只涉及任意小的 $\varepsilon$ → 充分必要
