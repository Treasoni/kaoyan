# 收敛速度问题

## 概念

当数列 $\{x_n\}$ 收敛于 $a$ 时，研究 $x_n$ 趋近 $a$ 的"快慢"。

## 常用描述方式

### 绝对误差

$$|x_n - a|$$

### 相对误差

$$\left|\frac{x_n - a}{a}\right|$$

### 收敛阶

若 $|x_n - a| = O(n^{-p})$，称 $p$ 阶收敛。

## 常见收敛速度比较

| 收敛速度 | 类型 | 示例 |
|----------|------|------|
| 较慢 | $O(\frac{1}{\ln n})$ | $\ln n / n$ |
| 中等 | $O(\frac{1}{n})$ | $1/n$ |
| 较快 | $O(\frac{1}{n^2})$ | $1/n^2$ |
| 很快 | $O(\frac{1}{2^n})$ | $1/2^n$ |

## 与迭代法的关系

在数值计算中，迭代序列 $x_{n+1} = g(x_n)$ 的收敛速度：

- **线性收敛**：$|x_{n+1} - a| \leq c|x_n - a|$，$0 < c < 1$
- **平方收敛**：$|x_{n+1} - a| \leq c|x_n - a|^2$

## 考试要求

> [!note] 数二要求
> 了解即可，主要在选择题或填空题中出现。

## 典型问题

比较两个数列收敛到同一极限的速度快慢。

## 典型例题

> [!example] 例1：比较收敛速度
> **题目**：比较数列 $a_n = \frac{1}{n}$ 和 $b_n = \frac{1}{n^2}$ 收敛到 $0$ 的速度。
>
> **分析**：比较 $|a_n - 0|$ 和 $|b_n - 0|$ 的趋近速度。
>
> **解答**：
> $$\lim_{n \to \infty} \frac{a_n}{b_n} = \lim_{n \to \infty} \frac{1/n}{1/n^2} = \lim_{n \to \infty} n = +\infty$$
>
> 这说明 $a_n$ 比 $b_n$ 收敛得**慢**。
>
> 直观理解：$n=100$ 时，$a_n = 0.01$，$b_n = 0.0001$，$b_n$ 更接近 $0$。

> [!example] 例2：指数收敛 vs 多项式收敛
> **题目**：比较 $a_n = \frac{1}{n}$ 和 $b_n = \frac{1}{2^n}$ 的收敛速度。
>
> **解答**：
> $$\lim_{n \to \infty} \frac{a_n}{b_n} = \lim_{n \to \infty} \frac{1/n}{1/2^n} = \lim_{n \to \infty} \frac{2^n}{n} = +\infty$$
>
> 指数收敛（$O(2^{-n})$）比多项式收敛（$O(n^{-1})$）**快得多**。

## 收敛速度等级

> [!important] 速度排序（从慢到快）
> $$O\left(\frac{1}{\ln n}\right) < O\left(\frac{1}{n}\right) < O\left(\frac{1}{n^2}\right) < O\left(\frac{1}{n^3}\right) < \cdots < O\left(\frac{1}{2^n}\right) < O\left(\frac{1}{n!}\right)$$
