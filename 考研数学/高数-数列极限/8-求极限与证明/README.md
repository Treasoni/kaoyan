## 典型大题分析

> [!example] 例1：递推数列综合题
> **题目**：设 $x_1 = 1$，$x_{n+1} = \frac{x_n + 2}{x_n + 1}$，证明 $\{x_n\}$ 收敛并求极限。
>
> **解答**：
>
> **（1）证明收敛**
>
> **有界性**：$0 < x_n < 2$
> - $x_1 = 1 \in (0, 2)$
> - 若 $x_n \in (0, 2)$，则 $x_{n+1} = \frac{x_n + 2}{x_n + 1} \in (1, \frac{4}{3}) \subset (0, 2)$
>
> **单调性**：$x_{n+1} - x_n = \frac{x_n + 2}{x_n + 1} - x_n = \frac{2 - x_n^2}{x_n + 1}$
>
> 当 $x_n \in (0, \sqrt{2})$ 时，$x_{n+1} > x_n$；当 $x_n \in (\sqrt{2}, 2)$ 时，$x_{n+1} < x_n$
>
> 需进一步分析...（考虑从 $x_1 = 1 < \sqrt{2}$ 开始，数列单调递增趋于 $\sqrt{2}$）
>
> **（2）求极限**
>
> 设 $\lim_{n \to \infty} x_n = a$，则 $a = \frac{a + 2}{a + 1}$
>
> $a^2 + a = a + 2$，$a^2 = 2$，$a = \sqrt{2}$（取正值）

> [!example] 例2：$n$ 项和极限
> **题目**：求 $\lim_{n \to \infty} \left(\frac{1}{n^2+1} + \frac{2}{n^2+2} + \cdots + \frac{n}{n^2+n}\right)$
>
> **分析**：用夹逼准则。
>
> **解答**：
> 放缩：
> $$\frac{1+2+\cdots+n}{n^2+n} \leq S_n \leq \frac{1+2+\cdots+n}{n^2+1}$$
>
> $$\frac{n(n+1)/2}{n^2+n} \leq S_n \leq \frac{n(n+1)/2}{n^2+1}$$
>
> $$\frac{n+1}{2(n+1)} = \frac{1}{2} \leq S_n \leq \frac{n^2+n}{2(n^2+1)} \to \frac{1}{2}$$
>
> 由夹逼准则，原式 $= \frac{1}{2}$

## 解题策略

> [!tip] 大题解题步骤
> 1. **判断题型**：递推？$n$ 项和？$f(n)$ 型？
> 2. **选择方法**：根据题型选择合适的方法
> 3. **书写规范**：
>    - 证明存在性：先证有界，再证单调
>    - 计算极限：设极限为 $a$，解方程
>    - 检验：验证结果是否合理
