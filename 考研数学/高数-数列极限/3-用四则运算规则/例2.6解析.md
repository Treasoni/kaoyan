# 例2.6：变量替换技巧

## 题目

> [!example] 例2.6
> 设 $\lim_{n\to\infty}(a_n + b_n) = 1$，$\lim_{n\to\infty}(a_n - b_n) = 3$，则（  ）
>
> (A) $\{a_n\}$ 极限存在，$\{b_n\}$ 极限不存在
>
> (B) $\{a_n\}$ 极限存在，$\{b_n\}$ 极限存在
>
> (C) $\{a_n\}$ 极限不存在，$\{b_n\}$ 极限不存在
>
> (D) $\{a_n\}$ 极限不存在，$\{b_n\}$ 极限存在

## 解题思路

### 思路分析

**问题**：已知 $a_n + b_n$ 和 $a_n - b_n$ 的极限，如何判断 $a_n$ 和 $b_n$ 的极限是否存在？

**关键洞察**：
- 直接由 $\lim(a_n + b_n)$ 存在，**不能**推出 $\lim a_n$ 和 $\lim b_n$ 都存在
- 但如果同时知道 $\lim(a_n + b_n)$ 和 $\lim(a_n - b_n)$，可以利用**变量替换**求解

### 变量替换法

**核心技巧**：令
$$u_n = a_n + b_n, \quad v_n = a_n - b_n$$

则 $\lim_{n\to\infty}u_n = 1$，$\lim_{n\to\infty}v_n = 3$。

**反解**：
$$a_n = \frac{1}{2}(u_n + v_n), \quad b_n = \frac{1}{2}(u_n - v_n)$$

## 完整解答

**解**：应选 **(B)**。

**第一步：变量替换**

令 $u_n = a_n + b_n$，$v_n = a_n - b_n$，则：
$$\lim_{n\to\infty}u_n = 1, \quad \lim_{n\to\infty}v_n = 3$$

**第二步：求 $u_n + v_n$ 和 $u_n - v_n$ 的极限**

由四则运算规则（加减法），$\{u_n + v_n\}$ 和 $\{u_n - v_n\}$ 的极限都存在：

$$\lim_{n\to\infty}(u_n + v_n) = \lim_{n\to\infty}u_n + \lim_{n\to\infty}v_n = 1 + 3 = 4$$

$$\lim_{n\to\infty}(u_n - v_n) = \lim_{n\to\infty}u_n - \lim_{n\to\infty}v_n = 1 - 3 = -2$$

**第三步：反解 $a_n$ 和 $b_n$**

$$a_n = \frac{1}{2}(u_n + v_n), \quad b_n = \frac{1}{2}(u_n - v_n)$$

由常数因子规则和四则运算规则：
$$\lim_{n\to\infty}a_n = \frac{1}{2} \times 4 = 2$$
$$\lim_{n\to\infty}b_n = \frac{1}{2} \times (-2) = -1$$

**结论**：$\{a_n\}$ 和 $\{b_n\}$ 的极限都存在，选 **(B)**。

## 关键技巧总结

> [!tip] 变量替换技巧
>
> **适用场景**：已知 $a_n + b_n$ 和 $a_n - b_n$ 的极限，求 $a_n$ 和 $b_n$ 的极限。
>
> **步骤**：
> 1. 令 $u_n = a_n + b_n$，$v_n = a_n - b_n$
> 2. 计算 $\lim(u_n + v_n)$ 和 $\lim(u_n - v_n)$
> 3. 反解：$a_n = \frac{1}{2}(u_n + v_n)$，$b_n = \frac{1}{2}(u_n - v_n)$
> 4. 求出 $\lim a_n$ 和 $\lim b_n$

## 重要注记

> [!warning] 逆命题不成立
>
> $\lim_{n\to\infty}(a_n + b_n)$ 存在，**并不意味着** $\lim_{n\to\infty}a_n$ 和 $\lim_{n\to\infty}b_n$ 都存在。
>
> **反例**：
> $$\lim_{n\to\infty}[\sin n + (-\sin n)] = \lim_{n\to\infty}0 = 0$$
> 但 $\lim_{n\to\infty}\sin n$ 与 $\lim_{n\to\infty}(-\sin n)$ 都不存在。
>
> **本例的特殊性**：同时已知 $a_n + b_n$ 和 $a_n - b_n$ 的极限，才能确定 $a_n$ 和 $b_n$ 的极限。

