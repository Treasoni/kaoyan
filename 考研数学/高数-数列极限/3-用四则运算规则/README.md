## 🎯 核心公式速查

### 数列极限四则运算

设 $\lim_{n\to\infty}x_n = a$，$\lim_{n\to\infty}y_n = b$，则：

| 运算 | 公式 | 条件 |
|------|------|------|
| **加法** | $\lim_{n\to\infty}(x_n + y_n) = a + b$ | 无 |
| **减法** | $\lim_{n\to\infty}(x_n - y_n) = a - b$ | 无 |
| **乘法** | $\lim_{n\to\infty}x_n y_n = ab$ | 无 |
| **除法** | $\lim_{n\to\infty}\frac{x_n}{y_n} = \frac{a}{b}$ | $b \neq 0$ |

> [!tip] 推广
> 四则运算规则可推广至**有限个**数列的情形。

### 极限存在性速判规则

| 情形 | 结论 | 记忆 |
|------|------|------|
| 存在 ± 存在 | = 存在 | ✅ 确定存在 |
| 存在 ± 不存在 | = 不存在 | ✅ 确定不存在 |
| 不存在 ± 不存在 | = **不确定** | ⚠️ 需要具体分析 |

## 📌 重要提醒

> [!warning] 逆命题不成立！
> $\lim_{n\to\infty}(a_n + b_n)$ 存在，**并不意味着** $\lim_{n\to\infty}a_n$ 和 $\lim_{n\to\infty}b_n$ 都存在。
>
> **反例**：$\lim_{n\to\infty}[\sin n + (-\sin n)] = 0$ 存在，但 $\lim_{n\to\infty}\sin n$ 不存在。
