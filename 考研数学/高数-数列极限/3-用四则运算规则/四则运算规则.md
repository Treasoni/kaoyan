# 四则运算规则

## 定理陈述

> [!thm] 数列极限四则运算法则
>
> 设 $\lim_{n\to\infty}x_n = a$，$\lim_{n\to\infty}y_n = b$，则：
>
> **（1）加减法**
> $$\lim_{n\to\infty}(x_n \pm y_n) = a \pm b$$
>
> **（2）乘法**
> $$\lim_{n\to\infty}x_n y_n = ab$$
>
> **（3）除法**
> $$\lim_{n\to\infty}\frac{x_n}{y_n} = \frac{a}{b} \quad (\text{要求 } b \neq 0)$$

> [!tip] 推广
> 四则运算规则可以推广至**有限个**数列的情形。

## 函数极限的类似结论

> [!note] 函数极限四则运算
>
> 设 $\lim_{x\to x_0}f(x) = A$，$\lim_{x\to x_0}g(x) = B$，则：
>
> $$\lim_{x\to x_0}[f(x) \pm g(x)] = A \pm B$$
>
> $$\lim_{x\to x_0}f(x)g(x) = AB$$
>
> $$\lim_{x\to x_0}\frac{f(x)}{g(x)} = \frac{A}{B} \quad (B \neq 0)$$

## 直观理解 💡

**核心思想**：极限运算与四则运算可以**交换顺序**。

**形象比喻**：
极限就像"最终的归宿"，四则运算就像"路上的操作"。如果你知道两个人最终的归宿，那么他们"相加后的归宿"就等于各自归宿的和。

**数学语言**：
$$\lim(\text{运算}) = \text{运算}(\lim)$$

即：先运算再取极限 = 先取极限再运算（结果相同）

## 定理条件 ⚠️

### 必须满足的条件

| 运算 | 必要条件 | 原因 |
|------|----------|------|
| 加减法 | $\lim x_n$ 和 $\lim y_n$ 都存在 | 否则无法进行运算 |
| 乘法 | $\lim x_n$ 和 $\lim y_n$ 都存在 | 同上 |
| **除法** | $\lim y_n \neq 0$ | 分母不能为零 |

> [!warning] 除法的额外条件
> 除法要求**分母的极限不为零**，这是最容易忽略的条件！
>
> - 若 $\lim y_n = 0$，则 $\lim\frac{x_n}{y_n}$ 可能不存在，也可能是 $\infty$
> - 需要具体分析分子分母的情况

### 常数因子规则

> [!cor] 推论：常数因子
> 若 $\lim_{n\to\infty}x_n = a$，$c$ 为常数，则：
> $$\lim_{n\to\infty}(c \cdot x_n) = c \cdot a$$
>
> **理解**：常数可以自由进出极限符号。

## 典型题型

1. **直接应用**：已知各部分极限，求整体极限
2. **逆向应用**：已知整体极限，判断部分极限是否存在
3. **综合应用**：结合变量替换技巧

## 解题方法

### 方法1：直接拆分

**适用场景**：求复合表达式的极限

**步骤**：
1. 识别表达式中的各个部分
2. 确认各部分极限存在
3. 分别求出各部分极限
4. 按四则运算规则组合

**例**：求 $\lim_{n\to\infty}\frac{2n + 1}{n + 2}$

$$
\lim_{n\to\infty}\frac{2n + 1}{n + 2} = \lim_{n\to\infty}\frac{2 + \frac{1}{n}}{1 + \frac{2}{n}} = \frac{2 + 0}{1 + 0} = 2
$$

### 方法2：变量替换

**适用场景**：直接应用困难时

**步骤**：
1. 引入新变量表示原表达式的组合
2. 利用新变量进行运算
3. 反解原变量



## 易错点 ⚠️

- [ ] **除法时忘记验证分母极限≠0**
- [ ] 误以为 $\lim(a_n + b_n)$ 存在 ⇒ $\lim a_n$ 和 $\lim b_n$ 都存在（逆命题不成立！）
- [ ] 对无穷多个数列使用四则运算（只能用于**有限个**）
