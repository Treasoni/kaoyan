# 极限存在性判断

## 核心规则

> [!important] 极限存在性速判规则
>
> | 情形 | 结论 | 确定性 |
> |------|------|--------|
> | 存在 ± 存在 | = 存在 | ✅ 确定 |
> | 存在 ± 不存在 | = 不存在 | ✅ 确定 |
> | 不存在 ± 不存在 | = **不确定** | ⚠️ 需具体分析 |

## 直观理解 💡

### 规则1：存在 ± 存在 = 存在

**理解**：两个确定的数进行加减，结果必然确定。

$$\lim a_n = A, \lim b_n = B \Rightarrow \lim(a_n \pm b_n) = A \pm B$$

### 规则2：存在 ± 不存在 = 不存在

**理解**：一个确定的数加上一个不确定的量，结果必然不确定。

**反证法**：
- 假设 $\lim(a_n + b_n)$ 存在且 $\lim a_n$ 存在
- 则 $\lim b_n = \lim[(a_n + b_n) - a_n]$ 也应该存在（由规则1）
- 与条件矛盾，故 $\lim(a_n + b_n)$ 不存在

### 规则3：不存在 ± 不存在 = 不确定

**理解**：两个不确定的量相加减，可能：
- 相互抵消 → 结果存在
- 不能抵消 → 结果不存在

**例子**：
- $\lim[\sin n + (-\sin n)] = \lim 0 = 0$ ✅ 存在
- $\lim[\sin n + \cos n]$ 不存在 ❌ 不存在

## 典型反例

> [!example] 反例：逆命题不成立
>
> **命题**：$\lim_{n\to\infty}(a_n + b_n)$ 存在 **不意味着** $\lim_{n\to\infty}a_n$ 和 $\lim_{n\to\infty}b_n$ 都存在。
>
> **反例**：
> - 设 $a_n = \sin n$，$b_n = -\sin n$
> - 则 $\lim_{n\to\infty}(a_n + b_n) = \lim_{n\to\infty}0 = 0$ ✅ 存在
> - 但 $\lim_{n\to\infty}\sin n$ 不存在 ❌
> - 且 $\lim_{n\to\infty}(-\sin n)$ 也不存在 ❌

## 规则总结图

```
                极限存在性判断
                     │
         ┌───────────┼───────────┐
         │           │           │
     存在±存在   存在±不存在  不存在±不存在
         │           │           │
       存在        不存在       不确定
         │           │           │
      (确定)       (确定)     (需具体分析)
```

## 典型题型

### 题型1：判断极限是否存在

> [!example] 例1
> 已知 $\lim_{n\to\infty}a_n$ 存在，$\lim_{n\to\infty}b_n$ 不存在，判断 $\lim_{n\to\infty}(a_n + b_n)$ 是否存在。
>
> **解**：由规则2，存在 + 不存在 = 不存在，故 $\lim_{n\to\infty}(a_n + b_n)$ 不存在。

### 题型2：逆向判断

> [!example] 例2
> 已知 $\lim_{n\to\infty}(a_n + b_n)$ 存在，能否推出 $\lim_{n\to\infty}a_n$ 和 $\lim_{n\to\infty}b_n$ 都存在？
>
> **解**：不能！反例：$a_n = \sin n$，$b_n = -\sin n$。

### 题型3：综合判断

> [!example] 例3
> 设 $\lim_{n\to\infty}(a_n + b_n) = 1$，$\lim_{n\to\infty}(a_n - b_n) = 3$，判断 $\lim_{n\to\infty}a_n$ 和 $\lim_{n\to\infty}b_n$ 是否存在。
>
> **解**：需要用变量替换技巧，详见 [[例2.6解析|例2.6解析]]。

## 易错点 ⚠️

- [ ] 误以为 $\lim(a_n + b_n)$ 存在 ⇒ $\lim a_n$ 存在
- [ ] 误以为不存在 + 不存在 = 不存在（实际是不确定）
- [ ] 混淆正向和逆向命题
