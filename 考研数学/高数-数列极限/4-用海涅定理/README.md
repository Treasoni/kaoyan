# 4-用海涅定理

> [!info] 模块概述
> 海涅定理（归结原则）是联系**数列极限**与**函数极限**的桥梁，是极限计算中非常重要的考点。

## 🎯 核心定理

> [!thm] 海涅定理（归结原则）
> 设 $f(x)$ 在 $U(x_0, \delta)$ 内有定义，则
> $$\lim_{x \to x_0} f(x) = A \text{ 存在} \Leftrightarrow \text{对任何以 } x_0 \text{ 为极限的数列 } \{x_n\} (x_n \neq x_0)，\lim_{n \to \infty} f(x_n) = A \text{ 存在}$$

## 🔗 三大常考转化

| 函数极限 | 取数列 | 结论 |
|----------|--------|------|
| $\lim_{x \to 0} f(x) = A$ | $x_n = \frac{1}{n}$ | $\lim_{n \to \infty} f\left(\frac{1}{n}\right) = A$ |
| $\lim_{x \to +\infty} f(x) = A$ | $x_n = n$ | $\lim_{n \to \infty} f(n) = A$ |
| $\lim_{x \to a} f(x) = A$ | $x_n \to a, x_n \neq a$ | $\lim_{n \to \infty} f(x_n) = A$ |

## 💡 核心价值

> [!important] 为什么要用海涅定理？
>
> **问题**：数列极限计算困难时，缺乏工具（不能求导、不能用洛必达）
>
> **解决**：通过海涅定理转化为函数极限，便可使用：
> - ✅ **洛必达法则**
> - ✅ **泰勒公式**
> - ✅ **等价无穷小代换**
> - ✅ 其他函数极限工具
