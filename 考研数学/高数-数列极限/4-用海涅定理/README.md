# 用海涅定理

> [!info] 概述
> 海涅定理（归结原则）是连接数列极限与函数极限的**桥梁**，它允许我们将数列极限转化为函数极限来处理，从而使用洛必达法则、泰勒公式等工具。

## 🔗 桥梁作用

海涅定理是数列极限与函数极限之间的**重要桥梁**：

```
数列极限 ←→ 海涅定理 ←→ 函数极限
   ↓                        ↓
离散问题               可用洛必达、泰勒等工具
```

## 学习目标

1. **理解定理含义**：数列极限与函数极限的关系
2. **掌握转化方法**：将 $\lim_{n \to \infty} f(n)$ 转化为 $\lim_{x \to +\infty} f(x)$
3. **熟练应用**：使用洛必达法则、泰勒公式求数列极限
