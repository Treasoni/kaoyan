# 用单调有界准则

## 定理（单调有界准则）

单调有界数列必有极限。

### 详细表述

- **单调递增 + 有上界** $\Rightarrow$ 收敛
- **单调递减 + 有下界** $\Rightarrow$ 收敛

## 适用场景

> [!tip] 典型特征
> 递推数列：$x_{n+1} = f(x_n)$ 型

## 解题步骤

### 第一步：证明有界性

用数学归纳法证明数列有界。

### 第二步：证明单调性

- 方法一：作差 $x_{n+1} - x_n$，判断符号
- 方法二：作商 $\frac{x_{n+1}}{x_n}$，与 1 比较
- 方法三：利用函数 $f(x)$ 的单调性

### 第三步：求极限

设 $\lim_{n \to \infty} x_n = a$，在递推式两边取极限：
$$a = f(a)$$

解方程得 $a$。

## 常见递推类型

1. **线性递推**：$x_{n+1} = ax_n + b$
2. **分式递推**：$x_{n+1} = \frac{a}{x_n + b}$
3. **根式递推**：$x_{n+1} = \sqrt{a + x_n}$
4. **乘积递推**：$x_{n+1} = x_n \cdot f(x_n)$

## 典型例题

设 $x_1 = \sqrt{2}$，$x_{n+1} = \sqrt{2 + x_n}$，求 $\lim_{n \to \infty} x_n$。

## 注意事项

⚠️ 求出方程的根后，需要根据单调性和有界性确定是哪个根！

## 完整典型例题

> [!example] 例1：根式递推（经典题型）
> **题目**：设 $x_1 = \sqrt{2}$，$x_{n+1} = \sqrt{2 + x_n}$，求 $\lim_{n \to \infty} x_n$。
>
> **解答**：
>
> **第一步：证明有界性**
>
> 用数学归纳法证明 $0 < x_n < 2$。
> - 当 $n=1$ 时，$x_1 = \sqrt{2} \in (0, 2)$ ✓
> - 假设 $x_k \in (0, 2)$，则 $x_{k+1} = \sqrt{2 + x_k} \in (\sqrt{2}, \sqrt{4}) = (\sqrt{2}, 2) \subset (0, 2)$ ✓
>
> 因此 $0 < x_n < 2$，有界。
>
> **第二步：证明单调性**
>
> $$x_{n+1} - x_n = \sqrt{2 + x_n} - x_n$$
>
> 设 $f(x) = \sqrt{2+x} - x$，$f'(x) = \frac{1}{2\sqrt{2+x}} - 1$
>
> 当 $x \in (0, 2)$ 时，$f'(x) < 0$，$f(x)$ 单调递减。
>
> $f(0) = \sqrt{2} > 0$，$f(2) = \sqrt{4} - 2 = 0$
>
> 所以当 $x \in (0, 2)$ 时，$f(x) > 0$，即 $x_{n+1} > x_n$。
>
> 数列单调递增且有上界，由单调有界准则，极限存在。
>
> **第三步：求极限**
>
> 设 $\lim_{n \to \infty} x_n = a$，在递推式两边取极限：
> $$a = \sqrt{2 + a}$$
> $$a^2 = 2 + a$$
> $$a^2 - a - 2 = 0$$
> $$(a - 2)(a + 1) = 0$$
>
> 解得 $a = 2$ 或 $a = -1$。
>
> 由于 $x_n > 0$，所以 $a \geq 0$，因此 $a = 2$。

> [!example] 例2：分式递推
> **题目**：设 $x_1 = 1$，$x_{n+1} = \frac{1}{1 + x_n}$，求 $\lim_{n \to \infty} x_n$。
>
> **解答**：
>
> **有界性**：$0 < x_n < 1$（数学归纳法）
>
> **单调性**：计算 $x_{n+2} = \frac{1}{1 + x_{n+1}} = \frac{1}{1 + \frac{1}{1+x_n}} = \frac{1+x_n}{2+x_n}$
>
> $$x_{n+2} - x_n = \frac{1+x_n}{2+x_n} - x_n = \frac{1+x_n - x_n(2+x_n)}{2+x_n} = \frac{1 - x_n^2}{2+x_n}$$
>
> 当 $x_n \in (0, 1)$ 时，$x_{n+2} > x_n$（偶数项子列单调递增）
>
> 类似地，奇数项子列单调递减。两个子列都收敛到同一极限。
>
> **求极限**：$a = \frac{1}{1+a}$，$a^2 + a - 1 = 0$，$a = \frac{\sqrt{5}-1}{2}$（黄金分割比）

## 易错点分析

> [!warning] 易错点1：忘记确定根的选择
> 解方程得到多个根后，必须根据有界性和单调性确定正确的根。
>
> 如例1中，$a = 2$ 或 $a = -1$，由于 $x_n > 0$，只能取 $a = 2$。

> [!warning] 易错点2：单调性判断错误
> 有些数列整体不单调，但奇偶子列分别单调。
>
> 如例2中，整体不单调，但奇数项子列和偶数项子列分别单调。

> [!warning] 易错点3：有界性证明不完整
> 用数学归纳法时，必须验证初始条件和递推步骤。
