# 压缩映射原理

## 核心定理

> [!thm] 压缩映射原理（简化版）
> 对数列 $\{x_n\}$，若存在常数 $k$（$0 < k < 1$），使得
> $$|x_{n+1} - a| \leqslant k|x_n - a|, \quad n = 1, 2, \dots$$
> 则 $\{x_n\}$ 收敛于 $a$，即 $\lim_{n \to \infty} x_n = a$。

## 为什么需要压缩映射？

> [!important] 使用场景
> 当 $x_{n+1} = f(x_n)$ 且 $f'(x) < 0$ 时：
> - 数列 $\{x_n\}$ **不单调**（摆动）
> - **不能**使用单调有界准则
> - **需要**使用压缩映射原理

## 几何理解

```
    x₃
    ↑     ╱╲

    a (极限)

当 f'(x) < 0 时，数列在 a 两侧来回摆动，
但每次都更接近 a（压缩）
```

## 使用步骤

### 第一步：验证条件

确认 $f'(x) < 0$，数列不单调。

### 第二步：找到压缩因子

利用拉格朗日中值定理：
$$
|f(x_n) - f(a)| = |f'(\xi)| \cdot |x_n - a|
$$

其中 $\xi$ 介于 $x_n$ 与 $a$ 之间。

找 $k = \max_{x \in I}|f'(x)|$，使 $|f'(\xi)| \leqslant k < 1$。

### 第三步：建立递推不等式

$$
|x_{n+1} - a| = |f(x_n) - f(a)| \leqslant k|x_n - a|
$$

### 第四步：递推并使用夹逼准则

$$
|x_{n+1} - a| \leqslant k^n|x_1 - a|
$$

当 $n \to \infty$ 时，$k^n \to 0$，由夹逼准则得 $|x_{n+1} - a| \to 0$。

## 典型例题

> [!example] 例：$x_{n+1} = \cos x_n$
>
> **分析**：$f(x) = \cos x$，$f'(x) = -\sin x < 0$（$x \in (0, \frac{\pi}{3})$）
>
> **解**：
> $$
> \begin{aligned}
> |x_{n+1} - a| &= |\cos x_n - \cos a| \\
> &= |-\sin\xi| \cdot |x_n - a| \quad \text{（拉格朗日中值定理）} \\
> &\leqslant \frac{\sqrt{3}}{2} \cdot |x_n - a|
> \end{aligned}
> $$
>
> 其中 $\xi \in \left(0, \frac{\pi}{3}\right)$，$\sin\xi \leqslant \sin\frac{\pi}{3} = \frac{\sqrt{3}}{2} < 1$
>
> 递推得 $|x_{n+1} - a| \leqslant \left(\frac{\sqrt{3}}{2}\right)^n|x_1 - a| \to 0$
>
> 故 $\lim_{n \to \infty} x_n = a$。

## 常用压缩因子表

| 函数 $f(x)$ | 区间 $I$ | $f'(x)$ | 压缩因子 $k$ |
|------------|---------|---------|-------------|
| $\cos x$ | $\left(0, \frac{\pi}{3}\right)$ | $-\sin x$ | $\frac{\sqrt{3}}{2} \approx 0.866$ |
| $\sin x$ | $\left(0, \frac{\pi}{3}\right)$ | $\cos x$ | $\frac{\sqrt{3}}{2} \approx 0.866$ |
| $\frac{a}{1 + x}$ | $(0, +\infty)$ | $-\frac{a}{(1+x)^2}$ | 视具体区间 |
| $e^{-x}$ | $(0, +\infty)$ | $-e^{-x}$ | $\max e^{-x} < 1$ |

## 与单调有界准则的对比

> [!note] 两种方法的适用场景

| 方法 | 适用条件 | 数列单调性 |
|------|---------|-----------|
| 单调有界准则 | $f'(x) > 0$ | 单调 |
| 压缩映射原理 | $f'(x) < 0$ | 不单调（摆动） |

```

         │
         ▼

         │
    ┌────┴────┐
    │         │
f'(x) > 0   f'(x) < 0
    │         │
    ▼         ▼
数列单调   数列摆动
    │         │
    ▼         ▼
单调有界   压缩映射
  准则       原理
```

## 关键技巧

> [!tip] 核心技巧
> 1. **判断条件**：$f'(x) < 0$ → 用压缩映射
> 2. **拉格朗日中值定理**：连接 $|f(x_n) - f(a)|$ 与 $|x_n - a|$
> 3. **找最大值**：$k = \max_{x \in I}|f'(x)|$ 且 $k < 1$
> 4. **夹逼收尾**：$k^n \to 0$ 推出结论

## 易错点 ⚠️

- [ ] $f'(x) < 0$ 时仍用单调有界准则
- [ ] 压缩因子 $k$ 未验证 $k < 1$
- [ ] 拉格朗日中值定理应用方向错误
- [ ] 忘记说明 $\xi$ 的范围
