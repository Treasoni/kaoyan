# 数列的概念

> [!info] 概述
> 数列是高等数学的基础概念，是学习数列极限的前提。数列的本质是"整标函数"，理解这一本质有助于后续学习。

## 学习目标

1. 理解数列的定义和几何意义
2. 掌握子列的概念及其性质
3. 熟悉常见数列类型及其性质
4. 记住常用不等式，为放缩做准备

## 学习建议

> [!tip] 学习提示
> - 数列概念是基础，不需要花太多时间
> - 重点记住常用不等式，这对后续夹逼准则至关重要
> - 子列的概念在证明数列发散时很有用
