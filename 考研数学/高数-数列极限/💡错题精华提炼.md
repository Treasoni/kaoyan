### 模板 1：夹逼准则精细放缩（错题01、17、18）
```
1. 观察分子是否规律变化
   ├─ 有规律 → 保留分子求和，只放缩分母
   └─ 无规律 → 可用 n·u_min 和 n·u_max
2. 放缩后检查左右极限是否相等
   └─ 不等 → 放缩太粗，需精细化
```
回链：[[错题本#错题01夹逼准则放缩精度问题\|错题01]]、[[错题本#错题17n项和极限夹逼准则失效与定积分定义法做错一次4月10\|错题17]]、[[错题本#错题18n项和极限提取无关项与夹逼放缩对象选择做错一次4月12\|错题18]]

### 模板 2：数学归纳法四步走（错题02、10）
```
1. 奠基：验证起始项
2. 归纳假设：假设 n=k 成立
3. 归纳递推：证明 n=k+1 也成立
4. 总结：宣布对所有 n 成立
```
回链：[[错题本#错题02递推数列有界性证明归纳法缺失\|错题02]]、[[错题本#错题10递归数列极限证明单调有界定理大题模板\|错题10]]

### 模板 3：目标驱动型证明（错题03）
```
1. 看目标：我要证明什么？
2. 看已知：我手里有什么？
3. 找连接：如何建立两者联系？
4. 结论：问题解决了吗？
```

### 模板 4：取子数列法判定无界/无穷大（错题04、06）
```
Step 1：找趋于 ∞ 的子列 → 证无界
Step 2：找趋于有限值/振荡的子列 → 证非无穷大
```

### 模板 5：最值判定标准流程（错题05）
```
1. 求极限 A
2. 写出前几项，找是否有 a_n > A 或 a_n < A
3. 利用保号性：
   ├─ 存在 a_n > A → 必有最大值
   └─ 存在 a_n < A → 必有最小值
```
回链：[[错题本#错题05数列有界性≠最值存在性\|错题05]]

### 模板 6：隐式递推数列极限通法（错题08）
```
1. 定性分析：用夹逼准则确定极限值（通常是 0）
2. 转化战场：找到等价无穷小桥梁（如 b² ~ 2(1-cos b)）
3. 变量归一化：通过已知等式统一变量
4. 阶数判定：低阶项起决定作用
```
回链：[[错题本#错题08隐式递推数列极限变量归一化与阶数判定\|错题08]]

### 模板 7：递归数列单调性判定（错题09）
```
1. 看 f(x) 是增还是减
2. f 增 → 数列单调（方向看 x₁ 与 x₂）
3. f 减 → 数列必摆动，排除所有"单调"选项
```
回链：[[错题本#错题09递归数列单调性判定函数单调性≠数列单调性\|错题09]]

### 模板 8：递归数列极限证明三部曲（错题10、19、21）
```
Step 1：分析迭代函数（求导、找不动点）
Step 2：归纳法证单调有界 / 压缩映像法证收敛
```
