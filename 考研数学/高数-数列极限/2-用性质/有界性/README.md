# 有界性

## 定理

若数列 $\{x_n\}$ 收敛，则 $\{x_n\}$ 有界。

## 数学表述

若 $\lim_{n \to \infty} x_n = a$，则 $\exists M > 0$，使得 $|x_n| \leq M$ 对所有 $n$ 成立。

## 重要说明

> [!warning] 注意
> - **收敛 → 有界**：成立（必要条件）
> - **有界 → 收敛**：不成立！如 $x_n = (-1)^n$

## 应用

- 判定发散：无界数列必发散
- 与单调有界准则配合使用

## 反例

- $x_n = (-1)^n$：有界但不收敛
- $x_n = n$：无界，发散
