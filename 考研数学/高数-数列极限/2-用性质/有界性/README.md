# 有界性

## 定理

若数列 $\{x_n\}$ 收敛，则 $\{x_n\}$ 有界。

## 数学表述

若 $\lim_{n \to \infty} x_n = a$，则 $\exists M > 0$，使得 $|x_n| \leq M$ 对所有 $n$ 成立。

## 重要说明

> [!warning] 注意
> - **收敛 → 有界**：成立（必要条件）
> - **有界 → 收敛**：不成立！如 $x_n = (-1)^n$

## 应用

- 判定发散：无界数列必发散
- 与单调有界准则配合使用

## 反例

- $x_n = (-1)^n$：有界但不收敛
- $x_n = n$：无界，发散

## 典型例题

> [!example] 例1：判定数列发散
> **题目**：判断数列 $x_n = n\sin n$ 的收敛性。
>
> **分析**：证明无界即可判定发散。
>
> **解答**：
> 取 $n = 2k\pi + \frac{\pi}{2}$ 的整数部分，则 $\sin n$ 接近 $1$。
>
> 由于 $n$ 可以无限增大，而 $|\sin n| \leq 1$，所以 $|x_n| = |n \sin n|$ 可以无限增大。
>
> 因此 $\{x_n\}$ 无界，必发散。

> [!example] 例2：有界但发散
> **题目**：举例说明"有界 $\not\Rightarrow$ 收敛"。
>
> **解答**：
> $x_n = (-1)^n$：
> - 有界：$|x_n| = 1 \leq 1$
> - 不收敛：奇数项为 $-1$，偶数项为 $1$，极限不存在

## 与单调有界准则的联系

> [!important] 重要联系
> 单调有界准则：**单调 + 有界 $\Rightarrow$ 收敛**
>
> 对比：
> - 单独"有界" $\not\Rightarrow$ 收敛
> - 单独"单调" $\not\Rightarrow$ 收敛（如 $x_n = n$ 单调递增但发散）
> - "单调 + 有界" $\Rightarrow$ 收敛
