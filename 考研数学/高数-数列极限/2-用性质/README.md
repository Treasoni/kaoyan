# 用性质求数列极限

数列极限的三大重要性质。

## 子目录说明

- **唯一性**：数列极限若存在则唯一
- **有界性**：收敛数列必有界
- **保号性**：极限符号与数列项符号的关系
  > ⚠️ 注意与函数极限的区别与联系

## 三大性质对比

| 性质 | 内容 | 作用 | 常见应用 |
|------|------|------|----------|
| **唯一性** | 收敛数列极限唯一 | 理论基础 | 证明发散（找两个不同极限的子列） |
| **有界性** | 收敛数列必有界 | 必要条件 | 判定发散（无界必发散） |
| **保号性** | 极限符号决定数列项符号 | 不等式推导 | 证明不等式、判定符号 |

### 关系图

```
收敛数列
    ├── 唯一性（极限唯一）
    ├── 有界性（必有界）→ 逆否：无界必发散
    └── 保号性（符号传递）
            ├── 原命题：a > 0 ⇒ xn > 0（某项之后）
            └── 逆命题：xn ≥ 0 ⇒ a ≥ 0（注意不等号变化）
```

### 与函数极限的区别

| 对比项 | 数列极限 | 函数极限 |
|--------|----------|----------|
| 有界性 | **全局**有界 | **局部**有界 |
| 保号性 | 从某项起保号 | 在某去心邻域保号 |
| 定义域 | 离散 $n \in \mathbf{N}_{+}$ | 连续 $x \in \mathbf{R}$ |
