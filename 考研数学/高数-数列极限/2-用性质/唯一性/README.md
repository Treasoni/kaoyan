# 唯一性

## 定理

若数列 $\{x_n\}$ 收敛，则其极限唯一。

## 证明思路

使用反证法：假设存在两个不同的极限 $a$ 和 $b$，通过 $\varepsilon-N$ 定义导出矛盾。

## 应用

- 证明数列发散：找两个子列收敛于不同极限
- 验证极限计算结果的正确性

## 易错点

⚠️ 唯一性只对收敛数列成立，发散数列无极限可言。

## 典型例题

> [!example] 例1：用唯一性证明发散
> **题目**：证明数列 $x_n = \cos\frac{n\pi}{2}$ 发散。
>
> **分析**：找两个子列收敛于不同值。
>
> **解答**：
> - 取 $n = 4k$：$x_{4k} = \cos(2k\pi) = 1$，子列收敛于 $1$
> - 取 $n = 4k + 2$：$x_{4k+2} = \cos\pi = -1$，子列收敛于 $-1$
>
> 由唯一性，若原数列收敛，则所有子列应收敛于同一极限。
> 但两个子列极限不同（$1 \neq -1$），因此原数列**发散**。

> [!example] 例2：验证极限计算
> **题目**：设 $\lim_{n \to \infty} x_n = 2$，$\lim_{n \to \infty} y_n = 3$，判断 $\lim_{n \to \infty} (x_n + y_n)$ 是否存在。
>
> **解答**：
> 由四则运算，$\lim_{n \to \infty} (x_n + y_n) = 2 + 3 = 5$
>
> 由唯一性，这个极限值是唯一的，不存在歧义。
