## 核心解题框架

```
高阶线性微分方程
    │
    ├─ 常系数
    │   ├─ 齐次 (f(x) = 0)
    │   │   ├─ 写特征方程
    │   │   ├─ 求特征根
    │   │   └─ 写通解
    │   │
    │   └─ 非齐次 (f(x) ≠ 0)
    │       ├─ 先求齐次通解 ȳ
    │       ├─ 再求非齐次特解 y*
    │       │   ├─ 待定系数法
    │       │   └─ 微分算子法
    │       └─ 通解 y = ȳ + y*
    │
    └─ 变系数（欧拉方程）
        ├─ 令 x = eᵗ 作变量代换
        ├─ 化为常系数方程
        └─ 按常系数方法求解后回代
```
