# 📝 章节总结：高阶线性微分方程的求解

> 本总结覆盖二阶/高阶常系数线性微分方程（齐次+非齐次）及欧拉方程的全部核心内容，基于教材目录与笔记整理。

---

## 一、章节知识结构图

```
高阶线性微分方程
    │
    ├── 常系数齐次（f(x) = 0）
    │   ├── 二阶常系数齐次
    │   └── n阶常系数齐次
    │
    ├── 常系数非齐次（f(x) ≠ 0）
    │   ├── 通解 = 齐次通解 + 非齐次特解
    │   ├── 待定系数法（类型一 / 类型二）
    │   └── 微分算子法（4种情形）
    │
    └── 变系数：欧拉方程（仅数学一）
        └── x = eᵗ 代换 → 常系数
```

## 二、二阶常系数齐次线性微分方程

### 标准形式

$$
y'' + p\,y' + q\,y = 0 \quad (p, q \text{ 为常数})
$$

### 解的结构

若 $y_1(x), y_2(x)$ 是方程的两个**线性无关**解（$\dfrac{y_1}{y_2} \neq \text{常数}$），则通解为：

$$
\boxed{y = C_1 y_1(x) + C_2 y_2(x)}
$$

### 特征方程法求解流程

**Step 1** — 写出特征方程：$r^2 + p\,r + q = 0$（$y'' \to r^2,\; y' \to r,\; y \to 1$）

**Step 2** — 求特征根 $r_{1,2} = \dfrac{-p \pm \sqrt{p^2 - 4q}}{2}$

**Step 3** — 由判别式 $\Delta = p^2 - 4q$ 分三种情形写通解：

| 情形 | $\Delta$ | 特征根 | 通解 |
|:----:|:--------:|:------:|:----:|
| 不等实根 | $\Delta > 0$ | $r_1 \neq r_2$ | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| 重根 | $\Delta = 0$ | $r_1 = r_2 = r$ | $y = (C_1 + C_2 x)e^{rx}$ |
| 共轭复根 | $\Delta < 0$ | $\alpha \pm \beta\,i$ | $y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$ |

> [!tip] 记忆口诀
> - 不等实根：两个 $e^{rx}$ 直接相加
> - 重根：$e^{rx}$ 前乘 $(C_1 + C_2 x)$ 凑出第二个线性无关解
> - 复根：指数取实部 $\alpha$，三角用 $\cos$ + $\sin$ 组合，系数取虚部 $\beta$

### 解的性质分析

| 条件 | 结论 |
|:----:|:----:|
| 所有特征根实部 $< 0$ | $x \to +\infty$ 时 $y \to 0$，有界 |
| 存在特征根实部 $> 0$ | 通解无界 |
| 重根 $r = 0$ | 通解含 $C_1 + C_2 x$，无界 |
| 复根且 $\alpha = 0$ | $y = C_1 \cos\beta x + C_2 \sin\beta x$，有界 + 周期 |

## 三、n 阶常系数齐次线性微分方程

### 标准形式

$$
a_n y^{(n)} + a_{n-1} y^{(n-1)} + \dots + a_1 y' + a_0 y = 0
$$

### 特征根 → 解的形式对应表

| 特征根类型 | 对应解的形式 |
|:----------:|:------------:|
| **单实根** $r$ | $C e^{rx}$ |
| **$k$ 重实根** $r$ | $(C_1 + C_2 x + \dots + C_k x^{k-1}) e^{rx}$ |
| **单复根** $\alpha \pm \beta i$ | $e^{\alpha x} (C_1 \cos\beta x + C_2 \sin\beta x)$ |
| **二重复根** $\alpha \pm \beta i$ | $e^{\alpha x} [(C_1 + C_2 x) \cos\beta x + (C_3 + C_4 x) \sin\beta x]$ |

> [!success] 通解 = 所有特征根对应解之和

### 反求方程（重点题型）

已知解的形式 → 反推微分方程：

1. 从解中提取特征根
2. 写出特征方程 $(r - r_1)(r - r_2)\dots = 0$
3. 展开得到微分方程

## 四、二阶常系数非齐次线性微分方程

### 标准形式

$$
y'' + p\,y' + q\,y = f(x) \quad (f(x) \neq 0)
$$

### 核心公式

> [!important]
> $$
> \boxed{y = \bar{y} + y^*}
> $$
> $\bar{y}$ — 对应齐次方程通解 | $y^*$ — 非齐次方程的**一个**特解

### 重要性质

- **叠加原理**：若 $y_1^*$ 对应 $f_1(x)$，$y_2^*$ 对应 $f_2(x)$，则 $y_1^* + y_2^*$ 对应 $f_1(x) + f_2(x)$
- **差的性质**：若 $y_1^*, y_2^*$ 都是特解，则 $y_1^* - y_2^*$ 是**齐次方程的解**

### 整体求解流程

```
求 y'' + py' + qy = f(x) 的通解
  ├── Step 1：求齐次通解 ȳ（特征方程法）
  ├── Step 2：求非齐次特解 y*（待定系数法 / 微分算子法）
  └── Step 3：通解 y = ȳ + y*
```

---

## 五、求特解：待定系数法

> 口诀：**一看 $f(x)$ 形式，二算特征根，三比较确定 $k$**

### 类型一：$f(x) = P_n(x)\,e^{\alpha x}$

设：
$$
y^* = e^{\alpha x} \cdot Q_n(x) \cdot x^k
$$

其中 $Q_n(x)$ 是与 $P_n(x)$ **同次**的待定多项式。

$k$ 值的确定：

| $\alpha$ 与特征根的关系 | $k$ |
|:----------------------:|:---:|
| $\alpha$ **不是**特征根 | $k = 0$ |
| $\alpha$ 是**单**特征根 | $k = 1$ |
| $\alpha$ 是**二重**特征根 | $k = 2$ |

### 类型二：$f(x) = e^{\alpha x}[P_m(x)\cos\beta x + P_n(x)\sin\beta x]$

设：
$$
y^* = e^{\alpha x}[Q_l^{(1)}(x)\cos\beta x + Q_l^{(2)}(x)\sin\beta x] \cdot x^k
$$

其中 $l = \max\{m, n\}$，$Q_l^{(1)}, Q_l^{(2)}$ 是两个**不同**的 $l$ 次待定多项式。

$k$ 值的确定：

| $\alpha \pm \beta i$ 与特征根的关系 | $k$ |
|:--------------------------------:|:---:|
| **不是**特征根 | $k = 0$ |
| **是**特征根 | $k = 1$ |

> [!warning] 类型二易错点
> 1. 即使 $f(x)$ 只有 $\cos$ 没有 $\sin$，特解中 $\cos$ 和 $\sin$ **必须同时出现**
> 2. $Q_l^{(1)}$ 和 $Q_l^{(2)}$ 是两个**独立**的多项式，系数各不相同
> 3. $l = \max\{m, n\}$，取 $\cos$ 和 $\sin$ 前多项式次数的**较大值**

### 类型一 vs 类型二 对比

| | 类型一 | 类型二 |
|:--:|:------:|:------:|
| $f(x)$ 形式 | $P_n(x) e^{\alpha x}$ | $e^{\alpha x}[P_m\cos\beta x + P_n\sin\beta x]$ |
| 待定多项式 | 一个 $Q_n(x)$ | 两个 $Q_l^{(1)}, Q_l^{(2)}$，$l = \max\{m,n\}$ |
| $k$ 判据 | $\alpha$ 是否为特征根 | $\alpha \pm \beta i$ 是否为特征根 |
| $k$ 可能值 | $0, 1, 2$ | $0, 1$ |

## 六、求特解：微分算子法

### 基本约定

$$
\mathrm{D} = \frac{\mathrm{d}}{\mathrm{d}x}, \quad F(\mathrm{D}) = \mathrm{D}^2 + p\,\mathrm{D} + q, \quad y^* = \frac{1}{F(\mathrm{D})}\,f(x)
$$

### 四种情形速查

#### ① $\dfrac{1}{F(\mathrm{D})}\,e^{\alpha x}$ 型

将 $\mathrm{D}$ 替换为 $\alpha$：
- $F(\alpha) \neq 0$：$y^* = \dfrac{1}{F(\alpha)} e^{\alpha x}$（$k=0$）
- $F(\alpha) = 0, F'(\alpha) \neq 0$：$y^* = x \cdot \dfrac{1}{F'(\alpha)} e^{\alpha x}$（$k=1$）
- $F(\alpha) = 0, F'(\alpha) = 0$：$y^* = x^2 \cdot \dfrac{1}{F''(\alpha)} e^{\alpha x}$（$k=2$）

#### ② $\dfrac{1}{F(\mathrm{D})}\,\cos\beta x$ 或 $\sin\beta x$ 型

将 $\mathrm{D}^2$ 替换为 $-\beta^2$；若分母仍有 $\mathrm{D}$，则**分子分母同乘共轭**消去 $\mathrm{D}$。

#### ③ $\dfrac{1}{F(\mathrm{D})}\,$多项式型

将 $\dfrac{1}{F(\mathrm{D})}$ 展开为 $\mathrm{D}$ 的泰勒多项式（截断到多项式次数），逐项施以 $\mathrm{D}$ 运算。

#### ④ $\dfrac{1}{F(\mathrm{D})}\,e^{\alpha x}\,\nu(x)$ 型（移位定理）

$$
\boxed{\frac{1}{F(\mathrm{D})}\,e^{\alpha x}\,\nu(x) = e^{\alpha x} \cdot \frac{1}{F(\mathrm{D}+\alpha)}\,\nu(x)}
$$

### 方法选择建议

| 方法 | 适用场景 | 优点 | 缺点 |
|:--:|:--------:|:----:|:----:|
| 待定系数法 | 所有 $f(x)$ 类型 | 形式固定，不易出错 | 计算量大 |
| 微分算子法 | $f(x)$ 含指数或三角函数 | 计算量小，速度快 | 需记多种规则 |

> [!tip] 学习建议
> 基础阶段以**待定系数法**为主理解原理；强化/冲刺阶段掌握**微分算子法**提速。

## 七、欧拉方程（仅数学一）

### 标准形式

$$
x^2 y'' + p\,x\,y' + q\,y = f(x) \quad (p, q \text{ 为常数})
$$

### 核心解法：变量代换法

令 $x = e^t$（$t = \ln x$），代入后化为常系数方程：

$$
\boxed{\frac{\mathrm{d}^2 y}{\mathrm{d}t^2} + (p-1)\frac{\mathrm{d}y}{\mathrm{d}t} + q\,y = f(e^t)}
$$

### 解题流程

```
欧拉方程 x²y'' + pxy' + qy = f(x)
  ├── x > 0：令 x = eᵗ
  │     ↓
  │   化为常系数 → 求解 → 回代 t = ln x
  └── x < 0：令 x = -eᵗ，同理，回代 t = ln(-x)
```

> [!warning] 常见错误
> 1. 忘记 $y''$ 转换时多出的 $-\dfrac{1}{x^2}\dfrac{\mathrm{d}y}{\mathrm{d}t}$ 项
> 2. 求解后忘记用 $t = \ln x$ 回代
> 3. $x < 0$ 未作处理（题目通常默认 $x > 0$）

## 八、核心公式速查卡

| 内容 | 公式 |
|:----:|:----:|
| 二阶齐次特征方程 | $r^2 + p r + q = 0$ |
| 特征根公式 | $r_{1,2} = \dfrac{-p \pm \sqrt{p^2 - 4q}}{2}$ |
| 不等实根通解 | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| 重根通解 | $y = (C_1 + C_2 x) e^{rx}$ |
| 复根通解 | $y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$ |
| 非齐次通解结构 | $y = \bar{y} + y^*$ |
| 非齐次类型一设解 | $y^* = e^{\alpha x} Q_n(x) x^k$ |
| 非齐次类型二设解 | $y^* = e^{\alpha x}[Q_l^{(1)}\cos\beta x + Q_l^{(2)}\sin\beta x] x^k$ |
| 欧拉方程代换 | $x = e^t$，化为 $y''_{tt} + (p-1) y'_t + qy = f(e^t)$ |
| 移位定理 | $\dfrac{1}{F(\mathrm{D})} e^{\alpha x}\nu(x) = e^{\alpha x} \dfrac{1}{F(\mathrm{D}+\alpha)}\nu(x)$ |

## 九、易错点总结

1. **线性无关判定**：$C_1, C_2$ 是两个独立任意常数，若 $y_1, y_2$ 线性相关则不是通解
2. **复根通解中的 $\beta$**：$\beta$ 是虚部系数（$\beta > 0$），不是特征根本身
3. **类型二特设**：即使 $f(x)$ 只含 $\cos$ 或只含 $\sin$，特解中两者必须同时出现
4. **$l = \max\{m, n\}$**：类型二中多项式次数取 $\cos$ 和 $\sin$ 系数的较大值
5. **$k$ 的确定**：类型二 $k$ 只有 $0$ 或 $1$（$\alpha \pm \beta i$ 是否为特征根），类型一 $k$ 可达 $2$
6. **欧拉方程**：$y''$ 转换时会产生 $-\frac{1}{x^2} y'_t$ 项，不可遗漏；求解后务必回代 $t = \ln x$
