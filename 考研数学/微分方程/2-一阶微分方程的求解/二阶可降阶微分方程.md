# 二阶可降阶微分方程

> 适用范围：数学一、数学二

## 类型一：$y'' = f(x, y')$（不显含 $y$）

令 $y' = p$，$y'' = p' = \frac{\mathrm{d}p}{\mathrm{d}x}$

原方程变为一阶方程：$\frac{\mathrm{d}p}{\mathrm{d}x} = f(x, p)$

若求得 $p = \varphi(x, C_1)$，即 $y' = \varphi(x, C_1)$，再积分得 $y = \int \varphi(x, C_1)\,\mathrm{d}x + C_2$。

## 类型二：$y'' = f(y, y')$（不显含 $x$）

令 $y' = p$，$y'' = \frac{\mathrm{d}p}{\mathrm{d}x} = \frac{\mathrm{d}p}{\mathrm{d}y} \cdot \frac{\mathrm{d}y}{\mathrm{d}x} = p\frac{\mathrm{d}p}{\mathrm{d}y}$

> [!warning] 关键
> 此处 $y''$ **不能**写成 $p'$，因为 $p' = \frac{\mathrm{d}p}{\mathrm{d}x}$ 会引入 $x$，增加复杂性。必须写成 $p\frac{\mathrm{d}p}{\mathrm{d}y}$。

原方程变为：$p\frac{\mathrm{d}p}{\mathrm{d}y} = f(y, p)$

若求得 $p = \varphi(y, C_1)$，由 $\frac{\mathrm{d}y}{\mathrm{d}x} = \varphi(y, C_1)$ 分离变量得 $\frac{\mathrm{d}y}{\varphi(y, C_1)} = \mathrm{d}x$，两边积分。

## 类型三：$y'' = f(y')$（不显含 $x$ 也不显含 $y$）

既不显含 $y$，又不显含 $x$，**按类型一处理**（即不显含 $y$ 来处理）。

令 $y' = p$，$y'' = p'$。
