## 解题流程

```
拿到一阶微分方程
    │
    ├─→ 能否分离变量？→ 直接可分离 / 换元后可分离
    │
    ├─→ 是否为 y'/x,y 的齐次形式？→ 令 u = y/x
    │
    ├─→ 是否为 y' + p(x)y = q(x)yⁿ？→ 伯努利方程，令 z = y^(1-n)
    │
    ├─→ 是否为 y' + p(x)y = q(x)？→ 一阶线性微分方程公式
    │
    └─→ 无法直接处理？→ 交换 x 与 y 的角色
```
