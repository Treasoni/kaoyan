# 常用数值近似值

> [!tip] 考研必备
> 这些数值在极限、极值、比较大小等题目中经常出现，建议熟记！

---

## 1. 基础常数

| 数值 | 近似值 | 备注 |
|------|--------|------|
| $\sqrt{2}$ | $1.414$ | $1.4^2 = 1.96$, $1.5^2 = 2.25$ |
| $\sqrt{3}$ | $1.732$ | $1.7^2 = 2.89$, $1.8^2 = 3.24$ |
| $\sqrt{5}$ | $2.236$ | $2.2^2 = 4.84$, $2.3^2 = 5.29$ |
| $\pi$ | $3.14159$ | 约等于 $3.14$ 或 $\frac{22}{7}$ |
| $e$ | $2.718$ | 自然对数的底，必背 |

## 2. π 的常用分数形式

| 数值 | 近似值 | 备注 |
|------|--------|------|
| $\frac{\pi}{6}$ | $0.523$ | 略大于 $0.5$，$\sin\frac{\pi}{6} = \frac{1}{2}$ |
| $\frac{\pi}{4}$ | $0.785$ | 约等于 $0.8$，$\tan\frac{\pi}{4} = 1$ |
| $\frac{\pi}{3}$ | $1.047$ | 略大于 $1$，$\sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}$ |
| $\frac{\pi}{2}$ | $1.571$ | 约等于 $1.6$ |
| $2\pi$ | $6.283$ | 一个完整周期 |

## 6. 应用示例

### 比较大小问题

> [!example] 例题
> 比较 $2$ 与 $\sqrt{3} + \frac{\pi}{6}$ 的大小。
>
> **解**：使用估算法
> - $\sqrt{3} \approx 1.732$
> - $\frac{\pi}{6} \approx 0.523$
> - $\sqrt{3} + \frac{\pi}{6} \approx 1.732 + 0.523 = 2.255$
>
> 因此 $\sqrt{3} + \frac{\pi}{6} > 2$
