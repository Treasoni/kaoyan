## 2. 单调性转换研究最值

当 $x > 0$ 时，$y = x$ 与 $y = \sqrt{x}$、$y = \sqrt[3]{x}$、$y = \ln x$ 具有相同的单调性，与 $y = \dfrac{1}{x}$ 具有相反的单调性。

| 见到 | 可用 | 说明 |
|------|------|------|
| $\sqrt{u},\sqrt[3]{u}$ | $u$ 研究最值 | 与原函数 $y = x$ 单调性相同 |
| $\vert u\vert$ | $u^2$ 研究最值（⭐最多） | $\vert u\vert = \sqrt{u^2}$，与 $u^2$ 有相同最值点 |
| $u_1u_2u_3$ | $\ln(u_1u_2u_3)$ 研究最值 | $\ln(u_1u_2u_3) = \ln u_1 + \ln u_2 + \ln u_3$ |
| $\dfrac{1}{u}$ | $u$ 研究最值 | 结论相反（最大/最小值点互换）|

## 3. 函数的四种特性速查

### 奇偶性

| 运算 | 奇+奇 | 偶+偶 | 奇$\pm$偶 | 奇$\times$奇 | 偶$\times$偶 | 奇$\times$偶 |
|------|-------|-------|-----------|-------------|-------------|-------------|
| 结果 | 奇 | 偶 | 非奇非偶 | 偶 | 偶 | 奇 |

- **复合**：内偶则偶，内奇同外
- **构造**：$f(x)+f(-x)$ 必偶，$f(x)-f(-x)$ 必奇
- **导数/积分**：$f$ 奇 $\Rightarrow f'$ 偶 $\Rightarrow f''$ 奇 $\Rightarrow\dots$（求导一次奇偶互换）；$f$ 奇 $\Rightarrow \displaystyle\int_0^x f(t)\mathrm{d}t$ 偶

### 周期性

- $f(ax+b)$ 周期 $= \dfrac{T}{|a|}$（原周期 $\div |a|$）
- 内层周期 $\Rightarrow$ 外层复合也周期

### 常用函数性质速查表

| 函数 | 奇偶性 | 单调性（主值区间） | 周期性 |
|------|--------|-------------------|--------|
| $y = x^2$ | 偶 | $x \geq 0$ 递增 | - |
| $y = x^3$ | 奇 | 严格递增 | - |
| $y = e^x$ | 无 | 严格递增 | - |
| $y = \ln x$ | 无 | 严格递增 | - |
| $y = \sin x$ | 奇 | - | $2\pi$ |
| $y = \cos x$ | 偶 | - | $2\pi$ |
| $y = \tan x$ | 奇 | 严格递增（每周期） | $\pi$ |
| $y = \arcsin x$ | 奇 | 严格递增 | - |
| $y = \arctan x$ | 奇 | 严格递增 | - |
| $y = \vert x\vert$ | 偶 | $x \geq 0$ 递增 | - |

## 4. 指数与对数运算

### 指数运算法则

- $a^{x_1} \cdot a^{x_2} = a^{x_1 + x_2}$
- $\dfrac{a^{x_1}}{a^{x_2}} = a^{x_1 - x_2}$
- $(a^x)^y = a^{xy}$

> **提取公因式技巧**：$e^{\tan x} - e^{\sin x} = e^{\sin x}(e^{\tan x - \sin x} - 1)$

### "1和0的统一美"——构造拉格朗日标准形

- $e^x - 1 = e^x - e^0$
- $\ln x = \ln x - \ln 1$
- $\ln(e+\frac{1}{x}) - 1 = \ln(e+\frac{1}{x}) - \ln e = \ln(1+\frac{1}{ex})$

### 对数运算法则

- $\log_a(xy) = \log_a x + \log_a y$
- $\log_a\left(\dfrac{x}{y}\right) = \log_a x - \log_a y$
- $\log_a x^n = n \log_a x$
- **换底公式**：$\log_a x = \dfrac{\log_b x}{\log_b a}$

### 对数指数化变形

- $x = e^{\ln x} \quad (x > 0)$
- $u^\nu = e^{\nu \ln u} \quad (u > 0)$
- $x^x = e^{x \ln x}$

## 5. 三角恒等变换公式

### 基本关系

$$
\tan x = \frac{\sin x}{\cos x}, \quad
\cot x = \frac{\cos x}{\sin x}
$$

$$
\sin^2 x + \cos^2 x = 1,\quad
1 + \tan^2 x = \sec^2 x,\quad
1 + \cot^2 x = \csc^2 x
$$

### 倍角公式

- $\sin 2x = 2\sin x \cos x$
- $\cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$
- $\tan 2x = \dfrac{2\tan x}{1 - \tan^2 x}$

### 降幂公式

$$
\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad
\cos^2 x = \frac{1 + \cos 2x}{2}
$$

### 三角函数特殊值

| $x$ | $0$ | $\dfrac{\pi}{6}$ | $\dfrac{\pi}{4}$ | $\dfrac{\pi}{3}$ | $\dfrac{\pi}{2}$ |
|-----|-----|-----------------|-----------------|-----------------|-----------------|
| $\sin x$ | $0$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{3}}{2}$ | $1$ |
| $\cos x$ | $1$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{1}{2}$ | $0$ |

### 辅助角公式

$$
a\sin x + b\cos x = \sqrt{a^2+b^2}\,\sin(x+\varphi),\quad \tan\varphi = \frac{b}{a}
$$

### 万能公式

$$
\sin 2x = \frac{2\tan x}{1 + \tan^2 x},\qquad
\cos 2x = \frac{1 - \tan^2 x}{1 + \tan^2 x}
$$

## 6. 重要三角极限与不等式

### 重要极限

| 极限 | 结果 |
|-----|------|
| $\displaystyle\lim_{x\to 0}\frac{\sin x}{x}$ | $1$ |
| $\displaystyle\lim_{x\to 0}\frac{\tan x}{x}$ | $1$ |
| $\displaystyle\lim_{x\to 0}\frac{1-\cos x}{x^2}$ | $\dfrac{1}{2}$ |
| $\displaystyle\lim_{x\to 0}\frac{\arcsin x}{x}$ | $1$ |
| $\displaystyle\lim_{x\to 0}\frac{\arctan x}{x}$ | $1$ |
| $\displaystyle\lim_{x\to +\infty}\arctan x$ | $\dfrac{\pi}{2}$ |
| $\displaystyle\lim_{x\to -\infty}\arctan x$ | $-\dfrac{\pi}{2}$ |

### 重要不等式

- 当 $0 < x < \dfrac{\pi}{2}$ 时：$\sin x < x < \tan x$
- $\vert \sin x \vert \leq \vert x \vert$，当且仅当 $x = 0$ 时取等

### 重要积分结论

- $\displaystyle\int_0^{\pi} \sin x \,dx = 2$（$\sin x$ 一拱面积为 $2$）

## 7. 反三角函数恒等式

### 基本恒等式

| 公式 | 条件 |
|------|------|
| $\sin(\arcsin x) = x$ | $x \in [-1, 1]$ |
| $\cos(\arccos x) = x$ | $x \in [-1, 1]$ |
| $\cos(\arcsin x) = \sqrt{1-x^2}$ | $x \in [-1, 1]$ |
| $\sin(\arccos x) = \sqrt{1-x^2}$ | $x \in [-1, 1]$ |
| $\sin(\arctan x) = \dfrac{x}{\sqrt{1+x^2}}$ | $x \in \mathbb{R}$ |
| $\cos(\arctan x) = \dfrac{1}{\sqrt{1+x^2}}$ | $x \in \mathbb{R}$ |
| $\tan(\arcsin x) = \dfrac{x}{\sqrt{1-x^2}}$ | $x \in (-1, 1)$ |

### 互补关系

$$
\arcsin x + \arccos x = \frac{\pi}{2},\quad x \in [-1, 1]
$$
$$
\arctan x + \operatorname{arccot} x = \frac{\pi}{2},\quad x \in \mathbb{R}
$$

### 反三角函数特殊值

| $x$ | $\arcsin x$ | $\arccos x$ | $\arctan x$ |
|-----|-------------|-------------|-------------|
| $0$ | $0$ | $\dfrac{\pi}{2}$ | $0$ |
| $\dfrac{1}{2}$ | $\dfrac{\pi}{6}$ | $\dfrac{\pi}{3}$ | — |
| $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\pi}{4}$ | $\dfrac{\pi}{4}$ | — |
| $\dfrac{\sqrt{3}}{2}$ | $\dfrac{\pi}{3}$ | $\dfrac{\pi}{6}$ | — |
| $1$ | $\dfrac{\pi}{2}$ | $0$ | $\dfrac{\pi}{4}$ |
| $\sqrt{3}$ | — | — | $\dfrac{\pi}{3}$ |
| $\dfrac{1}{\sqrt{3}}$ | — | — | $\dfrac{\pi}{6}$ |

### 反着用的值域限制（易错）

| 公式 | 成立条件 |
|------|---------|
| $\arcsin(\sin x) = x$ | $x \in [-\pi/2, \pi/2]$ |
| $\arccos(\cos x) = x$ | $x \in [0, \pi]$ |
| $\arctan(\tan x) = x$ | $x \in (-\pi/2, \pi/2)$ |


## 8. 取整函数 $y = [x]$

**定义**：不超过 $x$ 的最大整数，记作 $[x]$

**重要公式**：
- $[x + n] = [x] + n$（$n$ 为整数）
- $x - 1 < [x] \leq x$
- $\displaystyle\lim_{x \to 0^+}[x] = 0,\; \displaystyle\lim_{x \to 0^-}[x] = -1$

**小数部分函数**：$y = x - [x]$，是以 $1$ 为周期的周期函数
