# 函数极限与连续
## 1.三个重要函数：

| 函数                            | 图像特征     | 重要结论                     |
| ----------------------------- | -------- | ------------------------ |
| $y = \ln(x + \sqrt{x^2 + 1})$ | 奇函数，图(a) | 当 $x \to 0$ 时 $\sim x$   |
| $y = \frac{e^x - e^{-x}}{2}$  | 奇函数，图(b) | 双曲正弦 $\text{sh}\,x$      |
| $y = \frac{e^x + e^{-x}}{2}$  | 偶函数，图(c) | 双曲余弦 $\text{ch}\,x$（悬链线） |
