## 2.
 当 $x > 0$ 时，$y = x$ 与 $y = \sqrt{x}$、$y = \sqrt[3]{x}$、$y = \ln x$ 具有相同的单调性，与 $y = \frac{1}{x}$ 具有相反的单调性。
>
> | 见到 | 可用 | 说明 |
> |------|------|------|
> | $\sqrt{u}, \sqrt[3]{u}$ | $u$ 来研究最值 | 与原函数$y = x$单调性相同 |
> | $\|u\|$ | $u^2$ 来研究最值（⭐考得最多） | $\|u\| = \sqrt{u^2}$，与 $u^2$ 有相同的最值点 |
> | $u_1 u_2 u_3$ | $\ln(u_1u_2u_3)$ 来研究最值 | $\ln(u_1u_2u_3) = \ln u_1 + \ln u_2 + \ln u_3$） |
> | $\frac{1}{u}$ | $u$ 来研究最值 | 结论相反（最大/最小值点互换）（考得频率不高 )|

## 3. 函数的四种特性速查

### 奇偶性

| 运算 | 奇+奇 | 偶+偶 | 奇$\pm$偶 | 奇$\times$奇 | 偶$\times$偶 | 奇$\times$偶 |
|------|-------|-------|-----------|-------------|-------------|-------------|
| 结果 | 奇 | 偶 | 非奇非偶 | 偶 | 偶 | 奇 |

- **复合**：内偶则偶，内奇同外
- **构造**：$f(x)+f(-x)$ 必偶，$f(x)-f(-x)$ 必奇
- **导数/积分**：$f$ 奇 $\Rightarrow f'$ 偶 $\Rightarrow f''$ 奇 $\Rightarrow\dots$（求导一次奇偶互换）；$f$ 奇 $\Rightarrow \displaystyle\int_0^x f(t)\mathrm{d}t$ 偶

### 周期性

- $f(ax+b)$ 周期 $= \dfrac{T}{|a|}$（原周期 $\div |a|$）
- 内层周期 $\Rightarrow$ 外层复合也周期

### 常用函数性质速查表

| 函数 | 奇偶性 | 单调性（主值区间） | 周期性 |
|------|--------|-------------------|--------|
| $y = x^2$ | 偶 | $x \geq 0$ 递增 | - |
| $y = x^3$ | 奇 | 严格递增 | - |
| $y = e^x$ | 无 | 严格递增 | - |
| $y = \ln x$ | 无 | 严格递增 | - |
| $y = \sin x$ | 奇 | - | $2\pi$ |
| $y = \cos x$ | 偶 | - | $2\pi$ |
| $y = \tan x$ | 奇 | 严格递增（每周期） | $\pi$ |
| $y = \arcsin x$ | 奇 | 严格递增 | - |
| $y = \arctan x$ | 奇 | 严格递增 | - |
| $y = \vert x\vert$ | 偶 | $x \geq 0$ 递增 | - |
