# 数列单调性证明方法

## 1. 核心问题

**什么时候可以直接看出单调性？什么时候必须用数学归纳法？**

答案取决于：**数列的给定方式**。

---

## 2. 两类数列的判定方法

### 2.1 显式数列（通项公式型）→ 直接推导

**形式**： $x_n = f(n)$

**例子**： $x_n = \frac{1}{n}$

**方法**：
- 比较 $x_{n+1}$ 和 $x_n$ 的大小
- 即判断 $f(n+1) - f(n)$ 的符号
- 因为 $n$ 是独立自变量，可以直接做差或做比

**大白话**： $n$ 的变化是��立的，不需要借助前一项。

---

### 2.2 递归数列（迭代型）→ 数学归纳法

**形式**： $x_{n+1} = f(x_n)$

**例子**： $x_{n+1} = 2\ln(1+x_n)$

**问题**： $x_{n+1}$ 的大小取决于 $x_n$ 的大小

**方法**：数学归纳法

**大白话**：每一项都"继承"上一项的性质，需要证明这种继承关系能一直传���下去。

---

## 3. 为什么归纳法能看"全过程"？

### 3.1 一个常见的疑惑

> "$x_{n+1} < x_n$ 不是只说明这一项吗？为什么要用归纳法看全过程？"

### 3.2 关键区分：任意性 vs 连贯性

| 概念 | 含义 | 适用场景 |
|------|------|----------|
| **任意性** | 对任意正整数 $n$，不等式都成立 | 显式数列可以直接证明 |
| **连贯性** | 从第 1 项开始，性质逐项传递 | 递归数列需要归纳法 |

**核心困难**：在递归数列中，你无法"直接"证明对任意 $n$ 都成立。你只能证明：

$$\text{如果 } x_n > x_{n-1} \text{ 成立，那么 } x_{n+1} > x_n \text{ 也成立}$$

### 3.3 归纳法的本质：多米诺骨牌

归纳法 = 两步保证"全线坍塌"

1. **第一步（$n=1$）**：手动推倒第一块骨牌（证明 $x_2 < x_1$）
2. **第二步（归纳假设）**：证明"如果前一块倒了，后一块也一定会倒"

**二者结合**，才保证整条数列单调。

> [!warning] 考研大题注意事项
> 如果你不写归纳法，只写一句 $x_{n+1} < x_n$，阅卷老师会认为你只观察到局部，逻辑不严谨。在考研大题中，递归数列的单调性证明，**数学归纳法是必须展示的逻辑过程**。

---

## 4. 递归数列单调性判定流程

### Step 1：看 $f(x)$ 的单调性

设 $x_{n+1} = f(x_n)$，先判断 $f(x)$ 的单调性：

| $f(x)$ 的单调性 | 数列单调性 | 判定方法 |
|----------------|-----------|---------|
| **单调增** | 数列单调性由 $x_1, x_2$ 的大小决定 | 用归纳法证明 |
| **单调减** | 数列通常**摆动收敛**（不单调） | 另辟蹊径 |

### Step 2：归纳法模板（当 $f(x)$ 单调增时）

**第一步（奠基）**：计算 $x_1$ 和 $x_2$，比较大小
- 例如：$x_1 = a$，$x_2 = f(a)$，验证 $x_2 < x_1$

**第二步（归纳假设）**：
- 假设 $x_{k+1} < x_k$ 成立
- 利用 $f(x)$ 单调增 $\Rightarrow f(x_{k+1}) < f(x_k)$
- 即 $x_{k+2} < x_{k+1}$

**结论**：由数学归纳法，对任意 $n$，$x_{n+1} < x_n$

---

## 5. 对比总结表

| 判定维度 | 显式数列 $x_n = f(n)$ | 递归数列 $x_{n+1} = f(x_n)$ |
|---------|---------------------|---------------------------|
| **自变量** | $n$ 独立变化 | $x_n$ 依赖上一项 |
| **比较方法** | 直接比较 $f(n+1)$ 与 $f(n)$ | 需要知道 $x_n$ 才能算 $x_{n+1}$ |
| **证明工具** | 导数、定义直接比 | 数学归纳法 |
| **逻辑特点** | 一步到位 | 链条传递 |
| **考试要求** | 直接写结论即可 | 必须展示归纳过程 |

---

## 6. 记忆口诀

> [!tip] 一句话总结
> **通项看导数，递归用归纳；单调增的函数，单调性靠首项定。**
