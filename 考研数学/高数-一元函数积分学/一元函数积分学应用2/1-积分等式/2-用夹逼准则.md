# 用夹逼准则证明积分等式

> 适用场景：求含参积分的极限、证明特殊积分等式

## 核心思路

对于 $\lim_{n\to\infty}\int_a^b f_n(x) \, \mathrm{d}x$，通过放缩法建立不等式，再用夹逼准则求极限。

> [!important] 关键原则
> $\lim_{n\to\infty}\int_a^b \neq \int_a^b \lim_{n\to\infty}$，不能直接交换极限与积分！

## 重要结论

> [!theorem] 一般结论
> 设 $f(x)$ 在 $[0,1]$ 上连续，则 $\lim_{n\to\infty}\int_0^1 x^n f(x) \, \mathrm{d}x = 0$
>
> **证明**：由 $m \leq f(x) \leq M$，得 $\frac{m}{n+1} \leq \int_0^1 x^n f(x) \, \mathrm{d}x \leq \frac{M}{n+1}$，由夹逼准则得极限为 0。

## 常用放缩技巧

1. **基本放缩**：$0 \leq \frac{x^{n+1}}{1+x} \leq x^{n+1}$（$0 \leq x \leq 1$）
2. **指数放缩**：$e^{x^n} > x^n + 1 > 0$，即 $\frac{1}{e^{x^n}} < \frac{1}{x^n+1} < \frac{1}{x^n}$
3. **对数放缩**：$0 \leq \ln(1+t) \leq t$（$0 \leq t \leq 1$）

## 典型题型

### 类型一：凑微分法 + 夹逼准则

见例11.3：$\lim_{n\to\infty}\int_0^1 (n+1)x^n \ln(1+x) \, \mathrm{d}x$

**步骤**：
1. 凑微分：$\int_0^1 \ln(1+x) \, \mathrm{d}(x^{n+1})$
2. 分部积分得到 $\ln 2 - \int_0^1 \frac{x^{n+1}}{1+x} \, \mathrm{d}x$
3. 放缩：$0 \leq \int_0^1 \frac{x^{n+1}}{1+x} \, \mathrm{d}x \leq \frac{1}{n+2}$
4. 夹逼准则得极限为 $\ln 2$

### 类型二：积分比较 + 夹逼准则

见例11.4：$\lim_{n\to\infty}\int_0^1 |\ln t|[\ln(1+t)]^n \, \mathrm{d}t$

**步骤**：
1. 利用 $0 \leq \ln(1+t) \leq t$ 放缩被积函数
2. 计算上界积分（分部积分法）
3. 夹逼准则得极限为 0

### 类型三：周期函数的积分极限

见例11.5：$\lim_{x\to+\infty}\frac{1}{x}\int_0^x f(t) \, \mathrm{d}t$（$f(x)$ 为周期函数）

**关键**：利用周期函数积分性质，将积分区间分段表示，再用夹逼准则。

> [!warning] 注意
> 不能对含跳跃间断点的函数使用洛必达法则（无原函数），必须用夹逼准则。
