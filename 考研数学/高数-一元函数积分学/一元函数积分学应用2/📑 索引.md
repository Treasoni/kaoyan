# 一元函数积分学的应用（二）——积分等式与积分不等式

> 总目标：**证明积分等式与积分不等式**（第11讲内容，考研大题常客）

## 考试要求

| 项目 | 内容 |
|------|------|
| **考题** | 积分等式、积分不等式的证明方法 |
| **题型** | 解答题（压轴大题） |
| **重难点** | ①求积分；②积分后求极限 |

## 考点

| 考点类型 | 表达式 | 说明 |
|---------|--------|------|
| 定积分 | $\int_a^b f(x) \, \mathrm{d}x$ | 基本考点 |
| 含参积分的极限 | $\lim_{n\to\infty}\int_a^b f_n(x) \, \mathrm{d}x$ | $\lim_{n\to\infty}\int_a^b \neq \int_a^b\lim_{n\to\infty}$ |

## 知识结构

### 1-积分等式（重中之重）
- [[用中值定理]] — 推广的积分中值定理，$g(x)$ 不变号
- [[用夹逼准则]] — 求含参积分的极限，放缩法
- [[用积分法]] — 恒等变形、换元法、分部积分法

### 2-积分不等式（大题或难度大的��题）
- [[用函数的单调性]] — 积分上限变量化，构造辅助函数
- [[用拉格朗日中值定理]] — 条件为"一阶可导"，端点值简单
- [[用泰勒公式]] — 条件为"二阶可导"，简单函数值
- [[用积分法]] — 分部积分法，被积函数为两项相乘
- [[用牛顿-莱布尼茨公式]] — 联系 $f(x)$ 与 $f'(x)$

### 3-基础习题精练
- 习题11.1~11.6

## 方法选择指南

| 条件 | 推荐方法 |
|------|---------|
| $f(x)$ 连续 | 单调性 |
| $f(x)$ 一阶可导 + 端点值简单 | 拉格朗日中值定理 |
| $f(x)$ 二阶可导 + 函数值简单 | 泰勒公式 |
| 被积函数两项相乘 | 积分法（分部积分） |
| $f(x)$ 与 $f'(x)$ 需建立联系 | 牛顿-莱布尼茨公式 |
