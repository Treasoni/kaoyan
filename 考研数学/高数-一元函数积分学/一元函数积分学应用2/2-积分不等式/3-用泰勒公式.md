# 用泰勒公式证明积分不等式

> 适用条件：$f(x)$ 二阶可导，题中有简单函数值（甚至为 0）

## 核心思路

当无法用牛顿-莱布尼茨公式时，用泰勒公式将 $f(x)$ 展开成多项式，再对多项式做积分。

## 标准流程

1. 选取合适的展开点 $x_0$（通常取区间的中点或已知函数值的点）
2. 写出泰勒展开式
3. 两边在区间上积分
4. 利用积分性质放缩

## 典型题型

见例11.9：$f(1) = 0$，$M = \max|f''(x)|$，证明 $\left|\int_0^2 f(x) \, \mathrm{d}x\right| \leq \frac{1}{3}M$

**步骤**：
1. 选取 $x_0 = 1$（已知 $f(1) = 0$）展开：
$$f(x) = f(1) + f'(1)(x-1) + \frac{f''(\xi)}{2}(x-1)^2$$
2. 两边在 $[0,2]$ 上积分：
$$\int_0^2 f(x) \, \mathrm{d}x = f'(1)\underbrace{\int_0^2(x-1) \, \mathrm{d}x}_{=0} + \frac{1}{2}\int_0^2 f''(\xi)(x-1)^2 \, \mathrm{d}x$$
3. 取绝对值并放缩：
$$\left|\int_0^2 f(x) \, \mathrm{d}x\right| \leq \frac{M}{2}\int_0^2(x-1)^2 \, \mathrm{d}x = \frac{1}{3}M$$

> [!tip] 关键技巧
> - 选取展开点 $x_0$ 使 $f(x_0) = 0$，简化展开式
> - 利用 $\int_{x_0-R}^{x_0+R}(x-x_0) \, \mathrm{d}x = 0$ 消去一阶项
> - 剩下的高阶项用 $|f''(\xi)| \leq M$ 放缩

## 常用展开点选择

| 条件 | 展开点选择 |
|------|-----------|
| $f(c) = 0$ | $x_0 = c$ |
| $f'(c) = 0$ | $x_0 = c$（极值点） |
| 区间 $[a,b]$ 对称 | $x_0 = \frac{a+b}{2}$ |
