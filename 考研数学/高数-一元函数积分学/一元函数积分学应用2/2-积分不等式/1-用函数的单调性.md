# 用函数的单调性证明积分不等式

> 适用条件：$f(x)$ 在 $[a,b]$ 上连续（条件较弱）

## 核心思路

1. 将某一积分限（通常取上限）变量化
2. 移项构造辅助函数 $F(x)$
3. 证明 $F'(x) \leq 0$（或 $\geq 0$）
4. 由 $F(a) = 0$（或 $F(b) = 0$）得出结论

## 标准流程

```
积分不等式 → 上限变量化 → 移项构造 F(x) → 求 F'(x) → 判断符号 → 得证
```

## 典型题型

### 经典模式：含 $f(x)$ 和 $g(x)$ 的复合积分不等式

见例11.7：$f(x)$ 单调增加，$0 \leq g(x) \leq 1$，证明：
$$\int_a^{a+\int_a^b g(t) \, \mathrm{d}t} f(x) \, \mathrm{d}x \leq \int_a^b f(x)g(x) \, \mathrm{d}x$$

**步骤**：
1. 先证明预备结论：$0 \leq \int_a^x g(t) \, \mathrm{d}t \leq x - a$
2. 构造 $F(x) = \int_a^{a+\int_a^x g(u) \, \mathrm{d}u} f(t) \, \mathrm{d}t - \int_a^x f(t)g(t) \, \mathrm{d}t$
3. 求导得 $F'(x) = \{f[a+\int_a^x g(u) \, \mathrm{d}u] - f(x)\}g(x)$
4. 由 $f$ 单调增 + $g \geq 0$ 得 $F'(x) \leq 0$
5. 由 $F(a) = 0$ 得 $F(b) \leq 0$

> [!tip] 技巧
> 三个变量要区分开：积分上限的变量 $x$、内层积分的积分变量 $u$、外层积分的积分变量 $t$。

## 构造辅助函数的一般方法

对形如 $\int_a^b f(x) \, \mathrm{d}x \leq K$ 的不等式，构造：
$$F(x) = \int_a^x f(t) \, \mathrm{d}t - K \cdot \frac{x-a}{b-a}$$
然后证明 $F'(x) \leq 0$。
