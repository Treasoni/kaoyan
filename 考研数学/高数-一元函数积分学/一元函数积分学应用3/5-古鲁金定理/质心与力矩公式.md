# 质心计算公式与力矩计算公式

## 离散情形

### 两个质点（一维）

$x_1$ 处质量为 $m_1$，$x_2$ 处质量为 $m_2$，系统平衡时：

$$(\bar{x} - x_1)m_1 g = (x_2 - \bar{x})m_2 g$$

$$\bar{x} = \frac{x_1 m_1 + x_2 m_2}{m_1 + m_2}$$

### $n$ 个质点（二维）

$$\bar{x} = \frac{\sum_{i=1}^{n} x_i m_i}{\sum_{i=1}^{n} m_i}, \quad \bar{y} = \frac{\sum_{i=1}^{n} y_i m_i}{\sum_{i=1}^{n} m_i}$$

其中 $M_y = \sum_{i=1}^{n} x_i m_i$ 称为**力矩**，刻画系统绕 $y$ 轴旋转的趋势大小。

### 对任意直线的力矩

质量系统对直线 $L_0$：$ax + by + c = 0$ 的力矩为

$$M_{L_0} = \sum_{i=1}^{n} \frac{|ax_i + by_i + c|}{\sqrt{a^2 + b^2}}\,m_i$$

## 连续情形（曲线段）

### 力矩公式

曲线段 $L$：$y = f(x)$（$\rho$ 为线密度），对直线 $L_0$：$ax+by+c=0$ 的力矩

$$M_{L_0} = \int_a^b \frac{|ax+by+c|}{\sqrt{a^2+b^2}}\,\rho(x)\sqrt{1+[f'(x)]^2}\,\mathrm{d}x$$

### 形心到直线的距离

当 $\rho = $ 常数时：

$$r(\bar{x}, \bar{y}) = \frac{M_{L_0}}{M} = \frac{\displaystyle\int_a^b \frac{|ax+by+c|}{\sqrt{a^2+b^2}}\sqrt{1+[f'(x)]^2}\,\mathrm{d}x}{\displaystyle\int_a^b \sqrt{1+[f'(x)]^2}\,\mathrm{d}x}$$

其中 $r(\bar{x}, \bar{y})$ 为形心 $(\bar{x}, \bar{y})$ 到直线 $L_0$ 的距离。

## 连续情形（平面区域）

平面有界闭区域 $D$（$\rho$ 为面密度），对直线 $L_0$ 的力矩

$$M_{L_0} = \iint_D \frac{|ax+by+c|}{\sqrt{a^2+b^2}}\,\rho(x,y)\,\mathrm{d}\sigma$$

当 $\rho = $ 常数时：

$$r(\bar{x}, \bar{y}) = \frac{\displaystyle\iint_D \frac{|ax+by+c|}{\sqrt{a^2+b^2}}\,\mathrm{d}\sigma}{\displaystyle\iint_D \mathrm{d}\sigma}$$
