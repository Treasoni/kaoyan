# 一元函数积分学的应用（三）——物理应用与古鲁金定理

> 总目标：**掌握定积分的物理应用与古鲁金第一定理**（第12讲内容，数二考点）

| 项目 | 内容 |
|------|------|
| **考题** | 变力沿直线做功、抽水做功、静水压力、引力的求法 |
| **题型** | 选择题、填空题、解答题 |
| **重难点** | 静水压力的求法；古鲁金第一定理的综合应用 |

## 核心方法：微元法

所有物理应用的本质都是**微元法**：

1. **建系** → 建立合适的坐标系
2. **取微元** → 在 $[x, x+\mathrm{d}x]$ 上写出物理量的微元
3. **积分** → 对微元在区间上积分得到总量

## 知识结构

### 1-变力沿直线做功
- 功的微元 $\mathrm{d}W = F(x)\,\mathrm{d}x$
- 总功 $W = \int_a^b F(x)\,\mathrm{d}x$
- 典型题型：铁钉击入木板（阻力与深度成正比）

### 2-抽水做功
- 功的微元 $\mathrm{d}W = \rho g \cdot x \cdot A(x)\,\mathrm{d}x$
- 总功 $W = \rho g \int_a^b x\,A(x)\,\mathrm{d}x$
- 关键：确定水平截面面积 $A(x)$
- 典型题型：倒圆锥、半球形容器抽水

### 3-静水压力
- 压力微元 $\mathrm{d}P = \rho g \cdot x \cdot [f(x)-h(x)]\,\mathrm{d}x$
- 总压力 $P = \rho g \int_a^b x\,[f(x)-h(x)]\,\mathrm{d}x$
- 关键：确定水深 $x$ 处的平板宽度 $f(x)-h(x)$
- 典型题型：三角形平板、梯形平板

### 4-引力
- 引力微元 $\mathrm{d}F = \dfrac{Gm\mu}{(a-x)^2}\,\mathrm{d}x$
- 关键：建立坐标系，对细棒进行积分
- 注意：引力是矢量，需分解到坐标轴方向分别积分

## 公式速查

| 应用类型 | 微元 | 关键变量 |
|---------|------|---------|
| 变力做功 | $\mathrm{d}W = F(x)\,\mathrm{d}x$ | 力函数 $F(x)$ |
| 抽水做功 | $\mathrm{d}W = \rho g\,x\,A(x)\,\mathrm{d}x$ | 截面面积 $A(x)$ |
| 静水压力 | $\mathrm{d}P = \rho g\,x\,w(x)\,\mathrm{d}x$ | 平板宽度 $w(x)$ |
| 引力 | $\mathrm{d}F = \dfrac{Gm\mu}{r^2}\,\mathrm{d}x$ | 距离 $r$ |
| 古鲁金定理 | $A = 2\pi\bar{r}\cdot l$ | 形心到轴的距离 $\bar{r}$ |
