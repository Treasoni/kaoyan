# 变力沿直线做功

## 基本公式

设方向沿 $x$ 轴正向的力函数为 $y = F(x)$（$a \leqslant x \leqslant b$），则物体沿 $x$ 轴从点 $a$ 移动到点 $b$ 时，变力 $F(x)$ 所做的功为

$$W = \int_{a}^{b} F(x)\,\mathrm{d}x$$

**功的微元**：$\mathrm{d}W = F(x)\,\mathrm{d}x$

## 几何与物理意义

| 角度 | 意义 |
|------|------|
| 几何 | 曲边梯形的面积 |
| 物理 | 变力沿直线做功 |

## 解题步骤（微元法三步）

1. **建系** → 建立坐标系，引入记号
2. **取微元** → 在 $[x, x+\mathrm{d}x]$ 上写出 $\mathrm{d}W$
3. **积分** → 对微元在 $[a,b]$ 上积分

## 典型题型

### 铁钉击入木板（阻力与深度成正比）

> 铁钉击入木板，阻力与深度成正比，每次击打做功相等。

**翻译成数学语言**：
- 阻力：$f = kx$（$k$ 为常数）
- 功相等：$W_1 = W_2$

**取微元**：$\mathrm{d}W_1 = kx\,\mathrm{d}x$，$\mathrm{d}W_2 = kx\,\mathrm{d}x$

**积分**：
$$W_1 = \int_0^{x_1} kx\,\mathrm{d}x = \frac{k}{2}x_1^2, \quad x_1 = 1$$

$$W_2 = \int_{x_1}^{x_2} kx\,\mathrm{d}x = \frac{k}{2}x_2^2 - \frac{k}{2}x_1^2$$

由 $W_2 = W_1$ 得 $\frac{k}{2}x_2^2 = 2W_1 = k$，故 $x_2 = \sqrt{2}$

**结论**：第二锤击入 $(\sqrt{2}-1)\,\text{cm}$
