# 不定积分定义与性质

## 定义

> [!def] 原函数
> 设函数 $f(x)$ 在区间 $I$ 上有定义，若存在函数 $F(x)$，使得对任意 $x \in I$，都有
> $$
> F'(x) = f(x) \quad \text{或} \quad dF(x) = f(x)dx
> $$
> 则称 $F(x)$ 是 $f(x)$ 在区间 $I$ 上的**原函数**。

> [!def] 不定积分
> 函数 $f(x)$ 的全体原函数 $F(x) + C$（$C$ 为任意常数）称为 $f(x)$ 的**不定积分**，记作
> $$
> \int f(x)dx = F(x) + C
> $$

> [!tip] 关键要点
> - **不定积分是导数的逆运算**
> - **$+C$ 不能漏**（表示全体原函数）
> - **原函数存在定理**：连续函数必有原函数

## 基本性质

| 性质 | 公式 | 说明 |
|------|------|------|
| **导数与积分互逆** | $\frac{d}{dx}\int f(x)dx = f(x)$ | 先积后导，还原 |
| | $\int f'(x)dx = f(x) + C$ | 先导后积，差常数 |
| **线性性质** | $\int kf(x)dx = k\int f(x)dx$ | 常数因子提出 |
| | $\int [f(x) \pm g(x)]dx = \int f(x)dx \pm \int g(x)dx | | |

## 基本积分表

> [!summary] 必须熟记的基本积分公式

| 函数 | 不定积分 |
|------|----------|
| $\int k dx$ | $kx + C$ |
| $\int x^\mu dx$ | $\frac{x^{\mu+1}}{\mu+1} + C$（$\mu \neq -1$） |
| $\int \frac{1}{x} dx$ | $\ln|x| + C$ |
| $\int e^x dx$ | $e^x + C$ |
| $\int a^x dx$ | $\frac{a^x}{\ln a} + C$ |
| $\int \cos x dx$ | $\sin x + C$ |
| $\int \sin x dx$ | $-\cos x + C$ |
| $\int \frac{1}{\cos^2 x} dx$ | $\tan x + C$ |
| $\int \frac{1}{\sin^2 x} dx$ | $-\cot x + C$ |
| $\int \frac{1}{1+x^2} dx$ | $\arctan x + C$ |
| $\int \frac{1}{\sqrt{1-x^2}} dx$ | $\arcsin x + C$ |
| $\int \sec x \tan x dx$ | $\sec x + C$ |
| $\int \csc x \cot x dx$ | $-\csc x + C$ |
| $\int \sec x dx$ | $\ln|\sec x + \tan x| + C$ |
| $\int \csc x dx$ | $-\ln|\csc x + \cot x| + C$ |

## 典型题型

### 题型1：直接积分

> [!example] 例1
> **题目**：求 $\int (x^2 + 3x - 1)dx$
>
> **解答**：
> $$
> \begin{aligned}
> \int (x^2 + 3x - 1)dx
> &= \int x^2 dx + 3\int x dx - \int 1 dx \\
> &= \frac{x^3}{3} + \frac{3x^2}{2} - x + C
> \end{aligned}
> $$

### 题型2：代数恒等变形后积分

> [!example] 例2
> **题目**：求 $\int \frac{x^2}{1+x^2}dx$
>
> **解答**：
> $$
> \begin{aligned}
> \int \frac{x^2}{1+x^2}dx
> &= \int \frac{x^2+1-1}{1+x^2}dx \\
> &= \int \left(1 - \frac{1}{1+x^2}\right)dx \\
> &= x - \arctan x + C
> \end{aligned}
> $$

### 题型3：三角恒等变换

> [!example] 例3
> **题目**：求 $\int \tan^2 x dx$
>
> **解答**：
> $$
> \int \tan^2 x dx = \int (\sec^2 x - 1)dx = \tan x - x + C
> $$

## 易错点 ⚠️

### 易错点1：忘记常数 $C$

- ❌ **错误**：$\int 2x dx = x^2$
- ✅ **正确**：$\int 2x dx = x^2 + C$

### 易错点2：幂函数积分公式记错

- ❌ **错误**：$\int \frac{1}{x} dx = \ln x + C$
- ✅ **正确**：$\int \frac{1}{x} dx = \ln|x| + C$（注意绝对值）

### 易错点3：混淆 $x^{-1}$ 的积分

- ❌ **错误**：$\int \frac{1}{x} dx = \frac{x^0}{0} + C$
- ✅ **正确**：$\int \frac{1}{x} dx = \ln|x| + C$（$\mu = -1$ 时公式不适用）
