# 基本积分公式

## 📌 知识点定位

**所属模块**：高数-一元函数积分学 > 一元函数积分学的计算
**重要程度**：⭐⭐⭐⭐⭐
**考研要求**：熟练掌握，必须牢记

## 📖 概述

基本积分公式是所有积分计算的基础，必须牢记。

> [!tip] 核心思想
> 所有的积分计算通过各种方法最后都化为基本积分公式。

## 📝 核心公式

### 1. 幂函数公式
$$\int x^k \mathrm{d}x = \frac{1}{k+1} x^{k+1} + C, \quad k \neq -1$$

常用特例：
- $\int \frac{1}{x^2} \mathrm{d}x = -\frac{1}{x} + C$
- $\int \frac{1}{\sqrt{x}} \mathrm{d}x = 2\sqrt{x} + C$

### 2. 对数公式
$$\int \frac{1}{x} \mathrm{d}x = \ln|x| + C$$

### 3. 指数公式
$$\int e^x \mathrm{d}x = e^x + C$$
$$\int a^x \mathrm{d}x = \frac{a^x}{\ln a} + C, \quad a > 0, a \neq 1$$

### 4. 三角函数公式
$$\int \sin x \mathrm{d}x = -\cos x + C$$
$$\int \cos x \mathrm{d}x = \sin x + C$$
$$\int \tan x \mathrm{d}x = -\ln|\cos x| + C$$
$$\int \cot x \mathrm{d}x = \ln|\sin x| + C$$

> [!note] $\int \tan x \, \mathrm{d}x$ 推导
> **凑微分法**：
> $$\int \tan x \, \mathrm{d}x = \int \frac{\sin x}{\cos x} \, \mathrm{d}x = -\int \frac{\mathrm{d}(\cos x)}{\cos x} = -\ln|\cos x| + C$$
>
> 同理 $\int \cot x \, \mathrm{d}x = \int \frac{\cos x}{\sin x} \, \mathrm{d}x = \ln|\sin x| + C$

### 5. 正割与余割公式
$$\int \sec x \mathrm{d}x = \ln|\sec x + \tan x| + C$$
$$\int \csc x \mathrm{d}x = \ln|\csc x - \cot x| + C$$
$$\int \sec^2 x \mathrm{d}x = \tan x + C$$
$$\int \csc^2 x \mathrm{d}x = -\cot x + C$$
$$\int \sec x \tan x \mathrm{d}x = \sec x + C$$
$$\int \csc x \cot x \mathrm{d}x = -\csc x + C$$

> [!important] $\int \sec x \, \mathrm{d}x$ 推导 ⭐⭐⭐
> **方法一：分子分母同乘 $(\sec x + \tan x)$（经典技巧）**
> $$\int \sec x \, \mathrm{d}x = \int \sec x \cdot \frac{\sec x + \tan x}{\sec x + \tan x} \, \mathrm{d}x = \int \frac{\sec^2 x + \sec x \tan x}{\sec x + \tan x} \, \mathrm{d}x$$
> 注意分子恰好是分母的导数：$(\sec x + \tan x)' = \sec x \tan x + \sec^2 x$
> $$= \int \frac{\mathrm{d}(\sec x + \tan x)}{\sec x + \tan x} = \ln|\sec x + \tan x| + C$$
>
> **方法二：化为正弦余弦**
> $$\int \sec x \, \mathrm{d}x = \int \frac{1}{\cos x} \, \mathrm{d}x = \int \frac{\cos x}{\cos^2 x} \, \mathrm{d}x = \int \frac{\mathrm{d}(\sin x)}{1-\sin^2 x}$$
> 令 $u = \sin x$，则 $\int \frac{\mathrm{d}u}{1-u^2} = \frac{1}{2}\ln\left|\frac{1+u}{1-u}\right| + C = \frac{1}{2}\ln\left|\frac{1+\sin x}{1-\sin x}\right| + C$
> 化简即得 $\ln|\sec x + \tan x| + C$

> [!note] $\int \csc x \, \mathrm{d}x$ 推导
> **类似方法**：分子分母同乘 $(\csc x - \cot x)$
> $$\int \csc x \, \mathrm{d}x = \int \csc x \cdot \frac{\csc x - \cot x}{\csc x - \cot x} \, \mathrm{d}x = \int \frac{\csc^2 x - \csc x \cot x}{\csc x - \cot x} \, \mathrm{d}x$$
> 注意 $(\csc x - \cot x)' = -\csc x \cot x + \csc^2 x$
> $$= \int \frac{\mathrm{d}(\csc x - \cot x)}{\csc x - \cot x} = \ln|\csc x - \cot x| + C$$

### 6. 反三角函数公式
$$\int \frac{1}{1+x^2} \mathrm{d}x = \arctan x + C$$
$$\int \frac{1}{a^2+x^2} \mathrm{d}x = \frac{1}{a}\arctan \frac{x}{a} + C, \quad a > 0$$
$$\int \frac{1}{\sqrt{1-x^2}} \mathrm{d}x = \arcsin x + C$$
$$\int \frac{1}{\sqrt{a^2-x^2}} \mathrm{d}x = \arcsin \frac{x}{a} + C, \quad a > 0$$

### 7. 双曲函数公式
$$\int \frac{1}{\sqrt{x^2+a^2}} \mathrm{d}x = \ln(x+\sqrt{x^2+a^2}) + C$$
$$\int \frac{1}{\sqrt{x^2-a^2}} \mathrm{d}x = \ln|x+\sqrt{x^2-a^2}| + C, \quad |x| > |a|$$

> [!important] $\int \frac{1}{\sqrt{x^2+a^2}} \, \mathrm{d}x$ 推导 ⭐⭐⭐
> **方法一：三角换元**
> 令 $x = a\tan t$，$t \in (-\frac{\pi}{2}, \frac{\pi}{2})$，则 $\mathrm{d}x = a\sec^2 t \, \mathrm{d}t$
> $$\int \frac{1}{\sqrt{x^2+a^2}} \, \mathrm{d}x = \int \frac{a\sec^2 t}{a\sec t} \, \mathrm{d}t = \int \sec t \, \mathrm{d}t = \ln|\sec t + \tan t| + C$$
> 回代：$\tan t = \frac{x}{a}$，$\sec t = \frac{\sqrt{x^2+a^2}}{a}$
> $$= \ln\left(\frac{\sqrt{x^2+a^2}}{a} + \frac{x}{a}\right) + C = \ln(x + \sqrt{x^2+a^2}) + C_1$$
>
> **方法二：凑微分（更巧妙）**
> $$\int \frac{1}{\sqrt{x^2+a^2}} \, \mathrm{d}x = \int \frac{1}{\sqrt{x^2+a^2}} \cdot \frac{x+\sqrt{x^2+a^2}}{x+\sqrt{x^2+a^2}} \, \mathrm{d}x$$
> 注意 $\frac{\mathrm{d}}{\mathrm{d}x}(x+\sqrt{x^2+a^2}) = 1 + \frac{x}{\sqrt{x^2+a^2}} = \frac{x+\sqrt{x^2+a^2}}{\sqrt{x^2+a^2}}$
> $$= \int \frac{\mathrm{d}(x+\sqrt{x^2+a^2})}{x+\sqrt{x^2+a^2}} = \ln(x+\sqrt{x^2+a^2}) + C$$

> [!note] $\int \frac{1}{\sqrt{x^2-a^2}} \, \mathrm{d}x$ 推导
> **三角换元**：令 $x = a\sec t$，类似推导可得 $\ln|x+\sqrt{x^2-a^2}| + C$

### 8. 有理函数公式（重要）
$$\int \frac{1}{x^2-a^2} \mathrm{d}x = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C$$
$$\int \frac{1}{a^2-x^2} \mathrm{d}x = \frac{1}{2a}\ln\left|\frac{x+a}{x-a}\right| + C$$

> [!important] $\int \frac{1}{x^2-a^2} \, \mathrm{d}x$ 推导 ⭐⭐⭐
> **部分分式分解**：
> $$\frac{1}{x^2-a^2} = \frac{1}{(x-a)(x+a)} = \frac{A}{x-a} + \frac{B}{x+a}$$
> 通分：$1 = A(x+a) + B(x-a)$
> - 令 $x = a$：$1 = 2Aa \Rightarrow A = \frac{1}{2a}$
> - 令 $x = -a$：$1 = -2Ba \Rightarrow B = -\frac{1}{2a}$
>
> $$\int \frac{1}{x^2-a^2} \, \mathrm{d}x = \frac{1}{2a}\int \left(\frac{1}{x-a} - \frac{1}{x+a}\right) \mathrm{d}x = \frac{1}{2a}(\ln|x-a| - \ln|x+a|) + C = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C$$

> [!tip] 记忆技巧
> $\int \frac{1}{a^2-x^2} \, \mathrm{d}x = -\int \frac{1}{x^2-a^2} \, \mathrm{d}x$，所以结果符号相反

### 9. 圆弧积分公式（重要）
$$\int \sqrt{a^2-x^2} \mathrm{d}x = \frac{a^2}{2}\arcsin \frac{x}{a} + \frac{x}{2}\sqrt{a^2-x^2} + C, \quad a > |x| \geqslant 0$$

> [!important] $\int \sqrt{a^2-x^2} \, \mathrm{d}x$ 推导 ⭐⭐⭐
> **三角换元 + 分部积分**
>
> 令 $x = a\sin t$，$t \in [-\frac{\pi}{2}, \frac{\pi}{2}]$，则 $\mathrm{d}x = a\cos t \, \mathrm{d}t$，$\sqrt{a^2-x^2} = a\cos t$
> $$\int \sqrt{a^2-x^2} \, \mathrm{d}x = \int a\cos t \cdot a\cos t \, \mathrm{d}t = a^2 \int \cos^2 t \, \mathrm{d}t$$
>
> 利用降幂公式 $\cos^2 t = \frac{1+\cos 2t}{2}$：
> $$= a^2 \int \frac{1+\cos 2t}{2} \, \mathrm{d}t = \frac{a^2}{2}\left(t + \frac{\sin 2t}{2}\right) + C = \frac{a^2}{2}\left(t + \sin t \cos t\right) + C$$
>
> 回代：$\sin t = \frac{x}{a}$，$\cos t = \frac{\sqrt{a^2-x^2}}{a}$，$t = \arcsin\frac{x}{a}$
> $$= \frac{a^2}{2}\arcsin\frac{x}{a} + \frac{a^2}{2} \cdot \frac{x}{a} \cdot \frac{\sqrt{a^2-x^2}}{a} + C = \frac{a^2}{2}\arcsin\frac{x}{a} + \frac{x}{2}\sqrt{a^2-x^2} + C$$

> [!tip] 几何意义
> 此积分表示半径为 $a$ 的圆的上半部分面积微元，结果可理解为扇形面积 + 三角形面积

> [!tip] 结构对称法（最抗遗忘）
>
在纯代数层面上，你可以把等式右边看成两部分，它们都带有 $\frac{1}{2}$ 的系数，结构非常对称：
>
> - **“复读机”项：** $\frac{x}{2}\sqrt{a^2-x^2}$。这一项很好记，就是直接把原积分里的根号原封不动地抄下来，前面乘上一个 $\frac{x}{2}$。
>- **“老熟人”项：** $\frac{a^2}{2}\arcsin\frac{x}{a}$。回忆一下基础公式表，如果把这个根号放到分母上，即 $\int \frac{1}{\sqrt{a^2-x^2}} \mathrm{d}x$，它的积分结果就是 $\arcsin\frac{x}{a}$。在这个大公式里，这位老熟人只是额外戴上了一个 $\frac{a^2}{2}$ 的系数帽子

### 10. 二次三角函数公式
$$\int \sin^2 x \mathrm{d}x = \frac{x}{2} - \frac{\sin 2x}{4} + C$$
$$\int \cos^2 x \mathrm{d}x = \frac{x}{2} + \frac{\sin 2x}{4} + C$$
$$\int \tan^2 x \mathrm{d}x = \tan x - x + C$$
$$\int \cot^2 x \mathrm{d}x = -\cot x - x + C$$

> [!important] $\int \sin^2 x, \cos^2 x \, \mathrm{d}x$ 推导 ⭐⭐⭐
> **降幂公式**：$\sin^2 x = \frac{1-\cos 2x}{2}$，$\cos^2 x = \frac{1+\cos 2x}{2}$
>
> $$\int \sin^2 x \, \mathrm{d}x = \int \frac{1-\cos 2x}{2} \, \mathrm{d}x = \frac{x}{2} - \frac{\sin 2x}{4} + C$$
>
> $$\int \cos^2 x \, \mathrm{d}x = \int \frac{1+\cos 2x}{2} \, \mathrm{d}x = \frac{x}{2} + \frac{\sin 2x}{4} + C$$

> [!note] $\int \tan^2 x, \cot^2 x \, \mathrm{d}x$ 推导
> **利用恒等式**：$\tan^2 x = \sec^2 x - 1$
> $$\int \tan^2 x \, \mathrm{d}x = \int (\sec^2 x - 1) \, \mathrm{d}x = \tan x - x + C$$
>
> 同理 $\cot^2 x = \csc^2 x - 1$：
> $$\int \cot^2 x \, \mathrm{d}x = \int (\csc^2 x - 1) \, \mathrm{d}x = -\cot x - x + C$$

## ⚠️ 易错点

1. **常数 C 不能遗漏**：不定积分必须加常数 C
2. **对数公式中的绝对值**：$\int \frac{1}{x} \mathrm{d}x = \ln|x| + C$，绝对值不能省
3. **幂函数特殊情况**：$k = -1$ 时不能用幂函数公式，需用对数公式

## 🎯 典型例题

### 例题1
求不定积分 $\int \frac{\sqrt{x}}{\sqrt{4-x^3}}\mathrm{d}x$

**解**：
$$\int \frac{\sqrt{x}}{\sqrt{4-x^3}} \mathrm{d}x = \frac{2}{3}\int \frac{\mathrm{d}(x^{3/2})}{\sqrt{4-(x^{3/2})^2}} = \frac{2}{3}\int \frac{\mathrm{d}\left(\frac{1}{2}x^{3/2}\right)}{\sqrt{1-\left(\frac{1}{2}x^{3/2}\right)^2}} = \frac{2}{3}\arcsin \frac{x^{3/2}}{2} + C$$
