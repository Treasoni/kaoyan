## 概述
基本积分公式是所有积分计算的基础，必须牢记。

## 核心公式

### 1. 幂函数公式
$$\int x^k \mathrm{d}x = \frac{1}{k+1} x^{k+1} + C, \quad k \neq -1$$

常用特例：
- $\int \frac{1}{x^2} \mathrm{d}x = -\frac{1}{x} + C$
- $\int \frac{1}{\sqrt{x}} \mathrm{d}x = 2\sqrt{x} + C$

### 2. 对数公式
$$\int \frac{1}{x} \mathrm{d}x = \ln|x| + C$$

### 3. 指数公式
$$\int e^x \mathrm{d}x = e^x + C$$

$$\int a^x \mathrm{d}x = \frac{a^x}{\ln a} + C, \quad a > 0, a \neq 1$$

### 4. 三角函数公式
$$\int \sin x \mathrm{d}x = -\cos x + C$$

$$\int \cos x \mathrm{d}x = \sin x + C$$

$$\int \tan x \mathrm{d}x = -\ln|\cos x| + C$$

$$\int \cot x \mathrm{d}x = \ln|\sin x| + C$$

### 5. 正割与余割公式
$$\int \sec x \mathrm{d}x = \ln|\sec x + \tan x| + C$$

$$\int \csc x \mathrm{d}x = \ln|\csc x - \cot x| + C$$

$$\int \sec^2 x \mathrm{d}x = \tan x + C$$

$$\int \csc^2 x \mathrm{d}x = -\cot x + C$$

$$\int \sec x \tan x \mathrm{d}x = \sec x + C$$

$$\int \csc x \cot x \mathrm{d}x = -\csc x + C$$

### 6. 反三角函数公式
$$\int \frac{1}{1+x^2} \mathrm{d}x = \arctan x + C$$

$$\int \frac{1}{a^2+x^2} \mathrm{d}x = \frac{1}{a}\arctan \frac{x}{a} + C, \quad a > 0$$

$$\int \frac{1}{\sqrt{1-x^2} \mathrm{d}x = \arcsin x + C$$

$$\int \frac{1}{\sqrt{a^2-x^2} \mathrm{d}x = \arcsin \frac{x}{a} + C, \quad a > 0$$

### 7. 双曲函数公式
$$\int \frac{1}{\sqrt{x^2+a^2}} \mathrm{d}x = \ln(x+\sqrt{x^2+a^2}) + C$$

$$\int \frac{1}{\sqrt{x^2-a^2}} \mathrm{d}x = \ln|x+\sqrt{x^2-a^2}| + C, \quad |x| > |a|$$

### 8. 有理函数公式
$$\int \frac{1}{x^2-a^2} \mathrm{d}x = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C$$

$$\int \frac{1}{a^2-x^2} \mathrm{d}x = \frac{1}{2a}\ln\left|\frac{x+a}{x-a}\right| + C$$

### 9. 圆弧积分公式
$$\int \sqrt{a^2-x^2} \mathrm{d}x = \frac{a^2}{2}\arcsin \frac{x}{a} + \frac{x}{2}\sqrt{a^2-x^2} + C, \quad a > |x| \geqslant 0$$

### 10. 二次三角函数公式
$$\int \sin^2 x \mathrm{d}x = \frac{x}{2} - \frac{\sin 2x}{4} + C$$

$$\int \cos^2 x \mathrm{d}x = \frac{x}{2} + \frac{\sin 2x}{4} + C$$

$$\int \tan^2 x \mathrm{d}x = \tan x - x + C$$
$$\int \cot^2 x \mathrm{d}x = -\cot x - x + C$$

## 学习要点
1. ⭐ 这公式是所有积分计算的基础，必须熟练掌握
2. 公式中的常数 C 不能遗漏
3. 遇到复杂积分时，最终都要化为这些基本公式

4. 对数公式中的绝对值要注意

## 概述
不定积分的计算是积分学的核心内容，主要包括四大方法：凑微分法、换元法、分部积分法、有理函数积分法。

## 1-凑微分法

### 基本思想
$$\int f[g(x)] g'(x) \mathrm{d}x = \int f[g(x)] \mathrm{d}[g(x)] = \int f(u) \mathrm{d}u$$

复合函数链式求导的逆用。

### 层题策略
当被积函数比较复杂时，拿出一部分放到 $\mathrm{d}$ 后面去，若能凑成 $\int f(u)\mathrm{d}u$ 的形式，则凑微分成功。

### 层用凑微分公式
1. $x\mathrm{d}x = \frac{1}{2}\mathrm{d}(x^2) \Rightarrow \int xf(x^2)\mathrm{d}x = \frac{1}{2}\int f(u)\mathrm{d}u$
2. $\sqrt{x}\mathrm{d}x = \frac{2}{3}\mathrm{d}(x^{3/2})$
3. $\frac{\mathrm{d}x}{\sqrt{x}} = 2\mathrm{d}(\sqrt{x})$
4. $\frac{\mathrm{d}x}{x^2} = \mathrm{d}\left(-\frac{1}{x}\right)$
5. $\frac{1}{x}\mathrm{d}x = \mathrm{d}(\ln x)$ （当 $x>0$）
6. $e^x\mathrm{d}x = \mathrm{d}(e^x)$
7. $a^x\mathrm{d}x = \frac{1}{\ln a}\mathrm{d}(a^x)$
8. $\sin x \mathrm{d}x = \mathrm{d}(-\cos x)$
9. $\cos x \mathrm{d}x = \mathrm{d}(\sin x)$
10. $\frac{\mathrm{d}x}{\cos^2 x} = \sec^2 x \mathrm{d}x = \mathrm{d}(\tan x)$
11. $\frac{\mathrm{d}x}{\sin^2 x} = \csc^2 x \mathrm{d}x = \mathrm{d}(-\cot x)$
12. $\frac{1}{1+x^2} \mathrm{d}x = \mathrm{d}(\arctan x)$
13. $\frac{1}{\sqrt{1-x^2}} \mathrm{d}x = \mathrm{d}(\arcsin x)$

### 技巧：选择复杂部分求导
对被积函数的复杂部分 $g(x)$ 求导，若 $g'(x)$ 等于剩余部分，则可直接凑微分。

## 2-换元法

### 基本思想
$$\int f(x) \mathrm{d}x \xrightarrow{x=g(u)} \int f[g(u)] g'(u) \mathrm{d}u$$

引入新的自变量 $u$，将原式化简为 $\int h(u)\mathrm{d}u$，可代入公式。

### 常用换元类型

#### 1. 三角函数代换
- 含 $\sqrt{a^2-x^2}$：令 $x=a\sin t$
- 含 $\sqrt{a^2+x^2}$：令 $x=a\tan t$
- 含 $\sqrt{x^2-a^2}$：令 $x=a\sec t$

#### 2. 根式代换
- 含 $\sqrt[n]{ax+b}$：令 $\sqrt[n]{ax+b}=t$
- 含多个根式：取最小公倍数

#### 3. 倒代换
分母幂次比分子高两次及以上时，令 $x=\frac{1}{t}$

#### 4. 复杂函数代换
含 $a^x, e^x, \ln x, \arcsin x, \arctan x$ 等时，可令复杂函数等于 $t$

### 注意事项
1. $x=g(u)$ 须是单调可导函数
2. 计算结束后用反函数回代
## 3-分部积分法

### 基本公式
$$\int u \mathrm{d}v = uv - \int v \mathrm{d}u$$

### u, v 选取原则（反对幂指三）
相对位置在左边的选作 $u$（求导），右边的选作 $v$（积分）

- 反三角函数、对数
- 幂函数
- 指数函数
- 三角函数

### 适用情况
1. 被积函数为 $P_n(x)e^{kx}$, $P_n(x)\sin ax$, $P_n(x)\cos ax$ 等
2. 被积函数为 $e^{ax}\sin bx$, $e^{ax}\cos bx$ 等
3. 被积函数为 $P_n(x)\ln x$, $P_n(x)\arcsin x$, $P_n(x)\arctan x$ 等

## 4-有理函数的积分

### 定义
形如 $\int \frac{P_n(x)}{Q_m(x)}\mathrm{d}x$ ($n < m$) 的积分

### 计算步骤
1. 若 $n \geq m$，先化为真分式
2. 对 $Q_m(x)$ 因式分解
3. 将 $\frac{P_n(x)}{Q_m(x)}$ 拆成最简有理分式之和
4. 对各项分别积分
### 最简有理分式类型
1. $\frac{A}{ax+b}$
2. $\frac{A_k}{(ax+b)^k}$
3. $\frac{Ax+B}{px^2+qx+r}$
4. $\frac{A_kx+B_k}{(px^2+qx+r)^k}$
