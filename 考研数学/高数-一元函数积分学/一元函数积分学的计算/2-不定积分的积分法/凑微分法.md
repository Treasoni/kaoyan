# 凑微分法

## 📌 知识点定位

**所属模块**：高数-一元函数积分学 > 不定积分的积分法
**重要程度**：⭐⭐⭐⭐⭐
**考研要求**：熟练掌握凑微分法及其常用公式

## 📖 概述

凑微分法（第一换元法）是复合函数链式求导的逆用，是最常用的积分方法之一。

## 📝 核心方法

$$\int f[g(x)] g'(x) \mathrm{d}x = \int f[g(x)] \mathrm{d}[g(x)] \xlongequal{u=g(x)} \int f(u) \mathrm{d}u$$

> [!tip] 核心思想
> 当被积函数比较复杂时，拿出一部分放到 $\mathrm{d}$ 后面去，若能凑成 $\int f(u)\mathrm{d}u$ 的形式，则凑微分成功。

## 📋 常用凑微分公式

### 1. 幂函数凑微分
- $x\mathrm{d}x = \frac{1}{2}\mathrm{d}(x^2)$
- $\int xf(x^2)\mathrm{d}x = \frac{1}{2}\int f(u)\mathrm{d}u$

### 2. 根式凑微分
- $\sqrt{x}\mathrm{d}x = \frac{2}{3}\mathrm{d}(x^{3/2})$
- $\frac{\mathrm{d}x}{\sqrt{x}} = 2\mathrm{d}(\sqrt{x})$，故 $\int \frac{f(\sqrt{x})}{\sqrt{x}}\mathrm{d}x = 2\int f(u)\mathrm{d}u$

### 3. 负幂凑微分
- $\frac{\mathrm{d}x}{x^2} = \mathrm{d}\left(-\frac{1}{x}\right)$
- $\int \frac{f\left(-\frac{1}{x}\right)}{x^2} \mathrm{d}x = \int f(u)\mathrm{d}u$

### 4. 对数凑微分
- $\frac{1}{x}\mathrm{d}x = \mathrm{d}(\ln x)$（当 $x > 0$）
- $\int \frac{f(\ln x)}{x}\mathrm{d}x = \int f(\ln x)\mathrm{d}(\ln x) = \int f(u)\mathrm{d}u$

### 5. 指数函数凑微分
- $e^x\mathrm{d}x = \mathrm{d}(e^x)$
- $\int e^x f(e^x)\mathrm{d}x = \int f(e^x)\mathrm{d}(e^x) = \int f(u)\mathrm{d}u$
- $a^x\mathrm{d}x = \frac{1}{\ln a}\mathrm{d}(a^x)$（$a > 0$，$a \neq 1$）

### 6. 三角函数凑微分
- $\sin x \mathrm{d}x = \mathrm{d}(-\cos x)$
- $\cos x \mathrm{d}x = \mathrm{d}(\sin x)$

### 7. 正割/余割凑微分
- $\sec^2 x \mathrm{d}x = \mathrm{d}(\tan x)$
- $\csc^2 x \mathrm{d}x = \mathrm{d}(-\cot x)$

### 8. 反三角函数凑微分
- $\frac{1}{1+x^2} \mathrm{d}x = \mathrm{d}(\arctan x)$
- $\frac{1}{\sqrt{1-x^2}} \mathrm{d}x = \mathrm{d}(\arcsin x)$

## 🔍 解题技巧

### 对复杂部分求导
若不是常用的凑微分公式，==可对被积函数的复杂部分 $g(x)$ 求导==：
- 若 $g'(x) = f(x)$，即 $\mathrm{d}[g(x)] = f(x)\mathrm{d}x$
- 则 $\int f(x)g(x)\mathrm{d}x = \int g(x)\mathrm{d}[g(x)]$，凑微分成功

## 🎯 典型例题

### 例9.1
求不定积分 $\int \frac{\sqrt{x}}{\sqrt{4-x^3}} \mathrm{d}x$

**解**：
$$\int \frac{\sqrt{x}}{\sqrt{4-x^3}} \mathrm{d}x = \frac{2}{3}\int \frac{\mathrm{d}(x^{3/2})}{\sqrt{4-(x^{3/2})^2}} = \frac{2}{3}\int \frac{\mathrm{d}\left(\frac{1}{2}x^{3/2}\right)}{\sqrt{1-\left(\frac{1}{2}x^{3/2}\right)^2}} = \frac{2}{3}\arcsin \frac{x^{3/2}}{2} + C$$

### 例9.2
求不定积分 $\int e^{\frac{\sin\theta}{\cos\theta + \sin\theta}} \cdot \frac{1}{(\cos\theta + \sin\theta)^2}\mathrm{d}\theta$

**分析**：对复杂部分求导。

**解**：
$$\left(\frac{\sin\theta}{\cos\theta + \sin\theta}\right)' = \frac{1}{(\cos\theta + \sin\theta)^2}$$

故 $\mathrm{d}\left(\frac{\sin\theta}{\cos\theta + \sin\theta}\right) = \frac{1}{(\cos\theta + \sin\theta)^2}\mathrm{d}\theta$

$$\text{原式} = \int e^{\frac{\sin\theta}{\cos\theta + \sin\theta}}\mathrm{d}\left(\frac{\sin\theta}{\cos\theta + \sin\theta}\right) = e^{\frac{\sin\theta}{\cos\theta + \sin\theta}} + C$$

## ⚠️ 易错点

1. 凑微分后要确认能代入基本积分公式
2. 注意 $\frac{1}{x}\mathrm{d}x = \mathrm{d}(\ln|x|)$ 中的绝对值
3. 复杂函数先对复杂部分求导判断
