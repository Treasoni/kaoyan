## 概述
有理函数是指两个多项式的商， 形式为 $\frac{P_n(x)}{Q_m(x)}$ 其中 $n < m$。

## 计算步骤
1. 若 $n \geq m$（假分式），先化为真分式
2. 对 $Q_m(x)$ 因式分解
3. 将 $\frac{P_n(x)}{Q_m(x)}$ 拆成最简有理分式之和
4. 对各项分别积分

## 最简有理分式类型
1. $\frac{A}{ax+b}$ — 一次因式
2. $\frac{A_k}{(ax+b)^k}$ ($k \geq 2$) — $k$ 重一次因式
3. $\frac{Ax+B}{px^2+qx+r}$ — 二次不可约因式
4. $\frac{A_kx+B_k}{(px^2+qx+r)^k}$ ($k \geq 2$) — $k$ 重二次因式

### 三角函数有理式
令 $t = \tan\frac{x}{2}$，可化为有理函数积分：
$$\int R(\sin x, \cos x) \mathrm{d}x \xrightarrow{t=\tan\frac{x}{2}} \int R\left(\frac{2t}{1+t^2}, \frac{1-t^2}{1+t^2}\right) \frac{2}{1+t^2}\mathrm{d}t = \int \frac{P_n(t)}{Q_m(t)}\mathrm{d}t$$

## 注意事项
1. 三角函数有理式积分可能较复杂，考研中要求较低
2. 万能代换法虽理论上可行，但实际计算中较少使用
3. 若被积函数中有 $\ln x, \arcsin x, \arctan x$ 与 $P_n(x)$ 或 $e^{ax}$ 作乘法时，优先考虑分部积分法
## 例题
**例9.8** 求 $\int \frac{4x^2-6x-1}{(x+1)(2x-1)^2}\mathrm{d}x$

**解**:
设 $\frac{4x^2-6x-1}{(x+1)(2x-1)^2} = \frac{A}{x+1} + \frac{B}{2x-1} + \frac{C}{(2x-1)^2}$

通分后比较分子：
$$4x^2-6x-1 = A(2x-1)^2 + B(x+1)(2x-1) + C(2x-1)^2$$

由 $x = -1$ 得 $A = 1$
由 $x = \frac{1}{2}$ 得 $C = -2$
由 $x = 0$， $-1 = A - B + C = -1$

所以
$$\frac{4x^2-6x-1}{(x+1)(2x-1)^2} = \frac{1}{x+1} - \frac{0}{2x-1} - \frac{2}{(2x-1)^2}$$

因此
$$\int \frac{4x^2-6x-1}{(x+1)(2x-1)^2}\mathrm{d}x = \ln|x+1| + \frac{1}{2x-1} + \frac{1}{(2x-1)^2} + C$$
$$= \ln |x+1| + \ln\frac{2x-1}{x+1} + \frac{2}{2x-1} + C_1
$$
$$= \frac{1}{2}\ln\left|\frac{x-1}{x+1}\right| + C_1 = \frac{1}{4}\ln\frac{(x-1)^2}{x^2+1} + \frac{1}{2}\arctan x + C_1
$$

## 学习要点
1. 有理函数积分的关键是因式分解和拆分
2. 掌握因式分解的方法（待定系数法或赋值法）
3. 三角函数有理式积分可用万能代换，但计算量较大
4. 考研中常考简单的有理函数积分
 齐与复杂。
相结合
例如：
   - $\int \frac{1}{x(x^3+1)}\mathrm{d}x = \int \frac{x^2}{x^3(x^3+1)}\mathrm{d}(x^3) = \frac{1}{3}\ln\frac{x^3}{x^3+1} + C$
   - 令 $x^3 = t$，则 $\mathrm{d}x = 3x^2\mathrm{d}t$， 则
$$\int \frac{x^2}{x^3(x^3+1)}\mathrm{d}x = \frac{1}{3}\ln|x^3| + \frac{1}{3}\ln\frac{x^3}{t^3+1} + C$$
   - 或者直接拆分: $\frac{x^2}{x^3(x^3+1)} = \frac{x^2}{x^3} + \frac{1}{x^3+1}$
   - $\int \frac{x^2}{x^3(x^3+1)}\mathrm{d}x = \frac{1}{3}\ln(x^3+1) + \frac{1}{3}\arctan x + C$
   - 令 $x^3 = t$，则 $\mathrm{d}x = 3x^2\mathrm{d}t$， 则 $\int \frac{x^2}{x^3(x^3+1)}\mathrm{d}x = \frac{1}{3}\ln(t^3+1) + \frac{1}{3}\arctan t + C$
   - 最后回代: $\frac{1}{3}\ln\frac{x^3}{t^3+1} + \frac{1}{3}\arctan\frac{x^3}{t^3+1} + C$
   - 或令 $x^3 = t^3$，则 $\frac{x^2}{x^3(x^3+1)} = \frac{t^2}{t^3(t^3+1)}$
   - $\frac{x^2}{x^3} = \frac{1}{x^3+1} - \frac{1}{x^3+1} = \frac{t^2}{t^3(t^3+1)}$
   - $\frac{x^2}{t^3+1} = \frac{t^2}{t^3(t^3+1)}$
   - 最后回代: $\frac{1}{3}\ln\frac{t^2}{t^3(t^3+1)} + \frac{1}{3}\arctan\frac{t^2}{t^3(t^3+1)} + C$
   - 或令 $x^3 = t^3$，则 $\frac{x^2}{x^3(x^3+1)} = \frac{t^4}{(t^3+1)^4}$
   - $\frac{x^2}{x^3} = \frac{t^4}{(t^3+1)^4} - \frac{t^4}{(t^3+1)^4} = \frac{t^4}{t^4(t^3+1)^4}$
   - 最后回代: $\frac{x^2}{3}\ln\frac{t^4}{(t^3+1)^4} + \frac{x^2}{3}\arctan\frac{t^4}{(t^3+1)^4} + C$
