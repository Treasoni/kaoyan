# 反常积分的计算

## 📌 知识点定位

**所属模块**：高数-一元函数积分学 > 一元函数积分学的计算
**重要程度**：⭐⭐⭐⭐
**考研要求**：会计算反常积分

## 📖 概述

反常积分是对定积分的推广，包括无穷区间上的积分和无界函数的积分，是考研数学的常考内容。

> [!warning] 重要提醒
> 在计算反常积分时，注意识别奇点（端点、内部）！


## 📋 计算步骤

1. **识别反常积分类型**（无穷区间/无界函数）
2. **找出奇点**（端点或内部）
3. **根据类型选择计算方法**：
   - 无穷区间：求极限
   - 无界函数：拆区间后求极限
4. **判断收敛性**

## 🎯 典型例题

### 例9.26
计算反常积分 $\int_{\frac{1}{2}}^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{|x - x^2|}}$

**分析**：注意到 $x = 1$ 是瑕点（内部奇点），$\lim_{x\to 1} \frac{1}{\sqrt{|x - x^2|}} = \infty$

**解**：
$$\text{原式} = \int_{\frac{1}{2}}^1 \frac{\mathrm{d}x}{\sqrt{x - x^2}} + \int_1^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{x^2 - x}}$$

对于第一项：
$$\int_{\frac{1}{2}}^1 \frac{\mathrm{d}x}{\sqrt{x - x^2}} = \int_{\frac{1}{2}}^1 \frac{\mathrm{d}x}{\sqrt{\frac{1}{4} - \left(x - \frac{1}{2}\right)^2}} = \arcsin(2x - 1)\Big|_{\frac{1}{2}}^1 = \arcsin 1 = \frac{\pi}{2}$$

对于第二项：
$$\int_1^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{x^2 - x}} = \int_1^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{\left(x - \frac{1}{2}\right)^2 - \frac{1}{4}}} = \ln\left[\left(x - \frac{1}{2}\right) + \sqrt{\left(x - \frac{1}{2}\right)^2 - \frac{1}{4}}\right]\Big|_1^{\frac{3}{2}} = \ln(2 + \sqrt{3})$$

因此：$\int_{\frac{1}{2}}^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{|x - x^2|}} = \frac{\pi}{2} + \ln(2 + \sqrt{3})$

## 📐 Γ 函数（伽马函数）——反常积分秒杀工具

> [!tip] 识别信号
> 积分区间 $[0, +\infty)$，被积函数含 $x^a$ 与 $\mathrm{e}^{-bx}$ → 立即联想 Γ 函数。

### 1. 定义（两种脸）

**标准型**（常用）：

$$\Gamma(\alpha) = \int_{0}^{+\infty} x^{\alpha - 1} \mathrm{e}^{-x} \, \mathrm{d}x \quad (\alpha > 0)$$

> [!note] 注意
> 幂函数指数是 $\alpha - 1$，对应参数 $\alpha$。例如 $x^3$ → $\Gamma(4)$。

**变形型**（含 $t^2$ 项）：

令 $x = t^2$，得：

$$\Gamma(\alpha) = 2 \int_{0}^{+\infty} t^{2\alpha - 1} \mathrm{e}^{-t^2} \, \mathrm{d}t$$

> [!example] 特例：高斯积分
> $\alpha = \dfrac{1}{2}$ 时：$\Gamma\!\left(\dfrac{1}{2}\right) = 2\displaystyle\int_{0}^{+\infty} \mathrm{e}^{-t^2} \, \mathrm{d}t = \sqrt{\pi}$

### 2. 核心性质

| 性质 | 公式 |
| :---: | :---: |
| **递推公式** | $\Gamma(\alpha + 1) = \alpha\,\Gamma(\alpha)$ |
| **阶乘推广** | $n$ 为正整数时，$\Gamma(n + 1) = n!$ |

> [!important] 意义
> 将阶乘从整数推广到实数域，大幅简化分部积分过程。

### 3. 必背特殊值

$$\Gamma(1) = 1, \quad \Gamma(2) = 1, \quad \Gamma\!\left(\frac{1}{2}\right) = \sqrt{\pi}$$

**半整数递推规律**：

$$\Gamma\!\left(\frac{3}{2}\right) = \frac{1}{2}\Gamma\!\left(\frac{1}{2}\right) = \frac{\sqrt{\pi}}{2}$$

$$\Gamma\!\left(\frac{5}{2}\right) = \frac{3}{2} \cdot \frac{1}{2}\sqrt{\pi} = \frac{3\sqrt{\pi}}{4}$$

> [!tip] 记忆口诀
> 半整数 = 从 $\dfrac{1}{2}$ 开始，每升半步乘一个递减的系数：$\dfrac{1}{2},\;\dfrac{3}{2},\;\dfrac{5}{2},\;\ldots$

### 4. 三大解题模板

#### 模板① 标准套用（识别指数）

> **例**：计算 $I = \displaystyle\int_{0}^{+\infty} x^4 \mathrm{e}^{-x} \, \mathrm{d}x$
>
> **识别**：$\alpha - 1 = 4 \Rightarrow \alpha = 5$
>
> **结论**：$I = \Gamma(5) = 4! = 24$

#### 模板② 指数带系数（换元法）

> **例**：计算 $I = \displaystyle\int_{0}^{+\infty} x^2 \mathrm{e}^{-3x} \, \mathrm{d}x$
>
> **换元**：令 $3x = t$，$x = \dfrac{t}{3}$，$\mathrm{d}x = \dfrac{1}{3}\mathrm{d}t$
>
> $$I = \int_{0}^{+\infty} \left(\frac{t}{3}\right)^2 \mathrm{e}^{-t} \cdot \frac{1}{3}\mathrm{d}t = \frac{1}{27}\int_{0}^{+\infty} t^2 \mathrm{e}^{-t} \, \mathrm{d}t = \frac{1}{27}\Gamma(3) = \frac{2}{27}$$

#### 模板③ 指数为平方（高斯型）

> **例**：计算 $I = \displaystyle\int_{0}^{+\infty} \mathrm{e}^{-x^2} \, \mathrm{d}x$
>
> **直接对应**：Γ 变形公式的一半
>
> $$I = \frac{1}{2}\Gamma\!\left(\frac{1}{2}\right) = \frac{\sqrt{\pi}}{2}$$

## ⚠️ 易错点

1. **识别奇点是关键**：端点和内部都要检查
2. **含绝对值的积分**：要小心处理，拆区间去绝对值
3. **无界函数的反常积分**：可能要拆区间处理
4. **记住常用的反常积分结果**：$\int_0^{+\infty} \mathrm{e}^{-x^2}\mathrm{d}x = \frac{\sqrt{\pi}}{2}$
5. **Γ 函数使用前提**：区间必须是 $[0, +\infty)$，若为 $(-\infty, +\infty)$ 先利用偶函数性质化为 $2\int_0^{+\infty}$
6. **指数对应关系**：看到 $x^n$，参数是 $n+1$（即 $\Gamma(n+1)$）
7. **换元要彻底**：$\mathrm{e}$ 的指数不是 $-x$ 或 $-x^2$ 时，必须先换元把系数挪到 $\mathrm{d}t$ 外面
