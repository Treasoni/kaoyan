## 📖 概述

反常积分是对定积分的推广，包括**无穷区间上的积分**和**无界函数的积分**，是考研数学的常考内容。

> [!warning] 重要提醒
> 在计算反常积分时，注意识别奇点（端点、内部）！

---

## 📋 通用计算步骤

```
① 识别反常积分类型（无穷区间 / 无界函数）
        ↓
② 找出奇点（端点 或 内部）
        ↓
③ 根据类型选择计算方法：
   · 无穷区间 → 求极限
   · 无界函数 → 拆区间后求极限
        ↓
④ 判断收敛性
```

## 🎯 典型例题

### 例 9.26 含绝对值的瑕积分

> **题目**：计算 $\displaystyle\int_{\frac{1}{2}}^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{\vert x - x^2 \vert}}$

**【分析】**
$x = 1$ 是瑕点（内部奇点），$\displaystyle\lim_{x\to 1} \frac{1}{\sqrt{\vert x - x^2 \vert}} = \infty$

**【解】** 拆区间去绝对值：

$$\text{原式} = \int_{\frac{1}{2}}^1 \frac{\mathrm{d}x}{\sqrt{x - x^2}} + \int_1^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{x^2 - x}}$$

**第一项**（配方）：

$$\int_{\frac{1}{2}}^1 \frac{\mathrm{d}x}{\sqrt{x - x^2}} = \int_{\frac{1}{2}}^1 \frac{\mathrm{d}x}{\sqrt{\frac{1}{4} - \left(x - \frac{1}{2}\right)^2}} = \arcsin(2x - 1)\Bigg|_{\frac{1}{2}}^1 = \arcsin 1 = \frac{\pi}{2}$$

**第二项**（配方）：

$$\int_1^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{x^2 - x}} = \int_1^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{\left(x - \frac{1}{2}\right)^2 - \frac{1}{4}}} = \ln\left[\left(x - \frac{1}{2}\right) + \sqrt{\left(x - \frac{1}{2}\right)^2 - \frac{1}{4}}\right]\Bigg|_1^{\frac{3}{2}} = \ln(2 + \sqrt{3})$$

> [!success] 最终结果
> $\displaystyle\int_{\frac{1}{2}}^{\frac{3}{2}} \frac{\mathrm{d}x}{\sqrt{\vert x - x^2 \vert}} = \frac{\pi}{2} + \ln(2 + \sqrt{3})$

## 📐 Γ 函数（伽马函数）——反常积分秒杀工具

> [!tip] 🔍 识别信号
> 积分区间 $[0, +\infty)$，被积函数含 $x^a$ 与 $\mathrm{e}^{-bx}$ → **立即联想 Γ 函数**。

---

### 1️⃣ 定义（两种形态）

#### 标准型（最常用）

$$\boxed{\Gamma(\alpha) = \int_{0}^{+\infty} x^{\alpha - 1} \mathrm{e}^{-x} \, \mathrm{d}x \quad (\alpha > 0)}$$

> [!note] 关键对应
> 幂函数指数是 $\alpha - 1$，对应参数 $\alpha$。
>
> 例如：$x^3$ 的指数 $3 = \alpha - 1$ → $\alpha = 4$ → $\Gamma(4)$

#### 变形型（含 $t^2$ 项）

令 $x = t^2$，得：

$$\boxed{\Gamma(\alpha) = 2 \int_{0}^{+\infty} t^{2\alpha - 1} \mathrm{e}^{-t^2} \, \mathrm{d}t}$$


> [!example] 特例：高斯积分
> 当 $\alpha = \dfrac{1}{2}$ 时：
>
> $$\Gamma\!\left(\frac{1}{2}\right) = 2\int_{0}^{+\infty} \mathrm{e}^{-t^2} \, \mathrm{d}t = \sqrt{\pi}$$
>
> 这就是著名的**高斯积分** $\displaystyle\int_{0}^{+\infty} \mathrm{e}^{-t^2} \, \mathrm{d}t = \frac{\sqrt{\pi}}{2}$

---

### 2️⃣ 核心性质

| 性质 | 公式 | 说明 |
| :---: | :---: | :--- |
| **递推公式** | $\Gamma(\alpha + 1) = \alpha\,\Gamma(\alpha)$ | 每次降一阶，乘以当前参数 |
| **阶乘推广** | $\Gamma(n + 1) = n! \quad (n \in \mathbb{N}^+)$ | 阶乘从整数推广到实数域 |

> [!important] 核心意义
> **将阶乘从整数推广到实数域**，大幅简化分部积分过程。
> 看到 $\int_0^{+\infty} x^n \mathrm{e}^{-x}\mathrm{d}x$ 直接出答案 $n!$，无需逐步分部积分。

---

### 3️⃣ 必背特殊值

$$\boxed{\Gamma(1) = 1 \quad \quad \Gamma(2) = 1 \quad \quad \Gamma\!\left(\frac{1}{2}\right) = \sqrt{\pi}}$$

**半整数递推链**（用 $\Gamma(\alpha+1) = \alpha\Gamma(\alpha)$ 逐级递推）：

$$\Gamma\!\left(\frac{1}{2}\right) = \sqrt{\pi}$$

$$\Gamma\!\left(\frac{3}{2}\right) = \frac{1}{2} \cdot \Gamma\!\left(\frac{1}{2}\right) = \frac{\sqrt{\pi}}{2}$$

$$\Gamma\!\left(\frac{5}{2}\right) = \frac{3}{2} \cdot \Gamma\!\left(\frac{3}{2}\right) = \frac{3}{2} \cdot \frac{\sqrt{\pi}}{2} = \frac{3\sqrt{\pi}}{4}$$

$$\Gamma\!\left(\frac{7}{2}\right) = \frac{5}{2} \cdot \Gamma\!\left(\frac{5}{2}\right) = \frac{5}{2} \cdot \frac{3\sqrt{\pi}}{4} = \frac{15\sqrt{\pi}}{8}$$

> [!tip] 记忆口诀
> 半整数 = 从 $\dfrac{1}{2}$ 开始，每升半步**乘一个递增的系数**：
> $\dfrac{1}{2},\;\dfrac{3}{2},\;\dfrac{5}{2},\;\dfrac{7}{2},\;\ldots$
>


---

### 4️⃣ 四大解题模板

> [!danger] 🔥 模板④为考研极高频变体，务必熟练掌握！

---

#### 模板① 标准套用——直接识别指数

> **例**：计算 $\displaystyle I = \int_{0}^{+\infty} x^4 \mathrm{e}^{-x} \, \mathrm{d}x$

| 步骤 | 操作 |
| :---: | :--- |
| **识别** | $\alpha - 1 = 4 \;\Rightarrow\; \alpha = 5$ |
| **套用** | $I = \Gamma(5)$ |
| **计算** | $\Gamma(5) = 4! = 24$ |

> [!success] 答案：$I = 24$

---

#### 模板② 指数带系数——先换元再套用

> **例**：计算 $\displaystyle I = \int_{0}^{+\infty} x^2 \mathrm{e}^{-3x} \, \mathrm{d}x$

**Step 1 — 换元**：令 $3x = t$，则 $x = \dfrac{t}{3}$，$\mathrm{d}x = \dfrac{1}{3}\mathrm{d}t$

**Step 2 — 代入**：

$$I = \int_{0}^{+\infty} \left(\frac{t}{3}\right)^2 \mathrm{e}^{-t} \cdot \frac{1}{3}\,\mathrm{d}t = \frac{1}{27}\int_{0}^{+\infty} t^2 \mathrm{e}^{-t} \, \mathrm{d}t$$

**Step 3 — 套 Γ 函数**：

$$I = \frac{1}{27}\,\Gamma(3) = \frac{1}{27} \cdot 2! = \frac{2}{27}$$

> [!success] 答案：$I = \dfrac{2}{27}$

---

#### 模板③ 纯高斯型——$\mathrm{e}^{-x^2}$ 无幂函数

> **例**：计算 $\displaystyle I = \int_{0}^{+\infty} \mathrm{e}^{-x^2} \, \mathrm{d}x$

**直接对应** Γ 变形公式的一半：

$$\Gamma\!\left(\frac{1}{2}\right) = 2\int_{0}^{+\infty} \mathrm{e}^{-t^2}\,\mathrm{d}t = \sqrt{\pi}$$

所以：

$$I = \frac{1}{2}\,\Gamma\!\left(\frac{1}{2}\right) = \frac{\sqrt{\pi}}{2}$$

> [!success] 答案：$I = \dfrac{\sqrt{\pi}}{2}$

---

#### 模板④ 必考变体——$x^m \mathrm{e}^{-x^2}$ 型（考研极高频）

> [!danger] 🔥 考研极爱考
> 形如 $\displaystyle\int_{0}^{+\infty} x^m \mathrm{e}^{-x^2} \, \mathrm{d}x$ 的积分，出现频率极高。
> 可直接套用下方的**万能公式**，免去一切分部积分。

**推导**：令 $x^2 = t$，则 $x = \sqrt{t}$，$\mathrm{d}x = \dfrac{1}{2\sqrt{t}}\,\mathrm{d}t$：

$$\int_{0}^{+\infty} x^m \mathrm{e}^{-x^2} \, \mathrm{d}x = \int_{0}^{+\infty} t^{m/2} \cdot \mathrm{e}^{-t} \cdot \frac{1}{2\sqrt{t}}\,\mathrm{d}t = \frac{1}{2}\int_{0}^{+\infty} t^{\frac{m-1}{2}} \mathrm{e}^{-t}\,\mathrm{d}t$$

由此得到万能公式：

$$\boxed{\int_{0}^{+\infty} x^m \mathrm{e}^{-x^2} \, \mathrm{d}x = \frac{1}{2}\,\Gamma\!\left(\frac{m+1}{2}\right)}$$

**实战举例**：计算 $\displaystyle I = \int_{0}^{+\infty} x^2 \mathrm{e}^{-x^2} \, \mathrm{d}x$

| 步骤 | 操作 |
| :---: | :--- |
| **识别** | $m = 2$，代入万能公式 |
| **套用** | $I = \dfrac{1}{2}\,\Gamma\!\left(\dfrac{3}{2}\right)$ |
| **递推** | $\Gamma\!\left(\dfrac{3}{2}\right) = \dfrac{1}{2}\,\Gamma\!\left(\dfrac{1}{2}\right) = \dfrac{\sqrt{\pi}}{2}$ |
| **结果** | $I = \dfrac{1}{2} \cdot \dfrac{\sqrt{\pi}}{2} = \dfrac{\sqrt{\pi}}{4}$ |

> [!success] 答案：$I = \dfrac{\sqrt{\pi}}{4}$

**速查表**（$m = 0 \sim 4$ 常用结果）：

| $m$ | 套用公式 | 结果 |
| :---: | :--- | :---: |
| $0$ | $\dfrac{1}{2}\,\Gamma\!\left(\dfrac{1}{2}\right)$ | $\dfrac{\sqrt{\pi}}{2}$ |
| $1$ | $\dfrac{1}{2}\,\Gamma(1)$ | $\dfrac{1}{2}$ |
| $2$ | $\dfrac{1}{2}\,\Gamma\!\left(\dfrac{3}{2}\right)$ | $\dfrac{\sqrt{\pi}}{4}$ |
| $3$ | $\dfrac{1}{2}\,\Gamma(2)$ | $\dfrac{1}{2}$ |
| $4$ | $\dfrac{1}{2}\,\Gamma\!\left(\dfrac{5}{2}\right)$ | $\dfrac{3\sqrt{\pi}}{8}$ |

> [!note] 模板③是模板④的特例
> 当 $m = 0$ 时，模板④退化为模板③（纯高斯型）。
> 两个模板本质上共享同一个推导逻辑。

## ⚠️ 易错点速查

### 通用类

| # | 易错点 | 说明 |
| :---: | :--- | :--- |
| 1 | **识别奇点是关键** | 端点和内部都要检查 |
| 2 | **含绝对值的积分** | 要小心处理，拆区间去绝对值 |
| 3 | **无界函数的反常积分** | 可能要拆区间处理 |

### Γ 函数类

| # | 易错点 | 说明 |
| :---: | :--- | :--- |
| 4 | **常用反常积分结果** | $\displaystyle\int_0^{+\infty} \mathrm{e}^{-x^2}\mathrm{d}x = \frac{\sqrt{\pi}}{2}$ |
| 5 | **Γ 函数使用前提** | 区间必须是 $[0, +\infty)$；若为 $(-\infty, +\infty)$ 先用偶函数性质化为 $2\displaystyle\int_0^{+\infty}$ |
| 6 | **指数对应关系** | 看到 $x^n$，参数是 $n+1$（即 $\Gamma(n+1)$） |
| 7 | **换元要彻底** | $\mathrm{e}$ 的指数不是 $-x$ 或 $-x^2$ 时，必须先换元把系数挪到 $\mathrm{d}t$ 外面 |
| 8 | **带 $x^2$ 的变体公式** | 看到 $\displaystyle\int_0^{+\infty} x^m \mathrm{e}^{-x^2}\mathrm{d}x$ 直接套 $\dfrac{1}{2}\Gamma\!\left(\dfrac{m+1}{2}\right)$，不要再从头换元推导 |
