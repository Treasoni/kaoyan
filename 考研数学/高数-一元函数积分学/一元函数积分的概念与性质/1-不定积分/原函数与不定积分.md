# 原函数与不定积分

## 📌 知识点定位

| 项目 | 内容 |
|------|------|
| **所属模块** | 高数-一元函数积分学 > 不定积分 |
| **重要程度** | ⭐⭐⭐⭐⭐ |
| **考研要求** | 理解原函数的概念，理解不定积分的概念 |

---

## 🎯 核心概念（一句话记住）

> [!tip] 记忆口诀
> **"求导的逆运算"** —— 找一个函数 $F(x)$，让它求导后等于 $f(x)$

---

## 📖 定义详解

### 一、原函数

> [!abstract] 定义
> 设函数 $f(x)$ 定义在某区间 $I$ 上，若存在可导函数 $F(x)$，对于该区间上**任意一点**都有
> $$F'(x) = f(x)$$
> 成立，则称 $F(x)$ 是 $f(x)$ 在区间 $I$ 上的**一个原函数**。

### 二、不定积分

> [!abstract] 定义
> $$\int f(x)dx = F(x) + C$$
> 称为 $f(x)$ 在区间 $I$ 上的**不定积分**。

> [!note] 三个关键点
> 1. **$\int f(x)dx$** = 全体原函数（不是某一个！）
> 2. **$+C$** = 任意常数，不能省略！
> 3. **必须指明区间** —— 不同区间可能有不同的原函数

---

## 🔑 核心理解

### 为什么强调"一个"原函数？

```
若 F'(x) = f(x)，则对任意常数 C：
[F(x) + C]' = F'(x) + 0 = f(x) ✓

结论：原函数若有，必有无穷多个！
```

### 原函数 vs 不定积分

| 对比项 | 原函数 | 不定积分 |
|--------|--------|----------|
| **符号** | $F(x)$ | $\int f(x)dx$ |
| **含义** | **某一个**满足 $F' = f$ 的函数 | **全体**原函数 |
| **数量** | 一个（特指） | 无穷多个（集合） |
| **形式** | $F(x)$ | $F(x) + C$ |

---

## 🔗 逻辑链条：原函数的连续性

> [!important] 核心结论
> **只要原函数存在，它一定是连续函数！**

### 推导过程

$$f(x) \text{ 连续} \xRightarrow{\text{微积分基本定理}} F(x) \text{ 可导} \xRightarrow{\text{可导必连续}} F(x) \text{ 连续}$$

### 逐层解析

> [!success] 第一层：$f$ 连续 $\Rightarrow$ $F$ 可导
> 变上限积分 $\Phi(x) = \int_a^x f(t)dt$ 可导，且 $\Phi'(x) = f(x)$

> [!success] 第二层：$F$ 可导 $\Rightarrow$ $F$ 连续
> $$\lim_{\Delta x \to 0} [F(x+\Delta x) - F(x)] = F'(x) \cdot 0 = 0$$

> [!warning] 反向不成立！
> - 连续 $\nRightarrow$ 可导（反例：$|x|$ 在 $0$ 处）
> - $F$ 连续 $\nRightarrow$ $f$ 连续（导函数可以不连续）

### 考点应用

> [!example] 做题技巧
> **原函数必连续** —— 可用来快速排除选项！
>
> 遇到分段函数的原函数问题：
> 1. 分别求出各段的原函数
> 2. 用**连续性**确定常数（左右极限相等）
> 3. 验证分界点处导数是否正确

---

## 📊 三种积分形式对比

| 形式 | 名称 | 本质 | 结果类型 |
|------|------|------|----------|
| $\int f(x)dx$ | 不定积分 | 全体原函数 | **函数族** $F(x)+C$ |
| $\int_a^b f(x)dx$ | 定积分 | 曲边梯形面积 | **数值** |
| $\int_a^x f(t)dt$ | 变上限积分 | 动态面积 | **函数** $\Phi(x)$ |

## 🎯 典型例题

### 例题1：基本概念应用

> [!question] 题目
> 设 $0 < x < 1$，且 $\int (1-x^2)f(x^2)dx = \arcsin x + C$，则 $f(x) = (\quad)$

**解题思路**：原函数定义的逆向应用

$$\text{若 } \int g(x)dx = F(x) + C \text{，则 } F'(x) = g(x)$$

**解答过程**：

$$\begin{aligned}
\left[\int (1-x^2)f(x^2)dx\right]' &= (\arcsin x + C)' \\[6pt]
(1-x^2)f(x^2) &= \frac{1}{\sqrt{1-x^2}} \\[6pt]
f(x^2) &= (1-x^2)^{-\frac{3}{2}} \\[6pt]
f(x) &= \boxed{(1-x)^{-\frac{3}{2}}}
\end{aligned}$$

---

### 例题2：分段函数的原函数

> [!question] 题目
> 函数 $f(x) = \begin{cases} \sqrt{1+x^2}, & x < 0 \\ (x+1)\cos x, & x > 0 \end{cases}$ 的一个原函数为（ ）

**解题要点**：

```
┌─────────────────────────────────────────────┐
│  1. 分别求各段原函数                          │
│  2. 利用 "原函数必连续" 确定常数              │
│  3. 验证分界点 x=0 处导数正确                 │
└─────────────────────────────────────────────┘
```

> [!check] 检验步骤
> - [ ] $x<0$ 段积分正确
> - [ ] $x>0$ 段积分正确
> - [ ] $\lim_{x\to 0^-}F(x) = \lim_{x\to 0^+}F(x)$
> - [ ] $F'(0) = f(0)$（如果 $f$ 在 $0$ 有定义）

## ⚠️ 易错点清单

| 易错点 | 错误表现 | 正确做法 |
|--------|----------|----------|
| **忘记常数** | $\int x dx = \frac{1}{2}x^2$ | $= \frac{1}{2}x^2 + C$ |
| **忽略连续性** | 分段原函数不验证分界点 | 必须验证 $\lim_{左}=\lim_{右}$ |
| **区间问题** | 不同区间用同一原函数 | 注意定义域，分段讨论 |
| **概念混淆** | 原函数 = 不定积分 | 原函数是"一个"，不定积分是"全体" |

> **做题警觉口诀**：看到"原函数"三个字 → 立刻拉响连续性警报！
> - "原函数" = **处处可导** + **处处连续**
