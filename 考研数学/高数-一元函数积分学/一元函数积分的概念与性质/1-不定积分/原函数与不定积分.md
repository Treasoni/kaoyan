# 原函数与不定积分

## 📌 知识点定位

**所属模块**：高数-一元函数积分学 > 不定积分
**重要程度**：⭐⭐⭐⭐⭐
**考研要求**：理解原函数的概念，理解不定积分的概念

## 📖 核心概念

### 原函数定义

设函数 $f(x)$ 定义在某区间 $I$ 上，若存在可导函数 $F(x)$，对于该区间上任意一点都有
$$F'(x) = f(x)$$
成立，则称 $F(x)$ 是 $f(x)$ 在区间 $I$ 上的一个**原函数**。

### 不定积分定义

称
$$\int f(x)dx = F(x) + C$$
为 $f(x)$ 在区间 $I$ 上的**不定积分**。

> [!note] 重要说明
> - $\int f(x)dx$ 称为不定积分，表示**全体原函数**
> - $F(x) + C$ 中的 $C$ 为任意常数，代表原函数的一般形式
> - 谈到原函数与不定积分，必须指明 $f(x)$ 所定义的区间

## 🔑 关键要点

### 为什么强调"一个"原函数？

因为若 $F'(x) = f(x)$，则对于任意常数 $C$，都有
$$[F(x) + C]' = F'(x) = f(x)$$

故 $F(x) + C$ 也是原函数，所以 $f(x)$ 若有原函数，则原函数一定有无穷多个，$F(x) + C$ 称为**全体原函数**。

### 原函数与导函数的关系

#### 1. 核心前提

若函数 $F(x)$ 是 $f(x)$ 的一个原函数，即满足：
$$F'(x) = f(x)$$

#### 2. 逻辑推导链

根据导数与连续性的基本定理，可以得到如下推导：

$$f(x) \text{ 处处连续} \implies F(x) \text{ 处处可导} \implies F(x) \text{ 处处连续}$$

#### 3. 详细要点解析

**第一步（连续 $\implies$ 可导）**：若 $f(x)$ 在区间内连续，根据微积分基本定理，变上限积分函数 $\Phi(x) = \int_{a}^{x} f(t)dt$ 在该区间内处处可导，且 $\Phi'(x) = f(x)$。

**第二步（可导 $\implies$ 连续）**：这是函数的基本性质。如果函数 $F(x)$ 在某点可导，则它在该点必然连续。即：
$$\lim_{\Delta x \to 0} [F(x+\Delta x) - F(x)] = \lim_{\Delta x \to 0} \frac{F(x+\Delta x) - F(x)}{\Delta x} \cdot \Delta x = F'(x) \cdot 0 = 0$$

#### 4. 核心结论深化

即便 $f(x)$ 在某点不连续，只要 $F(x)$ 是 $f(x)$ 的原函数（即满足 $F'(x) = f(x)$ 处处成立），那么：

> [!important] $F(x)$ 依然必须是处处连续的

**证明逻辑**：根据导数的定义，如果 $F(x)$ 在某点可导（等于 $f(x)$），那么它在该点必须连续（可导必连续）。所以，**只要原函数存在，它就一定是连续函数**。

#### 5. 易错点警示（反向不成立）

> [!warning] 注意：该逻辑链条是单向的
> - $F(x)$ 连续 $\nRightarrow F(x)$ 可导（例如 $F(x) = |x|$ 在 $0$ 处连续但不可导）
> - $F(x)$ 连续 $\nRightarrow f(x)$ 连续（导函数不一定连续，存在含有震荡间断点的导函数）

## 📝 三种积分形式辨析

| 形式 | 名称 | 含义 |
|------|------|------|
| $\int f(x)dx$ | 不定积分 | 全体原函数 |
| $\int_a^b f(x)dx$ | 定积分 | 面积（数值） |
| $F(x) = \int_a^x f(t)dt$ | 变上限积分 | 动态面积（函数） |

## 🎯 典型例题

### 例题1：基本概念应用

设 $0 < x < 1$，且 $\int (1-x^2)f(x^2)dx = \arcsin x + C$，则 $f(x) = (\quad)$

**分析**：按照原函数定义，若 $\int \overline{f(x)}dx = F(x) + C$，则 $F'(x) = f(x)$

**解**：应选 $(B)$ $(1-x)^{-\frac{3}{2}}$

根据原函数 $F(x)$ 的定义 $F'(x) = f(x)$ 求解。

将所给表达式的等式两端分别关于 $x$ 求导，得：
$$\left[\int (1-x^2)f(x^2)dx\right]' = (\arcsin x + C)'$$

即：
$$2x(1-x^2)f(x^2) = \frac{1}{\sqrt{1-x^2}}$$

故 $f(x^2) = (1-x^2)^{-\frac{3}{2}}$

$$f(x) = (1-x)^{-\frac{3}{2}}$$

### 例题2：分段函数的原函数

函数 $f(x) = \begin{cases} \sqrt{1+x^2}, & x < 0 \\ (x+1)\cos x, & x > 0 \end{cases}$ 的一个原函数为（ ）

**分析**：$F'(x) = f(x)$。由 $f(x)$ 处处有定义得 $F(x)$ 处处可导，推出 $F(x)$ 处处连续。

**关键点**：
1. 原函数必连续
2. 需验证左右极限相等
3. 需验证导数正确

## ⚠️ 易错点

1. **忽略连续性**：原函数必连续，可用此排除选项
2. **区间问题**：原函数的存在依赖于具体区间
3. **任意常数**：不定积分必须加常数 $C$
