## 🎯 学习路线

```
阶段1: 不定积分 (8-10小时)
  定义性质 → 第一换元法 → 第二换元法
       ↓
  分部积分法 → 特殊类型积分
       ↓
阶段2: 定积分 (6-8小时)
  定义性质 → 微积分基本定理 → 计算方法
       ↓
  反常积分
       ↓
阶段3: 定积分应用 (4-6小时)
  几何应用 → 物理应用
```
