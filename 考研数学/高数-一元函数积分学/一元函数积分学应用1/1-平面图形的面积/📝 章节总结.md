# 平面图形的面积 - 章节总结

## 核心公式汇总

### 1. 直角坐标系

曲线 $y = y_1(x)$ 与 $y = y_2(x)$ 及 $x = a$，$x = b$（$a < b$）所围面积：

$$S = \int_a^b |y_1(x) - y_2(x)| \, \mathrm{d}x$$

### 2. 极坐标系

曲线 $r = r_1(\theta)$ 与 $r = r_2(\theta)$ 与射线 $\theta = \alpha$、$\theta = \beta$（$0 < \beta - \alpha \leqslant 2\pi$）所围面积：

$$S = \int_\alpha^\beta \frac{1}{2}|r_2^2(\theta) - r_1^2(\theta)| \, \mathrm{d}\theta$$

**退化形式**（从极点出发，$r_1 = 0$）：

$$S = \frac{1}{2}\int_\alpha^\beta r^2(\theta) \, \mathrm{d}\theta$$

### 3. 参数方程

曲线 $\begin{cases} x = x(t) \\ y = y(t) \end{cases}$ 所围面积：

$$S = \int_\alpha^\beta y(t) \cdot x'(t) \, \mathrm{d}t$$

**本质**：直角坐标系面积公式的换元法形式

---

## 推导思路：微元法

### 直角坐标系微元

$$\Delta S = |y_1(x) - y_2(x)| \, \mathrm{d}x$$

### 极坐标系微元

用经过极点的射线切分，微元扇环近似为三角形：

$$\mathrm{d}S = \frac{1}{2}|r_2^2(\theta) - r_1^2(\theta)| \, \mathrm{d}\theta$$

### 参数方程微元

换元对照表：

| 替换对象 | 操作 |
| -------- | ---- |
| 纵坐标 | $y = f(x) \to y(t)$ |
| 微分项 | $\mathrm{d}x \to x'(t)\,\mathrm{d}t$ |
| 积分限 | $x=a \Rightarrow t=t_1$，$x=b \Rightarrow t=t_2$ |

---

## 关键点

- **绝对值保证面积非负**：三种公式都含绝对值
- **大减小**：用上（外）函数减去下（内）函数
- **对称性简化**：如伯努利双纽线 $r^2 = a^2\cos 2\theta$，只需算第一象限再乘2
- **参数方程是换元**：给定参数方程本质是考查定积分换元法
- **反常积分**：可能用到收敛的反常积分计算面积

---

## 常见错误

| 错误 | 后果 |
| ---- | ---- |
| 忘记取绝对值 | 面积为负 |
| 参数方程遗漏 $x'(t)$ | 结果错误 |
| 积分上下限颠倒 | 结果为负 |
| 极坐标忘记 $\frac{1}{2}$ 系数 | 结果翻倍 |

## 典型例题

### 摆线面积

摆线 $\begin{cases} x = a(t - \sin t) \\ y = a(1 - \cos t) \end{cases}$（$a > 0$）一拱与 $x$ 轴所围面积：

$$S = \int_0^{2\pi} a(1 - \cos t) \cdot a(1 - \cos t) \, \mathrm{d}t = 3a^2\pi$$

### 验证例题

参数方程 $\begin{cases} x = 2t \\ y = t^2 \end{cases}$，$t \in [0, 1]$：

**方法A（消参）**：$y = \frac{1}{4}x^2$，$\int_0^2 \frac{1}{4}x^2 \, \mathrm{d}x = \frac{2}{3}$

**方法B（参数公式）**：$\int_0^1 t^2 \cdot 2 \, \mathrm{d}t = \frac{2}{3}$
