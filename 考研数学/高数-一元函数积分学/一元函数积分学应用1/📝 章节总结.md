# 📝 一元函数积分学应用1 — 章节总结

> 本章核心：定积分的几何应用，涵盖平面图形面积、旋转体体积、函数平均值及其他几何量（弧长、旋转曲面面积、形心、平行截面体积）的计算。**微元法**是贯穿全章的核心方法。

---

## 一、平面图形的面积

### 1. 直角坐标系

曲线 $y = y_1(x)$ 与 $y = y_2(x)$ 及 $x = a$，$x = b$（$a < b$）所围面积：

$$\boxed{S = \int_a^b \vert y_1(x) - y_2(x) \vert \, \mathrm{d}x}$$

- 微元：$\mathrm{d}S = \vert y_1(x) - y_2(x) \vert \, \mathrm{d}x$
- **易错**：忘记取绝对值导致面积为负
- 可能用到收敛的反常积分

### 2. 极坐标系

曲线 $r = r_1(\theta)$ 与 $r = r_2(\theta)$ 及 $\theta = \alpha$、$\theta = \beta$（$0 < \beta - \alpha \leqslant 2\pi$）所围曲边扇形面积：

$$\boxed{S = \int_\alpha^\beta \frac{1}{2}\vert r_2^2(\theta) - r_1^2(\theta) \vert \, \mathrm{d}\theta}$$

- 微元（扇环近似为三角形）：$\mathrm{d}S = \frac{1}{2}\vert r_2^2 - r_1^2 \vert \, \mathrm{d}\theta$
- 当 $r_1 = 0$（从极点出发）时退化：$S = \dfrac{1}{2}\displaystyle\int_\alpha^\beta r^2(\theta) \, \mathrm{d}\theta$
- 常用对称性简化（如双纽线 $r^2 = a^2\cos 2\theta$）

### 3. 参数方程

曲线由 $\begin{cases} x = x(t) \\ y = y(t) \end{cases}$ 给出时：

$$\boxed{S = \int_\alpha^\beta y(t) \cdot x'(t) \, \mathrm{d}t}$$

- 本质：直角坐标系面积公式的**换元法形式**
- 需正确确定参数 $t$ 的范围 $\alpha, \beta$

### 换元替换对照

| 替换对象 | 操作 |
| -------- | ---- |
| 纵坐标 | $y = f(x) \to y(t)$ |
| 微分项 | $\mathrm{d}x \to x'(t)\,\mathrm{d}t$（**极易遗漏**） |
| 积分限 | $x=a \Rightarrow t=t_1$，$x=b \Rightarrow t=t_2$ |

### 典型例题

> [!example] 摆线一拱面积
> 摆线 $\begin{cases} x = a(t - \sin t) \\ y = a(1 - \cos t) \end{cases}$（$a > 0$）一拱与 $x$ 轴所围面积：
>
> $$S = \int_0^{2\pi} a(1 - \cos t) \cdot a(1 - \cos t) \, \mathrm{d}t = 3a^2\pi$$

> [!example] 实例验证（直角坐标 vs 参数方程）
> 参数方程 $\begin{cases} x = 2t \\ y = t^2 \end{cases}$，$t$ 从 $0$ 到 $1$ 时与 $x$ 轴围成面积。
>
> **消参法**：$y = \dfrac{1}{4}x^2$，$A = \displaystyle\int_0^2 \frac{1}{4}x^2 \, \mathrm{d}x = \frac{2}{3}$
>
> **参数法**：$x'(t) = 2$，$A = \displaystyle\int_0^1 t^2 \cdot 2 \, \mathrm{d}t = \frac{2}{3}$ ✅

## 二、旋转体的体积

### 1. 绕 $x$ 轴旋转（圆盘法）

$$\boxed{V_x = \pi \int_a^b y^2(x) \, \mathrm{d}x}$$

- 微元：$\mathrm{d}V = \pi y^2(x) \, \mathrm{d}x$（圆盘面积 × 厚度）
- 先确定函数定义域（如 $\sqrt{\sin x}$ 要求 $\sin x \geqslant 0$）

### 2. 绕 $y$ 轴旋转（圆柱壳法）

$$\boxed{V_y = 2\pi \int_a^b x\vert y(x) \vert \, \mathrm{d}x}$$

- 微元（圆柱壳展开为长方体）：$\mathrm{d}V = \underbrace{2\pi x}_{\text{周长}} \cdot \underbrace{\vert y(x) \vert}_{\text{高度}} \cdot \underbrace{\mathrm{d}x}_{\text{厚度}}$
- 记忆口诀：$V_x$ 往"$\pi$"里代，$V_y$ 前面是 $2\pi$

> [!tip] 技巧
> 利用反函数，可将绕 $x$ 轴旋转用 $V_y$ 公式表示（$x$、$y$ 地位交换）。

### 3. 绕定直线旋转

曲线 $y = f(x)$ 绕直线 $L_0: Ax + By + C = 0$ 旋转（过 $L_0$ 的垂线与曲线至多一个交点）：

$$\boxed{V = \frac{\pi}{(A^2 + B^2)^{3/2}} \int_a^b [Ax + Bf(x) + C]^2 \vert Af'(x) - B \vert \, \mathrm{d}x}$$

- 当 $A = C = 0$ 时退化为绕 $x$ 轴公式
- **使用条件**：过 $L_0$ 的垂线与曲线至多一个交点
- 掌握结论、会套公式即可，考试可直接使用

## 三、函数的平均值

$$\boxed{\bar{y} = \frac{1}{b - a} \int_a^b y(x) \, \mathrm{d}x}$$

- 由积分中值定理：$\bar{y} = y(\xi)$，$\xi \in [a, b]$
- 常与函数方程、变限积分综合考查
- 观察 $f(x+T) - f(x)$ 形式 → 联想构造 $F(x) = \int_x^{x+T} f(t) \, \mathrm{d}t$

## 四、其他几何应用

### 1. 平面曲线的弧长（仅数学一、二）

| 坐标系 | 弧长公式 |
|--------|----------|
| 直角坐标 $y = y(x)$ | $s = \displaystyle\int_a^b \sqrt{1 + [y'(x)]^2} \, \mathrm{d}x$ |
| 参数方程 | $s = \displaystyle\int_\alpha^\beta \sqrt{[x'(t)]^2 + [y'(t)]^2} \, \mathrm{d}t$ |
| 极坐标 $r = r(\theta)$ | $s = \displaystyle\int_\alpha^\beta \sqrt{[r(\theta)]^2 + [r'(\theta)]^2} \, \mathrm{d}\theta$ |

### 2. 旋转曲面的面积（仅数学一、二）

> 核心关系：在弧长微元 $\mathrm{d}s$ 基础上乘以 $2\pi\vert y \vert$（旋转周长）

| 坐标系 | 侧面积公式（绕 $x$ 轴） |
|--------|--------------------------|
| 直角坐标 | $S = 2\pi \displaystyle\int_a^b \vert y \vert \sqrt{1 + (y')^2} \, \mathrm{d}x$ |
| 参数方程 | $S = 2\pi \displaystyle\int_\alpha^\beta \vert y(t) \vert \sqrt{(x'_t)^2 + (y'_t)^2} \, \mathrm{d}t$ |
| 极坐标 | $S = 2\pi \displaystyle\int_\alpha^\beta \vert r\sin\theta \vert \sqrt{r^2 + (r')^2} \, \mathrm{d}\theta$ |

> [!note] 体积 vs 侧面积
> - 算体积用 $\mathrm{d}x$（圆盘/壳）
> - 算侧面积用 $\mathrm{d}s$（弧微分），$S = 2\pi\vert f(x) \vert \, \mathrm{d}s$

### 3. 形心坐标公式（仅数学一、二）

平面区域 $D: 0 \leqslant y \leqslant f(x)$，$a \leqslant x \leqslant b$ 的形心：

$$\bar{x} = \frac{\displaystyle\int_a^b xf(x) \, \mathrm{d}x}{\displaystyle\int_a^b f(x) \, \mathrm{d}x}, \qquad \bar{y} = \frac{\dfrac{1}{2}\displaystyle\int_a^b f^2(x) \, \mathrm{d}x}{\displaystyle\int_a^b f(x) \, \mathrm{d}x}$$

### 4. 平行截面面积为已知的立体体积（仅数学一、二）

截面面积函数 $A(x)$：

$$\boxed{V = \int_a^b A(x) \, \mathrm{d}x}$$

- 本质：旋转体体积公式的一般化（$A(x) = \pi f^2(x)$ 时退化为圆盘法）
- 考研历史中尚未出现过，理解"微元法"思想即可

## 六、易错点汇总

| 错误表现             | 正确做法                                                          |
| ---------------- | ------------------------------------------------------------- |
| 面积公式忘记取绝对值       | 始终用 $\vert y_1 - y_2 \vert$，保证非负                              |
| 参数方程面积漏掉 $x'(t)$ | 记注是换元：$\mathrm{d}x = x'(t)\,\mathrm{d}t$                      |
| 绕 $y$ 轴体积记错公式    | 圆柱壳法：$V_y = 2\pi\int x\vert y \vert \, \mathrm{d}x$           |
| 绕定直线旋转不满足使用条件    | 确认垂线与曲线至多一个交点                                                 |
| 弧长与侧面积混淆         | 弧长用 $\mathrm{d}s$，侧面积 = $2\pi\vert y \vert \cdot \mathrm{d}s$ |
| 忽视对称性导致计算冗余      | 观察图形对称性，先算一部分再乘倍数                                             |

## 七、方法论总结

### 微元法三步走

1. **取微元**：在小区间上用"以直代曲"构造 $\mathrm{d}A = f(x)\,\mathrm{d}x$
2. **确定积分限**：找到变量的变化范围 $[a, b]$
3. **积分求和**：$A = \int_a^b \mathrm{d}A$

### 解题一般流程

1. 画图（或想象）确定积分区域
2. 选择合适的坐标系（直角/极坐标/参数方程）
3. 套用对应公式
4. 利用对称性简化
5. 计算定积分
