## 概述
���微分法（第一换元法）是复合函数链式求导的逆用，是最常用的积分方法之一。

## 核心方法
$$\int f[g(x)] g'(x) \mathrm{d}x = \int f[g(x)] \mathrm{d}[g(x)] = \int f(u) \mathrm{d}u$$

 其中 $u = g(x)$

## 屘用凑微分公式
1. **幂函数凑微分**：
   - $x\mathrm{d}x = \frac{1}{2}\mathrm{d}(x^2)$
   - $\int xf(x^2)\mathrm{d}x = \frac{1}{2}\int f(u)\mathrm{d}u$



2. **根式凑微分**：
   - $\sqrt{x}\mathrm{d}x = \frac{2}{3}\mathrm{d}(x^{3/2})$
   - $\int \sqrt{x} f(x^{3/2})\mathrm{d}x = \frac{2}{3}\int f(u)\mathrm{d}u$



3. **负幂凑微分**：
   - $\frac{\mathrm{d}x}{x^2} = \mathrm{d}\left(-\frac{1}{x}\right)$
   - $\int \frac{f\left(-\frac{1}{x}\right)}{x^2} \mathrm{d}x = \int f(u)\mathrm{d}u$
   - $\int \frac{f(\ln x)}{x}\mathrm{d}x = \int f(\ln x)\mathrm{d}(\ln x) = \int f(u)\mathrm{d}u$

   - 特别注意： 当 $x > 0$ 时, $\frac{1}{x}\mathrm{d}x = \mathrm{d}(\ln x)$

   - $x \leq 0$ 时, $\int \frac{f(\ln x)}{x}\mathrm{d}x = \int f(\ln x)\mathrm{d}(\ln |x|) + C$（需要讨论）

   - $\int \frac{f(\ln |x|)}{x} \mathrm{d}x = \int f(\ln |x)\mathrm{d}(\ln |x|) = \int f(u)\mathrm{d}u$

   - 此时: $u = \ln |x|$

5. **指数函数凑微分**：
   - $e^x\mathrm{d}x = \mathrm{d}(e^x)$
   - $\int e^x f(e^x)\mathrm{d}x = \int f(e^x)\mathrm{d}(e^x) = \int f(u)\mathrm{d}u$

   - $a^x\mathrm{d}x = \frac{1}{\ln a}\mathrm{d}(a^x)$

   - $\int a^x f(a^x)\mathrm{d}x = \frac{1}{\ln a}\int f(a^x)\mathrm{d}(a^x) = \frac{1}{\ln a}\int f(u)\mathrm{d}u$
   - 特别注意: $a > 0$ 且 $a \neq 1$

6. **三角函数凑微分**：
   - $\sin x \mathrm{d}x = \mathrm{d}(-\cos x)$
   - $\int \sin x \cdot f(-\cos x) \mathrm{d}x = \int f(-\cos x)\mathrm{d}(-\cos x) = \int f(u)\mathrm{d}u$
   - $\cos x \mathrm{d}x = \mathrm{d}(\sin x)$
   - $\int \cos x \cdot f(\sin x) \mathrm{d}x = \int f(\sin x)\mathrm{d}(\sin x) = \int f(u)\mathrm{d}u$

7. **正割/余割凑微分**：
   - $\frac{\mathrm{d}x}{\cos^2 x} = \sec^2 x \mathrm{d}x = \mathrm{d}(\tan x)$
   - $\int \frac{f(\tan x)}{\cos^2 x} \mathrm{d}x = \int f(\tan x)\mathrm{d}(\tan x) = \int f(u)\mathrm{d}u$
   - $\frac{\mathrm{d}x}{\sin^2 x} = \csc^2 x \mathrm{d}x = \mathrm{d}(-\cot x)$
   - $\int \frac{f(-\cot x)}{\sin^2 x} \mathrm{d}x = \int f(-\cot x)\mathrm{d}(-\cot x) = \int f(u)\mathrm{d}u$

8. **反三角函数凑微分**：
   - $\frac{1}{1+x^2} \mathrm{d}x = \mathrm{d}(\arctan x)$
   - $\int \frac{f(\arctan x)}{1+x^2} \mathrm{d}x = \int f(\arctan x)\mathrm{d}(\arctan x) = \int f(u)\mathrm{d}u$
   - $\frac{1}{\sqrt{1-x^2}} \mathrm{d}x = \mathrm{d}(\arcsin x)$
   - $\int \frac{f(\arcsin x)}{\sqrt{1-x^2}} \mathrm{d}x = \int f(\arcsin x)\mathrm{d}(\arcsin x) = \int f(u)\mathrm{d}u$

## 层题技巧
### 对复杂部分求导
若不是常用的凑微分公式，可对被积函数的复杂部分 $g(x)$ 求导：
- 若 $g'(x) = f(x)$， 即 $\mathrm{d}[g(x)] = f(x)\mathrm{d}x$
- 则 $\int f(x)g(x)\mathrm{d}x = \int g(x)\mathrm{d}[g(x)]$，凑微分成功

### 例题
**例9.1** 求不定积分 $\int \frac{\sqrt{x}}{\sqrt{4-x^3}} \mathrm{d}x$

**解**：
$$\int \frac{\sqrt{x}}{\sqrt{4-x^3}} \mathrm{d}x = \frac{2}{3}\int \frac{\mathrm{d}(x^{3/2})}{\sqrt{4-(x^{3/2})^2}}$$
$$= \frac{2}{3}\int \frac{\mathrm{d}\left(\frac{1}{2}x^{3/2}\right)}{\sqrt{1-\left(\frac{1}{2}x^{3/2}\right)^2}} = \frac{2}{3}\arcsin \left(\frac{1}{2}x^{3/2}\right) + C$$

$$= \frac{2}{3}\arcsin \frac{x^{3/2}}{2} + C$$
