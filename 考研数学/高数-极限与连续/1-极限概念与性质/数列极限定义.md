# 数列极限定义

> [!info] 概述
> **数列极限**是微积分理论的起点，描述了数列项随项数增大而"无限接近"某个固定值的行为。理解数列极限的 $\varepsilon$-$N$ 定义是掌握整个极限理论的基础。

## 1. 数列极限的 ε-N 定义

### 定义

> [!def] 数列极限
> 设 $\{x_n\}$ 为一数列，如果存在常数 $a$，对于**任意给定的正数** $\varepsilon$（不论它多么小），**总存在正整数** $N$，使得当 $n > N$ 时，不等式
> $$
> |x_n - a| < \varepsilon
> $$
> 都成立，则称常数 $a$ 是数列 $\{x_n\}$ 的极限，或称数列 $\{x_n\}$ **收敛于** $a$，记为
> $$
> \lim_{n \to \infty} x_n = a \quad \text{或} \quad x_n \to a \ (n \to \infty)
> $$

### ε-N 语言的逻辑结构

$$
\lim_{n \to \infty} x_n = a \Leftrightarrow \forall \varepsilon > 0, \exists N > 0, \text{ 当 } n > N \text{ 时，有 } |x_n - a| < \varepsilon
$$

| 符号 | 含义 | 作用 |
|------|------|------|
| $\forall \varepsilon > 0$ | 任意小的正数 | 描述"任意接近"的程度 |
| $\exists N > 0$ | 存在某个分界点 | 标记"从哪一项开始" |
| $n > N$ | 项数足够大 | 确保在分界点之后 |
| $|x_n - a| < \varepsilon$ | 距离足够近 | 保证接近目标值 |

### 直观理解 💡

**核心思想**：只要你想让 $x_n$ 与 $a$ 的距离小于任意给定的 $\varepsilon$，我就总能找到一个分界点 $N$，使得从第 $N+1$ 项开始，所有项都满足你的要求。

**类比说明**：
- $\varepsilon$ 是你提出的"精度要求"（比如误差不超过 0.001）
- $N$ 是我的"承诺位置"（比如从第 100 项开始保证满足）
- 只要你提出任何精度要求，我都能找到对应的承诺位置

**几何意义**：
```
        a-ε        a          a+ε
         ◞─────────┼─────────◟
         └─────────────────────┘
                  收敛域

从第 N+1 项开始，所有 x_n 都落入这个收敛域内
```

## 2. 数列极限的性质

### 性质1：唯一性 ⭐

> [!thm] 极限的唯一性
> 如果数列 $\{x_n\}$ 收敛，那么它的极限**唯一**。

**直观理解**：数列不可能同时无限接近两个不同的值。

**证明思路**（反证法）：
假设 $\lim_{n \to \infty} x_n = a$ 且 $\lim_{n \to \infty} x_n = b$，且 $a \neq b$。
取 $\varepsilon = \frac{|a - b|}{2}$，由极限定义：
- 存在 $N_1$，当 $n > N_1$ 时，$|x_n - a| < \varepsilon$
- 存在 $N_2$，当 $n > N_2$ 时，$|x_n - b| < \varepsilon$

取 $N = \max(N_1, N_2)$，当 $n > N$ 时：
$$|a - b| = |(x_n - b) - (x_n - a)| \leq |x_n - b| + |x_n - a| < 2\varepsilon = |a - b|$$

矛盾！因此假设不成立，极限唯一。

---

### 性质2：有界性 ⭐

> [!thm] 收敛数列的有界性
> 如果数列 $\{x_n\}$ 收敛，那么数列 $\{x_n\}$ **一定有界**。

**直观理解**：既然数列项都聚集在极限值附近，那当然不会无限增大。

**注意**：有界数列**不一定收敛**（如 $x_n = (-1)^n$ 有界但发散）

**证明思路**：
设 $\lim_{n \to \infty} x_n = a$，取 $\varepsilon = 1$，存在 $N$，当 $n > N$ 时，$|x_n - a| < 1$。
此时 $|x_n| < |a| + 1$。

取 $M = \max\{|x_1|, |x_2|, \ldots, |x_N|, |a| + 1\}$，则对所有 $n$，$|x_n| \leq M$。

---

### 性质3：保号性 ⭐

> [!thm] 数列极限的保号性
> 如果 $\lim_{n \to \infty} x_n = a$，且 $a > 0$（或 $a < 0$），那么**存在正整数** $N$，当 $n > N$ 时，都有 $x_n > 0$（或 $x_n < 0$）。

**推论**：如果从某项起 $x_n \geq 0$（或 $x_n \leq 0$），且 $\lim_{n \to \infty} x_n = a$，则 $a \geq 0$（或 $a \leq 0$）。

**直观理解**：极限为正，那么足够靠后的项也必须为正（不会突然变负）。

**注意**：即使是所有项 $x_n > 0$，极限也可能是 $0$（如 $x_n = \frac{1}{n}$）

## 3. 数列极限的收敛准则

### 准则1：夹逼准则（夹逼定理）⭐⭐⭐

> [!thm] 夹逼准则
> 如果数列 $\{x_n\}$，$\{y_n\}$，$\{z_n\}$ 满足下列条件：
> 1. 从某项起，$y_n \leq x_n \leq z_n$
> 2. $\lim_{n \to \infty} y_n = a$，$\lim_{n \to \infty} z_n = a$
>
> 那么数列 $\{x_n\}$ 的极限存在，且 $\lim_{n \to \infty} x_n = a$

**几何意义**：
```
y_n ──────╱             ╲──── a
           ╲           ╱
x_n ──────╳─────────╳──── a
           ╱           ╲
z_n ──────╲             ╱──── a

当 y_n 和 z_n 都趋近 a 时，夹在中间的 x_n 也必须趋近 a
```

**典型应用**：
- 处理复杂的和式极限
- 处理含有 $n$ 个分式的极限
- 处理三角函数相关的极限

> [!example] 例1：夹逼准则应用
> **题目**：求 $\lim_{n \to \infty} \left(\frac{1}{n^2 + n + 1} + \frac{2}{n^2 + n + 2} + \cdots + \frac{n}{n^2 + n + n}\right)$
>
> **解答**：
> 设 $S_n = \frac{1}{n^2 + n + 1} + \frac{2}{n^2 + n + 2} + \cdots + \frac{n}{n^2 + n + n}$
>
> **放大**：$\frac{1}{n^2 + n + n} \leq \frac{k}{n^2 + n + k} \leq \frac{k}{n^2 + n + 1}$
>
> $$S_n \leq \frac{1 + 2 + \cdots + n}{n^2 + n + 1} = \frac{n(n+1)}{2(n^2 + n + 1)}$$
>
> $$S_n \geq \frac{1 + 2 + \cdots + n}{n^2 + n + n} = \frac{n(n+1)}{2(n^2 + 2n)}$$
>
> 两边取极限：
> $$\lim_{n \to \infty} \frac{n(n+1)}{2(n^2 + 2n)} = \frac{1}{2}$$
> $$\lim_{n \to \infty} \frac{n(n+1)}{2(n^2 + n + 1)} = \frac{1}{2}$$
>
> 由夹逼准则，$\lim_{n \to \infty} S_n = \frac{1}{2}$

---

### 准则2：单调有界准则 ⭐⭐⭐

> [!thm] 单调有界准则
> **单调有界数列必有极限**：
> - 单调递增且有上界的数列必有极限
> - 单调递减且有下界的数列必有极限

**直观理解**：
- 单调递增 + 有上界 → 不断上升但永远超不过某个值 → 必然趋近某个极限
- 单调递减 + 有下界 → 不断下降但永远低不过某个值 → 必然趋近某个极限

**注意**：仅"有界"或仅"单调"都不能保证收敛！

> [!example] 例2：单调有界准则应用
> **题目**：设 $x_1 = \sqrt{2}$，$x_{n+1} = \sqrt{2 + x_n}$，证明 $\{x_n\}$ 收敛并求极限。
>
> **证明**：
>
> **(1) 有界性**：用数学归纳法
> - $x_1 = \sqrt{2} < 2$
> - 假设 $x_n < 2$，则 $x_{n+1} = \sqrt{2 + x_n} < \sqrt{4} = 2$ ✓
>
> **(2) 单调性**：
> $$x_{n+1} - x_n = \sqrt{2 + x_n} - x_n = \frac{2 + x_n - x_n^2}{\sqrt{2 + x_n} + x_n} = \frac{(2 - x_n)(1 + x_n)}{\sqrt{2 + x_n} + x_n}$$
>
> 由于 $x_n < 2$，所以 $x_{n+1} - x_n > 0$，即 $\{x_n\}$ 单调递增。
>
> **(3) 由单调有界准则**，$\{x_n\}$ 收敛。
>
> **(4) 求极限值**：
> 设 $\lim_{n \to \infty} x_n = a$，由 $x_{n+1} = \sqrt{2 + x_n}$ 得：
> $$a = \sqrt{2 + a} \Rightarrow a^2 = 2 + a \Rightarrow a^2 - a - 2 = 0$$
> $$a = 2 \text{ 或 } a = -1$$
>
> 由于 $x_n > 0$，故 $a \geq 0$，因此 $a = 2$。

## 4. 常见数列极限

### 基本极限公式

$$
\begin{aligned}
\lim_{n \to \infty} \frac{1}{n} &= 0 \\
\lim_{n \to \infty} q^n &= 0 \quad (|q| < 1) \\
\lim_{n \to \infty} \sqrt[n]{a} &= 1 \quad (a > 0) \\
\lim_{n \to \infty} \sqrt[n]{n} &= 1 \\
\lim_{n \to \infty} \frac{n!}{n^n} &= 0
\end{aligned}
$$

## 典型题型

### 题型1：用 ε-N 定义证明极限

> [!example] 例3
> **题目**：用 $\varepsilon$-$N$ 定义证明 $\lim_{n \to \infty} \frac{2n + 1}{3n - 1} = \frac{2}{3}$
>
> **证明**：
> 对任意 $\varepsilon > 0$，要使
> $$\left|\frac{2n + 1}{3n - 1} - \frac{2}{3}\right| = \left|\frac{3(2n+1) - 2(3n-1)}{3(3n-1)}\right| = \left|\frac{5}{3(3n-1)}\right| = \frac{5}{9n - 3} < \varepsilon$$
>
> 只需 $\frac{5}{9n - 3} < \varepsilon$，即 $n > \frac{5}{9\varepsilon} + \frac{1}{3}$。
>
> 取 $N = \left[\frac{5}{9\varepsilon} + \frac{1}{3}\right] + 1$，则当 $n > N$ 时，必有
> $$\left|\frac{2n + 1}{3n - 1} - \frac{2}{3}\right| < \varepsilon$$
>
> 故 $\lim_{n \to \infty} \frac{2n + 1}{3n - 1} = \frac{2}{3}$

### 题型2：用夹逼准则求极限

> [!example] 例4
> **题目**：求 $\lim_{n \to \infty} \left(\frac{1}{\sqrt{n^2 + 1}} + \frac{1}{\sqrt{n^2 + 2}} + \cdots + \frac{1}{\sqrt{n^2 + n}}\right)$
>
> **解答**：
> 设 $S_n = \frac{1}{\sqrt{n^2 + 1}} + \frac{1}{\sqrt{n^2 + 2}} + \cdots + \frac{1}{\sqrt{n^2 + n}}$
>
> **放大缩小**：
> $$\frac{n}{\sqrt{n^2 + n}} < S_n < \frac{n}{\sqrt{n^2 + 1}}$$
>
> $$\frac{n}{\sqrt{n^2 + n}} = \frac{1}{\sqrt{1 + \frac{1}{n}}} \to 1$$
> $$\frac{n}{\sqrt{n^2 + 1}} = \frac{1}{\sqrt{1 + \frac{1}{n^2}}} \to 1$$
>
> 由夹逼准则，$\lim_{n \to \infty} S_n = 1$

### 题型3：单调有界数列极限

> [!example] 例5
> **题目**：设 $x_1 = 1$，$x_{n+1} = 1 + \frac{x_n}{1 + x_n}$，求 $\lim_{n \to \infty} x_n$
>
> **解答**：
> **(1) 单调性**：
> $$x_1 = 1, \quad x_2 = 1 + \frac{1}{2} = 1.5$$
> 假设 $0 < x_n < 2$，则 $0 < \frac{x_n}{1 + x_n} < 1$，故 $1 < x_{n+1} < 2$。
>
> $$x_{n+1} - x_n = 1 + \frac{x_n}{1 + x_n} - x_n = \frac{1 - x_n^2}{1 + x_n}$$
>
> 由于 $1 < x_n < 2$，所以 $x_{n+1} - x_n < 0$，即 $\{x_n\}$ 单调递减。
>
> **(2) 有界性**：显然 $x_n > 1$（由归纳法可证）
>
> **(3)** 由单调有界准则，$\{x_n\}$ 收敛。
>
> **(4) 设** $\lim_{n \to \infty} x_n = a$，则：
> $$a = 1 + \frac{a}{1 + a} \Rightarrow a(1 + a) = 1 + a + a \Rightarrow a^2 - a - 1 = 0$$
> $$a = \frac{1 \pm \sqrt{5}}{2}$$
>
> 由于 $x_n > 1$，故 $a = \frac{1 + \sqrt{5}}{2}$

## 易错点 ⚠️

### 易错点1：混淆"任意"与"存在"

- ❌ **错误**：认为 $\varepsilon$ 是某个特定的很小的数
- ✅ **正确**：$\varepsilon$ 可以是**任意正数**，无论多小

### 易错点2：忽视收敛的充要条件

- ❌ **错误**：认为有界数列一定收敛
- ✅ **正确**：收敛 $\Rightarrow$ 有界，但有界 $\nRightarrow$ 收敛

### 易错点3：保号性的方向理解错误

- ❌ **错误**：认为 $x_n > 0$ 则极限 $a > 0$
- ✅ **正确**：$x_n > 0$ 只能保证极限 $a \geq 0$（可能是0）

### 易错点4：夹逼准则的等号问题

- ❌ **错误**：忽略"从某项起"的条件
- ✅ **正确**：前有限项不影响极限，只需从某项开始满足不等式
