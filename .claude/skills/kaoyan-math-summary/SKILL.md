# 考研数学章节笔记整理

## 触发条件

> [!important] 重要：优先使用此 Skill
> 当用户请求与**数学章节总结**相关的任务时，**必须优先调用此 Skill**

触发表达：
- "做一个章节总结"
- "帮我给XX做章节总结"
- "整理XX章节的笔记"
- "汇总这一章的内容"
- "总结一下这一章"

---

## 核心功能

1. **扫描章节笔记** - 自动发现章节下所有 `.md` 文件
2. **提取核心内容** - 定义、定理、公式、个人理解、易错点、方法
3. **智能查重合并** - 避免同一知识点被多次记录
4. **生成结构化总结** - 按固定模板输出 `📝 章节总结.md`
5. **知识孤岛检测** - 提醒未提取到核心内容的笔记

---

## 工作流程

```
[确认章节路径]
      ↓
[扫描笔记文件] → 排除索引、进度、README
      ↓
[逐个提取内容] → 分类缓存（定义/定理/公式/理解/易错点/方法）
      ↓
[智能查重合并]
      ↓
[生成总结文件]
      ↓
[输出统计 + 孤岛提醒]
```

---

## 内容组织原则

1. **按原章节结构组织** - 保持原有的子文件夹层级
2. **精简而非复制** - 定义/定理保留完整，公式集中展示
3. **保护个人笔记** - `[!personal]` 块完整保留，不做修改

---

## 注意事项

1. **不删除原文件** - 只读取和生成新文件
2. **增量更新** - 如果总结文件已存在，询问是否覆盖
3. **LaTeX 校验** - 确保所有公式括号正确闭合
4. **图片保留** - 保留图片链接，数学几何图形很重要
5. **表格绝对值** - 使用 `\vert` 而非 `|`
