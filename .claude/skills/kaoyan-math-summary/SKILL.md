# 考研数学章节笔记整理

## 触发条件

用户需要整理某个数学章节的笔记时，会使用以下表达：
- "整理XX章节的笔记"
- "生成XX章节总结"
- "汇总这一章的内容"
- "整理数学笔记"
- "帮我总结一下XX章"

## 工作流程

### 1. 确认章节路径

首先确认用户要整理的章节：

```
用户工作目录/考研数学/
├── 高数-函数极限与连续/
├── 高数-一元函数微分学/
├── 高数-一元函数积分学/
├── 高数-多元函数/
├── 高数-常微分方程/
└── 线代/
```

如果用户没有明确指定，询问：
> 请问要整理哪个章节？例如：
> - 高数-函数极限与连续
> - 高数-一元函数微分学
> - 线代

### 2. 扫描章节文件

使用 Glob 扫描指定章节下的所有 `.md` 文件（排除 `📑 索引.md` 和 `📊 学习进度.md`）：

```
章节路径/**/*.md
```

按子文件夹分组读取笔记内容。

### 3. 提取内容

从每个笔记文件中提取以下内容：

#### A. 必须背诵的内容（核心知识）

| Callout 类型 | 说明 | 提取优先级 |
|-------------|------|-----------|
| `[!def]` | 定义 | ⭐⭐⭐⭐⭐ |
| `[!thm]` | 定理 | ⭐⭐⭐⭐⭐ |
| `[!lemma]` | 引理 | ⭐⭐⭐⭐ |
| `[!cor]` | 推论 | ⭐⭐⭐⭐ |
| `[!formula]` | 公式 | ⭐⭐⭐⭐⭐ |
| `[!important]` | 重要结论 | ⭐⭐⭐⭐⭐ |
| `[!tip]` 中标注"必须背诵" | 必背公式 | ⭐⭐⭐⭐⭐ |

#### B. 个人理解（保留用户心得）

| Callout 类型 | 说明 |
|-------------|------|
| `[!personal]` | 用户的个人理解记录 |

#### C. 易错点与警告

| Callout 类型 | 说明 |
|-------------|------|
| `[!danger]` | 易错点、常见错误 |
| `[!warning]` | 注意事项 |

#### D. 例题（可选）

| Callout 类型 | 说明 |
|-------------|------|
| `[!example]` | 典型例题 |

### 4. 生成总结文件

在章节目录下创建 `📝 章节总结.md`，结构如下：

created: YYYY-MM-DD
chapter: 章节名称

### 5. 内容组织原则

1. **按原章节结构组织**：保持原有的子文件夹层级结构
2. **精简而非复制**：
   - 定义/定理：保留完整内容
   - 公式：集中展示，便于背诵
   - 易错点：合并同类项
3. **保护个人笔记**：
   - `[!personal]` 块**完整保留**，不做任何修改
   - 标注来源文件，便于回溯

### 6. 特殊处理

#### LaTeX 公式
- 保持原格式，不做修改
- 多个相关公式可合并在一个 `$$...$$` 块中

#### Wikilink 链接
- 保留原有的 `[[...]]` 链接
- 调整相对路径，确保链接有效

#### Callout 块嵌套
- 如果原笔记有嵌套结构，保持嵌套

## 输出确认

整理完成后，向用户展示：

1. **统计信息**：
   - 处理了多少个笔记文件
   - 提取了多少个定义/定理
   - 提取了多少条个人理解
   - 提取了多少个易错点

2. **文件位置**：
   - 总结文件的完整路径

3. **下一步建议**：
   > ✅ 章节总结已生成！
   > 你可以：
   > - 打开总结文件进行复习
   > - 补充遗漏的个人理解
   > - 使用 `/understanding` 验证对重点知识的理解

## 注意事项

1. **不删除原文件**：只读取和生成新文件，不修改或删除原有笔记
2. **增量更新**：如果总结文件已存在，询问是否覆盖或追加
3. **保持一致性**：公式符号、术语与原笔记保持一致
4. **质量检查**：确保所有 LaTeX 公式正确闭合
