## 2. B站政治视频「真看视频 + 零遗漏板书溯源」标准工作流（SOP）

当用户提供 B 站视频链接时，**严禁仅凭标题猜测或只用考纲通用文字敷衍**，必须执行以下 5 步真看视频提取闭环：

### Step 1：探测分P列表、合集（ugc_season）与字幕轨道
1. 调用 B 站公开 API `https://api.bilibili.com/x/web-interface/view?bvid=<BVID>` 获取：
   - 全部分 P（`pages`：`page`、`part`、`cid`、`duration`）；
   - 所属合集（`ugc_season.sections[].episodes`），确认是否有上下部关联视频（例如马哲与政经科社分属两个 BV 号）。
2. 检查字幕 API；若无外挂 CC 字幕，直接进入 **Step 2 浏览器视频画面逐帧提取**。

### Step 2：Browser MCP 逐P密集跳帧看视频与高清板书截图
1. 使用 `mcp__browser__browser` 打开对应分 P：`https://www.bilibili.com/video/<BVID>/?p=<N>`。
2. **解决 B 站暂停跳帧画面卡死技巧**：
   切换分 P 或大幅跳转 `currentTime` 时，使用微播放解码脚本确保画面刷新：
   ```javascript
   (() => {
     const v = document.querySelector('video');
     if (v) {
       v.muted = true;
       v.currentTime = TARGET_SECONDS;
       v.play();
       setTimeout(() => v.pause(), 400);
     }
     return v ? v.currentTime : null;
   })()
   ```
   等待 `1500~2000ms` 后执行 `screenshot video`。
3. **关键采样时间点**：
   - 每屏思维导图/讲义写满但尚未切换到下一屏的**完整板书定格帧**；
   - 视频中弹出的**互动提问弹窗帧**（`提问：...`）；
   - 片尾最后 5~15 秒的**《肖1000题》作业页码与题号帧**。
4. 将代表性完整板书截图复制到对应科目 `assets/` 目录（如 `考研政治/1-马原/assets/07-政经上-商品经济与劳动生产率板书.jpg`），并在笔记对应章节开头用 `> [!note]- 原始视频板书截图（溯源）` 折叠嵌入。

### Step 3：板书 100% 零遗漏精校 + 考纲历年真题补全
1. **100% 还原UP主独创内容**：
   - **记忆口诀**（如空卡“具使抽价”、“资金人”、“政经会”、“战时取余”、“长期利用生产力”、“双人神德公，单人泰资哥”等）；
   - **手绘趣味例子与公式推导**（如 1 辆电动车换 100 个西瓜、爸爸用玉米和电饭煲做饭、劳动生产率三行分数约分表）；
   - **黑板红叉 `❌` 与绿勾 `✅` 避坑标注**（如“❌ 唯一源泉”、“❌ 社会主义优越性不是国家垄断形成原因”、“❌ 职工选举管理者”）；
   - **现场互动提问弹窗**（还原为 `❓ 现场互动提问` 区块）。
2. **叠加考纲与真题补全**：
   - 在视频精简处用 `📌【考纲 & 历年真题补全】` 补齐考研政治大纲标准帽子词与真题高频干扰项。

## 3. 笔记排版与背诵友好型规范（9 大定稿约束）

1. **按视频分P建立独立笔记 + 汇总总表**：
   - 每一集生成一篇独立笔记（如 `01-导论.md` ~ `09-科学社会主义.md`），并在同目录维护一篇 `📋 <科目>必背速查与遮挡自测.md`。
2. **双轨考情靶向标注**：
   - 每个一级/二级考点标题后显式标注 `【100%仅考选择题】` 或 `【选择高频 + 34题分析大题必背★★★】`。
3. **顶部考情 Callout 含精确《1000题》题号，底部不放打卡表**：
   - 笔记顶部 `> [!info] 考情定位与使用说明` 必须写明视频链接与片尾布置的《肖1000题》单选/多选精确页码与题号；
   - **严禁**在笔记底部放置刷题进度打卡空表格。
4. **全节 Mermaid 思维导图**：
   - 笔记开头用 `mermaid` `graph LR` 还原该集完整板书结构；所有含中文、括号、标点的节点文本必须用双引号 `["..."]` 包裹。
5. **色彩层级克制**：
   - `==高亮==` 仅用于「唯一、根本、核心、标志、枢纽、实质、第一性」等单选题题眼帽子词；
   - **加粗**用于多选题采分点与口诀；
   - `> [!warning] 常见干扰项（❌ 错 vs ✅ 对）` 专放命题人张冠李戴陷阱。
6. **大题「原理 + 方法论 + 触发词」速背卡**：
   - 凡考分析大题的章节（如唯物论、辩证法、认识论），必须提炼 `> [!tip] 34题分析大题王牌模板速背卡`。
7. **篇末「🎙️ 假装当老师·遮挡自测」**：
   - 每篇笔记末尾设置 4 道核心复述题（带 `⌜⌟` 标记），答案统一收入单一 `> [!note]- 点击核对本节复述标准答案` 折叠块中。
8. **格式自检**：
   - 表格内数学绝对值一律用 `\lvert...\rvert`，禁用裸 `|`；
   - 写完后校验所有 `![[...]]` 嵌入图片文件真实存在。
