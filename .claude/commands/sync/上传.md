# 上传学习数据到 MemOS

正在将本地学习数据上传到 MemOS...

## 执行步骤

### 步骤 1: 获取今日日期

首先确定今日日期（格式：YYYY-MM-DD），然后查找对应的每日计划文件。

### 步骤 2: 读取本地学习文件

使用 `Glob` 工具查找今日学习计划文件：
- 路径：`考研计划/每日计划/{日期}-每日计划.md`
- 路径：`考研英语/📅 复习计划.md`

### 步骤 3: 提取关键信息

从读取的文件中提取：
- 今日学习内容
- 完成状态
- 学习时长
- 数学进度
- 英语词汇进度
- 下一步计划

### 步骤 4: 保存到 MemOS

使用 `mcp__MemoryOperatingSystem__add_message` 工具上传：

**参数**：
- `conversation_first_message`: "考研学习计划 - 湖南大学控制工程与科学专硕"
- `messages`: 提取的学习数据

**消息格式**：
```json
{
  "role": "user",
  "content": "今日学习记录 {日期}\n\n学习时间：{时长}\n科目：{科目}\n\n【数学】{内容}\n\n【英语】{内容}\n\n下次复习：{日期}"
}
```

### 步骤 5: 确认上传

输出上传结果确认。
