# /sync 命令帮助

MemOS 学习进度双向同步命令。

## 用法

| 命令 | 功能 |
|------|------|
| `/sync 上传` | 将本地学习数据保存到 MemOS |
| `/sync 拉取` | 从 MemOS 获取最新学习进度 |

## 推荐工作流

```
学习前 → /sync 拉取 → 获取最新进度和复习提醒
                 ↓
               开始学习
                 ↓
学习后 → /sync 上传 → 保存今日学习状态
```

## 示例

```bash
# 学习开始前，拉取最新进度
/sync 拉取

# 学习结束后，上传今日数据
/sync 上传
```

---

> [!tip] 提示
> - `上传` 会将今日学习计划、复习进度等保存到 MemOS
> - `拉取` 会显示用户画像、最近记录、复习提醒等
> - 定期同步可以保持跨设备数据一致
