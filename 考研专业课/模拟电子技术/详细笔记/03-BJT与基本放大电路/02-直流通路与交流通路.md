## 4. 直流通路与交流通路

### 4.1 直流通路

直流通路用于求静态工作点。

处理规则：

| 元件/信号 | 直流通路中怎么处理 |
| --- | --- |
| 耦合电容、旁路电容 | 开路 |
| 电感 | 短路 |
| 交流信号源 | 置零，保留内阻 |
| 直流电源 | 保留 |
| BJT | 用直流模型，常取 $V_{BEQ}\approx0.7V$ |

直流通路只关心：

$$
I_{BQ},\quad I_{CQ},\quad V_{CEQ}
$$

### 4.2 交流通路

交流通路用于求动态指标。

处理规则：

| 元件/信号 | 交流通路中怎么处理 |
| --- | --- |
| 大容量耦合电容 | 近似短路 |
| 大容量旁路电容 | 近似短路 |
| 直流电压源 | 交流接地 |
| 理想直流电流源 | 开路 |
| BJT | 换成小信号模型 |

交流通路只关心：

$$
A_v,\quad R_i,\quad R_o,\quad A_{vs}
$$

> [!warning] 顺序不能反
> 一定是先直流后交流。因为小信号模型里的 $r_{be}$ 由静态电流决定，Q 点没求出来，动态参数没有根。
