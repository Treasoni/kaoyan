# 07 常见错误模式与考试重点

## 一、常见错误模式

### 错误1：忘记检查自启动

| 错误表现 | 纠正方法 |
|---------|---------|
| 设计时序逻辑时未验证无效状态的去向 | 必须将所有无效状态代入转换方程，确认能进入有效循环 |

### 错误2：卡诺图圈组错误

| 错误表现 | 纠正方法 |
|---------|---------|
| 不按 $2^n$ 规则圈组 | 每个圈必须包含 $2^n$ 个方格（1, 2, 4, 8...） |

### 错误3：异步清零 vs 同步清零混淆

| 错误��现 | 纠正方法 |
|---------|---------|
| 用异步清零时取状态 $S_{N-1}$ | 异步清零取 $S_N$（因为 $S_N$ 瞬间出现后立即清零） |
| 用同步清零时取状态 $S_N$ | 同步清零取 $S_{N-1}$（等待下一个 CP 沿才清零） |

### 错误4：忘记异步置数/清零端的优先级

| 错误表现 | 纠正方法 |
|---------|---------|
| 忽略 $\overline{CR}$ 的最高优先级 | **异步清零 > 同步置数 > 计数/保持** |

### 错误5：状态编码不合理

| 错误表现 | 纠正方法 |
|---------|---------|
| 编码位数不够 | 必须满足 $2^{N-1} < M \leq 2^N$ |

### 错误6：米利型/穆尔型输出混用

| 错误表现 | 纠正方法 |
|---------|---------|
| 在比较器等非线性电路中使用虚短虚断 | 线性区才有虚短虚断 |
| 米利型输出画在状态圆圈内 | 米利型输出标在**方向线旁斜线右侧**；穆尔型输出标在**圆圈内** |

## 二、考试重点与题型

### 必考题型1：时序电路分析

> 频率：极高 | 难度：中~高

**分析思路**：
1. 由电路图写时钟方程、激励方程、输出方程
2. 代入触发器特性方程，得状态方程
3. 列状态转换表
4. 画状态图/时序图
5. 说明逻辑功能

**常考电路**：
- 同步加法计数器
- 减法计数器
- 环形计数器
- 扭环形计数器

### 必考题型2：时序电路设计

> 频率：极高 | 难度：高

**设计思路**：
1. 由需求画原始状态图/时序图
2. 状态化简 + 状态分配
3. 选触发器，求激励方程和输出方程
4. 画电路图
5. 检查自启动

### 必考题型3：集成计数器应用

> 频率：极高 | 难度：中

**要求**：熟练掌握 74LS160/161/162/163 构成 N 进制计数器

| 方法 | 关键步骤 |
|------|---------|
| 异步清零法 | $S_N$ 译码 → $\overline{CR}$ |
| 同步清零法 | $S_{N-1}$ 译码 → $\overline{CR}$ |
| 同步置数法 | $S_{N-1}$ 译码 → $\overline{PE}$，$D$ 端接起始值 |

### 必考题型4：移位寄存器应用

> 频率：中 | 难度：中

**要求**：掌握 74LS194 构成环形计数器和扭环形计数器

## 三、核心公式速查

### 触发器特性方程

$$\text{D-FF: } Q^{n+1} = D$$

$$\text{JK-FF: } Q^{n+1} = J\bar{Q}^n + \bar{K}Q^n$$

$$\text{T-FF: } Q^{n+1} = T\bar{Q}^n + \bar{T}Q^n = T \oplus Q^n$$

$$\text{T'-FF: } Q^{n+1} = \bar{Q}^n$$

### 同步二进制计数器激励方程

$$\text{递增: } T_i = \prod_{j=0}^{i-1}Q_j$$

$$\text{递减: } T_i = \prod_{j=0}^{i-1}\bar{Q}_j$$

### 状态编码位数

$$2^{N-1} < M \leq 2^N$$
