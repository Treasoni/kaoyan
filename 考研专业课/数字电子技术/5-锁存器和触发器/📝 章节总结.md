# 第五章：锁存器和触发器 - 章节总结

> [!tip] 考试重要性
> 本章是822考试**必考章节**，特性方程和波形分析是高频考点！

---

## 一、核心概念

### 1. 双稳态电路
- 具有**0**和**1**两个稳定状态
- 一旦进入某状态，能长期保持
- 是锁存器和触发器的基础

### 2. 锁存器 vs 触发器

| 特性 | 锁存器 | 触发器 |
|------|--------|--------|
| 敏感信号 | **电平敏感** | **边沿敏感** |
| 状态更新 | E=1期间持续 | 仅在边沿瞬间 |
| 透明性 | 透明 | 不透明 |
| 抗干扰 | 弱 | 强 |

### 3. 触发器的特点
1. 两个稳定状态（0和1）
2. 在时钟边沿触发翻转
3. 具有记忆功能
4. 输出由触发沿前瞬间的输入决定

---

## 二、四种触发器特性方程 ⭐必背

### 1. D触发器
$$Q^{n+1} = D$$

> 次态等于D，与现态无关

### 2. JK触发器
$$Q^{n+1} = J\bar{Q}^n + \bar{K}Q^n$$

| J | K | $Q^{n+1}$ | 功能 |
|---|---|-----------|------|
| 0 | 0 | $Q^n$ | 保持 |
| 0 | 1 | 0 | 置0 |
| 1 | 0 | 1 | 置1 |
| 1 | 1 | $\bar{Q}^n$ | 翻转 |

### 3. T触发器
$$Q^{n+1} = T \oplus Q^n$$

- T=0：保持
- T=1：翻转

### 4. T'触发器
$$Q^{n+1} = \bar{Q}^n$$

> 每来一个CP脉冲，Q翻转一次（计数）

### 5. SR触发器
$$\left\{ \begin{array}{l} Q^{n+1} = S + \bar{R}Q^n \\ SR = 0 \end{array} \right.$$

> 有约束条件，S和R不能同时为1

---

## 三、功能转换速查 ⭐常考

### D触发器转换

| 目标 | 转换逻辑 |
|------|----------|
| → JK | $D = J\bar{Q} + \bar{K}Q$ |
| → T | $D = T \oplus Q$ |
| → T' | $D = \bar{Q}$ |

### JK触发器转换

| 目标 | 转换逻辑 |
|------|----------|
| → T | $J = K = T$ |
| → T' | $J = K = 1$ |

---

## 四、波形分析方法 ⭐必考

### 四步法
1. **确定触发沿**：上升沿还是下降沿
2. **标记触发时刻**：在CP上标出所有触发沿
3. **读取输入值**：确定每个触发沿**前瞬间**的输入
4. **计算次态**：根据特性方程确定Q

### 关键点
- Q只在**触发沿瞬间**改变
- 两个触发沿之间Q**保持不变**
- 必须看**触发沿前瞬间**的输入值
- 异步信号$\bar{S}_D/\bar{R}_D$**优先级最高**

---

## 五、常见错误警示

> [!danger] 必须避免

1. **锁存器/触发器混淆**：锁存器电平敏感，触发器边沿敏感
2. **J=K=1理解错误**：是翻转，不是禁止
3. **触发沿判断错误**：看清楚是上升沿还是下降沿
4. **读值时机错误**：必须读触发沿**前瞬间**的值
5. **忘记异步信号**：$\bar{S}_D/\bar{R}_D$优先级最高
