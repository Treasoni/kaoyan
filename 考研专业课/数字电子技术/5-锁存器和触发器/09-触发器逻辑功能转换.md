# 触发器逻辑功能转换

> [!warning] 822考纲对照
> **大纲要求**：掌握不同功能触发器之间的转换方法
>
> **考试频率**：⭐⭐⭐⭐ 常考

---

## 1. 转换原理

> [!info] 基本思路
> 利用已有的触发器（如D触发器），通过添加组合逻辑电路，实现其他功能触发器的特性方程。

### 转换步骤
1. 写出目标触发器的特性方程
2. 写出已有触发器的特性方程
3. 令两者相等，求出转换逻辑
4. 画出转换电路

---

## 2. D触发器 → JK触发器 ⭐重点

### 目标
用D触发器实现JK触发器功能

### 转换过程

**目标特性方程**（JK触发器）：
$$Q^{n+1} = J\bar{Q}^n + \bar{K}Q^n$$

**已有特性方程**（D触发器）：
$$Q^{n+1} = D$$

**令两者相等**：
$$D = J\bar{Q}^n + \bar{K}Q^n$$

### 转换电路

```
         ┌───────────────────┐
    J ───┤                   │
         │    组合逻辑电路    ├─── D ──┐
    K ───┤                   │         │
         └───────────────────┘         │
                                       ↓
         ┌───┐                      ┌───┐
   Q̄ ────┤   │                      │   ├─── Q
         │ D │                      │   │
   CP ───┤>  │                      │   ├─── Q̄
         └───┘                      └───┘
           D触发器                   D触发器
```

### 逻辑表达式
$$D = J\bar{Q} + \bar{K}Q$$

可用与或门实现：
- $J\bar{Q}$：J和$\bar{Q}$的与
- $\bar{K}Q$：$\bar{K}$和Q的与
- 两者相或得到D

---

## 3. D触发器 → T触发器

### 目标
用D触发器实现T触发器功能

### 转换过程

**目标特性方程**（T触发器）：
$$Q^{n+1} = T\bar{Q}^n + \bar{T}Q^n = T \oplus Q^n$$

**令两者相等**：
$$D = T \oplus Q = T\bar{Q} + \bar{T}Q$$

### 转换电路

```
         ┌───┐
    T ───┤ =1├─── D ──┐
         │   │         │
    Q ───┤   │         ↓
         └───┘      ┌───┐
   异或门            │   ├─── Q
                    │ D │
               CP ──┤>  ├─── Q̄
                    └───┘
```

> [!tip] 简化实现
> 只需要一个**异或门**：$D = T \oplus Q$

---

## 4. D触发器 → T'触发器

### 目标
用D触发器实现T'触发器功能（计数触发器）

### 转换过程

**目标特性方程**（T'触发器）：
$$Q^{n+1} = \bar{Q}^n$$

**令两者相等**：
$$D = \bar{Q}$$

### 转换电路

```
              ┌───┐
   Q̄ ─────────┤   ├─── Q
              │ D │
         CP ──┤>  ├─── Q̄
              └───┘

   只需将 Q̄ 接到 D 端
```

> [!tip] 最简实现
> 只需将$\bar{Q}$输出端直接接到D输入端！

### 功能验证
- 当$Q=0$时，$\bar{Q}=1$，$D=1$，下一个CP后$Q=1$
- 当$Q=1$时，$\bar{Q}=0$，$D=0$，下一个CP后$Q=0$
- **每来一个CP，Q翻转一次**，实现计数功能

---

## 5. JK触发器 → T触发器

### 目标
用JK触发器实现T触发器功能

### 转换过程

**目标特性方程**（T触发器）：
$$Q^{n+1} = T\bar{Q}^n + \bar{T}Q^n$$

**JK触发器特性方程**：
$$Q^{n+1} = J\bar{Q}^n + \bar{K}Q^n$$

**比较系数**：
- 当$T=0$时：$Q^{n+1} = Q^n$（保持）→ 需要$J=0, K=0$
- 当$T=1$时：$Q^{n+1} = \bar{Q}^n$（翻转）→ 需要$J=1, K=1$

### 转换方案
$$J = K = T$$

### 转换电路

```
         ┌───┐
    T ───┼─┤J ├─── Q
         │ │  │
         │ │  │
   CP ───┼─┤>o├─── Q̄
         │ │  │
         └─┤K │
           └───┘

   将 T 同时接到 J 和 K 端
```

---

## 6. JK触发器 → T'触发器

### 转换方案
$$J = K = 1$$

### 转换电路

```
           ┌───┐
     1 ────┼─┤J ├─── Q
           │ │  │
           │ │  │
   CP ─────┼─┤>o├─── Q̄
           │ │  │
     1 ────┼─┤K │
           └─┴──┘

   J、K 端都接高电平
```

> [!tip] 最简实现
> J和K端都接高电平（或悬空），即实现T'触发器！

---

## 7. 转换关系总结表

| 已有 \ 目标 | D触发器 | JK触发器 | T触发器 | T'触发器 |
|-------------|---------|----------|---------|----------|
| **D触发器** | - | $D=J\bar{Q}+\bar{K}Q$ | $D=T\oplus Q$ | $D=\bar{Q}$ |
| **JK触发器** | $J=D, K=\bar{D}$ | - | $J=K=T$ | $J=K=1$ |

---

## 8. 典型例题

> [!example] 例1：用D触发器设计T'触发器

**解答**：
1. T'触发器特性方程：$Q^{n+1} = \bar{Q}^n$
2. D触发器特性方程：$Q^{n+1} = D$
3. 令$D = \bar{Q}$
4. 将$\bar{Q}$端直接连接到D端即可

> [!example] 例2：用D触发器设计JK触发器

**解答**：
1. JK触发器特性方程：$Q^{n+1} = J\bar{Q}^n + \bar{K}Q^n$
2. 令$D = J\bar{Q} + \bar{K}Q$
3. 需要用与或门实现该逻辑

## 9. 常见错误

> [!danger] 错误警示

| 错误类型 | 表现 | 纠正方法 |
|----------|------|----------|
| 方程写错 | 特性方程记错 | 熟记各触发器特性方程 |
| 逻辑化简错误 | 转换逻辑不正确 | 仔细化简逻辑表达式 |
| 接线错误 | Q和$\bar{Q}$混淆 | 注意互补输出端 |
