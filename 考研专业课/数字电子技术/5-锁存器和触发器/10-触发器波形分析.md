# 触发器波形分析

> [!warning] 822考纲对照
> **大纲要求**：能根据触发器（重点是JK-FF和D-FF）的特性方程熟练地画出输出波形
>
> **考试频率**：⭐⭐⭐⭐⭐ 必考

---

## 1. 波形分析基本方法

### 分析步骤（四步法）

1. **确定触发沿**：看逻辑符号判断上升沿还是下降沿触发
2. **标记触发时刻**：在CP波形上标出所有触发沿
3. **读取输入值**：确定每个触发沿**前瞬间**的输入信号值
4. **计算次态**：根据特性方程确定次态，画出Q波形

> [!tip] 核心原则
> - Q只在**触发沿瞬间**改变
> - 两个触发沿之间Q**保持不变**
> - 必须看**触发沿前瞬间**的输入值

---

## 2. D触发器波形分析

### 特性方程
$$Q^{n+1} = D$$

### 分析要点
- 上升沿触发：在CP↑时刻采样D值
- 下降沿触发：在CP↓时刻采样D值
- Q的次态 = D在触发沿前瞬间的值

> [!example] 例1：D触发器波形分析
> 上升沿触发D触发器，初态Q=0

**分析方法**：
```
CP:  ─┐  ┌─┐  ┌─┐  ┌─┐  ┌─
       └─┘ └─┘ └─┘ └─┘
       ↑   ↑   ↑   ↑
      (1) (2) (3) (4)  触发沿

D:   ──┐  ┌───┐    ┌────
       └──┘   └────┘
      0  1   0     1

Q:   ──┐  ┌────┐    ┌──
       └──┘    └────┘
      0  1    0     1
```

**逐步分析**：
| 触发沿 | D值（前瞬间） | $Q^{n+1}$ |
|--------|---------------|-----------|
| (1) | 0 | 0 |
| (2) | 1 | 1 |
| (3) | 0 | 0 |
| (4) | 1 | 1 |

## 3. JK触发器波形分析 ⭐重点

### 特性方程
$$Q^{n+1} = J\bar{Q}^n + \bar{K}Q^n$$

### 功能速查表

| J | K | $Q^{n+1}$ | 功能 |
|---|---|-----------|------|
| 0 | 0 | $Q^n$ | 保持 |
| 0 | 1 | 0 | 置0 |
| 1 | 0 | 1 | 置1 |
| 1 | 1 | $\bar{Q}^n$ | 翻转 |

> [!example] 例2：JK触发器波形分析
> 下降沿触发JK触发器，初态Q=0

**分析方法**：
```
CP:  ─┐  ┌─┐  ┌─┐  ┌─┐  ┌─
       └─┘ └─┘ └─┘ └─┘
         ↓   ↓   ↓   ↓
        (1) (2) (3) (4)  触发沿

J:   ──┐  ┌─────┐  ┌────
       └──┘     └──┘
      0  1     0   1

K:   ──────┐  ┌─────┐  ┌
            └──┘     └──┘
         0   1    0    1

Q:   ────┐  ┌──────┐  ┌──
          └──┘      └──┘
      0  1    0     1   0
```

**逐步分析**：
| 触发沿 | J | K | $Q^n$ | $Q^{n+1}$ | 功能 |
|--------|---|---|-------|-----------|------|
| (1) | 1 | 0 | 0 | 1 | 置1 |
| (2) | 0 | 1 | 1 | 0 | 置0 |
| (3) | 0 | 0 | 0 | 0 | 保持 |
| (4) | 1 | 1 | 0 | 1 | 翻转 |

## 4. 带异步控制的波形分析 ⭐重要

### 异步信号优先级
$$\bar{S}_D/\bar{R}_D > CP$$

> [!danger] 注意
> 异步置位/复位信号**立即生效**，不需要等待时钟边沿！

### 分析方法
1. **首先**处理异步信号（$\bar{S}_D$、$\bar{R}_D$）
2. 异步信号作用期间，CP和D/J/K信号**无效**
3. 异步信号**撤除后**，恢复正常触发

> [!example] 例3：带异步复位的D触发器

```
CP:     ─┐  ┌─┐  ┌─┐  ┌─
          └─┘ └─┘ └─┘
          ↑   ↑   ↑

D:      ──┐  ┌─────┐  ┌
          └──┘     └──┘

R̄_D: ────────┐     ┌────  (低电平复位)
                └─────┘

Q:   ──┐  ┌──┐    ┌─┐  ┌
        └──┘  └────┘ └──┘
              ↑
          异步复位
```

**分析**：
- 第1个CP↑：D=1，Q变1
- $\bar{R}_D$变低：Q立即变0（不受CP控制）
- 第2、3个CP↑：$\bar{R}_D$仍为低，Q保持0
- $\bar{R}_D$变高后：恢复正常触发

## 5. 多触发器级联分析

### 分析方法
1. 先分析**第一级**触发器
2. 根据第一级输出，分析**第二级**
3. 逐级向后推进

> [!example] 例4：两级D触发器级联（二分频器）

```
CP:   ─┐┌─┐┌─┐┌─┐┌─┐┌─
        └┘ └┘ └┘ └┘ └┘
        ↑ ↑ ↑ ↑ ↑

Q0:   ──┐┌─┐┌─┐┌─┐┌───
        └┘ └┘ └┘ └┘
      (第一级输出)

Q1:   ────┐┌───┐┌───┐┌─
          └┘   └┘   └┘
      (第二级输出)
```

**分析**：
- $Q_0^{n+1} = D_0$（假设D0接某个信号）
- $Q_1^{n+1} = Q_0$（D1接Q0）
- Q1频率 = CP频率 ÷ 4（四分频）

## 6. 常见错误与避免方法

> [!danger] 错误警示

| 错误类型 | 表现 | 避免方法 |
|----------|------|----------|
| 触发沿判断错误 | 上升沿画成下降沿 | 仔细看逻辑符号 |
| 输入值读取错误 | 看了触发沿后的值 | 必须看**前瞬间**的值 |
| 忘记保持特性 | Q随输入连续变化 | 两个触发沿间Q不变 |
| 异步信号遗漏 | 忽略$\bar{S}_D/\bar{R}_D$ | 先处理异步信号 |
| J=K=1处理错误 | 以为是保持 | J=K=1是**翻转** |

## 8. 波形分析技巧总结

> [!tip] 高分技巧

1. **先标触发沿**：在CP波形上用箭头标出所有触发沿
2. **画竖虚线**：从触发沿向下画虚线，帮助定位
3. **读前不读后**：只看触发沿**前瞬间**的输入值
4. **先异步后同步**：先处理$\bar{S}_D/\bar{R}_D$，再处理CP
5. **翻转要谨慎**：J=K=1时Q翻转，不是保持
