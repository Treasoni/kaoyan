# T触发器与T'触发器

> [!warning] 822考纲对照
> **大纲要求**：掌握T触发器和T'触发器的特性方程
>
> **考试频率**：⭐⭐⭐

---

## 1. T触发器

> [!info] 定义
> T触发器是一种具有**保持**和**翻转**两种功能的触发器，由控制信号T决定工作模式。

 ### 特性表

| T | $Q^n$ | $Q^{n+1}$ | 功能 |
|---|-------|-----------|------|
| 0 | 0 | 0 | **保持** |
| 0 | 1 | 1 | **保持** |
| 1 | 0 | 1 | **翻转** |
| 1 | 1 | 0 | **翻转** |

### 特性方程 ⭐核心

$$Q^{n+1} = T\bar{Q}^n + \bar{T}Q^n = T \oplus Q^n$$

> [!tip] 理解
> - T=0：$Q^{n+1} = Q^n$（保持）
> - T=1：$Q^{n+1} = \bar{Q}^n$（翻转）
### 功能总结

| T | 功能 | 说明 |
|---|------|------|
| 0 | 保持 | 状态不变 |
| 1 | 翻转 | 状态取反 |

## 2. T'触发器

> [!info] 定义
> T'触发器是T触发器的特例，T端固定接高电平，**每来一个时钟脉冲就翻转一次**。

### 特性方程 ⭐核心

$$Q^{n+1} = \bar{Q}^n$$

> [!tip] 特点
> - 只有一个输入端：时钟信号CP
> - 每来一个CP脉冲，Q翻转一次
> - **计数工作状态**

### 逻辑符号

```
     ┌───┐
CP ──┤>T'├── Q
     │   ├── Q̄
     └───┘
```

### 应用

1. **计数器**：累计输入脉冲个数
2. **分频器**：Q频率 = CP频率 ÷ 2

```
CP:  010101010101
Q:   001100110011
     └─二分频─┘
```

## 3. 用JK触发器构成T/T'触发器

### JK → T触发器

**转换方法**：$J = K = T$

```
         ┌───┐
    T ───┼─┤J ├─── Q
         │ │  │
   CP ───┼─┤>o├─── Q̄
         │ │  │
         └─┤K │
           └───┘
```

### JK → T'触发器

**转换方法**：$J = K = 1$

```
           ┌───┐
     1 ────┼─┤J ├─── Q
           │ │  │
   CP ─────┼─┤>o├─── Q̄
           │ │  │
     1 ────┼─┤K │
           └─┴──┘
```

## 4. 用D触发器构成T/T'触发器

### D → T触发器

**转换方法**：$D = T \oplus Q$

```
         ┌───┐
    T ───┤ =1├─── D ──┐
         │   │         │
    Q ───┤   │         ↓
         └───┘      ┌───┐
                    │   ├─── Q
                    │ D │
               CP ──┤>  ├─── Q̄
                    └───┘
```

### D → T'触发器

**转换方法**：$D = \bar{Q}$

```
              ┌───┐
   Q̄ ─────────┤   ├─── Q
              │ D │
         CP ──┤>  ├─── Q̄
              └───┘
```

> [!tip] 最简实现
> 只需将$\bar{Q}$接到D端！

## 5. 四种触发器特性方程汇总

| 触发器 | 特性方程 | 功能 |
|--------|----------|------|
| D | $Q^{n+1} = D$ | 置0、置1 |
| JK | $Q^{n+1} = J\bar{Q}^n + \bar{K}Q^n$ | 保持、置0、置1、翻转 |
| T | $Q^{n+1} = T \oplus Q^n$ | 保持、翻转 |
| T' | $Q^{n+1} = \bar{Q}^n$ | 翻转 |
| SR | $Q^{n+1} = S + \bar{R}Q^n$（约束$SR=0$） | 保持、置0、置1 |
