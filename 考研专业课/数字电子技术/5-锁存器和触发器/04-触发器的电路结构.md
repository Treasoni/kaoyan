## 1. 锁存器 vs 触发器

> [!info] 核心区别
> - **锁存器**：对脉冲**电平**敏感
> - **触发器**：对脉冲**边沿**敏感

### 敏感特性对比

```
锁存器（电平敏感）：
E:  ─────┐     ┌─────────
          └─────┘
         ████████  E=1期间敏感

触发器（边沿敏感）：
CP: ─────┐     ┌─────────
          └─────┘
              ↑    仅上升沿敏感
```

| 特性 | 锁存器 | 触发器 |
|------|--------|--------|
| 敏感信号 | 电平 | 边沿 |
| 更新时机 | E=1期间 | CP边沿瞬间 |
| 透明性 | 透明 | 不透明 |
| 抗干扰 | 弱 | 强 |

## 2. 三种触发器结构

### 2.1 主从触发器

> [!info] 基本思想
> 将两个锁存器级联，利用交互锁存实现边沿触发。

#### CMOS主从D触发器

```
    ┌──────────┐    ┌──────────┐
D ──┤ 主锁存器 ├───┤ 从锁存器 ├── Q
    │  (TG1)   │    │  (TG3)   │
CP ─┤  (TG2)   │    │  (TG4)   │
    └──────────┘    └──────────┘
```

#### 工作过程

| CP | 主锁存器 | 从锁存器 | 说明 |
|----|----------|----------|------|
| 0 | 接收D | 保持 | D进入主锁存器 |
| 0→1 | 锁存D | 接收主 | D传送到Q |
| 1 | 保持 | 保持 | 状态锁定 |

> [!tip] 关键特点
> - **上升沿触发**：状态在CP上升沿更新
> - **隔离输入**：CP=1时D与输出隔离

### 2.2 维持阻塞触发器

> [!info] 基本思想
> 利用反馈线"维持"和"阻塞"信号路径，保证边沿触发。

#### 维持阻塞D触发器

```
         ┌─────────────────────┐
         │    维持阻塞结构     │
D ───────┤                     ├── Q
         │  6个与非门构成      │
CP ──────┤                     ├── Q̄
         └─────────────────────┘
```

#### 工作原理

1. **CP=0**：准备阶段，D信号进入
2. **CP上升沿**：触发翻转，Q=D
3. **CP=1**：
   - 置1维持线：维持Q=1
   - 置0阻塞线：阻塞D=0进入
   - 或：置0维持线 + 置1阻塞线

> [!tip] 关键特点
> - 仅在**上升沿瞬间**更新状态
> - CP=1期间不受D变化影响

### 2.3 利用传输延迟的触发器

> [!info] 基本思想
> 利用门电路的传输延迟差异，实现下降沿触发。

#### JK触发器结构

```
         ┌─────────────────────┐
J ──────���┤                     │
         │  利用传输延迟       ├── Q
CP̄ ──────┤  的JK触发器        │
         │                     ├── Q̄
K ───────┤                     │
         └─────────────────────┘
```

> [!tip] 关键特点
> - **下降沿触发**
> - G3、G4门的延迟大于SR锁存器翻转时间

## 3. 触发方式对比

### 上升沿触发

```
CP: ─────┐     ┌─────────
          └─────┘
              ↑
          触发时刻
```

- 逻辑符号：方框内`>`，无小圆圈
- 例：74HC74

### 下降沿触发

```
CP: ─────┐     ┌─────────
          └─────┘
                ↓
            触发时刻
```

- 逻辑符号：方框内`>`，外加小圆圈
- 例：74LS112

## 5. 异步控制端

> [!info] 功能
> 无论CP处于什么状态，都能直接置位/复位触发器。

### 异步端功能

| $\bar{S}_D$ | $\bar{R}_D$ | Q | 功能 |
|-------------|-------------|---|------|
| 0 | 1 | 1 | 异步置1 |
| 1 | 0 | 0 | 异步置0 |
| 0 | 0 | 禁止 | 不允许 |
| 1 | 1 | 正常 | CP触发 |

> [!danger] 注意
> - 异步信号**优先级最高**
> - 正常工作时$\bar{S}_D = \bar{R}_D = 1$
