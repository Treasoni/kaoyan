# 基本双稳态电路

> [!warning] 822考纲对照
> **大纲要求**：了解双稳态电路的基本概念
>
> **考试频率**：⭐

---

## 1. 基本概念

> [!info] 定义
> 双稳态电路是具有**0**和**1**两种稳定状态，一旦进入其中一种状态，就能长期保持不变的单元电路。

### 双稳态特点
1. 有两个稳定状态（0状态和1状态）
2. 状态可以长期保持
3. 通过外部信号可以改变状态
4. 具有存储1位二进制数据的功能

---

## 2. 最简单的双稳态电路

### 电路结构

两个非门交叉耦合：

```
    ┌─────┐
────┤  G1 ├──┐ Q
    └─────┘  │
      ↑      ↓
      │    ┌─────┐
      └────┤  G2 ├──── Q̄
           └─────┘
```

### 工作原理

**状态1**：$Q = 0$，$\bar{Q} = 1$
- $Q = 0$输入G2，输出$\bar{Q} = 1$
- $\bar{Q} = 1$输入G1，输出$Q = 0$
- 形成稳定状态

**状态2**：$Q = 1$，$\bar{Q} = 0$
- $Q = 1$输入G2，输出$\bar{Q} = 0$
- $\bar{Q} = 0$输入G1，输出$Q = 1$
- 形成稳定状态

> [!info] 状态定义
> - **0状态**：$Q = 0$，$\bar{Q} = 1$
> - **1状态**：$Q = 1$，$\bar{Q} = 0$
> - $Q$和$\bar{Q}$总是**逻辑互补**

---

## 3. 功能局限性

### 无法实际使用
- 接通电源后，**随机进入**0或1状态
- **没有控制机构**，无法在运行中改变状态
- 不能作为实际存储电路使用

### 解决方案
在基本双稳态电路基础上添加控制机构：
- 添加输入端 → SR锁存器
- 添加时钟控制 → 触发器

---

## 4. 双稳态电路家族

```
基本双稳态电路
       │
       ├──→ SR锁存器
       │        │
       │        ├──→ 门控SR锁存器
       │        │
       │        └──→ D锁存器
       │
       └──→ 触发器（边沿触发）
                │
                ├──→ D触发器
                ├──→ JK触发器
                ├──→ T触发器
                └──→ SR触发器
```
