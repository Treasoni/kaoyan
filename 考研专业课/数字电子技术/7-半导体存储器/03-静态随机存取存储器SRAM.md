# 静态随机存取存储器（SRAM）

> [!abstract] 学习导览

## 📌 速查卡片（考前快速回顾）

| 项目 | 核心内容 |
|------|----------|
| **全称** | Static Random Access Memory（静态随机存取存储器） |
| **存储原理** | 锁存器（6管触发器）—— 不是电容！ |
| **易失性** | ✅ 易失（断电丢数据） |
| **是否需要刷新** | ❌ 不需要（与DRAM的关键区别） |
| **集成度** | 较低（6管/位 → 占面积大） |
| **速度** | 较快 |
| **功耗** | 较大 |
| **容量公式** | $2^n \times m$ 位（$n$根地址线，$m$根数据线） |

> [!danger] 高频易错
> - SRAM ≠ 非易失性！SRAM是**易失性**存储器，ROM才是非易失性
> - SRAM用**锁存器（6管）**存储数据，**不是电容**（那是DRAM）

## 一、SRAM的基本结构

### 1.1 组成部分

SRAM芯片内部由三部分组成：

```
┌─────────────────────────────────┐
│         地址译码器               │
│  ┌───────────────────────────┐  │
│  │                           │  │
│  │       存储阵列             │  │
│  │   (存储单元矩阵)           │  │
│  │                           │  │
│  └──────────┬────────────────┘  │
│             │ I/O                │
│        I/O控制电路               │
└─────────────────────────────────┘
```

1. **存储阵列** —— 由大量存储单元排列成矩阵
2. **地址译码器** —— 将地址码译成行/列选通信号
3. **输入/输出控制电路** —— 控制数据的读写方向与时机

### 1.2 端口信号

| 信号 | 名称 | 功能 |
|------|------|------|
| $A_0 \sim A_{n-1}$ | 地址线 | 选择存储单元 |
| $\text{I/O}_0 \sim \text{I/O}_{m-1}$ | 数据线 | 双向数据传输 |
| $\overline{CE}$ | 片选信号 | 低电平有效，选中芯片 |
| $\overline{WE}$ | 写使能信号 | 低电平有效，控制写操作 |
| $\overline{OE}$ | 输出使能信号 | 低电平有效，控制读操作 |

> [!tip] 记忆口诀
> **CE** = Chip Enable（片选），**WE** = Write Enable（写使能），**OE** = Output Enable（输出使能）
> 三个都是**低电平有效**（上面带横线）

### 1.3 容量表示

容量计算公式：
$$
\text{容量} = 2^n \times m \text{ 位}
$$

其中 $n$ = 地址线根数，$m$ = 数据线根数。

**例**：$A_0 \sim A_{12}$（13根地址线） + $I/O_0 \sim I/O_7$（8根数据线）
$$
\text{容量} = 2^{13} \times 8 = 8192 \times 8 = 64\text{Kb}
$$

## 二、SRAM工作模式（重点）

### 2.1 工作模式速查表

| 工作模式 | $\overline{CE}$ | $\overline{WE}$ | $\overline{OE}$ | I/O引脚状态 |
|----------|:---------------:|:---------------:|:---------------:|-------------|
| **保持（微功耗）** | **1** | × | × | 高阻 |
| **读** | **0** | **1** | **0** | **数据输出** |
| **写** | **0** | **0** | × | **数据输入** |
| **输出无效** | **0** | **1** | **1** | 高阻 |

> [!tip] 模式记忆法
> 只看 $\overline{CE}$ 和 $\overline{WE}$ 两位即可确定核心模式：
> - $\overline{CE}=1$ → **保持**（芯片未选中，歇着）
> - $\overline{CE}=0,\ \overline{WE}=1$ → **读**（写使能无效→只能是读）
> - $\overline{CE}=0,\ \overline{WE}=0$ → **写**（写使能有效→写操作）
> - 读模式下再看 $\overline{OE}$：$\overline{OE}=0$ 才输出，$\overline{OE}=1$ 则输出无效

### 2.2 各模式详解

**保持模式（微功耗）**：
- $\overline{CE}=1$ → SRAM 未被选中
- 三态缓冲器呈**高阻态**（数据线与内部隔离）
- 电源控制电路降低内部工作电压，处于**微功耗状态**
- 数据仍在存储单元中，只是不对外通信

**读模式**：
- $\overline{CE}=0$，$\overline{WE}=1$，$\overline{OE}=0$
- 存储阵列中对应地址的数据送到 I/O 数据线上
- $\overline{OE}=0$ 使输出缓冲器导通

**写模式**：
- $\overline{CE}=0$，$\overline{WE}=0$
- $\overline{OE}$ 无关（输出缓冲器被 $\overline{WE}$ 封锁）
- I/O 线上的数据写入被选中的存储单元

**输出无效**：
- $\overline{CE}=0$，$\overline{WE}=1$，$\overline{OE}=1$
- 虽然片选有效、写使能无效，但输出被 $\overline{OE}$ 封锁
- I/O 线呈高阻态

> [!warning] 易错提醒
> - $\overline{CE}=0$ **是芯片工作的前提条件**——不看 CE 只看 WE/OE 是典型的错误
> - $\overline{WE}$ 和 $\overline{OE}$ **不能同时为 0**，否则读写冲突

## 三、SRAM的特点

| 特点 | 说明 |
|------|------|
| **数据保持** | 只要不断电，数据永久保存（不像DRAM需要刷新） |
| **无需刷新** | 静态存储，无刷新操作（"静态"的含义就在于此） |
| **集成度** | 较低（6管/位 → 同样面积下容量小） |
| **功耗** | 较大（6个管持续导通耗电） |
| **速度** | 较快（无需刷新等待，适合缓存） |

> [!info] "静态"的含义
> "静态"（Static）是指**不需要周期性刷新**，数据只要不掉电就能一直保持，而非指速度慢。

### SRAM vs DRAM 对比

| 对比项 | SRAM | DRAM |
|--------|------|------|
| **存储单元** | 6个晶体管（锁存器） | 1个晶体管+1个电容 |
| **是否需要刷新** | ❌ 不需要 | ✅ 需要周期性刷新 |
| **速度** | ⚡ 快 | 🐢 较慢 |
| **集成度** | 低（管多用面积大） | 高（管少集成度高） |
| **功耗** | 较大 | 较小 |
| **典型用途** | CPU缓存（Cache） | 内存条（主存） |
| **成本** | 高 | 低 |

> [!tip] 记忆方法
> - **SRAM** → Static → 静态锁存，无需刷新 → 速度快 → 做**Cache**
> - **DRAM** → Dynamic → 动态电容，需刷新 → 集成度高 → 做**主存**

## 四、SRAM读操作时序

### 4.1 读操作条件

同时满足以下条件：
- ✅ 有效地址加到地址输入端
- ✅ $\overline{CE}=0$（片选有效）
- ✅ $\overline{WE}=1$（写使能无效）
- ✅ $\overline{OE}=0$（输出使能有效）

### 4.2 两种读操作方式

| 方式 | 特点 | 适用场景 |
|------|------|----------|
| **地址控制的读操作** | $\overline{CE}$ 和 $\overline{OE}$ 始终保持低电平，数据输出只与地址有关 | 地址变化时自动读取 |
| **片选控制的读操作** | 地址已经有效或与 $\overline{CE}$ 同时有效，由 $\overline{CE}$ 控制数据输出 | 需要通过片选信号控制读取时间 |

> [!info] 读操作对比
> - **地址控制**：$\overline{CE}$ 和 $\overline{OE}$ 固定为 0，地址变了就自动读
> - **片选控制**：地址已准备好，用 $\overline{CE}$ 的下跳沿控制读出时刻

---

## 五、SRAM写操作时序

### 5.1 写操作条件

同时满足以下条件：
- ✅ 有效地址加到地址输入端
- ✅ $\overline{CE}=0$（片选有效）
- ✅ $\overline{WE}=0$（写使能有效）
- ✅ I/O 线上的数据准备好

### 5.2 两种写操作方式

| 方式 | 特点 | 关键时序 |
|------|------|----------|
| **片选控制的写操作** | $\overline{CE}$ 下降沿启动写操作 | $\overline{WE}$ 与地址同时有效或提前有效 |
| **写信号控制的写操作** | $\overline{WE}$ 下降沿启动写操作 | $\overline{CE}$ 提前有效 |

> [!warning] 时序要点
> - **建立时间**（$t_{su}$）：数据/地址在操作信号有效前须提前稳定
> - **保持时间**（$t_h$）：数据/地址在操作信号结束后须继续保持
> - 分清建立时间和保持时间是常考易错点！

## 六、常见错误模式

| 错误类型 | 错误示例 | 纠正方法 |
|----------|----------|----------|
| **SRAM/ROM混淆** | 认为SRAM是非易失性 | → SRAM**易失性**，ROM**非易失性** |
| **忘记片选条件** | 只看 $\overline{WE}$ 和 $\overline{OE}$ | → 必须 $\overline{CE}=0$ 才能工作 |
| **读写时序混淆** | 混淆建立时间和保持时间 | → 建立时间在操作**前**，保持时间在操作**后** |
| **存储单元结构错误** | 认为SRAM用电容存储 | → SRAM用**锁存器（6管）** |
| **"静态"理解错误** | 认为静态=速度快 | → "静态"指**不需要刷新**，不动态刷新 |

## ✅ 自我检测

检查以下说法是否正确：

1. SRAM 需要定期刷新才能保持数据，对吗？
2. 若 $\overline{CE}=0$，$\overline{WE}=1$，$\overline{OE}=1$，I/O 引脚处于什么状态？
3. SRAM 的存储单元由几个晶体管构成？DRAM 呢？
4. 某 SRAM 芯片有 10 根地址线和 8 根数据线，其容量是多少？
5. "静态"的含义是指 SRAM 读写速度慢且不变，对吗？
6. 读操作时，$\overline{WE}$ 应为何值？写操作时呢？

<details>
<summary>🔍 参考答案</summary>

1. **错误**。SRAM 不需要刷新（DRAM 才需要），这是两者核心区别。
2. **高阻态**（输出无效模式）。
3. SRAM 用 **6 管**锁存器，DRAM 用 **1 管 + 1 电容**。
4. 容量 = $2^{10} \times 8 = 1024 \times 8 = 8\text{Kb}$。
5. **错误**。"静态"是指不需要动态刷新，不是指速度。
6. 读操作：$\overline{WE}=1$；写操作：$\overline{WE}=0$。
