# 只读存储器（ROM）

> 📚 **学习目标**：掌握ROM的基本结构、工作原理、读操作时序及ROM实现组合逻辑的方法
> 🔗 **前置知识**：[[01-存储器概述与分类]]

## 一、ROM的基本结构

### 1.1 组成部分

ROM由三部分组成：

```
地址输入 → 地址译码器 → 存储阵列 → 输出控制电路 → 数据输出
```

1. **存储阵列**
   - 由许多存储单元组成
   - 每个存储单元存放1位二值数据
   - 存储单元排列成矩阵形式

2. **地址译码器**
   - 将输入的地址代码译成相应的地址信号
   - 从存储矩阵中选出相应的存储单元

3. **输出控制电路**
   - 包含三态缓冲器
   - 与系统数据总线连接
   - 无数据输出时呈高阻态

### 1.2 基本术语

| 术语 | 含义 |
|------|------|
| **字** | 按一定位数编组的一组数据 |
| **字长** | 一个字中所含的位数 |
| **地址** | 每个字的编号 |
| **地址单元** | 构成字的存储单元 |

### 1.3 容量计算

$$
\text{容量} = \text{字数} \times \text{字长}
$$

地址单元个数 $N$ 与地址码位数 $n$ 的关系：
$$
N = 2^n
$$

## 二、各类ROM特点总结

### 2.1 掩模ROM

- 出厂时数据固定
- 由制造商根据用户需求制造
- 成本低，适合大批量生产

### 2.2 PROM

- 出厂时全为1（或全为0）
- 用户可通过编程器写入一次
- 熔丝烧断后不可恢复

### 2.3 EPROM

- 使用SIMOS管构成存储单元
- 紫外线照射15~20分钟擦除全部内容
- 芯片有透明石英盖板
- 可多次擦写

### 2.4 E²PROM

- 使用Flotox MOS管构成
- **电擦除**，不需要取出芯片
- 以**字为单位**擦写
- 可重复擦写1万次以上
- 集成度较低

### 2.5 Flash存储器

- 使用快闪叠栅MOS管
- **电擦除**，按块擦除
- 存储单元结构简单（单管）
- 集成度高
- 广泛用于U盘、存储卡

## 三、常见错误模式

| 错误类型    | 错误示例            | 纠正方法                        |
| ------- | --------------- | --------------------------- |
| ROM类型混淆 | 分不清EPROM和E²PROM | EPROM紫外线擦除，E²PROM电擦除        |
| ROM本质误解 | 认为ROM是时序电路      | ROM是组合电路                    |
| 容量计算错误  | 地址线与数据线混淆       | 地址线决定字数，数据线决定字长             |
