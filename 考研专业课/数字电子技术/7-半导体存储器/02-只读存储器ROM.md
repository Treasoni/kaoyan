# 只读存储器（ROM）

> 📚 **学习目标**：掌握ROM的基本结构、工作原理、读操作时序及ROM实现组合逻辑的方法
> 🔗 **前置知识**：[[01-存储器概述与分类]]

---

## 一、ROM的基本结构

### 1.1 组成部分

ROM由三部分组成：

```
地址输入 → 地址译码器 → 存储阵列 → 输出控制电路 → 数据输出
```

1. **存储阵列**
   - 由许多存储单元组成
   - 每个存储单元存放1位二值数据
   - 存储单元排列成矩阵形式

2. **地址译码器**
   - 将输入的地址代码译成相应的地址信号
   - 从存储矩阵中选出相应的存储单元

3. **输出控制电路**
   - 包含三态缓冲器
   - 与系统数据总线连接
   - 无数据输出时呈高阻态

### 1.2 基本术语

| 术语 | 含义 |
|------|------|
| **字** | 按一定位数编组的一组数据 |
| **字长** | 一个字中所含的位数 |
| **地址** | 每个字的编号 |
| **地址单元** | 构成字的存储单元 |

### 1.3 容量计算

$$
\text{容量} = \text{字数} \times \text{字长}
$$

地址单元个数 $N$ 与地址码位数 $n$ 的关系：
$$
N = 2^n
$$

## 二、ROM的工作原理

### 2.1 存储原理

- **字线**：地址译码器的输出线
- **位线**：连接存储单元的输出线
- **存储单元**：字线与位线交叉处
  - **有器件连接**（二极管/MOS管）→ 存储"1"
  - **无器件连接** → 存储"0"

### 2.2 读操作过程

以图示ROM为例，地址码 $A_1A_0 = 01$ 时：

1. 地址译码器输出 $\overline{Y}_1$ 为低电平
2. $\overline{Y}_1$ 字线上二极管导通
3. 相应位线变为低电平
4. 输出使能 $\overline{OE} = 0$ 时
5. 位线电平经缓冲器反相输出
6. 数据 $D_3D_2D_1D_0 = 1101$

### 2.3 ROM的本质

**ROM属于组合逻辑电路**：给定一组输入（地址），便可得到一组输出（内容）。

## 三、二维译码结构

### 3.1 为什么需要二维译码

对于大容量ROM，一维译码电路规模庞大。

**示例**：$2^8 \times 1$ 位ROM
- 一维译码：需要256个8输入与非门
- 二维译码：规模大大减小

### 3.2 二维译码结构

- **行译码器**：选择行线
- **列译码器**（数据选择器）：选择位线

**工作过程**：
1. 高位地址经行译码器选择行线
2. 低位地址经列译码器选择位线
3. 行线和列线交叉处的MOS管决定存储值

## 四、ROM读操作时序

### 4.1 关键时序参数

| 参数 | 符号 | 含义 |
|------|------|------|
| 地址存取时间 | $t_{AA}$ | 从地址有效到数据稳定输出 |
| 片选存取时间 | $t_{CE}$ | 从CE有效到数据稳定输出 |
| 输出使能时间 | $t_{OE}$ | 从OE有效到数据稳定输出 |
| 输出失效时间 | $t_{OZ}$ | CE或OE失效后数据端呈高阻态 |
| 输出保持时间 | $t_{OH}$ | 地址失效后数据保持有效的时间 |

### 4.2 读操作步骤

1. **地址有效**：欲读取单元的地址加到地址输入端
2. **片选有效**：加入有效的片选信号 $\overline{CE} = 0$
3. **输出使能**：$\overline{OE} = 0$，经过延时后数据输出
4. **操作结束**：$\overline{CE}$ 或 $\overline{OE}$ 无效，数据端呈高阻态

### 4.3 时序要求

只有在以下条件**同时满足**时，数据才能稳定输出：
- 地址有效
- $\overline{CE} = 0$
- $\overline{OE} = 0$
- 延迟时间 $\geq t_{AA}, t_{CE}, t_{OE}$

## 五、ROM的应用

### 5.1 实现组合逻辑函数

ROM可实现多输入、多输出的逻辑函数。

**设计方法**：
1. 列出真值表
2. 逻辑函数的输入作为地址
3. 输出作为存储内容
4. 将内容按地址写入ROM

### 5.2 应用实例：码制转换

**题目**：用ROM实现二进制码与格雷码相互转换

**设计**：
- 转换方向控制位 C（1位）
- 输入代码 $I_3I_2I_1I_0$（4位）
- 输出代码 $O_3O_2O_1O_0$（4位）

**ROM配置**：
- 地址线：5根（$A_4 = C$，$A_3A_2A_1A_0 = I_3I_2I_1I_0$）
- 数据线：4根
- 容量：$2^5 \times 4 = 32 \times 4$ 位

**工作模式**：
- $C = 0$：二进制码 → 格雷码
- $C = 1$：格雷码 → 二进制码

### 5.3 应用实例：乘法运算

**题目**：用ROM实现两个4位二进制数相乘

**设计**：
- 输入：8根地址线（高4位和低4位各为一个乘数）
- 输出：8根数据线（8位乘积）
- ROM容量：$2^8 \times 8$ 位

## 六、各类ROM特点总结

### 6.1 掩模ROM

- 出厂时数据固定
- 由制造商根据用户需求制造
- 成本低，适合大批量生产

### 6.2 PROM

- 出厂时全为1（或全为0）
- 用户可通过编程器写入一次
- 熔丝烧断后不可恢复

### 6.3 EPROM

- 使用SIMOS管构成存储单元
- 紫外线照射15~20分钟擦除全部内容
- 芯片有透明石英盖板
- 可多次擦写

### 6.4 E²PROM

- 使用Flotox MOS管构成
- **电擦除**，不需要取出芯片
- 以**字为单位**擦写
- 可重复擦写1万次以上
- 集成度较低

### 6.5 Flash存储器

- 使用快闪叠栅MOS管
- **电擦除**，按块擦除
- 存储单元结构简单（单管）
- 集成度高
- 广泛用于U盘、存储卡

## 七、常见错误模式

| 错误类型 | 错误示例 | 纠正方法 |
|----------|----------|----------|
| ROM类型混淆 | 分不清EPROM和E²PROM | EPROM紫外线擦除，E²PROM电擦除 |
| ROM本质误解 | 认为ROM是时序电路 | ROM是组合电路 |
| 容量计算错误 | 地址线与数据线混淆 | 地址线决定字数，数据线决定字长 |
| 忘记OE控制 | 忽略输出使能信号 | $\overline{OE} = 0$ 时才能输出数据 |

## 九、例题

### 【例1】ROM容量计算

**题目**：用ROM实现两个3位二进制数相乘，求所需ROM容量。

**解**：
- 输入：$3 + 3 = 6$ 根地址线
- 输出：$3 + 3 = 6$ 根数据线（乘积最多6位）
- 容量：$2^6 \times 6 = 64 \times 6$ 位

### 【例2】码制转换ROM

**题目**：用ROM实现8421BCD码到余3码的转换，求ROM容量。

**解**：
- 输入：4位BCD码（10个有效输入）
- 输出：4位余3码
- 容量：$2^4 \times 4 = 16 \times 4$ 位
