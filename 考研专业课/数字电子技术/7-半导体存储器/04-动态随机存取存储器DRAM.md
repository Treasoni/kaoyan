# 动态随机存取存储器（DRAM）

> 📚 **学习目标**：掌握DRAM的存储单元结构、刷新机制、地址分时送入及操作时序
> 🔗 **前置知识**：[[01-存储器概述与分类]]、[[03-静态随机存取存储器SRAM]]

---

## 一、DRAM存储单元

### 1.1 单管DRAM存储单元结构

DRAM存储单元由**1个MOS管 + 1个电容**构成：

**组件**：
- **电容C**：存储电荷
  - 有电荷（高电压）→ 存储"1"
  - 无电荷（低电压）→ 存储"0"
- **MOS管T**：开关
  - 行选择线X为高电平 → T导通，C与位线连通
  - 行选择线X为低电平 → T截止，C与位线隔离

### 1.2 与SRAM存储单元对比

| 特性 | SRAM | DRAM |
|------|------|------|
| **存储单元** | 6管锁存器 | 1管+1电容 |
| **存储原理** | 触发器双稳态 | 电容电荷 |
| **是否需要刷新** | 不需要 | 需要定期刷新 |
| **集成度** | 较低 | 较高 |
| **功耗** | 较大 | 较小 |
| **速度** | 较快 | 较慢 |
| **成本** | 较高 | 较低 |

### 1.3 DRAM的特点

**优点**：
- 结构简单（1管/位）
- 集成度高
- 功耗小
- 成本低

**缺点**：
- 需要定期刷新
- 读出时会破坏存储数据（破坏性读出）
- 接口电路复杂

## 二、DRAM的刷新机制

### 2.1 为什么需要刷新

电容中存储的电荷会因漏电流而逐渐消散，必须定期补充电荷，否则数据丢失。

### 2.2 刷新方式

**读操作刷新**：
- 读出时会消耗电容中的电荷
- 读出后必须及时刷新
- 刷新控制R为高电平时，读出数据经刷新缓冲器对电容刷新

**只选通行选择线刷新**：
- 行选线X为高电平，$\overline{WE}$ 为高电平
- 电容数据经T到达位线
- 经输出缓冲器和刷新缓冲器对存储单元刷新
- 整行刷新，不进行列选通
## 三、DRAM的基本结构

### 3.1 结构特点

DRAM内部设有：
- **行地址寄存器**：由RAS控制
- **列地址寄存器**：由CAS控制
- **刷新计数器**：自动产生刷新地址
- **刷新控制及定时电路**

### 3.2 地址分时送入

**为什么要分时送入**：
- DRAM容量大，地址线多
- 采用分时送入可减少引脚数

**分时送入方法**：
1. 先送行地址（RAS控制）
2. 再送列地址（CAS控制）

**示例**：
- 1M字存储器需要 $2^{20}$ 个地址，即20根地址线
- 采用分时送入只需10根地址线

## 四、DRAM的操作方式

### 4.1 读/写操作

**操作步骤**：
1. RAS变为低电平，送入行地址
2. CAS变为低电平，送入列地址
3. 在 $\overline{WE}$ 作用下完成读/写
4. 读操作时 $\overline{OE}$ 应为低电平

### 4.2 页模式操作

**"页"的定义**：同一行的所有列构成的存储单元

**特点**：
- 不改变行地址，只改变列地址
- RAS保持低电平
- 可显著提高读写速度

### 4.3 RAS只刷新操作

**特点**：
- 只刷新行地址指定行的所有存储单元
- 不进行实际的读/写操作
- CAS保持高电平
- 需要外部地址计数器提供刷新地址

### 4.4 CAS先于RAS有效的刷新

**操作过程**：
1. CAS首先变为低电平
2. RAS变为低电平
3. DRAM内部刷新控制电路
4. 刷新计数器连续生成刷新地址
5. 自动进行刷新操作

## 六、DRAM与SRAM对比

| 特性 | SRAM | DRAM |
|------|------|------|
| **存储单元** | 6管锁存器 | 1管+1电容 |
| **是否需要刷新** | 不需要 | 需要定期刷新 |
| **集成度** | 较低 | 较高 |
| **功耗** | 较大 | 较小 |
| **速度** | 较快 | 较慢 |
| **成本** | 较高 | 较低 |
| **破坏性读出** | 否 | 是 |
| **接口电路** | 简单 | 复杂 |
| **典型应用** | Cache | 主内存 |
