# 动态随机存取存储器（DRAM）

> 📚 **学习目标**：掌握DRAM的存储单元结构、刷新机制、地址分时送入及操作时序
> 🔗 **前置知识**：[[01-存储器概述与分类]]、[[03-静态随机存取存储器SRAM]]

---

## 一、DRAM存储单元

### 1.1 单管DRAM存储单元结构

DRAM存储单元由 **1个MOS管 + 1个电容** 构成：

| 组件 | 作用 | 工作原理 |
|-----|------|---------|
| **电容C** | 存储电荷 | 有电荷（高电压）→ 存储"1"；无电荷（低电压）→ 存储"0" |
| **MOS管T** | 开关控制 | 行选择线X高电平 → T导通，C与位线连通；X低电平 → T截止，C与位线隔离 |

```
        行选择线X
            │
          ┌─┴─┐
          │ T │  ← MOS管（开关）
          └─┬─┘
            │
          ──┴──
          ─  C ─  ← 电容（存储电荷）
          ────
            │
           GND
```

### 1.2 DRAM的特点

> [!tip] **核心要点**
> DRAM最关键的三个特征：**需要刷新**、**破坏性读出**、**地址分时送入**

| | 优点 | 缺点 |
|--|------|------|
| **结构** | 结构简单（1管/位），集成度高 | 接口电路复杂 |
| **功耗** | 功耗小 | 需要定期刷新 |
| **成本** | 成本低 | 读出时会破坏存储数据（破坏性读出） |

## 二、刷新机制

### 2.1 为什么需要刷新？

> [!warning] **核心问题**
> 电容中存储的电荷会因**漏电流**而逐渐消散，必须定期补充电荷，否则数据丢失。

### 2.2 两种刷新方式

#### 方式一：读操作刷新

```
读出过程 → 消耗电容电荷 → 刷新缓冲器 → 补充电荷（刷新）
```

- 读出时会消耗电容中的电荷
- 读出后必须及时刷新
- 刷新控制R为高电平时，读出数据经**刷新缓冲器**对电容刷新

#### 方式二：只选通行选择线刷新

```
行选线X高电平 + WE高电平 → 电容数据经T到达位线 → 刷新缓冲器 → 整行刷新
```

- 行选线X为高电平，$\overline{WE}$ 为高电平
- 电容数据经T到达位线
- 经输出缓冲器和刷新缓冲器对存储单元刷新
- **整行刷新**，不进行列选通

> [!info] **注意**
> 只选通行选择线刷新是 **整行同时刷新**，效率更高。

## 三、DRAM的基本结构

### 3.1 内部组成

| 组成部分 | 说明 |
|---------|------|
| **行地址寄存器** | 由RAS（行地址选通）控制 |
| **列地址寄存器** | 由CAS（列地址选通）控制 |
| **刷新计数器** | 自动产生刷新地址 |
| **刷新控制及定时电路** | 控制刷新时序 |

### 3.2 地址分时送入

> [!question] **为什么需要分时送入？**
> DRAM容量大，地址线多。采用分时送入可**减少引脚数**。

**分时送入流程**：
```
① 先送行地址（RAS控制） → ② 再送列地址（CAS控制）
```

**示例**：
- 1M字存储器需要 $2^{20}$ 个地址，即20根地址线
- 采用分时送入只需**10根地址线**

> [!tip] **记忆要点**
> RAS对应**行（Row）**，CAS对应**列（Column）** — 先选行，再选列，就像在表格中定位单元格。

## 四、DRAM的操作方式

### 4.1 读/写操作

**标准操作步骤**：
```
① RAS↓（低电平）→ 送入行地址
② CAS↓（低电平）→ 送入列地址
③ WE 作用下完成读/写
④ 读操作时 OE 应为低电平
```

| 信号 | 读操作 | 写操作 |
|------|-------|-------|
| $\overline{RAS}$ | ↓ 低电平（送行地址） | 同左 |
| $\overline{CAS}$ | ↓ 低电平（送列地址） | 同左 |
| $\overline{WE}$ | 高电平 | 低电平 |
| $\overline{OE}$ | 低电平 | 任意 |

### 4.2 页模式操作

> [!info] **"页"的定义**
> 同一行的所有列构成的存储单元

**特点**：
- 不改变行地址，只改变列地址 → 显著提高读写速度
- RAS保持低电平（不重新选通行地址）

### 4.3 RAS只刷新

**特点**：
- 只刷新行地址指定行的所有存储单元
- 不进行实际的读/写操作
- CAS保持高电平
- 需要**外部地址计数器**提供刷新地址

### 4.4 CAS先于RAS有效的刷新

**操作过程**：
```
① CAS↓（首先变为低电平）
② RAS↓（变为低电平）
③ DRAM内部刷新控制电路启动
④ 刷新计数器连续生成刷新地址
⑤ 自动进行刷新操作
```

> [!tip] **记忆技巧**
> CAS先于RAS → 触发内部自动刷新，无需外部地址计数器。

## 五、DRAM vs SRAM 对比总结

| 对比项 | SRAM | DRAM |
|-------|------|------|
| **存储单元** | 6管锁存器 | 1管 + 1电容 |
| **存储原理** | 触发器双稳态 | 电容电荷 |
| **是否需要刷新** | ❌ 不需要 | ✅ 需要定期刷新 |
| **破坏性读出** | ❌ 否 | ✅ 是 |
| **集成度** | 较低 ⬇ | 较高 ⬆ |
| **功耗** | 较大 | 较小 |
| **速度** | 较快 ⚡ | 较慢 |
| **成本** | 较高 | 较低 💰 |
| **接口电路** | 简单 | 复杂 |
| **典型应用** | Cache（高速缓存） | 主内存（内存条） |

> [!summary] **快速记忆口诀**
> **SRAM**：6管、高速、无需刷新、Cache专用
> **DRAM**：1管1容、需刷新、破坏读出、主内存担当
