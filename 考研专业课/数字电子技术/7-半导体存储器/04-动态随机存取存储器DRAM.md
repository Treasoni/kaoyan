# 动态随机存取存储器（DRAM）

> 📚 **学习目标**：掌握DRAM的存储单元结构、刷新机制、地址分时送入及操作时序
> 🔗 **前置知识**：[[01-存储器概述与分类]]、[[03-静态随机存取存储器SRAM]]

---

## 一、DRAM存储单元

### 1.1 单管DRAM存储单元结构

DRAM存储单元由 **1个MOS管 + 1个电容** 构成：

| 组件 | 作用 | 工作原理 |
|-----|------|---------|
| **电容C** | 存储电荷 | 有电荷（高电压）→ 存储"1"；无电荷（低电压）→ 存储"0" |
| **MOS管T** | 开关控制 | 行选择线X高电平 → T导通，C与位线连通；X低电平 → T截止，C与位线隔离 |

```
        行选择线X
            │
          ┌─┴─┐
          │ T │  ← MOS管（开关）
          └─┬─┘
            │
          ──┴──
          ─  C ─  ← 电容（存储电荷）
          ────
            │
           GND
```

### 1.2 DRAM的特点

> [!tip] **核心要点**
> DRAM最关键的三个特征：**需要刷新**、**破坏性读出**、**地址分时送入**

| | 优点 | 缺点 |
|--|------|------|
| **结构** | 结构简单（1管/位），集成度高 | 接口电路复杂 |
| **功耗** | 功耗小 | 需要定期刷新 |
| **成本** | 成本低 | 读出时会破坏存储数据（破坏性读出） |

## 二、刷新机制

### 2.1 为什么需要刷新？

> [!warning] **核心问题**
> 电容中存储的电荷会因**漏电流**而逐渐消散，必须定期补充电荷，否则数据丢失。


## 三、DRAM的基本结构

### 3.1 内部组成

| 组成部分 | 说明 |
|---------|------|
| **行地址寄存器** | 由RAS（行地址选通）控制 |
| **列地址寄存器** | 由CAS（列地址选通）控制 |
| **刷新计数器** | 自动产生刷新地址 |
| **刷新控制及定时电路** | 控制刷新时序 |

### 3.2 地址分时送入

> [!question] **为什么需要分时送入？**
> DRAM容量大，地址线多。采用分时送入可**减少引脚数**。

**分时送入流程**：
```
① 先送行地址（RAS控制） → ② 再送列地址（CAS控制）
```

**示例**：
- 1M字存储器需要 $2^{20}$ 个地址，即20根地址线
- 采用分时送入只需**10根地址线**

> [!tip] **记忆要点**
> RAS对应**行（Row）**，CAS对应**列（Column）** — 先选行，再选列，就像在表格中定位单元格。

## 四、DRAM vs SRAM 对比总结

| 对比项 | SRAM | DRAM |
|-------|------|------|
| **存储单元** | 6管锁存器 | 1管 + 1电容 |
| **存储原理** | 触发器双稳态 | 电容电荷 |
| **是否需要刷新** | ❌ 不需要 | ✅ 需要定期刷新 |
| **破坏性读出** | ❌ 否 | ✅ 是 |
| **集成度** | 较低 ⬇ | 较高 ⬆ |
| **功耗** | 较大 | 较小 |
| **速度** | 较快 ⚡ | 较慢 |
| **成本** | 较高 | 较低 💰 |
| **接口电路** | 简单 | 复杂 |
| **典型应用** | Cache（高速缓存） | 主内存（内存条） |

> [!summary] **快速记忆口诀**
> **SRAM**：6管、高速、无需刷新、Cache专用
> **DRAM**：1管1容、需刷新、破坏读出、主内存担当
