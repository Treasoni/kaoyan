# 数据选择器

## 一、数据选择器概述

### 定义

**数据选择器（MUX）**：从多路输入数据中选择一路传输到公共输出端的逻辑电路

### 功能比较

相当于**多输入的单刀多掷开关**

```
         数据选择器
  D_0  ─────┐
  D_1  ─────┤
  D_2  ─────┼──────> Y (输出)
  D_3  ─────┤          ↑
   ⋮       │          │
  D_n ─────┘        选择信号
```

### 结构组成

| 组成部分 | 功能 |
|----------|------|
| **数据输入端** | $D_0, D_1, \dots, D_{2^n-1}$ |
| **地址输入端** | $A_{n-1}, \dots, A_1, A_0$（选择哪一路） |
| **输出端** | $Y$（被选中的数据） |
| **使能端** | $\bar{E}$ 或 $\bar{S}$（控制工作） |

---

## 二、2选1数据选择器

### 逻辑符号

```
D_0 ─────┐
         │ 2选1
D_1 ─────┤ MUX ────> Y
         │
A ───────┘
(选择)
```

### 真值表

| $A$ | $Y$ |
|-----|-----|
| 0 | $D_0$ |
| 1 | $D_1$ |

### 逻辑表达式

$$Y = \bar{A}D_0 + AD_1$$

---

## 三、4选1数据选择器

### 逻辑表达式

$$Y = \bar{A}_1\bar{A}_0D_0 + \bar{A}_1A_0D_1 + A_1\bar{A}_0D_2 + A_1A_0D_3$$

或写成：
$$Y = \sum_{i=0}^{3} m_i \cdot D_i$$

其中 $m_i$ 是地址变量组成的最小项。

### 真值表

| $A_1$ | $A_0$ | $Y$ |
|-------|-------|-----|
| 0 | 0 | $D_0$ |
| 0 | 1 | $D_1$ |
| 1 | 0 | $D_2$ |
| 1 | 1 | $D_3$ |

---

## 四、典型芯片：74LS153 ⭐

### 功能概述

74LS153是**双4选1数据选择器**（包含两个独立的4选1 MUX）

### 引脚功能

| 引脚 | 功能 | 说明 |
|------|------|------|
| $D_{10} \sim D_{13}$ | 第1组数据输入 | 4路输入 |
| $D_{20} \sim D_{23}$ | 第2组数据输入 | 4路输入 |
| $A_1, A_0$ | 公共地址输入 | 两组共用 |
| $\bar{E}_1, \bar{E}_2$ | 使能端 | 低电平有效 |
| $Y_1, Y_2$ | 输出 | 两组独立输出 |

### 输出表达式

当 $\bar{E}=0$ 时：

$$Y = \bar{A}_1\bar{A}_0D_0 + \bar{A}_1A_0D_1 + A_1\bar{A}_0D_2 + A_1A_0D_3$$

---

## 五、8选1数据选择器：74LS151 ⭐⭐

### 功能概述

74LS151是**8选1数据选择器**

### 引脚功能

| 引脚 | 功能 |
|------|------|
| $D_0 \sim D_7$ | 8路数据输入 |
| $A_2, A_1, A_0$ | 3位地址输入 |
| $\bar{E}$ | 使能端（低电平有效） |
| $Y$ | 原码输出 |
| $\bar{Y}$ | 反码输出 |

### 输出表达式

$$Y = \sum_{i=0}^{7} m_i \cdot D_i$$

其中 $m_i$ 是 $A_2A_1A_0$ 组成的最小项。

## 六、用数据选择器实现逻辑函数 ⭐⭐⭐ 必考

### 原理

任何 $n$ 变量逻辑函数可表示为：
$$L = f(X_1, X_2, \dots, X_n)$$

若用 $2^n$ 选1 MUX：
- 将 $n$ 个变量接到地址端 $A_{n-1} \dots A_0$
- 根据真值表设置数据输入 $D_i$ 的值

### 方法一：真值表法

**步骤**：
1. 列出函数真值表
2. 变量接地址端
3. 数据输入 $D_i$ = 真值表对应的输出值

**示例**：用8选1 MUX实现 $L = A \oplus B \oplus C$

| $A$ | $B$ | $C$ | $L$ | $D_i$ 连接 |
|-----|-----|-----|-----|------------|
| 0 | 0 | 0 | 0 | $D_0 = 0$ |
| 0 | 0 | 1 | 1 | $D_1 = 1$ |
| 0 | 1 | 0 | 1 | $D_2 = 1$ |
| 0 | 1 | 1 | 0 | $D_3 = 0$ |
| 1 | 0 | 0 | 1 | $D_4 = 1$ |
| 1 | 0 | 1 | 0 | $D_5 = 0$ |
| 1 | 1 | 0 | 0 | $D_6 = 0$ |
| 1 | 1 | 1 | 1 | $D_7 = 1$ |

**连接**：
- $A \to A_2$, $B \to A_1$, $C \to A_0$
- $D_0=D_3=D_5=D_6=0$, $D_1=D_2=D_4=D_7=1$

---

### 方法二：降维法（用小MUX实现多变量函数）⭐

**原理**：用 $2^{n-1}$ 选1 MUX实现 $n$ 变量函数

**步骤**：
1. 将 $n-1$ 个变量接地址端
2. 第 $n$ 个变量（或其反/0/1）接数据端

**示例**：用4选1 MUX实现 $L = AB + BC$

#### Step 1：列出降维卡诺图

选择 $A, B$ 接地址端，$C$ 作为数据端变量：

| $A$ | $B$ | $L$ | $D_i$ 连接 |
|-----|-----|-----|------------|
| 0 | 0 | 0 | $D_0 = 0$ |
| 0 | 1 | $C$ | $D_1 = C$ |
| 1 | 0 | 0 | $D_2 = 0$ |
| 1 | 1 | $1$ | $D_3 = 1$ |

#### Step 2：连接

- $A \to A_1$, $B \to A_0$
- $D_0 = 0$, $D_1 = C$, $D_2 = 0$, $D_3 = 1$

> [!tip] 降维卡诺图画法
> 将卡诺图分成若干组，每组对应一个数据输入，组内的值即为该数据端的连接！

## 七、数据选择器的扩展

### 用两片74LS151组成16选1 MUX

**方法**：
1. 用高位 $A_3$ 控制两片的使能端（互补）
2. 两片输出相或

```
         片1 (低位)              片2 (高位)
D_0~D_7 ─> 74LS151 ─ Y_1 ─┐   D_8~D_15 ─> 74LS151 ─ Y_2 ─┐
                           │                               │
A_3=0 ───> \bar{E}_1      │   A_3=1 ───> \bar{E}_2        │
                           │                               │
         A_3 ───────────> 反相器 ───┘────────────────────┘
                           │                               │
                           └───────> OR ───────> Y
```

| $A_3$ | 工作的片 | 选择的数据 |
|-------|----------|------------|
| 0 | 片1 | $D_0 \sim D_7$ |
| 1 | 片2 | $D_8 \sim D_{15}$ |

## 八、应用实例

### 1. 并行转串行

**原理**：地址循环计数，依次选通各路数据

```
并行数据 D_0~D_7
    ↓
   MUX  ────> 串行输出
    ↑
循环计数器 (000→111→000...)
```

### 2. 函数发生器

用MUX实现各种逻辑函数，改变数据输入即可改变函数功能。

## 九、MUX vs 译码器实现逻辑函数

| 比较项 | 译码器 | 数据选择器 |
|--------|--------|------------|
| **实现n变量函数** | 需要 $n$-$2^n$ 译码器 + 或门 | 需要 $2^n$ 选1 MUX |
| **额外器件** | 需要或门/与非门 | 不需要 |
| **灵活性** | 任意函数 | 任意函数 |
| **降维能力** | 不能降维 | **可以降维** ⭐ |

> [!tip] 选择建议
> - 3变量以下：两者皆可
> - 需要降维（用4选1实现3变量）：**选MUX**
> - 多个函数共用变量：**选译码器**（输出独立）

## 十、常见错误

| 错误类型 | 表现 | 避免方法 |
|----------|------|----------|
| 地址和数据混淆 | 变量接错端 | 地址端接**最高位变量**，数据端接低位或常量 |
| 忘记使能端 | 输出恒为0 | $\bar{E}$ 接地（有效） |
| 降维时卡诺图错误 | 数据端连接错误 | 仔细分析每个地址对应的输出表达式 |
| 用错MUX类型 | 4选1实现4变量 | 4选1最多实现3变量（降维） |
