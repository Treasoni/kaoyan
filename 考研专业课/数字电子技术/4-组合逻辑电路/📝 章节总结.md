## 📚 核心知识点

### 1. 组合逻辑电路的定义与特点
- **定义**：输出只取决于当前输入，与历史状态无关
- **特点**：无反馈、无记忆元件
- **数学描述**：$$L_i = f(A_1, A_2, \dots, A_n)$$

- **分析四步法**：逻辑图 → 表达式 → 化简 → 真值表 → 功能
- **设计四步法**：功能描述 → 真值表 → 表达式 → 化简 → 逻辑图
- **冒险类型**：
  - 0型冒险： $L = A \cdot \bar{A}$ 形式
  - 1型冒险: $L = A + \bar{A}$ 形式
- **消除方法**：
  - 消去互补相乘项
  - 增加冗余项 ⭐
  - 输出端并联电容
### 2. 译码器（74LS138）⭐
- **功能**：3线-8线二进制译码器
- **使能条件**： $G_1=1, \bar{G}_{2A}=\bar{G}_{2B}=0$
- **输出**：低电平有效
- **实现逻辑函数**：
  $$L = \sum m_i = \overline{\prod \bar{Y}_i}$$
  即：最小项之和 = 对应输出的与非
### 3. 数据选择器（74LS151/153）⭐
- **功能**：从多路数据中选择一路输出
- **输出表达式**：$$Y = \sum_{i=0}^{2^n-1} D_i \cdot m_i$$
- **实现逻辑函数**：
  - 真值表法： $D_i$ = 真值表输出值
  - 降维法： 用 $2^{n-1}$ 选1 MUX 实现 $n$ 变量函数
### 4. 算术运算单元
| 娡块 | 输入 | 输出 | 表达式 |
|------|------|------|----------|
| **半加器** | $A, B$ | $S, C$ | $S = A \oplus B$, $C = AB$ |
| **全加器** | $A, B, C_{i-1}$ | $S, C_i$ | $s = A \oplus B \oplus C_{i-1}$, $c_i = AB + (A \oplus B)C_{i-1}$ |

## 📐 重点公式
### 格雷码与二进制码转换
$$\begin{cases}
B_{n-1} = G_{n-1} \\
B_{n-2} = B_{n-1} \oplus G_{n-2} \\
\vdots \\
B_0 = B_1 \oplus G_0
\end{cases}$$
### 译码器实现逻辑函数
$$L = \sum m_i = \overline{\prod \bar{Y}_i}$$
### MUX实现逻辑函数（降维法）
$$Y = \sum_{i=0}^{2^{n-1}-1} m_i \cdot D_i$$
其中 $D_i$ 可以是 0, 1, 或第 $n$ 个变量及其反变量。
### 全加器
$$\begin{cases}
S_i = A_i \oplus B_i \oplus C_{i-1} \\
c_i = A_i B_i + (A_i \oplus B_i)C_{i-1}
\end{cases}$$

## ⚠️ 常见错误
| 错误类型 | 表现 | 避免方法 |
|----------|------|----------|
| 分析时步骤跳过 | 直接看图说功能 | 必须写表达式、列真值表 |
| 设计时真值表错误 | 遗漏输入组合 | 确保 $2^n$ 行完整 |
| 译码器忘记使能端 | 不工作 | $G_1=1, \bar{G}_{2A}=\bar{G}_{2B}=0$ |
| MUX实现函数用错门 | 地址/数据端混淆 | 区分 $A_i$（地址）和 $D_i$（数据） |
| 全加器忘记进位 | 只写S不写c | 全加器有3输入2输出 |
| 竞争冒险判断 | 忽略互补项 | 检查 $A \cdot \bar{A}$ 或 $A + \bar{A}$ 形式 |

## 🎯 解题策略
### 分析组合逻辑电路
1. 从输入到输出逐级写表达式
2. 化简表达式
3. 列真值表（$2^n$ 行）
4. 分析真值表确定功能
### 设计组合逻辑电路
1. 正确理解功能要求
2. 列真值表（$2^n$ 行）
3. 写表达式并化简
4. 根据器件类型变换表达式
5. 画逻辑图
### 用译码器实现逻辑函数
1. 展开为最小项之和：$L = \sum m_i$
2. 连接：$A_i$ 接地址端
3. $D_i$ 接与非门，与非门输出为 $L$
### 用MUX实现逻辑函数
1. **真值表法**：$D_i$ = 真值表对应输出
2. **降维法**：
   - 选择 $n-1$ 个变量接地址端
   - 第 $n$ 个变量接数据端（或0或1）
   - 分析每个地址对应的输出表达式
### 多位加法器设计
1. 最低位用半加器
2. 其他位用全加器
3. 依次串联进位
