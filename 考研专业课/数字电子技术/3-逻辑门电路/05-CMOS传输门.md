# CMOS传输门

> [!info] 概述
> CMOS传输门（Transmission Gate, TG）是一种**双向开关**，既可以传输**数字信号**，也可以传输**模拟信号**。它由一个NMOS和一个PMOS并联组成。

---

## 一、传输门的结构

### 1.1 电路结构

```
        C ─────┬─────┐
                │     │
            ┌───┴───┐ │
            │ NMOS  │ │
            └───┬───┘ │
                │     │
    vI ─────────┼─────┼─── vO
                │     │
            ┌───┴───┐ │
            │ PMOS  │ │
            └───┬───┘ │
                │     │
        C̄ ─────┴─────┘
```

### 1.2 结构特点

| 特点 | 说明 |
|------|------|
| **双向性** | 输入和输出可互换使用 |
| **互补控制** | C和$\overline{C}$是一对互补信号 |
| **低导通电阻** | 两管并联，电阻较小且稳定 |

### 1.3 逻辑符号

```
    ┌─────────┐
 ───┤   TG    ├───
 C ─┤         │
    └─────────┘
```

## 二、工作原理

### 2.1 两种工作状态

| 控制信号 | NMOS状态 | PMOS状态 | 传输门状态 |
|----------|----------|----------|-----------|
| $C=0, \overline{C}=V_{DD}$ | 截止 | 截止 | **断开**（高阻态） |
| $C=V_{DD}, \overline{C}=0$ | 导通 | 导通 | **导通**（低电阻） |

### 2.2 导通时的电阻特性

当传输门导通时：
- NMOS：在 $0 \leq v_I \leq V_{DD} - V_T$ 范围内导通
- PMOS：在 $V_T \leq v_I \leq V_{DD}$ 范围内导通
- **并联后**：在 $0 \leq v_I \leq V_{DD}$ 全范围内导通

> [!important] 重要
> 由于两管互补作用，传输门的**导通电阻随输入电压变化较小**，比单管更稳定。

### 2.3 导通电阻曲线

```
Ron ↑
    │╲
    │ ╲      NMOS单独
    │  ╲____
    │       ╲
    │        ╲╱╲     并联后
    │      ╱    ╲___
    │   __╱ PMOS单独
    │__╱
    └────────────────→ vI
    0      VDD/2     VDD
```

## 三、模拟开关

### 3.1 结构

传输门可用于构建**模拟开关**，传输模拟信号（正负电压范围）。

```
        VDD (+)
         │
        ┌┴┐
        │ │ PMOS
        └┬┘
    ────┼──── vO
        │
        ┌┴┐
        │ │ NMOS
        └┬┘
         │
       VSS (-)

    控制信号范围：VSS ~ VDD
```

### 3.2 模拟开关应用

| 应用 | 说明 |
|------|------|
| **采样-保持电路** | 对模拟信号采样并保持 |
| **斩波电路** | 将直流信号调制成交流 |
| **A/D转换** | 模拟信号的选择与传输 |
| **多路复用器** | 选择多路模拟信号中的一路 |

### 3.3 导通电阻要求

模拟开关的导通电阻：
- 一般在**数百欧**以下
- 精密CMOS模拟开关可达**几欧**级别
- 导通电阻稳定性对于线性传输很重要

## 四、传输门在数字电路中的应用

### 4.1 异或门实现

用传输门实现的**异或门**：

```
         A ────────┬──────────────
                   │
               ┌───┴───┐
           TG1 │       │ TG2
               └───┬───┘
                   │
    A ─────┬───────┼─────────── L
           │       │
       ┌───┴───┐   │
       │ 反相器 │   │
       └───┬───┘   │
           │       │
    B ─────┴───────┘

    当 B=0: TG1断开, TG2导通, L = A
    当 B=1: TG1导通, TG2断开, L = Ā
```

**逻辑功能**：
$$L = A\overline{B} + \overline{A}B = A \oplus B$$

### 4.2 2选1数据选择器

```
         0 ────────┬────────────
                   │
               ┌───┴───┐
           TG1 │       │
               └───┬───┘
                   ├─── L
               ┌───┴───┐
           TG2 │       │
               └───┬───┘
                   │
         1 ────────┴────────────

    C=0: TG1导通, TG2断开, L = 0输入
    C=1: TG1断开, TG2导通, L = 1输入
```

**逻辑功能**：
$$L = \overline{C} \cdot D_0 + C \cdot D_1$$

### 4.3 三态输出门

传输门可用于实现三态输出功能：
- 使能有效：传输门导通，正常输出
- 使能无效：传输门断开，高阻态

## 五、传输门的优点

| 优点 | 说明 |
|------|------|
| **双向传输** | 信号可双向传输 |
| **低导通电阻** | 两管并联，电阻小 |
| **电阻稳定** | 互补作用使电阻随电压变化小 |
| **结构简单** | 只需两个MOS管 |
| **传输延迟短** | 适合高速电路 |

## 📝 典型例题

> [!example] 例1：分析传输门构成的电路
> 下图是用传输门构成的电路，分析其逻辑功能：
> - 两个传输门TG1和TG2
> - TG1：输入A，控制B
> - TG2：输入Ā，控制B（反相）
> - 两传输门输出相连
>
> **解答**：
> | B | TG1 | TG2 | 输出L |
> |---|-----|-----|-------|
> | 0 | 导通 | 断开 | A |
> | 1 | 断开 | 导通 | Ā |
>
> 逻辑功能：$L = A \oplus B$（异或门）

> [!example] 例2：用传输门设计2选1数据选择器
>
> **解答**：
> - 使用两个传输门
> - TG1传输D0，控制信号为$\overline{C}$
> - TG2传输D1，控制信号为$C$
> - 输出：$L = \overline{C} \cdot D_0 + C \cdot D_1$

## ⚠️ 易错点

| 错误 | 正确理解 |
|------|---------|
| 传输门只能单向传输 | 传输门是**双向**的，输入输出可互换 |
| 传输门只能传输数字信号 | 传输门可传输**模拟信号**和数字信号 |
| 忘记互补控制信号 | 必须提供C和$\overline{C}$一对互补信号 |
