# MOS管及其开关特性

> [!info] 概述
> MOS管（Metal-Oxide-Semiconductor Field-Effect Transistor）是CMOS逻辑门电路的核心元件。理解MOS管的开关特性是掌握CMOS门电路工作原理的基础。

---

## 一、MOS管的分类

| 分类依据 | 类型 | 说明 |
|----------|------|------|
| 按导电载流子 | N沟道（NMOS） | 电子导电 |
| | P沟道（PMOS） | 空穴导电 |
| 按导电沟道形成 | 增强型 | $v_{GS}=0$时无导电沟道 |
| | 耗尽型 | $v_{GS}=0$时有导电沟道 |

> [!important] 重要
> **CMOS电路使用的是增强型MOS管**（NMOS和PMOS）

---

## 二、N沟道增强型MOS管

### 2.1 结构与符号

**结构组成**：
- **P型衬底**（Substrate）
- **两个高掺杂N区**：源极（s）和漏极（d）
- **栅极**（g）：与衬底间有SiO₂绝缘层
- **绝缘电阻**：高达 $10^{12} \sim 10^{15}\Omega$

**符号**：
```
        d
        │
    g ──┤
        │
        s
```

### 2.2 工作原理

> [!def] 开启电压 $V_T$（或 $V_{TH}$）
> 使MOS管开始导通的最小栅源电压。

**工作状态**：

| 条件 | 状态 | 导电沟道 | 漏极电流 |
|------|------|---------|---------|
| $v_{GS} < V_T$ | 截止 | 无 | $i_D = 0$ |
| $v_{GS} \geq V_T$ | 导通 | 形成N型反型层 | $i_D > 0$ |

### 2.3 输出特性曲线

```
    iD ↑
       │    ┌── 饱和区
       │   ╱│
       │  ╱ │
       │ ╱  │
       │╱   │
       ├────┴──── 可变电阻区
       │
       └────────→ vDS
         截止区
```

**三个工作区**：

| 工作区 | 条件 | 特点 | 等效 |
|--------|------|------|------|
| **截止区** | $v_{GS} < V_T$ | $i_D \approx 0$，电阻达 $10^9\Omega$ 以上 | 开关断开 |
| **可变电阻区** | $v_{GS} \geq V_T$ 且 $v_{DS} < v_{GS} - V_T$ | $i_D$ 随 $v_{DS}$ 线性变化 | 可变电阻 |
| **饱和区** | $v_{GS} \geq V_T$ 且 $v_{DS} \geq v_{GS} - V_T$ | $i_D$ 基本恒定 | 恒流源 |

### 2.4 导通电阻

在可变电阻区，MOS管的导通电阻为：

$$R_{ds} = \frac{1}{2K_n(v_{GS} - V_T)}$$

其中 $K_n = \frac{k_n'}{2} \cdot \frac{W}{L}$ 为电导常数。

> [!tip] 记忆
> **$v_{GS}$ 越大，导通电阻 $R_{ds}$ 越小**（导电沟道越宽）

## 三、P沟道增强型MOS管

### 3.1 结构特点

- 在**N型衬底**上制作两个高浓度P区
- 导电载流子为**空穴**
- 电压极性与NMOS相反

### 3.2 电压特性

| 参数 | NMOS | PMOS |
|------|------|------|
| 开启电压 | $V_{TN} > 0$ | $V_{TP} < 0$ |
| 栅源电压 | $v_{GS} > 0$ 导通 | $v_{GS} < 0$ 导通 |
| 漏源电压 | $v_{DS} > 0$ | $v_{DS} < 0$ |
| 漏极电流 | 流入漏极 | 流出漏极 |

---

## 四、MOS管开关电路

### 4.1 基本开关电路

```
       VDD
        │
        ├── RD（漏极电阻）
        │
    ────┴──── 输出 vO
        │
       ┌┴┐
       │ │ MOS管
       └┬┘
        │
    ────┴──── 输入 vI（栅极）
        │
       GND
```

### 4.2 开关工作状态

| 输入 | MOS管状态 | 输出 | 逻辑 |
|------|----------|------|------|
| $v_I < V_T$（低电平） | 截止 | $v_O \approx V_{DD}$（高电平） | 输入0，输出1 |
| $v_I > V_T$（高电平） | 导通（可变电阻区） | $v_O \approx 0$（低电平） | 输入1，输出0 |

### 4.3 开关等效电路

**截止时**（$v_I < V_T$）：
```
       VDD
        │
        ├── RD
        │
    ────┴──── vO = VDD（高电平）
        │
        │ 断开
        │
       GND
```

**导通时**（$v_I > V_T$）：
```
       VDD
        │
        ├── RD
        │
    ────┴──── vO ≈ 0（低电平）
        │
        ┌┴┐
        │ │ Ron（约1kΩ以下）
        └┬┘
        │
       GND
```

## 五、MOS管开关的动态特性

### 5.1 电容效应

MOS管存在以下寄生电容：
- **$C_{gb}$**：栅极-衬底电容（输入电容 $C_I$）
- **$C_{db}$**：漏极-衬底电容
- **$C_{gd}$**：栅极-漏极电容

### 5.2 开关时间

```
输入vI: ─────┐     ┌─────────
             └─────┘

输出vO: ──────────┐     ┌────
                   └─────┘
                   ↑     ↑
                 t_pHL  t_pLH
```

| 参数 | 含义 |
|------|------|
| $t_{pHL}$ | 输出从高电平跳变到低电平的传输延迟时间 |
| $t_{pLH}$ | 输出从低电平跳变到高电平的传输延迟时间 |

### 5.3 提高开关速度的方法

用**PMOS管替代电阻$R_D$**，构成CMOS反相器：
- 充电时：PMOS导通电阻小，充电快
- 放电时：NMOS导通电阻小，放电快

## 六、四种MOS管对比

| 类型 | 符号特点 | 开启/夹断电压 | 导通条件 |
|------|---------|--------------|---------|
| N沟道增强型 | 箭头指向沟道 | $V_T > 0$ | $v_{GS} > V_T$ |
| P沟道增强型 | 箭头指向沟道 | $V_T < 0$ | $v_{GS} < V_T$ |
| N沟道耗尽型 | 箭头指向沟道，虚线 | $V_P < 0$ | $v_{GS} > V_P$ |
| P沟道耗尽型 | 箭头指向沟道，虚线 | $V_P > 0$ | $v_{GS} < V_P$ |

> [!warning] 易混淆
> - **增强型**：$v_{GS}=0$时**不导通**，需要"增强"才能导通
> - **耗尽型**：$v_{GS}=0$时**已导通**，需要"耗尽"才能截止

## 📝 典型例题

> [!example] 例1：MOS管开关状态判断
> 已知NMOS管的开启电压 $V_T = 2V$，判断以下情况的工作状态：
> (1) $v_{GS} = 1V, v_{DS} = 5V$
> (2) $v_{GS} = 4V, v_{DS} = 1V$
> (3) $v_{GS} = 4V, v_{DS} = 5V$
>
> **解答**：
> (1) $v_{GS} = 1V < V_T = 2V$，**截止区**
> (2) $v_{GS} = 4V > V_T$，且 $v_{DS} = 1V < v_{GS} - V_T = 2V$，**可变电阻区**
> (3) $v_{GS} = 4V > V_T$，且 $v_{DS} = 5V > v_{GS} - V_T = 2V$，**饱和区**

---

## ⚠️ 易错点

| 错误 | 正确理解 |
|------|---------|
| MOS管工作在饱和区时相当于开关导通 | 数字电路中MOS管导通应工作在**可变电阻区** |
| NMOS和PMOS的开启电压都是正的 | PMOS的开启电压 $V_{TP} < 0$ |
| 忘记考虑衬底连接 | NMOS衬底接最低电位，PMOS衬底接最高电位 |
