# OD门与三态门

> [!info] 概述
> OD门（漏极开路门）和三态门是两种特殊的CMOS门电路输出结构，它们解决了普通CMOS门电路输出端不能直接相连的问题。⭐⭐⭐⭐⭐ **必考内容**

---

## 一、普通CMOS门输出端不能直接相连

### 1.1 问题分析

如果将两个普通CMOS与非门输出端直接相连：

```
        VDD
         │
    G1 ──┼──┐
         │  │  低阻通路！
    G2 ──┼──┘
         │
        GND
```

| 情况 | G1输出 | G2输出 | 结果 |
|------|--------|--------|------|
| 1 | 高电平（TP导通） | 低电平（TN导通） | 形成低阻通路，产生大电流，可能损坏器件 |

### 1.2 解决方案

1. **OD门（Open Drain）**：漏极开路门，配合上拉电阻实现"线与"
2. **三态门（Three-State）**：具有高阻态，可用于总线

---

## 二、CMOS漏极开路门（OD门）

### 2.1 电路结构

> [!def] 漏极开路门（OD门）
> OD门是指CMOS门电路的输出电路**只有NMOS管**，且漏极是**开路**的。

```
    A ──┬───┐
        │   │
       ┌┴┐  │
       │ │   │ 逻辑电路
       └┬┘  │
    B ──┼───┘
        │
       ┌┴┐
       │ │ 输出NMOS（漏极开路）
       └┬┘
        │
       输出L ────┐
                 │
                ⏚ 开路！
```

### 2.2 逻辑符号

OD门在逻辑符号中用 **"Ⓞ"** 或 **"≂"** 标记：

```
    ┌─────≎─────┐
    │   &   Ⓞ   │
    └────────────┘
```

### 2.3 正常工作电路

OD门**必须外接上拉电阻**才能正常工作：

```
        VDD
         │
         └── Rp（上拉电阻）
             │
         ┌───┴───┐
         │  OD门 │
         └───┬───┘
             │
            L ───→ 输出
```

## 三、OD门的线与功能

### 3.1 线与连接

> [!def] 线与（Wired-AND）
> 多个OD门输出端连接在一起，通过上拉电阻接电源，实现**与逻辑**功能。

```
        VDD
         │
         └── Rp
             │
    ┌────┬───┴───┬────┐
    │    │       │    │
   OD1  OD2    OD3   ...
    │    │       │    │
    └────┴───┬───┴────┘
             │
             L
```

### 3.2 线与逻辑

若三个OD门输出分别为 $\overline{A}$、$\overline{B}$、$\overline{C}$，则线与后：

$$L = \overline{A} \cdot \overline{B} \cdot \overline{C} = \overline{A + B + C}$$

> [!tip] 记忆
> **线与 = 与非-与非 = 或非**

### 3.3 线与的优点

| 优点 | 说明 |
|------|------|
| 减少门电路数量 | 用连线代替与门 |
| 简化电路设计 | 多个输出直接相连 |
| 实现电平转换 | 上拉电阻可接不同电压 |

## 四、上拉电阻计算 ⭐⭐⭐⭐⭐ 必考

### 4.1 两种极限情况

**情况1：只有一个OD门导通（输出低电平）**

此时需要计算 $R_{p(min)}$，确保电流不超过额定值。

**情况2：所有OD门截止（输出高电平）**

此时需要计算 $R_{p(max)}$，确保输出电平不低于规定值。

### 4.2 计算公式

> [!thm] 上拉电阻最小值
> $$R_{p(min)} = \frac{V_{DD} - V_{OL(max)}}{I_{OL(max)} - I_{IL(total)}}$$
>
> 其中：
> - $V_{DD}$：电源电压
> - $V_{OL(max)}$：输出低电平最大值
> - $I_{OL(max)}$：OD门最大灌电流
> - $I_{IL(total)}$：负载门低电平输入电流总和

> [!thm] 上拉电阻最大值
> $$R_{p(max)} = \frac{V_{DD} - V_{OH(min)}}{I_{OZ(total)} + I_{IH(total)}}$$
>
> 其中：
> - $V_{OH(min)}$：输出高电平最小值
> - $I_{OZ(total)}$：所有OD门截止时的漏电流总和
> - $I_{IH(total)}$：负载门高电平输入电流总和

### 4.3 电阻选择

$$R_{p(min)} \leq R_p \leq R_{p(max)}$$

- **追求速度**：选接近 $R_{p(min)}$ 的值
- **追求功耗**：选接近 $R_{p(max)}$ 的值

### 4.4 典型例题

> [!example] 例1：上拉电阻计算
> 3个OD与非门74HC03线与，驱动1个反相器74HC04和1个三输入与非门74HC10。
> 已知：$V_{DD}=5V$，$V_{OL(max)}=0.33V$时$I_{OL(max)}=4mA$，$V_{OH(min)}=4.4V$时$I_{OZ}=5\mu A$，
> $I_{IH(max)}=I_{IL(max)}=1\mu A$。
>
> **解答**：
>
> **(1) 计算 $R_{p(min)}$**
> 负载输入端数：$n = 1 + 3 = 4$
> $I_{IL(total)} = 4 \times 1\mu A = 4\mu A$
> $$R_{p(min)} = \frac{5V - 0.33V}{4mA - 0.004mA} = \frac{4.67V}{3.996mA} \approx 1.17k\Omega$$
>
> **(2) 计算 $R_{p(max)}$**
> $I_{OZ(total)} = 3 \times 5\mu A = 15\mu A$
> $I_{IH(total)} = 4 \times 1\mu A = 4\mu A$
> $$R_{p(max)} = \frac{5V - 4.4V}{15\mu A + 4\mu A} = \frac{0.6V}{19\mu A} \approx 31.58k\Omega$$
>
> **(3) 选择**：$R_p$ 在 $1.17k\Omega \sim 31.58k\Omega$ 之间，可选用 **2kΩ** 标准值。

## 五、OD门的其他应用

### 5.1 驱动LED

```
        VCC (+5V)
         │
         └── LED
             │
         ┌───┴───┐
         │  OD门 │
         └───┬───┘
             │
        输入控制
```

- 输入高电平 → OD门导通 → LED亮
- 输入低电平 → OD门截止 → LED灭

### 5.2 电平转换

```
        3.3V系统              5V系统
           │                    │
           └── Rp ─────────────┘
                 │
             ┌───┴───┐
             │  OD门  │
             └───┬───┘
                 │
            3.3V逻辑输入
```

## 六、三态输出门

### 6.1 三态概念

> [!def] 三态门
> 三态门具有三种输出状态：
> 1. **高电平**（逻辑1）
> 2. **低电平**（逻辑0）
> 3. **高阻态**（High-Z，禁止态）

### 6.2 电路结构

```
    EN ──┬───────────┐
         │           │
         ▼           │
    A ──┬───┐   ┌───┴───┐
        │   │   │       │
       ┌┴┐ ┌┴┐ │ 逻辑   │
       │ │ │ │ │ 电路   │
       └┬┘ └┬┘ │       │
         │   │ └───┬───┘
         └───┴─────┤
                   │
                  L ───→ 输出
```

### 6.3 真值表

| EN（使能） | A（输入） | L（输出） |
|-----------|----------|----------|
| 1（有效） | 0 | 0 |
| 1（有效） | 1 | 1 |
| 0（无效） | × | **高阻态** |

### 6.4 逻辑符号

```
高电平有效：          低电平有效：
┌─────────┐       ┌─────────┐
│    1    │       │    ○    │
│   ──    │       │   ──    │
└─────────┘       └─────────┘
   EN=1有效          EN=0有效
```

## 七、三态门的应用

### 7.1 总线传输

```
         数据总线
             │
    ┌────────┼────────┐
    │        │        │
   三态门1  三态门2  三态门3
    │        │        │
   设备1    设备2    设备3

    任何时刻只有一个三态门使能
```

### 7.2 总线工作原则

> [!warning] 重要原则
> **任何时刻只能有一个三态门处于使能状态**，其他三态门必须处于高阻态。

| 时刻 | 设备1 | 设备2 | 设备3 | 总线状态 |
|------|-------|-------|-------|---------|
| T1 | 使能 | 高阻 | 高阻 | 传输设备1数据 |
| T2 | 高阻 | 使能 | 高阻 | 传输设备2数据 |
| T3 | 高阻 | 高阻 | 使能 | 传输设备3数据 |

### 7.3 双向数据传输

```
        ┌─────────┐
   D ───┤  三态门  ├───┬─── 数据总线
        └─────────┘   │
                      │
        ┌─────────┐   │
   Q ←──┤  输入缓冲 │←──┘
        └─────────┘

    DIR=1: 数据D→总线（输出）
    DIR=0: 总线→Q（输入）
```

## 八、OD门 vs 三态门

| 特性 | OD门 | 三态门 |
|------|------|--------|
| 输出状态 | 2态（高/低） | 3态（高/低/高阻） |
| 外接元件 | 需要上拉电阻 | 不需要 |
| 线与功能 | 支持 | 不支持（需要分时使能） |
| 开关速度 | 较慢（受Rp影响） | 较快 |
| 功耗 | 静态功耗较高 | 静态功耗低 |
| 典型应用 | 线与、电平转换、LED驱动 | 总线传输、双向接口 |

## ⚠️ 易错点

| 错误 | 正确理解 |
|------|---------|
| OD门输出可以直接相连 | 必须**外接上拉电阻**才能工作 |
| 三态门输出可以直接相连 | 必须**分时使能**，不能同时使能 |
| 上拉电阻越小越好 | $R_p$不能太小，否则电流超过额定值 |
| 忘记计算负载电流 | 计算$R_p$时要考虑所有负载的输入电流 |
