# TTL逻辑门电路

> [!info] 概述
> TTL（Transistor-Transistor Logic）是应用最早的集成电路技术，使用**双极结型三极管（BJT）**作为开关元件。虽然已被CMOS取代主导地位，但在教育和简单数字电路中仍有应用。

---

## 一、BJT的开关特性

### 1.1 BJT开关电路

```
        VCC
         │
         └── RC
             │
         ┌───┴───┐
         │  BJT  │
         └───┬───┘
             │
    vO ──────┤
             │
            GND

    vI ──→ 基极
```

### 1.2 两种开关状态

| 状态 | 条件 | 特点 | 等效 |
|------|------|------|------|
| **截止** | $v_{BE} < V_{BE(th)}$（约0.7V） | $i_C \approx 0$，$v_{CE} \approx V_{CC}$ | 开关断开 |
| **饱和** | $i_B > I_{BS} = \frac{I_{CS}}{\beta}$ | $i_C = I_{CS} = \frac{V_{CC}}{R_C}$，$v_{CE} = V_{CES} \approx 0.2V$ | 开关闭合 |

### 1.3 饱和条件

> [!thm] BJT饱和导通条件
> $$i_B > I_{BS} = \frac{I_{CS}}{\beta} = \frac{V_{CC}}{\beta R_C}$$

其中：
- $I_{BS}$：基极临界饱和电流
- $I_{CS}$：集电极饱和电流
- $\beta$：电流放大系数

### 1.4 BJT vs MOS管开关特性

| 特性 | BJT | MOS管 |
|------|-----|-------|
| 控制方式 | 电流控制（$i_B$） | 电压控制（$v_{GS}$） |
| 输入电阻 | 低（kΩ级） | 高（$10^{12}\Omega$以上） |
| 开关速度 | 较慢（电荷存储效应） | 较快 |
| 功耗 | 较高 | 低 |

## 二、TTL反相器基本电路

### 2.1 电路结构

TTL反相器由三部分组成：

```
        VCC
         │
    ┌────┴────┐
    │ 输出级  │ T3, T4, D
    ├────────┤
    │ 中间级  │ T2
    ├────────┤
    │ 输入级  │ T1
    └────────┘
        GND
```

### 2.2 各部分功能

| 部分 | 元件 | 功能 |
|------|------|------|
| **输入级** | T1（多发射极BJT） | 提高开关速度 |
| **中间级** | T2 | 产生互补信号驱动输出级 |
| **输出级** | T3, T4, D | 推拉式输出，增强带载能力 |

### 2.3 工作原理

| 输入 | T1状态 | T2状态 | T3状态 | T4状态 | 输出 |
|------|--------|--------|--------|--------|------|
| 低电平（0.2V） | 放大 | 截止 | 截止 | 导通 | 高电平（3.6V） |
| 高电平（3.6V） | 倒置放大 | 饱和 | 饱和 | 截止 | 低电平（0.2V） |

### 2.4 TTL典型电平

| 参数 | 典型值 |
|------|--------|
| $V_{OH}$ | 3.6V |
| $V_{OL}$ | 0.3V |
| $V_{IH(min)}$ | 2V |
| $V_{IL(max)}$ | 0.8V |

## 三、TTL与非门

### 3.1 结构特点

将TTL反相器的输入级T1改为**多发射极BJT**：

```
    A ──┬──┐
        │  │
       ┌┴┐ │
       │ │ │ T1（多发射极）
       └┬┘ │
    B ──┼──┘
        │
       中间级 + 输出级
```

### 3.2 工作原理

| A | B | T1发射结 | 输出 |
|---|---|---------|------|
| 0 | 0 | 至少一个导通 | 1 |
| 0 | 1 | 至少一个导通 | 1 |
| 1 | 0 | 至少一个导通 | 1 |
| 1 | 1 | 都截止 | 0 |

**逻辑功能**：$L = \overline{A \cdot B}$（与非门）

## 四、肖特基TTL（抗饱和TTL）

### 4.1 问题：深度饱和导致速度慢

BJT从饱和到截止需要**消散基区存储电荷**，这是TTL速度受限的主要原因。

### 4.2 解决方案：肖特基二极管钳位

> [!def] 肖特基势垒二极管（SBD）
> - 导通电压低（0.4~0.5V）
> - 无电荷存储效应
> - 开关速度快

**钳位原理**：在BJT的基极-集电极之间并联SBD，限制饱和深度。

```
        基极
         │
        ┌┴┐
        │ │ SBD
        └┬┘
         │←── 钳位在0.4V
        ┌┴┐
        │ │ BJT
        └┬┘
         │
       集电极
```

### 4.3 肖特基TTL系列

| 系列 | 特点 |
|------|------|
| **74S** | 肖特基TTL，速度快 |
| **74LS** | 低功耗肖特基，速度与功耗平衡 |
| **74AS** | 先进肖特基，速度更快 |
| **74ALS** | 先进低功耗肖特基，速度功耗均改善 |
| **74F** | FAST系列，综合性能好 |

## 五、集电极开路门（OC门）

### 5.1 结构

TTL的OC门与CMOS的OD门类似，输出级BJT的**集电极开路**。

```
    ┌───────────┐
    │   TTL逻辑  │
    │   电路     │
    ├───────────┤
    │    T      │←── 集电极开路
    └─────┬─────┘
          │
         OC输出
```

### 5.2 应用

与CMOS OD门相同：
- **线与功能**
- **电平转换**
- **驱动指示灯**

### 5.3 上拉电阻计算

与OD门计算公式相同。

## 七、TTL vs CMOS对比

### 7.1 主要差异

| 特性 | CMOS | TTL |
|------|------|-----|
| 有源器件 | MOS管 | BJT |
| 输入电阻 | 极高（$10^{12}\Omega$） | 较低（kΩ级） |
| 静态功耗 | 极低 | 较高 |
| 噪声容限 | 大 | 较小 |
| 电源电压 | 范围宽（1.8~18V） | 固定（5V） |
| 速度 | 快（现代系列） | 较慢 |
| 集成度 | 高 | 低 |

### 7.2 输入端悬空处理

| 类型 | 悬空结果 | 处理方法 |
|------|---------|---------|
| **CMOS** | 不确定，可能振荡 | **必须接确定电平** |
| **TTL** | 相当于高电平 | 可以悬空，但不推荐 |

### 7.3 输入端电阻特性

**TTL特殊现象**：

当TTL输入端通过电阻接地时：
- 电阻 < 0.7kΩ（关门电阻）：相当于低电平
- 电阻 > 2kΩ（开门电阻）：相当于高电平

> [!warning] TTL输入端电阻
> TTL输入端通过电阻接地时，由于输入电流流过电阻产生压降，电阻值会影响逻辑状态。这与CMOS不同（CMOS输入电流极小，电阻接地始终为低电平）。

## 八、TTL与CMOS接口

### 8.1 CMOS驱动TTL

| 条件 | 是否需要接口 |
|------|-------------|
| 相同电源电压 | 不需要 |
| CMOS高电压驱动TTL | 需要电平转换 |

### 8.2 TTL驱动CMOS

**问题**：TTL的$V_{OH}$（2.4V）可能不满足CMOS的$V_{IH}$（3.5V）

**解决方案**：
1. 使用**TTL兼容CMOS**（74HCT系列）
2. 使用**上拉电阻**提升高电平

```
    TTL输出 ────┬──── CMOS输入
                 │
                Rp（上拉电阻）
                 │
               VDD
```

## 📝 典型例题

> [!example] 例1：BJT开关状态判断
> 已知：$V_{CC}=5V$，$R_C=1k\Omega$，$\beta=100$，$i_B=0.1mA$。
> 判断BJT是否饱和。
>
> **解答**：
> 集电极饱和电流：$I_{CS} = \frac{V_{CC}}{R_C} = \frac{5V}{1k\Omega} = 5mA$
>
> 临界饱和基极电流：$I_{BS} = \frac{I_{CS}}{\beta} = \frac{5mA}{100} = 0.05mA$
>
> 因为 $i_B = 0.1mA > I_{BS} = 0.05mA$
>
> **BJT处于饱和状态**

## ⚠️ 易错点

| 错误 | 正确理解 |
|------|---------|
| TTL输入端悬空为低电平 | TTL输入端悬空相当于**高电平** |
| CMOS和TTL可以直接连接 | 需要**电平兼容**或使用接口 |
| TTL功耗比CMOS低 | TTL功耗**比CMOS高** |
| BJT饱和越深越好 | 饱和太深会**降低开关速度** |
