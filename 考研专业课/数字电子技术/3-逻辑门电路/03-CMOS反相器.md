# CMOS反相器

> [!info] 概述
> CMOS反相器是CMOS逻辑门电路的**基本单元**。它由一个**NMOS管**和一个**PMOS管**组成互补结构，是理解所有CMOS门电路的基础。⭐⭐⭐⭐⭐ **核心考点**

---

## 一、电路结构

### 1.1 基本电路

```
        VDD
         │
        ┌┴┐
        │ │ TP (PMOS)
        └┬┘
    ────┼──── 输出 vO
        │
        ┌┴┐
        │ │ TN (NMOS)
        └┬┘
         │
        GND

    输入vI ──→ 栅极（两管栅极相连）
```

### 1.2 连接特点

| 元件 | 连接方式 |
|------|---------|
| TN和TP栅极 | 连在一起作为输入端 |
| TN和TP漏极 | 连在一起作为输出端 |
| TN源极 | 接地（GND） |
| TP源极 | 接电源（$V_{DD}$） |
| TN衬底 | 接最低电位（GND） |
| TP衬底 | 接最高电位（$V_{DD}$） |

### 1.3 正常工作条件

$$V_{DD} > V_{TN} + |V_{TP}|$$

即电源电压必须大于两个管子开启电压绝对值之和。

---

## 二、工作原理

### 2.1 两种极限情况

| 输入 | TN状态 | TP状态 | 输出 | 逻辑 |
|------|--------|--------|------|------|
| $v_I = 0$（逻辑0） | 截止（$v_{GSN} < V_{TN}$） | 导通（$v_{SGP} > |V_{TP}|$） | $v_O \approx V_{DD}$（逻辑1） | 非门 |
| $v_I = V_{DD}$（逻辑1） | 导通（$v_{GSN} > V_{TN}$） | 截止（$v_{SGP} < |V_{TP}|$） | $v_O \approx 0$（逻辑0） | 非门 |

### 2.2 等效电路

**输入低电平时**：
```
        VDD
         │
        ┌┴┐
        │ │ TP 导通（小电阻）
        └┬┘
    ────┼──── vO ≈ VDD
        │
        ┌┴┐
        │ │ TN 截止（开路）
        └┬┘
         │
        GND
```

**输入高电平时**：
```
        VDD
         │
        ┌┴┐
        │ │ TP 截止（开路）
        └┬┘
    ────┼──── vO ≈ 0
        │
        ┌┴┐
        │ │ TN 导通（小电阻）
        └┬┘
         │
        GND
```

## 三、电压传输特性

### 3.1 特性曲线

```
    vO ↑
   VDD ┤━━━━━━━━━╮
       │         ╰─╮
       │           ╰─╮ AB
   VDD/2┤             ╰───╮ CD
       │           ╱──╯  │
       │         ╱─╯     │ EF
     0 ┤─────────╯━━━━━━━╯━━━→ vI
       0    VTN    VDD/2    VDD-|VTP|  VDD
                        VTH
```

### 3.2 五个工作区域

| 区域 | 输入范围 | TN状态 | TP状态 | 输出 |
|------|---------|--------|--------|------|
| **AB** | $0 \leq v_I < V_{TN}$ | 截止 | 可变电阻区 | $v_O = V_{DD}$ |
| **BC** | $V_{TN} \leq v_I < V_{DD}/2$ | 饱和区 | 可变电阻区 | $v_O$ 下降 |
| **CD** | $v_I = V_{DD}/2$ | 饱和区 | 饱和区 | $v_O$ 急剧变化 |
| **DE** | $V_{DD}/2 < v_I \leq V_{DD}-|V_{TP}|$ | 可变电阻区 | 饱和区 | $v_O$ 继续下降 |
| **EF** | $v_I > V_{DD}-|V_{TP}|$ | 可变电阻区 | 截止 | $v_O = 0$ |

### 3.3 阈值电压

> [!def] 阈值电压 $V_{TH}$
> CMOS反相器输出状态发生转换时的输入电压，**$V_{TH} = V_{DD}/2$**

这是CMOS反相器的重要参数，当 $v_I = V_{TH}$ 时，两管同时导通，输出电压急剧变化。

## 四、电流传输特性

### 4.1 漏极电流变化

```
    iD ↑
       │       ╱╲
       │      ╱  ╲
       │     ╱    ╲
       │    ╱      ╲
     0 ┤───╱────────╲───→ vI
       0  VTN    VDD-|VTP|  VDD
              VDD/2
```

### 4.2 关键特点

1. **稳态时**：一个管子导通，一个管子截止，$i_D \approx 0$
2. **转换区**：两管同时导通，$i_D$ 达到最大值（在 $v_I = V_{DD}/2$ 处）
3. **静态功耗极低**：稳态时几乎为零

> [!warning] 注意
> 应避免CMOS反相器长时间工作在转换区（$V_{TN} < v_I < V_{DD}-|V_{TP}|$），否则会产生较大的电流尖峰和功耗。

## 五、输入/输出逻辑电平

### 5.1 输入电平范围

```
    电压
     ↑
VDD ─┼────────────────┬──────────
     │    禁止区      │ 高电平区
VIH ─┼────────────────┤ ← 输入高电平下限
     │                │
VIL ─┼────────────────┤ ← 输入低电平上限
     │   低电平区     │ 禁止区
  0 ─┼────────────────┴──────────
     └─────────────────────────→
```

| 参数 | 含义 | 典型值(74LVC, 3.3V) |
|------|------|-------------------|
| $V_{IL(max)}$ | 输入低电平上限 | 0.8V |
| $V_{IH(min)}$ | 输入高电平下限 | 2.0V |

### 5.2 输出电平范围

| 参数 | 含义 | 典型值(74LVC, 3.3V) |
|------|------|-------------------|
| $V_{OL(max)}$ | 输出低电平上限 | 0.2V (I_O = 0.1mA) |
| $V_{OH(min)}$ | 输出高电平下限 | 3.1V (I_O = -0.1mA) |

## 六、CMOS反相器的特点

### 6.1 主要优点

> [!success] CMOS反相器的优点

1. **静态功耗极低**
   - 稳态时一个管子截止，漏电流极小
   - 静态功耗接近于零

2. **逻辑摆幅大**
   - $V_{OH} \approx V_{DD}$，$V_{OL} \approx 0$
   - 噪声容限大，抗干扰能力强

3. **输入电阻高**
   - MOS管栅极绝缘，$R_{in} > 10^{12}\Omega$
   - 对前级电路负载小

4. **带负载能力强**
   - 充放电回路电阻小
   - 开关速度快

### 6.2 输出特性

**输出低电平时**（灌电流负载）：
- TN导通，TP截止
- 电流从负载流向TN

**输出高电平时**（拉电流负载）：
- TP导通，TN截止
- 电流从TP流向负载

---

## 七、工作速度

### 7.1 容性负载

CMOS反相器的负载通常是**电容性**的（下一级门电路的输入电容）。

### 7.2 充放电过程

**输出由低变高**（充电）：
- TP导通，$V_{DD}$通过TP向$C_L$充电
- 充电时间常数：$\tau_{LH} = R_{on(P)} \cdot C_L$

**输出由高变低**（放电）：
- TN导通，$C_L$通过TN放电
- 放电时间常数：$\tau_{HL} = R_{on(N)} \cdot C_L$

### 7.3 传输延迟

由于电路互补对称，$R_{on(N)} \approx R_{on(P)}$，因此：
$$t_{pLH} \approx t_{pHL}$$

## 📝 典型例题

> [!example] 例1：CMOS反相器工作状态分析
> 已知CMOS反相器，$V_{DD} = 5V$，$V_{TN} = 1V$，$V_{TP} = -1V$。
> 分析当 $v_I = 0V, 2.5V, 5V$ 时两管的工作状态和输出电压。
>
> **解答**：
> | 输入 | TN状态 | TP状态 | 输出 |
> |------|--------|--------|------|
> | 0V | 截止（$v_{GSN}=0<V_{TN}$） | 导通（$v_{SGP}=5V>|V_{TP}|$） | $v_O \approx 5V$ |
> | 2.5V | 导通（$v_{GSN}=2.5V>V_{TN}$） | 导通（$v_{SGP}=2.5V>|V_{TP}|$） | $v_O \approx 2.5V$（转换区）|
> | 5V | 导通（$v_{GSN}=5V>V_{TN}$） | 截止（$v_{SGP}=0<|V_{TP}|$） | $v_O \approx 0V$ |

> [!example] 例2：阈值电压计算
> CMOS反相器电源电压$V_{DD} = 3.3V$，求阈值电压$V_{TH}$。
>
> **解答**：
> $$V_{TH} = \frac{V_{DD}}{2} = \frac{3.3V}{2} = 1.65V$$

---

## ⚠️ 易错点

| 错误 | 正确理解 |
|------|---------|
| 认为CMOS反相器导通时两管都导通 | 稳态时**只有一个导通**，转换时才两管同时导通 |
| 阈值电压等于开启电压 | $V_{TH} = V_{DD}/2$，与$V_T$不同 |
| 忽略衬底连接 | 衬底连接错误会导致寄生二极管正偏 |
