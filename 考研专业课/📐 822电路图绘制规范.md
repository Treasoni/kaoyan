# 822电路图绘制规范

> [!info] 用途
> 以后生成模电、数电、电路等图示时，优先使用可编辑的 Obsidian Excalidraw。需要教材级正式图时，再使用 `circuitikz` 或 SVG。

---

## 1. 输出优先级

| 场景 | 推荐格式 | 原因 |
| --- | --- | --- |
| 课堂笔记、错题整理、复习卡片 | Obsidian Excalidraw `.md` | 可编辑、可拖动、适合二次修改 |
| 教材级总结、PDF讲义 | `circuitikz` 或 SVG | 符号更标准，适合打印 |
| 快速讲解、临时草图 | Mermaid 或手绘风 Excalidraw | 快速表达拓扑关系 |

---

## 2. 标准生成流程

1. 先把题目转成电路结构描述。
2. 判断电路类型：共射、共集、差分、运放、反馈、功放、稳压、逻辑门、时序电路等。
3. 选择已有模板或搭建标准拓扑。
4. 放置器件符号，保持网格对齐。
5. 标注节点、电流方向、电压极性、输入输出。
6. 根据学习目的添加分析层：直流通路、交流通路、微变等效、反馈路径。
7. 最后检查悬空节点、极性、符号方向、输入输出和反馈路径。

---

## 3. 器件符号库

### 基础元件

| 元件 | 绘制要求 | 标注示例 |
| --- | --- | --- |
| 电阻 | 水平或竖直，避免斜放 | $R_B$、$R_C$、$R_E$、$R_L$ |
| 电容 | 耦合电容、旁路电容要区分位置 | $C_1$、$C_2$、$C_E$ |
| 电源 | 顶部放 $V_{CC}$ 或 $V_{DD}$，底部接地 | $V_{CC}$、$-V_{EE}$ |
| 接地 | 统一使用三横线或倒三角 | GND |
| 信号源 | 左侧输入，右侧输出 | $u_i$、$u_o$ |

### 半导体器件

| 元件 | 绘制要求 | 易错检查 |
| --- | --- | --- |
| NPN | 集电极在上、发射极在下，箭头向外 | 箭头方向和电流方向 |
| PNP | 发射极箭头向内 | 电源极性 |
| NMOS | 漏极在上、源极在下 | $U_{GS}$ 极性 |
| PMOS | 与 NMOS 极性相反 | 衬底/源极关系 |
| 二极管 | 箭头方向体现导通方向 | 正负端 |
| 稳压管 | 反向稳压使用 | 稳压方向 |
| 运放 | 左侧输入、右侧输出，上下供电 | 同相/反相端不能反 |

## 4. 模电图层规范

| 图层 | 颜色/线型 | 用途 |
| --- | --- | --- |
| 原电路 | 黑色实线 | 标准电路结构 |
| 直流通路 | 红色标注 | 分析静态工作点 |
| 交流通路 | 蓝色标注 | 分析动态参数 |
| 反馈路径 | 紫色虚线 | 判断反馈类型 |
| 等效模型 | 灰色或独立区域 | 微变等效电路 |
| 关键注释 | 黄色浅底 | 易错点、边界条件 |

## 5. 常用模板

### 共射放大电路

必须包含：
- $V_{CC}$、$R_C$、$R_B$ 或分压偏置 $R_{B1}$、$R_{B2}$
- NPN 三极管
- $R_E$ 与旁路电容 $C_E$（若题目有）
- 输入耦合电容 $C_1$
- 输出耦合电容 $C_2$
- 负载 $R_L$
- 标注 $u_i$、$u_o$、$I_{BQ}$、$I_{CQ}$、$U_{CEQ}$

### 运放电路

必须包含：
- 运放三角形
- 同相端 `+`、反相端 `-`
- 输入电阻、反馈电阻
- 输出端 $u_o$
- 判断工作区：线性区才能写虚短虚断

### 负反馈放大电路

必须包含：
- 基本放大电路
- 反馈网络
- 输入比较点
- 输出取样点
- 反馈路径用虚线标出
- 标注“电压/电流取样”和“串联/并联比较”

### 微变等效电路

必须包含：
- 交流地
- $r_{be}$ 或 $g_m u_{gs}$
- 受控源
- $R_C$、$R_L$、$R_E$ 的交流等效关系
- 输入电阻 $R_i$ 和输出电阻 $R_o$ 的观察端

## 6. 检查清单

- 器件方向是否符合康华光习惯。
- 输入在左，输出在右，电源上方，地在下方。
- 三极管箭头方向是否正确。
- 运放同相端和反相端是否标清。
- 耦合电容和旁路电容是否位置正确。
- 直流通路中电容是否开路。
- 交流通路中电源是否交流接地。
- 反馈路径是否能看出取样和比较方式。
- 节点名、电压极性、电流方向是否自洽。
