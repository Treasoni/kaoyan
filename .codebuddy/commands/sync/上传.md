# 上传学习数据到 MemOS

正在将本地学习数据上传到 MemOS...

## 执行步骤

### 步骤 1: 获取今日日期

首先确定今日日期（格式：YYYY-MM-DD），然后查找对应的每日计划文件。

### 步骤 2: 读取本地学习文件

使用 `Glob` 工具查找今日学习文件：
- 路径：`考研计划/每日计划/{日期}-每日计划.md`
- 路径：`考研英语/📅 复习计划.md`
- 路径：`考研专业课/**/*.md` （专业课笔记，扫描电路分析/模电/数电等）

**专业课扫描逻辑**：
- 查找所有 `.md` 文件
- 识别文件名中的模块信息（电路分析、模拟电子技术、数字电子技术）
- 提取文件中的 `tags` 字段
- 整理专业课学习进度

### 步骤 3: 提取关键信息

从读取的文件中提取：
- 今日学习内容
- 完成状态
- 学习时长
- 数学进度
- 英语词汇进度
- **笔记标签（tags）** - 从笔记文件的 frontmatter 中提取
- 下一步计划

**标签提取规则**：
- 识别笔记文件中的 `tags: [...]` 字段
- 将标签格式化为 `#标签名` 格式
- 将标签作为 MemOS 消息内容的一部分保存
- 用于未来的知识图谱构建和知识点关联

### 步骤 4: 保存到 MemOS

使用 `mcp__MemoryOperatingSystem__add_message` 工具上传：

**参数**：
- `conversation_first_message`: "考研学习计划 - 湖南大学控制工程与科学专硕"
- `messages`: 提取的学习数据

**消息格式**：
```json
{
  "role": "user",
  "content": "今日学习记录 {日期}\n\n学习时间：{时长}\n科目：{科目}\n\n【数学】{内容}\n\n【英语】{内容}\n\n**标签**：{提取的标签，格式化为 #数学 #极限 #函数}\n\n下次复习：{日期}"
}
```

**标签处理示例**：
- 原始：`tags: [数学, 极限, 函数, 反函数]`
- 格式化：`**标签**：#数学 #极限 #函数 #反函数`
- 作用：保存到 MemOS 后，可通过标签检索相关知识点，用于知识图谱构建

### 步骤 5: 确认上传

输出上传结果确认。
