## 🎯 学习路线

```
阶段1: 导数计算基础 (8-10小时)
  导数定义 → 基本公式 → 四则运算 → 复合函数
       ↓
  隐函数 → 反函数 → 参数方程 → 高阶导数
       ↓
阶段2: 中值定理 (6-8小时)
  罗尔 → 拉格朗日 → 柯西 → 泰勒公式 ⭐
       ↓
  洛必达法则
       ↓
阶段3: 导数应用 (6-7小时)
  单调性 → 极值 → 最值 → 凹凸性 → 拐点 → 渐近线
```

## 📝 学习建议

1. **计算能力第一**：熟练掌握各种求导方法，这是后续应用的基础
2. **理解中值定理**：罗尔、拉格朗日是核心，泰勒公式要会用
3. **综合应用**：能用导数分析函数的所有性质
4. **证明题训练**：中值定理证明是数二难点和重点
