## 一、我的考试科目与换校兼容性

| 科目 | 代码 | 限制 |
|------|------|------|
| 思想政治理论 | 101 | 全国统考，无限制 |
| 英语二 | 204 | ⚠️ 不能调剂到考英语一的院校 |
| 数学二 | 302 | ⚠️ 不能调剂到考数学一的院校 |
| 822电子技术基础 | 自命题 | 模电+数电，54所院校通用 |

### 调剂科目规则

```
数一 → 数二 ✅    数二 → 数一 ❌
英一 → 英二 ✅    英二 → 英一 ❌

结论：考数二+英二的考生，只能调剂到同样考数二+英二的院校
```

## 三、调剂院校分析

### 3.1 调剂基本规则（针对数二+英二考生）

```
我的情况：政治 + 英语二 + 数学二 + 822电子技术基础（模电+数电）

能调剂到：
├── 同样考 数二+英二 的电子信息专硕（0854）
├── 对数学英语要求更低的专业
└── 同一学科门类（工学08）下的相近专业

不能调剂到：
├── 考 数一+英一 的院校/专业 ❌
└── 湖南大学电气院（明确不接收普通调剂）❌
```

## 四、策略建议

### 4.1 现阶段策略（4月-8月）

```
✅ 继续按湖南大学822复习模电+数电
   ├── 全国54所院校考这个科目，换校成本极低
   ├── 康华光《电子技术基础》是最通用的参考书
   └── 即使后期换校，专业课复习基本不用变

❌ 不要现在就换目标院校
   ├── 现在换校只会增加焦虑
   ├── 9月招生简章出来后再确认最稳妥
   └── 湖大控制学科评估A-，值得冲刺
```

### 4.2 暑假评估策略（7月-8月）

根据复习进度自我评估：

| 复习进度 | 建议目标 |
|----------|----------|
| 进度正常，模电数电掌握良好 | 继续冲湖大 |
| 感觉吃力但基础还行 | 考虑转入：合肥工业大学、西南交通大学 |
| 基础薄弱，需降低难度 | 考虑转入：太原理工、南昌大学、长安大学 |
| 想稳妥保底 | B区211：贵州大学、广西大学 |

### 4.3 调剂预案（如果需要）

```
初试成绩出来后（2027年2月底）：

达到湖大复试线（预估370-400+）
└── 全力备战湖大复试

未达湖大线但过了A区国家线（预估270-290）
├── 冲刺：A区211（合工大、西南交大等）
├── 稳妥：A区强势双非（桂林电子科大、中北大学等）
└── 保底：A区普通双非

只过了B区国家线（预估260-280）
├── 冲刺：云南大学、贵州大学
└── 稳妥：广西大学、新疆大学
```
