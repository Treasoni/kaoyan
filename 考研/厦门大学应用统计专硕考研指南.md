# 厦门大学应用统计专硕（025200）考研指南

> [!abstract] 快速概览
> - **院校**：厦门大学（985/211/双一流）
> - **专业**：应用统计（专业学位，代码 025200）
> - **学科评估**：统计学 **A**（第四轮，全国第6）
> - **培养单位**：统计学与数据科学系（全日制）、王亚南经济研究院（2026起仅非全日制）
> - **2026计划招生**：全日制约75人（大幅扩招）
> - **学费**：全日制 3.3万/年；非全日制 5万/年（全程15万）

## 四、2026年招生变动（重要）

### 4.1 全日制（统计学与数据科学系）

- 计划招生**约75人**（2025年仅约27人，**扩招近3倍**）
- 复试形式：**现场复试**（笔试+面试）
- 复试时间：2026年3月底
- 2026年4月6日已公布拟录取名单（PDF附件）

### 4.2 非全日制（王亚南经济研究院）

- **2026年起王亚南经济研究院停止全日制招生**，改为只招非全日制
- 非全日制计划招生**39人**（通过调剂录取）
- 学费：全程15万元（5万/年）
- 上课时间：周末
- 不享受奖助学金、不安排住宿
- 毕业证书注明"非全日制"

### 4.3 其他招生单位

- **数学科学学院**也招收应用统计方向（学硕统计学下的应用统计方向）
- 数学科学学院2026复试线：统计学 45/45/85/90/335

## 五、复试方案

### 5.1 复试构成

| 项目 | 内容 | 分值 |
|------|------|------|
| 笔试 | 英语 | 满分100分制下占一定比例 |
| 面试（中文） | 专业和综合素质 | - |
| 面试（英文） | 英语口语 | - |
| 品德考核 | 思想政治素质 | 合格/不合格 |

### 5.2 成绩计算

$$总成绩 = \frac{初试成绩}{5} \times 60\% + 复试成绩（百分制） \times 40\%$$

### 5.3 复试淘汰规则（全日制）

出现以下任一情况直接淘汰：
1. 英语笔试和英语面试成绩加总低于15分
2. 中文面试中两位及以上面试专家打不合格等级
3. 去掉一个最高分后，中文面试平均分低于36分

### 5.4 复试比例

- 一般为 **150%**（即招10人约15人进复试）

## 七、报考建议与难度分析

### 7.1 难度评估

| 维度 | 评价 | 说明 |
|------|------|------|
| 院校层次 | 极高 | 985/C9/双一流 |
| 学科实力 | 极高 | 统计学A，全国第6 |
| 考试难度 | 高 | 英语一+数学三+432自命题 |
| 竞争程度 | 中高 | 报考热度高，但2026扩招 |
| 复试友好度 | 中等 | 复试占比40%，有淘汰机制 |

### 7.2 2026年扩招的影响

- 全日制名额从约27人扩大到约75人，**录取概率显著提升**
- 分数线可能因扩招而下降（2026校线330已大幅降低）
- 但因厦大统计学科实力强+985光环，报考人数也会相应增加

### 7.3 备考规划建议

| 阶段 | 时间 | 重点 |
|------|------|------|
| 基础阶段 | 现在-8月 | 数学三基础+英语一阅读+专业课教材通读 |
| 强化阶段 | 9月-10月 | 数学真题+专业课重难点+英语真题 |
| 冲刺阶段 | 11月-12月 | 政治背诵+全科模拟+专业课真题演练 |

### 7.4 与当前湖南大学备选的对比

| 对比项 | 湖南大学（控制工程） | 厦门大学（应用统计） |
|--------|---------------------|---------------------|
| 院校层次 | 985/B类 | 985/C9级别 |
| 学科评估 | 控制科学B+ | 统计学A |
| 英语 | 英语二 | 英语一（更难） |
| 数学 | 数学二 | 数学三 |
| 专业课 | 822电子技术基础 | 432统计学 |
| 专业课难度 | 中等 | 中等偏高 |
| 2026招生 | 电气院+机器人院 | 统计系75人（扩招） |
| 跨考难度 | 需电子技术基础 | 需统计学基础 |
