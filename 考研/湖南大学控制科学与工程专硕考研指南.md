#### 固定题型（历年反复出现）

| 题型 | 科目 | 分值 | 具体考查内容 |
|------|------|------|--------------|
| 多级放大电路分析 | 模电 | ~20分 | 求静态工作点 → 画交流通路 �� 画小信号等效电路 → 求电压增益 → 求输入/输出电阻 |
| 差分放大电路 | 模电 | ~20分 | 静态分析 + 动态指标计算 |
| 反馈电路分析 | 模电 | ~15-20分 | 判断反馈类型 + 计算闭环增益 |
| 功率放大电路 | 模电 | ~15-20分 | 效率计算、功率计算 |
| 组合逻辑电路设计 | 数电 | ~15-20分 | 真值表 → 化简 → 电路实现 |
| 时序逻辑电路分析/设计 | 数电 | ~15-20分 | 状态转换图 → 激励方程 → 电路实现 |

#### 备考要点

1. **课后习题是核心**：很多真题是课后习题改编的，课后习题是复习重点
2. **答题策略**：先写公式再算结果，即使结果算错公式分也能拿到
3. **分点作答**：每道大题4~8小问，各小问之间知识点不一定相关，不会的小问跳过即可
4. **822和825真题都要做**：2024年后统一考822，但825真题同样要练，难度相当
5. **真题刷法**：8道大题一张卷子，一个多小时可写完，留2~3套做模拟，其余二刷三刷
6. **范围广但深度适中**：湖大所有章节都考，但不需要学得很深，重点章节掌握好即可拿120+

## 七、备考建议

### 7.1 各科目复习策略

#### 数学（重中之重，每天3-4h）
- **重点**：高数60%、线代20%、概率20%（数学二不考概率）
- **推荐**：张宇、汤家凤、李永乐系列
- **目标**：数学一120+，数学二135+

#### 822 电子技术基础（每天2-3h）
- **模电重点**：基本放大电路、运算放大器、反馈电路、功率放大
- **数电重点**：逻辑代数、组合逻辑电路、时序逻辑电路
- **推荐**：康华光《电子技术基础》（模拟+数字）+ 历年真题

#### 英语（每天2h）
- **重点**：阅读理解（40分）、作文（25分）
- 英语二略简单，翻译和作文与英语一不同

#### 政治（9月后开始，每天1-2h）
- **重点**：马原、毛中特
- **推荐**：肖秀荣系列、徐涛强化班

### 7.2 分阶段时间规划

```
【基础阶段】现在 - 6月
├── 数学：一轮基础，完成教材+基础习题
├── 英语：背单词（5500词），学语法
└── 专业课：通读教材，理解基本概念

【强化阶段】7月 - 9月
├── 数学：刷题强化，建立知识体系
├── 英语：阅读训练（每天2篇）
├── 政治：开始复习（8月开始）
└── 专业课：重点章节突破，做课后题

【冲刺阶段】10月 - 12月
├── 全科：真题模拟（近10年）
├── 数学：查漏补缺，模拟考试
├── 政治：背诵押题（11月后）
└── 专业课：历年真题反复练习
```
